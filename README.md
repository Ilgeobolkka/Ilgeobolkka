# 읽어볼까

> 임시 작업명입니다. 공개 출시 전 브랜드명과 유사 상표를 다시 검토합니다.

읽어볼까는 책 전체를 구매하는 대신 실제로 읽은 페이지에만 포인트를 사용하는 반응형 웹 서비스입니다. 초기 MVP는 매출보다 페이지 과금의 정확성과 사용자가 과금 결과를 신뢰할 수 있는지를 검증합니다.

## 현재 상태

- 제품 및 도메인 계약 문서화 완료
- 구현 전 단계
- 백엔드는 Java 21과 Spring Boot 4.1.0, 운영 데이터베이스는 Amazon RDS for MySQL로 결정
- 로컬 개발과 테스트용 MySQL 8.4는 Docker Compose로 실행하며 기본 호스트 포트는 3307
- Spring datasource는 환경변수 계약을 사용해 로컬 Compose와 운영 RDS를 같은 애플리케이션으로 연결
- 애플리케이션 배포 방식, 인증 구현 방식, 파일 저장소는 미정
- PG 결제와 백오피스는 MVP 이후 범위

## 핵심 경험

1. 독자가 이메일과 비밀번호로 로그인합니다.
2. 100권의 도서 목록을 보거나 제목·저자로 검색합니다.
3. 책 상세에서 기본 정보를 확인합니다.
4. 처음 뷰어에 들어갈 때 페이지당 50P 자동 차감에 동의합니다.
5. 페이지를 넘기거나 뷰어를 종료하지 않고 6초가 지나면 해당 페이지가 열람 확정됩니다.
6. 처음 열람 확정된 페이지에만 50P가 차감됩니다.
7. 같은 페이지는 추가 차감 없이 다시 읽을 수 있습니다.
8. 내 서재와 포인트 내역에서 이어 읽기 위치와 차감 결과를 확인합니다.

| 구분 | 결정 |
| --- | --- |

| 제공 형태 | 반응형 웹 |

## 로컬 MySQL과 테스트

로컬 실행에는 JDK 21이 필요하며 Gradle의 JDK 자동 다운로드는 사용하지 않습니다.
민감한 로컬 접속값은 Git에서 제외되는 `.env`에 저장합니다. `DB_URL`은 로컬 Compose MySQL을 가리키며, 처음 실행할 때 공유용 예시를 복사한 뒤 비밀번호를 변경합니다.

```bash
cp .env.example .env
docker compose up -d --wait
./gradlew test
./gradlew check
```

로컬의 기존 MySQL과 충돌하지 않도록 Compose MySQL은 기본적으로 `localhost:3307`을 사용합니다. 종료할 때는 `docker compose down`을 실행하며, 데이터는 `mysql-data` 볼륨에 유지됩니다.

운영에서는 Compose MySQL을 실행하지 않습니다. 배포 환경이 RDS 엔드포인트를 포함한 `DB_URL`을 주입하고, `DB_USERNAME`과 `DB_PASSWORD`는 AWS Secrets Manager에서 주입합니다. TLS와 네트워크 설정을 포함한 운영 계약은 [배포 가이드](./docs/deployment.md)를 따릅니다.

## MVP에서 하지 않는 것

- 실제 PG 결제와 포인트 충전
- 관리자 계정과 백오피스
- 도서 등록·수정·판매 중지·삭제
- 무료 또는 과금 제외 페이지
- 페이지 차감 취소와 환불
- 회원 탈퇴와 비밀번호 찾기
- 소셜 로그인
- 목차, 책갈피, 메모, 하이라이트
- 확대·축소, 글꼴·줄간격 설정
- 리뷰, 평점, 추천, 장르 필터, 자동완성, 본문 검색
- 원본 PDF 다운로드, 인쇄, 오프라인 읽기
- DRM과 화면 캡처 방지
- 네이티브 모바일 앱

## 초기 데이터

- AI가 작성한 가상 더미 도서 100권과 PDF·표지·메타데이터
- 정상 흐름 계정: 10,000P
- 잔액 부족 계정: 0P
- 10,000P 계정에는 테스트 포인트 지급 +10,000P 내역을 함께 생성
- 일반 회원가입 사용자의 초기 포인트는 0P

더미 도서는 MVP 시연과 검증에만 사용합니다. 공개 배포 전에는 AI 생성 본문과 표지를 포함한 실제 사용 자산의 권리 상태를 별도로 확인합니다.

## 성공 기준

- 처음 읽은 페이지에만 정확히 50P가 차감됩니다.
- 같은 페이지를 다시 읽어도 중복 차감되지 않습니다.
- 포인트 내역 합계와 현재 잔액이 항상 일치합니다.
- 포인트가 부족하면 새로운 페이지 열람을 시작할 수 없습니다.

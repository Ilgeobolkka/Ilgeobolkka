# 읽어볼까

> 책을 전부 사기 전에, 필요한 페이지부터 읽어보세요.

읽어볼까는 책 전체를 한 번에 구매하기 부담스러운 독자가 필요한 페이지부터 읽고, 계속 읽고 싶은 책은
서비스 안에서 온라인으로 소장할 수 있게 돕는 데스크톱 웹 서비스입니다.

페이지는 원본 PDF 기준으로 나누고, 프로그램 화폐인 **잉크**로 한 페이지씩 대여합니다. 무엇을 읽어야
할지 막막할 때는 독서 목적과 추가 잉크 예산을 바탕으로 **AI 잉크 경로**를 만들어 한 권 안에서 필요한
지식까지 이어지는 읽기 순서를 제안합니다.

## 해결하려는 문제

책에서 필요한 내용이 일부뿐이어도 독자는 전체 금액을 먼저 지불해야 하는 경우가 많습니다. 전자책의 화면
구성에 따라 페이지 수가 달라지면 내가 어디까지 읽었고 얼마만큼 이용했는지도 예측하기 어렵습니다.

읽어볼까는 이 문제를 세 가지 선택지로 풀어냅니다.

| 독자의 상황 | 읽어볼까의 선택지 |
| --- | --- |
| 필요한 부분부터 읽어보고 싶다 | 원본 PDF 페이지를 기준으로 필요한 페이지만 잉크로 대여합니다. |
| 목적에 맞는 읽기 순서를 알고 싶다 | 한 권 안에서 독서 목적과 예산에 맞는 AI 잉크 경로를 제안합니다. |
| 계속 읽고 싶은 책을 발견했다 | 도서 원가를 원화로 결제하고 서비스 안에서 기간 제한 없이 읽습니다. |

페이지 대여와 온라인 소장은 서로 다른 상품입니다. 대여에 사용한 잉크를 도서 가격으로 전환하거나 소장
금액에 합산하지 않아, 독자는 필요한 순간에 원하는 방식을 명확하게 선택할 수 있습니다.

## 주요 경험

### 책을 찾습니다

카테고리로 둘러보거나 제목과 저자로 검색합니다. 목록에서 표지와 도서 원가를 살펴보고, 상세 화면에서
책 소개와 전체 페이지 수, 현재 소장 상태를 확인할 수 있습니다.

### 필요한 페이지부터 읽습니다

페이지 이용권으로 충전한 잉크는 만료되지 않습니다. 소장하지 않았거나 아직 대여하지 않은 페이지를 처음
열 때 `1페이지 = 1잉크`가 차감되고, 해당 페이지를 30일 동안 다시 읽을 수 있습니다. 텍스트뿐 아니라
표·수식·삽화처럼 원래 배치가 중요한 페이지도 원본 페이지 번호를 유지해 제공합니다.

### 목적에 맞는 AI 잉크 경로를 만듭니다

독서 목적과 추가로 사용할 잉크의 상한을 입력하면 관련도뿐 아니라 선수 개념, 읽기 순서, 중복과 내용의
균형을 고려한 페이지 경로를 제안합니다. 경로 생성·미리보기·저장만으로는 잉크가 차감되지 않으며, 독자가
경로의 페이지를 실제로 열 때 기존 페이지 대여 정책이 적용됩니다.

저장한 경로는 내 서재에서 이어 읽고, 같은 책의 다른 목적을 위한 경로도 별도로 보관할 수 있습니다.

### 마음에 든 책은 온라인으로 소장합니다

도서에 정해진 원가를 원화로 결제하면 모든 페이지를 기간 제한 없이 읽을 수 있습니다. 온라인 소장은
서비스 안의 열람 권한이며 원본 PDF 다운로드, 인쇄 또는 오프라인 파일 소유를 뜻하지 않습니다.

### 내 서재에서 이어 읽습니다

한 페이지 이상 대여했거나 온라인 소장한 책, AI 경로를 저장한 책을 한곳에서 확인합니다. 마지막으로 읽은
페이지와 대여 상태, 소장 여부를 확인하고 읽던 위치나 저장한 경로로 돌아갈 수 있습니다. 잉크 지급·차감
내역과 소장 결제 내역은 서로 구분해 제공합니다.

## 제품 원칙

- **예측 가능한 단위**: 화면 크기가 바뀌어도 원본 PDF 페이지 번호와 잉크 사용 단위는 변하지 않습니다.
- **명확한 권한**: 페이지 대여와 온라인 소장을 구분하고 현재 대여 기간·비용·소장 상태를 화면에 표시합니다.
- **열 때만 차감**: 페이지 체류 시간이나 AI 경로 생성만으로 과금하지 않고, 권한 없는 페이지를 실제로 열
  때만 잉크를 차감합니다.
- **안전한 결제 반영**: 브라우저의 결제 완료 표시만 신뢰하지 않고 서버가 결제 상태·금액·통화를 검증한
  뒤 잉크나 소장 권한을 한 번만 부여합니다.
- **보호된 콘텐츠**: 인증과 열람 권한을 확인한 뒤 요청한 한 페이지의 콘텐츠만 제공하며 원본 PDF는 직접
  노출하지 않습니다.

## MVP 범위

현재 읽어볼까는 데스크톱 브라우저용 MVP입니다. 회원가입과 로그인, 도서 탐색, 잉크 구매와 내역, 페이지
대여와 뷰어, 온라인 소장, 내 서재, AI 잉크 경로의 생성·저장·열람·피드백 흐름을 제공합니다.

- 결제는 **PortOne V2 테스트 채널**까지만 연동하며 운영 실결제는 활성화하지 않습니다.
- 콘텐츠는 실제 출판물이 아닌 공개 가능한 AI 시연 도서와 페이지로 구성합니다.
- 모바일 전용 레이아웃과 네이티브 앱, PDF 다운로드·인쇄, 결제 취소·환불은 MVP 범위에 포함하지 않습니다.
- AI 잉크 경로는 콘텐츠 품질과 외부 전송 조건을 확인한 지원 도서에서만 제공합니다.

현재 구현 상태와 출시 검증 근거는 [PRD 색인](./docs/prd/README.md)의 문서 상태에서 관리합니다.

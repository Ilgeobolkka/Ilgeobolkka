# 0001. 서버 검증 6초 기준으로 열람을 확정한다

- 상태: 승인됨
- 날짜: 2026-07-22

## 맥락

페이지가 잠깐 표시된 것과 실제 과금 대상을 구분해야 하지만 사용자의 독서를 완벽하게 측정할 수는 없습니다. 읽어볼까는 독자가 같은 페이지를 유지한 채 6초가 지난 경우를 열람 확정으로 정의하고, 조작된 즉시 확정 요청을 막기 위해 서버 시간으로 경과를 검증합니다.

## 고려한 대안

- 페이지가 표시되는 즉시 차감: 우발적으로 연 페이지까지 과금될 수 있어 제외했습니다.
- 활성 화면에 머문 시간만 계산: 규칙과 구현이 복잡해지고 사용자가 예측하기 어려워 제외했습니다.
- 읽기 완료 버튼: 독서 흐름을 반복해서 끊기 때문에 제외했습니다.

## 결정

- 페이지를 넘기거나 뷰어를 종료하지 않고 6초가 지나야 열람 확정됩니다.
- 탭 전환, 창 최소화, 다른 앱 사용은 경과 시간을 취소하지 않습니다.
- 6초 전 페이지 이동과 종료에는 포인트를 차감하지 않습니다.
- 차감 실패 후 사용자가 모르는 시점에 나중에 자동 차감하지 않습니다.
- 같은 사용자·도서·페이지는 최초 한 번만 차감합니다.

## 결과

- 6초 안에 내용을 확인하고 이동하는 사용자는 과금되지 않을 수 있으며 이를 MVP 한계로 받아들입니다.
- 열람 시작 시각과 확정 요청을 연결하는 서버 계약이 필요합니다.
- 판정 기준을 바꾸면 기존 과금 의미가 달라지므로 새 결정으로 기록해야 합니다.

# 0020. 모든 도서에 공통 잉크 이용권을 사용한다

- 상태: 승인됨
- 날짜: 2026-07-25

## 맥락

기존 50P 단가는 페이지 한 장의 체감 가격이 높고 `1원 = 1P`라는 현금성 표현이 페이지 이용권의 성격을 드러내지 못했습니다.
카테고리나 책을 고르기 전에 사용할 수 있는 단위를 구매하게 하되, MVP에서는 실제 PG 연동 없이 잉크 차감의 정확성을 먼저 검증해야 합니다.

## 고려한 대안

- `1페이지 = 50P`, `1원 = 1P` 유지 — 기존 구현 자료를 재사용할 수 있지만 확정된 10원 수준의 페이지 가격과 잉크 이용권이라는 제품 언어에 맞지 않습니다.
- 책별 잉크 단가 — 출판 계약이나 인기 차이를 반영할 수 있지만 가격 운영과 화면 설명이 늘어나 과금 정확성을 검증하는 MVP 범위를 벗어납니다.
- 카테고리별 이용권 — 상품을 구분하기 쉽지만 독자가 다른 분야의 책을 읽을 때 잔액이 나뉘고 카테고리가 탐색과 결제 경계를 동시에 갖게 됩니다.
- 전 도서 공통 잉크 이용권 — 가격 차등화는 못 하지만 한 잔액과 한 규칙으로 모든 페이지를 설명할 수 있습니다.

## 결정

### 선택한 기술

페이지 이용 단위는 `잉크`를 사용합니다. 모든 도서와 카테고리에 `1페이지 = 1잉크`를 적용하고, 판매 단위는 `100잉크 = 1,000원`으로 정합니다.
모든 지급과 차감은 변경하지 않는 잉크 내역으로 남기며 현재 잔액과 내역 합계를 일치시킵니다.

### 핵심 근거

- **가격 이해 — 1잉크 vs 50P**: 한 페이지 요청이 한 단위 사용으로 바로 대응하고, 100잉크 묶음의 실질 페이지 가격이 10원임을 쉽게 설명할 수 있습니다.
- **사용 범위 — 공통 잔액 vs 카테고리별 잔액**: 카테고리는 탐색 분류로만 유지되어 사용자가 잉크를 어느 책에서든 이어 쓸 수 있습니다.
- **MVP 복잡도 — 전역 단가 vs 책별 단가**: `Book`이나 페이지에 가격 필드를 두지 않아 가격 변경·할인·정산 규칙을 구현하지 않고 차감 원자성에 집중할 수 있습니다.
- **감사 가능성 — 원장 유지 vs 잔액만 저장**: 차감 후 잔액과 지급·차감 이유를 보존하면 현재 잔액을 설명하고 중복 차감을 검증할 수 있습니다.

## 결과

- 포인트 명칭과 50P 단가는 새 구현에서 사용하지 않습니다.
- MVP에는 실제 PG 결제를 포함하지 않지만 이후 결제 성공 시 100잉크 묶음을 지급하는 계약의 기준이 됩니다.
- 구매 잉크와 무료 잉크의 유효기간·차감 순서는 아직 결정하지 않았으며 영구 유효로 간주하지 않습니다.
- 이 결정은 포인트 원장과 50P 단가를 함께 정한 ADR-0003을 대체하며, 변경 불가능한 원장을 잉크 내역으로 이어갑니다.

# 0002. 원본 PDF 대신 현재 페이지 이미지를 제공한다

- 상태: 승인됨
- 날짜: 2026-07-22

## 맥락

브라우저에 원본 PDF 전체를 전달하면 사용자가 파일을 저장해 이후 페이지 과금을 우회할 수 있습니다. 초기 도서 준비 단계에서 PDF를 페이지별 이미지로 변환하고, 뷰어에는 현재 페이지 이미지만 제공합니다.

## 고려한 대안

- PDF 전체를 브라우저 PDF 뷰어에 전달: 구현은 단순하지만 원본 다운로드를 막을 수 없어 제외했습니다.
- DRM 적용: 보호 수준은 높일 수 있지만 MVP의 과금 검증 범위를 크게 넘어서 제외했습니다.

## 결정

- 도서 원본 PDF를 페이지별 이미지로 미리 변환합니다.
- 뷰어에는 사용자가 현재 보고 있는 페이지 이미지만 제공합니다.
- 원본 PDF 전체를 브라우저에 전달하지 않습니다.

## 결과

- 원본 PDF 다운로드와 한 번의 요청으로 모든 페이지를 받는 흐름을 제공하지 않습니다.
- 페이지 이동마다 현재 페이지 자산을 요청해야 합니다.
- 개별 이미지 저장과 화면 캡처는 완전히 막지 않으며 MVP의 명시적 한계로 둡니다.
- 확대·축소와 고급 뷰어 기능은 후속 고도화 후보입니다.

# 0024. 혼합 페이지 콘텐츠를 유형별로 검증한다

- 상태: 승인됨
- 날짜: 2026-07-25

## 맥락

혼합 변환은 이미지 품질뿐 아니라 텍스트 읽기 순서, 누락, 원본 페이지 매핑과 유형 선택의 정확성을 검증해야 합니다.
전수 육안 검사만으로 100권을 반복 검증하기는 어렵지만 페이지 수와 권한 경계는 자동 검사에서 한 건도 누락할 수 없습니다.

## 고려한 대안

- 변환 성공 여부만 확인 — 빠르지만 텍스트 순서 오류와 깨진 표·수식을 발견하지 못합니다.
- 모든 페이지를 매번 사람이 검사 — 품질 문제를 가장 넓게 볼 수 있지만 반복 비용과 판정 편차가 큽니다.
- 모든 콘텐츠 유형에 같은 이미지 기준 적용 — 절차는 하나지만 텍스트 누락·순서와 반응형 가독성을 검사할 수 없습니다.
- 자동 완전성 검사와 유형별 고정 표본 검사 결합 — 표본 밖의 시각 오류 가능성은 남지만 구조 누락을 자동으로 막고 대표 위험을 반복 가능한 방식으로 비교할 수 있습니다.

## 결정

### 선택한 기술

모든 도서에 페이지 수·연속 번호·중복·권한 테스트를 자동 적용합니다.
텍스트 페이지는 추출 누락과 문단·글자 순서, 이미지 페이지는 원본 배치·표·수식·삽화·화질과 용량, 혼합 페이지는 텍스트와 이미지의 순서·중복·누락을 검증합니다.
각 도서의 첫·중간·마지막 페이지와 작은 글자, 표·수식·삽화, 복잡한 배치 표본을 manifest로 고정하여 원본 PDF와 모바일·데스크톱 뷰포트에서 비교합니다.

### 핵심 근거

- **완전성 — 자동 전수 검사 vs 변환 성공만 확인**: `1..totalPageCount`가 모두 한 번씩 존재하는지 검사하면 원본과 서비스 페이지 번호가 어긋난 데이터의 배포를 막을 수 있습니다.
- **재현성 — 고정 manifest vs 매번 표본 선정**: 같은 위험 페이지를 같은 이유로 다시 확인할 수 있어 변환 도구나 설정 변경의 영향을 비교할 수 있습니다.
- **원인 분리 — 유형별 기준 vs 공통 이미지 기준**: 텍스트 순서 오류는 추출기를, 이미지 번짐은 렌더링 설정을 고치는 식으로 실패 원인에 맞는 조치를 선택할 수 있습니다.
- **비용 — 전수 구조 검사와 표본 육안 검사 vs 전수 육안 검사**: 자동화할 수 있는 누락·번호·권한 검사는 전수로 수행하고 사람 판단이 필요한 가독성만 대표·위험 표본으로 제한합니다.

## 결과

- 변환 도구, 원본 SHA-256, 페이지 유형과 표본 선정 이유를 검증 자료에 기록해야 합니다.
- 표본에서 실패한 유형의 설정은 전체 데이터에 적용하지 않고 원인 수정 후 같은 표본으로 다시 검증합니다.
- 권한 없는 페이지와 원본 PDF에 직접 접근할 수 없는지 통합 테스트가 필요합니다.
- 이 결정은 모든 페이지가 동일한 이미지 데이터셋이라는 전제의 ADR-0014를 대체합니다.

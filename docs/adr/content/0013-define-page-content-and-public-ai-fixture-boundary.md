# 0013. 원본 PDF 연결 콘텐츠와 공개 AI 시연 fixture 경계를 정의한다

- 상태: 승인됨
- 날짜: 2026-07-29

## 맥락

[ADR-0011](./0011-align-page-content-with-source-pdf.md)은 원본 PDF 페이지와 `BookPage`를 연결하고,
페이지별 `TEXT`·`IMAGE` 형식과 권한 검증을 거쳐 콘텐츠를 전달하도록 결정했습니다. 이 페이지 연결·콘텐츠
형식·권한 검증 결정은 계속 유지합니다.

다만 ADR-0011은 모든 원본 PDF와 이미지 저장소를 비공개로 유지했습니다. 현재 MVP는 실존 작품을 바탕으로
하지 않은 AI 시연 도서만 사용하고 별도 콘텐츠 저장소를 운영하지 않습니다. 팀이 같은 PDF 페이지를
기준으로 변환과 뷰어를 검증하려면 공개해도 되는 시연 PDF를 저장소에서 공유할 예외가 필요합니다. 따라서
모든 원본 PDF를 비공개로 관리하던 저장 경계만 공개 가능한 AI 시연 fixture에 한해 변경하며, 이 변경 때문에
ADR-0011을 대체합니다.

Git에 포함한 파일은 삭제 커밋 뒤에도 과거 이력과 복제본에 남습니다. 따라서 이 예외는 실제 저작물,
권리 제한 자료와 개인정보가 없는 시연 전용 콘텐츠에만 적용해야 합니다.

## 고려한 대안

- 개발자 로컬에만 보관 — 저장소를 새로 받은 팀원이 같은 입력으로 검증할 수 없어 제외합니다.
- MVP부터 비공개 콘텐츠 저장소 운영 — 실제 콘텐츠에는 적합하지만 시연 fixture만을 위해 운영 범위를 넓혀 제외합니다.
- 공개 가능한 AI 시연 PDF만 Git fixture로 보관 — 팀 공유가 단순하고 실제 콘텐츠의 비공개 원칙을 유지할 수 있어 선택합니다.

## 결정

원본 PDF와 연결한 페이지 콘텐츠의 저장·전달 경계를 다음과 같이 통합합니다.

- `Book.totalPageCount`와 `BookPage` 수는 기준 PDF 페이지 수와 일치해야 합니다.
- 각 `BookPage`는 같은 번호의 PDF 페이지와 일대일로 연결합니다.
- 일반 본문은 `TEXT`, 원본 배치 보존이 필요한 페이지는 전체 페이지 `IMAGE`로 저장합니다.
- 한 페이지의 형식은 `TEXT` 또는 `IMAGE` 중 하나입니다.
- 실제 사용 콘텐츠와 공개 여부가 확인되지 않은 PDF·이미지 저장소는 비공개로 유지합니다.
- 실존 작품·권리 제한 자료·개인정보가 없는 공개 가능 AI 시연 PDF만 Git fixture로 허용합니다.
- 시연 PDF는 애플리케이션 JAR·배포 이미지·정적 자산에 포함하거나 HTTP로 제공하지 않습니다.
- 콘텐츠 요청은 로그인 세션, 현재 `ReadingSession`과 온라인 소장 또는 활성 대여 권한을 확인합니다.
- 한 요청에는 현재 페이지 콘텐츠 하나만 반환하고 내부 저장소 경로를 노출하지 않습니다.
- 개인 열람 콘텐츠에는 `Cache-Control: private, no-store`를 적용합니다.
- 변환 위치·형식·검증 절차는 [콘텐츠 변환과 품질 검증](../../content-conversion.md), HTTP 형식은
  [API 계약](../../api-spec.md)을 따릅니다.

## 결과

- 화면 표시가 바뀌어도 기준 PDF 페이지 번호가 안정된 권한 단위로 남습니다.
- 일반 본문은 텍스트 접근성을 얻고 복잡한 페이지는 원본 배치를 이미지로 보존합니다.
- 별도 콘텐츠 저장소 없이도 팀원이 같은 시연 PDF로 변환 결과를 재현할 수 있습니다.
- 시연 PDF는 공개 자료이므로 접근제어의 기밀성 근거가 될 수 없고, 권한 검증은 런타임 API 동작으로 확인합니다.
- 변환 파이프라인이 페이지별 형식 판정과 텍스트 읽기 순서 검증을 부담합니다.
- 저장소 크기가 증가하며 잘못 반입한 파일은 Git 이력에서 완전히 회수할 수 없습니다.
- 페이지 내부 혼합 콘텐츠, OCR 보정 편집과 더 강한 DRM은 별도 기술 결정이 필요합니다.

# 0013. 공개 AI 시연 PDF를 Git fixture로 관리한다

- 상태: 승인됨
- 날짜: 2026-07-29

## 맥락

[ADR-0011](./0011-align-page-content-with-source-pdf.md)은 원본 PDF를 비공개로 유지하도록 결정했습니다.
이 결정은 ADR-0011 전체를 대체하지 않으며, 원본 PDF 비공개 결정에 대한 공개 AI 시연 fixture 한정
예외입니다. 현재 MVP는 실존 작품을 바탕으로 하지 않은 AI 시연 도서만 사용하고 별도 콘텐츠 저장소를
운영하지 않습니다. 팀이 같은 PDF 페이지를 기준으로 변환과 뷰어를 검증하려면 공개해도 되는 시연 PDF를
저장소에서 공유할 예외가 필요합니다.

Git에 포함한 파일은 삭제 커밋 뒤에도 과거 이력과 복제본에 남습니다. 따라서 이 예외는 실제 저작물,
권리 제한 자료와 개인정보가 없는 시연 전용 콘텐츠에만 적용해야 합니다.

## 고려한 대안

- 개발자 로컬에만 보관 — 저장소를 새로 받은 팀원이 같은 입력으로 검증할 수 없어 제외합니다.
- MVP부터 비공개 콘텐츠 저장소 운영 — 실제 콘텐츠에는 적합하지만 시연 fixture만을 위해 운영 범위를 넓혀 제외합니다.
- 공개 가능한 AI 시연 PDF만 Git fixture로 보관 — 팀 공유가 단순하고 실제 콘텐츠의 비공개 원칙을 유지할 수 있어 선택합니다.

## 결정

- 실존 작품·권리 제한 자료·개인정보를 포함하지 않은 AI 시연 PDF만 Git fixture로 보관할 수 있습니다.
- 이 PDF의 페이지 수와 번호를 해당 시연 도서의 서비스 페이지 기준으로 사용합니다.
- 시연 PDF는 애플리케이션 JAR·배포 이미지·정적 자산에 포함하거나 HTTP로 제공하지 않습니다.
- 실제 사용 콘텐츠와 공개 여부가 확인되지 않은 PDF는 ADR-0011에 따라 비공개로 관리합니다.
- 변환 위치·형식·검증 절차는 [콘텐츠 변환과 품질 검증](../../content-conversion.md)에서 관리합니다.

## 결과

- 별도 콘텐츠 저장소 없이도 팀원이 같은 시연 PDF로 변환 결과를 재현할 수 있습니다.
- 시연 PDF는 공개 자료이므로 접근제어의 기밀성 근거가 될 수 없고, 권한 검증은 런타임 API 동작으로 확인합니다.
- 저장소 크기가 증가하며 잘못 반입한 파일은 Git 이력에서 완전히 회수할 수 없습니다.

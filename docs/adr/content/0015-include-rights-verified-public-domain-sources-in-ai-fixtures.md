# 0015. 권리 검증된 공개 원전을 AI 시연 fixture에 포함한다

- 상태: 대체됨 ([ADR-0016](./0016-publish-korean-original-ebook-content-for-ai-fixtures.md))
- 날짜: 2026-08-07

## 맥락

[ADR-0013](./0013-define-page-content-and-public-ai-fixture-boundary.md)은 공개 Git fixture를 실존 작품을
바탕으로 하지 않은 합성 시연 PDF로 제한했습니다. 이 결정은 권리 위험을 작게 만들었지만, 짧고 반복적인
합성 문장만으로는 책 안에서 개념·선수 관계·적용·한계를 검색하고 경로로 구성하는 AI 기능의 품질을 충분히
검증하기 어렵습니다. 비소설 90권에는 도서마다 다른 어휘, 문단 구조와 논지 전개가 필요합니다.

저작권 보호기간이 끝난 원문도 수집처가 공개했다고 해서 모든 국가에서 자동으로 재배포할 수 있는 것은
아닙니다. 현대 편집·번역·삽화에는 별도 권리가 남을 수 있고 Project Gutenberg의 상표·라이선스 문구는
원저작물과 다른 경계입니다. Git에 잘못 반입한 파일은 삭제 커밋 뒤에도 이력과 복제본에 남으므로, 출처별
권리 근거와 실제 사용 바이트를 파일 단위로 추적해야 합니다.

이 변경은 합성 콘텐츠만 허용한 ADR-0013을 대체합니다. PDF 페이지와 `TEXT`·`IMAGE` 변환, 권한 검증
결정은 계속 유지합니다.

## 고려한 대안

- 합성 콘텐츠만 더 길게 작성 — 권리 경계는 단순하지만 실제 고서의 어휘·문단·논지 다양성을 재현하기 어려워 제외합니다.
- 공개 원문 전체와 원래 제목·저자를 그대로 도서로 적재 — 출처는 명확하지만 기존 100권 메타데이터 보존 계약을 깨고 제품 시연 목적과 맞지 않아 제외합니다.
- Creative Commons 논문과 현대 공개 자료를 함께 사용 — 자료는 최신이지만 문서별 BY·NC·ND·SA 조건과 제3자 이미지 권리를 각각 처리해야 해 이번 fixture에서는 제외합니다.
- 권리 검증된 공개 원문 일부와 새 연결 본문·도표를 함께 편집 — 기존 메타데이터를 보존하면서 실제 문체와 개념 다양성을 얻을 수 있어 선택합니다.

## 결정

- 공개 Git fixture는 새 합성 콘텐츠뿐 아니라 파일별 권리 검증을 통과한 공개 원문 일부를 포함할 수 있습니다.
- `ai-route-v2`의 외부 원전은 Project Gutenberg가 `Public domain in the USA.`로 표시한 영어 plain text 중
  구조화된 저자·번역자·기여자의 사망연도가 모두 1955년 이하인 비소설만 사용합니다.
- 원전의 Project Gutenberg 머리말·꼬리말·상표·라이선스 문구는 PDF 본문에 포함하지 않습니다.
- 기존 도서 ID·제목·저자·카테고리·소개는 제품 fixture 메타데이터로 유지하되, PDF의 출처 면과
  `source-ledger.json`에서 가상 메타데이터와 실제 원전의 제목·저자·출처를 구분합니다.
- 도서마다 서로 다른 원전 하나를 배정합니다. 원문 인용과 새로 작성한 한국어 연결 본문을 함께 사용하며,
  페이지별 원문 SHA-256과 원전 파일 SHA-256을 권리 원장에 기록합니다.
- 원전의 스캔·삽화는 개별 이미지 권리를 별도로 확인하지 않는 한 사용하지 않습니다. `IMAGE` 페이지는
  원전 개념을 바탕으로 새로 작성한 도표만 사용합니다.
- 비소설 PDF는 `contentVersion`, `bookId`, 기존 제목의 결정적 seed로 48~72페이지를 배정해 도서마다
  길이를 다르게 만들며, 최소 6개 장을 유지합니다.
- 원문 파일 자체는 임시 제작 입력으로만 사용하고 Git에는 고정 PDF, manifest, 평가 데이터,
  출처·권리 원장과 검수 근거만 보존합니다.
- 파일별 권리·개인정보 검사와 모든 이미지 분석 텍스트의 사람 검수가 끝나기 전에는 embedding 생성과
  AI 경로 지원 활성화를 금지합니다.

## 결과

- 실제 공개 원전의 어휘와 논지 전개를 사용해 후보 검색·중복·선수 관계 평가의 입력 다양성이 커집니다.
- 기존 100권 메타데이터와 원전의 서지정보가 다르므로 PDF와 권리 원장에서 두 정체성을 명확히 구분해야 합니다.
- 출처 URL·권리 문구·기여자 사망연도·원문 SHA와 페이지별 사용 근거를 계속 검증해야 합니다.
- 외부 원전의 교정으로 원문 바이트가 달라져도 고정 PDF는 자동 재생성하지 않으며, 변경하려면 manifest와
  검수 근거를 새로 만들고 재평가해야 합니다.
- 잘못 반입한 원문은 Git 이력에서 완전히 회수하기 어렵습니다. 이 결정을 되돌리려면 공개 전 새 콘텐츠
  버전의 합성 PDF·manifest·평가 데이터를 다시 제작하고 전체 embedding·품질 평가를 반복해야 합니다.

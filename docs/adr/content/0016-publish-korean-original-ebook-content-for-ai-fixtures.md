# 0016. AI 시연 fixture를 한국어 창작 전자책으로 제작한다

- 상태: 승인됨
- 날짜: 2026-08-07

## 맥락

[ADR-0015](./0015-include-rights-verified-public-domain-sources-in-ai-fixtures.md)은 실제 고서의 어휘와 논지
다양성을 얻기 위해 공개 원문 일부를 PDF 본문에 직접 넣도록 결정했습니다. 그러나 가상 도서 제목 아래
영어 원문과 원문을 설명하는 반복 문장을 배치한 결과는 한 권의 책으로 이어지는 원고가 아니라 검색용
문서 묶음처럼 보였습니다. 페이지마다 제작 방식과 분석 관점을 설명하는 문장도 독자가 읽는 본문과 AI
검수 메타데이터의 경계를 흐렸습니다.

AI 검색 품질을 검증하려면 실제 전자책처럼 장 사이의 논지가 이어지고, 같은 개념이 맥락·사례·반례·결론에서
서로 다른 표현으로 나타나야 합니다. 기존 100권의 한국어 제목·저자·카테고리·소개를 유지하는 계약도
있으므로, 독자에게 보이는 원고의 언어와 서지 정체성이 해당 메타데이터와 자연스럽게 맞아야 합니다.

이 변경은 공개 원문 일부를 본문에 직접 싣도록 한 ADR-0015를 대체합니다. 공개 fixture의 권리 검증과
출처 추적, 고정 PDF·manifest·평가 데이터 관리 원칙은 유지합니다.

## 고려한 대안

- 영어 공개 원문을 그대로 유지하고 디자인만 개선 — 가상 한국어 도서와 원문의 서지·언어가 계속 충돌하므로 제외합니다.
- 공개 원문을 페이지마다 한국어로 직역 — 번역문이 한 권의 기획과 문체로 이어지지 않고 번역 품질 검수 비용이 커 제외합니다.
- 설명 문장 템플릿만 다양하게 변경 — 반복을 감출 뿐 독자용 본문과 분석 메타데이터가 분리되지 않아 제외합니다.
- 공개 고서는 참고 자료로만 추적하고 한국어 창작 원고와 도표를 새로 제작 — 기존 메타데이터와 자연스럽게 연결되고 실제 책의 논지 전개를 만들 수 있어 선택합니다.

## 결정

- 비소설 90권의 독자 표시 본문, 표지, 목차, 장·절 제목, 사례, 도표, 맺음말은 한국어 창작 콘텐츠로 새로 작성합니다.
- 각 PDF는 표지, 판권, 머리말, 목차, 최소 6개 장, 장별 본문과 사례·한계, 맺음말, 참고 자료를 갖춘 하나의 전자책으로 편집합니다.
- 본문에는 `이 페이지는`, `검색 시연`, `AI 분석`, `공개 원전 발췌`처럼 제작 과정이나 페이지 역할을 설명하는 문장을 넣지 않습니다.
- 영어는 URL, 원전의 고유 서지정보, 기술 표준명처럼 정확한 추적에 필요한 곳으로 제한하고, 독자용 본문과 도표의 설명은 한국어로 씁니다.
- Project Gutenberg 공개 원전은 도서별 참고 자료와 권리 근거로만 추적합니다. 원문 문장·스캔·삽화를 PDF 본문에 직접 싣거나 번역하지 않습니다.
- 화면용 본문과 분리된 `aiAnalysisText`에는 핵심 논지, 선수 개념, 적용 조건과 한계를 한국어로 기록합니다.
- 48~72페이지의 결정적 길이 배정, 최소 6개 장, TEXT·IMAGE 구분, 선수 DAG, 평가 정답 분리 계약은 유지합니다.
- 사람 편집 검수 전에는 embedding 생성과 AI 경로 지원 활성화를 금지합니다.

## 결과

- 제목·저자·소개와 본문이 한 권의 한국어 전자책으로 이어져 실제 검색 입력과 유사한 문맥을 제공합니다.
- 공개 원문 직접 인용과 번역 검수 부담은 줄지만, 새 원고의 문체·사실성·장 간 연결을 별도로 검수해야 합니다.
- 참고 원전의 실제 문장이 검색 대상에 들어가지 않으므로 고서 문체 자체를 평가하는 용도로는 사용할 수 없습니다.
- 이 결정을 되돌리려면 비소설 PDF와 페이지 분석, manifest, 평가 데이터, embedding을 같은 콘텐츠 버전에서 모두 다시 제작해야 합니다.

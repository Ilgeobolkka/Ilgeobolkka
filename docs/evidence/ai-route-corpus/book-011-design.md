# book-011 「느린 아침을 수집하는 법」 설계·검수 근거

SCRUM-485 90권 확장 중 에세이 카테고리 첫 번째 도서입니다. 현재 다른 도서 작업과 공유
`manifest.json`·`evaluation.json`에서 충돌하지 않도록 단일 도서 fragment로 작성했습니다.

## 대상 도서

| 필드 | 값 | 처리 |
| --- | --- | --- |
| `bookId` | 11 | 유지 |
| `category` | 에세이 | 유지 |
| `title` | 느린 아침을 수집하는 법 | 유지 |
| `author` | 가상 작가 011 | 유지 |
| `description` | 서두르지 않는 아침의 감각을 기록한 가상 에세이입니다. | 유지 |
| `totalPageCount` | 4 → **50** | 재제작 |

제목·저자·카테고리·소개는 `src/main/resources/demo/books.json`의 기존 값을 유지했습니다.

## 개념 범위

[`essay-category-plan.md`](./essay-category-plan.md)가 book-011에 배정한 느림, 아침의 리츄얼,
감각적 관찰, 하루를 여는 태도를 핵심 주제로 사용했습니다. 같은 카테고리의 다른 도서에 배정된 계절,
골목, 차 한 잔의 온도, 도시 소음, 짧은 대화, 감정 정리, 실패, 고정 산책, 무언의 친절은 핵심
개념으로 사용하지 않았습니다.

느림은 늦잠이나 모든 행동을 천천히 하는 상태가 아니라 현재 조건을 확인하고 필요한 속도와 첫 행동을
고르는 태도로 정의했습니다. 넉넉한 아침만 보여 주지 않고 늦잠, 돌봄, 통증, 여유 강박, 타인의 빠른
속도처럼 느림이 그대로 적용되지 않는 반례와 한계도 별도 장에 배치했습니다.

## 장 구성

50페이지는 목차 1페이지와 본문 49페이지로 구성합니다.

| 장 | 페이지 | 중심 역할 | 내용 |
| --- | --- | --- | --- |
| 1장 알람보다 먼저 시작된 것 | 2~8 | `PREREQUISITE`·`CORE` | 서두름과 느림의 구분, 시간 여백의 출발점 |
| 2장 아침의 빈칸을 만드는 연습 | 9~15 | `CORE`·`EXAMPLE` | 전날 준비, 행동 축소, 동선과 전환 경계 |
| 3장 감각을 깨우는 작은 기록 | 16~22 | `CORE`·`COUNTERPOINT` | 시각·촉각·후각 관찰과 판단 없는 한 문장 기록 |
| 4장 반복이 의식이 되는 순간 | 23~29 | `CORE`·`COUNTERPOINT` | 개인 리츄얼의 구조와 복귀, 형식 집착의 한계 |
| 5장 느린 아침이 실패하는 날 | 30~36 | `COUNTERPOINT`·`EXAMPLE` | 늦잠·돌봄·통증·강박에 맞춘 유연한 느림 |
| 6장 내 속도와 타인의 속도 | 37~43 | `PREREQUISITE`·`COUNTERPOINT` | 생활표의 차이, 속도 존중, 공동 공간의 합의 |
| 7장 하루를 여는 태도를 수집하다 | 44~50 | `CONCLUSION` | 기록 회고, 판단 유보, 단일 과업, 열린 결론 |

본문은 에세이의 서사 흐름을 유지하면서도 AI 경로 평가가 서로 다른 개념 페이지를 구별할 수 있도록
절마다 고유한 관찰 장면과 결론을 사용했습니다. TEXT 45페이지는 각 3문단, 500~573자이며 평균은
518.4자입니다.

| 6 | 두 종류의 아침 지도 | 겹친 서두름과 전환 여백을 같은 행동 수로 비교 |

처음 렌더링한 6페이지에서 멈춤 표시가 세면대·옷장 상자와 겹친 문제를 발견해 원의 크기와 설명 위치를
수정한 뒤 다시 렌더링했습니다. 최종 PDF의 목차, 첫 본문, 중간 본문, 마지막 본문과 이미지 4페이지를
PNG로 다시 확인해 글자 잘림·겹침·깨진 한글이 없음을 확인했습니다.

## 구조 메타데이터

- 내용 역할 5종을 모두 사용했습니다. `FRONT_MATTER`는 목차 1페이지에만 사용합니다.
- 목차만 `aiRouteCandidatePage=false`이고 나머지 49페이지는 모두 `true`입니다.
- 선수 관계는 절 식별자로 설계한 뒤 최종 페이지 번호로 계산했으며, 자기 참조·범위 밖 참조·순환이
  없습니다.
- 대표 경로는 `[4, 10, 18, 24, 33, 39, 44, 47]`로 비연속 배치했습니다.
- `start-is-attitude` 중복 그룹은 7페이지의 시작 방식 설명과 45페이지의 결론 재진술만 연결합니다.
- `aiPublicGuideTopic`은 원문 결론·수치·사례 결과를 옮기지 않은 별도 공개 안내 문장입니다.

## 평가 케이스: 비소장·예산 0

> 아래는 제작 당시 기록이다. 정답 경로 10건을 선수 폐쇄 기준으로 다시 계산했으므로 시나리오·정답
> 경로·필수 개념의 현재 값은 [평가 정답 경로 재조정](./evaluation-replan.md)과

| 필드 | 값 |
| --- | --- |
| `caseId` | `case-book-011` |
| `purpose` | 이미 빌려 둔 페이지 안에서 출근 전 마음이 조급해지는 이유를 돌아보고, 하루를 덜 끌려가듯 시작하는 방법을 찾고 싶다 |
| `owned` / `maxAdditionalInk` / `depth` | `false` / `0` / `null` |
| `requiredConcepts` | 느림, 시간 여백, 감각적 관찰, 아침의 리츄얼, 하루를 여는 태도 |
| `helpfulConcepts` | 유연한 느림, 속도 존중, 단일 과업 |
| `referencePageNumbers` | 4, 10, 18, 24, 33, 39, 44, 47 |
| `activeRentalPageNumbers` | 4, 10, 18, 24, 33, 39, 44, 47 |

예산 0 시나리오이므로 정답 경로와 그 경로에 기록한 필수 선수 페이지를 모두 활성 대여 페이지 안에
두었습니다. 목적 문장에는 책 제목이나 정답 페이지 번호를 넣지 않았습니다.

## 권리·개인정보

본문과 도표는 실존 작품을 인용·번역·모방하지 않고 이 fixture를 위해 새로 작성했습니다. 등장 장면은
특정 실존 인물·가게·회사와 연결되지 않는 일반적인 가상 일상이며 개인정보를 포함하지 않습니다.

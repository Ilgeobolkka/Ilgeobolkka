# book-013 「낯선 골목과 친해지는 시간」 설계

[에세이 카테고리 계획](./essay-category-plan.md)의 13번을 만든 근거다. 정책·검증 계약은
[AI 경로 콘텐츠 코퍼스](../../ai-route-content-corpus.md)를 따르고, 이 문서는 그 계약 안에서 내린
선택과 이유만 적는다. 에세이 카테고리 세 번째 권이다.

## 대상 도서

- `bookId` 13, 카테고리 에세이. 제목·저자·소개는 `src/main/resources/demo/books.json`의 기존 값을
  유지한다 (저자 「가상 작가 013」, 소개 「매일 다른 골목을 걷고 적은 가상 에세이입니다」).
- `totalPageCount`는 4 → **50**으로 재제작했다.
- 화자는 이름 없는 「나」이고 무대는 가상의 동네다. 실존 지명·상호·인물과 연결되지 않는다.

## 개념 범위

계획 문서가 이 권에 배정한 낯섦, 걷기(도보 탐색), 우연한 경로, 익숙해짐의 과정을 핵심 주제로 썼다.
같은 카테고리에서 갈라야 할 자리가 둘이다.

- 12(창가)는 관찰자가 움직이지 않는다. 13은 걷는 것 자체가 방법이라, 12가 창틀로 한 일(테두리를 정해
  견줄 수 있게 만드는 일)을 여기서는 걸음 수와 갈림길 규칙이 한다.
- 19(저녁 산책)는 같은 길을 같은 시각에 되풀이해 쌓는다. 13은 매번 다른 길로 들어가 낯섦이 익숙함으로
  바뀌는 과정을 본다. 방향이 반대라, 이 권에서 같은 골목을 두 번 만나는 일은 목표가 아니라 3.2에서
  다루는 사건이고, 4.2에서는 오히려 되풀이가 무엇을 지우는지를 적었다.
- 14의 온도, 15의 소음, 16의 대화, 17의 감정 정리, 18의 실패, 20의 친절은 핵심 개념으로 쓰지 않았다.
  6.1에서 사람 이야기가 나오지만 이는 친절이나 대화가 아니라 관찰자와 거주자의 자리 차이를 다룬다.

## 이 책의 뼈대

「무엇을 볼지 고르는 일을 규칙에 맡긴다」가 이 권의 방법이고 구조다.

- 1.1이 낯섦을 정보가 없는 상태로 정의하고, 그것이 되돌릴 수 없는 자원이라는 데서 1.3의 규칙이 나온다.
  쉬운 골목부터 고르면 어려운 것만 남는다는 문제를 규칙으로 푼다.
- 2장이 걸어야만 얻는 값(걸음 수·표시)을, 3장이 규칙이 만든 경로와 그 경로가 드러낸 그물을 다룬다.
- 4장에서 익숙해짐이 얻는 일이자 잃는 일이라는 것이 드러나고, 4.2가 이 권의 반례 축이다.
- 6장은 이 방법이 닿지 못하는 곳이다. 남의 생활을 구경거리로 삼는 문제(6.1), 걷지 못하는 몸과 시간
  (6.2), 대상이 없어지는 일(6.3)이다.
- 7.1이 1.1을 지나온 언어로 다시 말하고, 친해졌다는 말이 맞는지를 되묻는 데서 닫는다.

## 장 구성 (50페이지, 목차 1 + 본문 49)

```
1장 낯선 것 앞에서            p2–8    PREREQUISITE  낯섦·지도의 한계·길을 고르는 규칙
2장 걸어서 아는 것            p9–15   CORE          걸어서 아는 것·골목의 표시·되돌아 나오기
3장 우연을 규칙으로 만들기    p16–23  CORE          우연한 경로·겹치는 길·잃어버림
4장 익숙해지는 동안           p24–30  CORE·COUNTER  익숙해짐·익숙함의 대가·사람이 사는 자리
5장 골목을 적는 법            p31–37  EXAMPLE       단어로 적기·골목에 이름 붙이기·길을 이어 붙이기
6장 낯섦을 다룰 때 조심할 것  p38–44  COUNTERPOINT  구경거리가 되는 삶·걷지 못하는 자리·사라지는 골목
7장 낯선 골목과 친해지는 시간 p45–50  CONCLUSION    친해진다는 것·골목에 남는 물음
```

이미지 4개: p8(규칙이 고른 길), p11(지도의 길이와 걸음의 길이), p18(한 달 동안 걸은 자리),
p37(종이 여든두 장을 붙이면). 생성 스크립트는 [`figures013.py`](./tools/figures013.py)다.

네 도표에서 표기를 고정했다 — 실제로 걸은 자리는 언제나 주황 실선이고 걷지 않은 길은 옅은 회색이다.
이 권의 주장이 「규칙이 데려간 곳과 데려가지 않은 곳이 갈린다」이므로, 그림마다 두 색의 뜻이 달라지면
네 장을 이어서 읽을 수 없다.

중복 그룹 1개: `strange-until-walked` = [2, 45]. 낯섦을 정보 없는 상태로 세우는 1.1 첫 페이지와, 그
상태가 끝난 자리에서 같은 말을 다시 하는 7.1 첫 페이지다. 재진술 페이지(45)에는 선수를 두지 않았다.
짝(2)을 선수로 걸면 45를 고른 경로에 2가 반드시 따라와 중복 그룹 규칙을 어기기 때문이며, 12번과 같은
처리다.

## 선수 관계 설계

1.1에서 세 갈래가 갈라진다. 1.2(지도) → 6.1이 아니라 1.2 → 6.1은 두지 않았고, 1.3(규칙)이 2장·3장·5장·
6.2의 공통 뿌리가 된다. 규칙이 이 책의 방법이므로 방법을 쓰는 장들이 전부 거기 붙는 것이 구조 그대로다.

- 어느 후보 페이지도 선수 폐쇄가 8페이지를 넘지 않는다.
- 폐쇄 5페이지 이하인 후보 페이지가 일곱 개 장을 모두 덮는다 (기준 3개 장).
- 후보 페이지 49개 전부가 폐쇄 15페이지 이하다 (기준 75%).

## 검증

`corpus_lib.validate_book()` → `validate_fragment.py` → `merge_fragments.py` → `validate_manifest.py`를
차례로 통과했다.

- 50페이지(48~72), 7개 장(최소 6), 내용 역할 5종 모두 사용
- `TEXT` 본문 45페이지가 350~465자(평균 385.9자, 합계 17,364자)로 전량 345자 이상
- `estimatedReadingSeconds`에 60초로 눌린 페이지가 하나도 없음
- `FRONT_MATTER`(목차)와 `aiRouteCandidatePage=false`가 정확히 일치
- 선수 관계가 후보 제외 페이지를 가리키지 않음, 위상 정렬로 50페이지 전체 방문
- PDF 페이지 50개, 텍스트 46개, 이미지 4개(p8,11,18,37) — `pdfcheck.py`로 확인
- PDF 규격: A4, 728,198 bytes, PDF 1.4
- PDF SHA-256: `e89c761e48f0aa78c427d5470b032b38f5d7f373c4634536ed06b33048e61f5d`

초고는 페이지당 260~393자(평균 301자)로 12번보다도 얇았다. 마흔다섯 페이지 전부에 `EXTRA` 문단을
더했고 페이지마다 다른 내용을 담았다. PDF는 Chrome Headless 출력이므로 다시 생성하면 바이트와
SHA-256이 달라질 수 있다.

## 평가 케이스: 비소장·예산 10 시나리오

| 필드 | 값 |
| --- | --- |
| `caseId` | `case-book-013` |
| `purpose` | 이 책을 사지는 않았고, 사는 동네에서 늘 지나치기만 하던 골목에 들어가 보고 싶은데 무작정 걷지 않고 어떻게 다녀야 할지 알고 싶다 |
| `owned` / `maxAdditionalInk` / `depth` | `false` / `10` / `null` |
| `requiredConcepts` | 낯섦, 길을 고르는 규칙, 걸어서 아는 것, 골목의 표시, 우연한 경로, 익숙해짐 |
| `helpfulConcepts` | 지도의 한계, 되돌아 나오기, 겹치는 길, 사람이 사는 자리 |
| `referencePageNumbers` | 2, 7, 9, 12, 16, 24, 29 |
| `irrelevantPageNumbers` | 31~34 (수첩을 어떻게 쓰고 골목에 이름을 어떻게 붙이는지) |

목적이 「무작정 걷지 않고 어떻게 다닐지」라 규칙(1.3)에서 갈라지는 두 갈래를 모두 담았다. 한쪽은
걸어서 아는 것(9) → 골목의 표시(12) → 익숙해짐(24) → 사람이 사는 자리(29)이고 다른 쪽은 우연한
경로(16)다. 예산 10에 경로가 7이라 세 자리가 남는데, 어느 한 갈래를 더 파는 대신 대체 페이지에 두 갈래의
이어지는 절과 6장의 첫 페이지들을 두어 어느 쪽으로든 갈 수 있게 했다.

무관은 5.1·5.2 두 절이다. 두 절의 어느 문단도 이 사례의 필수·도움 개념을 주제로 삼지 않아 절째 뺐다.
같은 5장이라도 5.3은 무관이 아니다 — 종이를 이어 붙이는 이야기가 `겹치는 길`과 `되돌아 나오기`를 직접
다루기 때문이다. 절을 반으로 가르지 않으려고 5.3은 통째로 남겼다.

대체 페이지는 폐쇄가 상한 10 이하인 열여섯 개다. 정답 일곱 페이지 각각의 같은 절 짝과 이웃 절 첫
페이지를 골랐고, 5장은 무관이라 빼고 7장은 결론이라 뺐다.

## 재현 조건

1. `python3 build013.py` — 원고와 조각 생성 (PDF SHA 없이 실행하면 자리표시자를 넣는다)
2. `python3 figures013.py pdfbuild013` — 도표 4개 SVG 생성
3. Chrome Headless로 각 SVG를 794×1123 PNG로 렌더링
4. `python3 build_pdf_generic.py 13 8,11,18,37 pdfbuild013` — 조판 HTML 생성
5. Chrome Headless `--print-to-pdf`로 PDF 출력, `pdfcheck.py`로 구성 확인
6. PDF를 `fixtures/content/ai-route-v2/pdfs/`에 두고 SHA-256을 인자로 `build013.py` 재실행
7. `merge_fragments.py 13`으로 정본에 병합

## 검수

- 도표 네 장을 PNG로 렌더링해 눈으로 확인했고 넷 다 고쳤다.
  - p18은 큰길을 화면 가운데에 가로로 두어 「큰길」 이름표가 걷지 않은 무리의 점선 상자와 겹쳐 「ㄴ길」로
    읽혔다. 큰길을 맨 위로 올리고 골목이 아래로 뻗게 바꿨다. 이렇게 하니 「안쪽으로 갈수록 촘촘해진다」가
    아래로 갈수록 진해지는 모양으로 그림에 그대로 나타났다.
  - p37은 빗살 구역으로 표시한 네모들이 실제로는 서로 이어져 있어 그림이 본문과 어긋났다. 큰길에 스터브
    하나씩만 올리고 서로 잇지 않는 열넷을 따로 그렸다. 같은 자리에서 막다른 표시가 무리 안쪽에 흩어져
    있던 것도 맨 아래 줄로 모았다.
  - p11은 돌바닥 무늬가 오르막 곡선과 따로 놀아 바닥선 아래 일직선으로 깔려 있었다. 곡선을 표본 좌표로
    그리고 그 좌표 위에 무늬를 얹어 둘을 맞췄다. 걸음 수 막대도 길이가 걸음 수에 비례하도록 고쳤다.
  - p8은 지도 상자가 「오른쪽 위」라고 적혀 있는데 실제로는 오른쪽 아래에 있었다. 본문 쪽을 그림에 맞췄다.
- 5.3의 막다른 길 수를 스물아홉에서 서른셋으로 고쳤다. 그림에서 막다른 표시를 어디에 다는지 정하고 나니
  세어지는 값이 서른셋이었고, 본문 수치를 그림에 맞추는 편이 그림을 수치에 맞추는 것보다 정직했다.
- 무관 페이지를 5장 전체에서 5.1·5.2로 줄였다. 5.3을 무관에 넣으면 이 사례의 도움 개념 둘을 주제로
  삼는 절을 무관이라 적는 것이 되어 정답표가 스스로와 어긋난다.
- 리뷰에서 지적받아 고친 것 하나. 이 권의 개념 이름을 이 권의 것으로 바꿨다. 「기록의 규칙」·「남는
  물음」·「이름 붙이기」를 「단어로 적기」·「골목에 남는 물음」·「골목에 이름 붙이기」로 바꿨다. 세 자리에
  아홉 권이 똑같은 이름을 쓰고 있었는데, 이름이 겹치면 개념 이름만 보고 어느 권의 것인지 가릴 수 없고
  카테고리 안에서 개념이 서로 다르다는 것도 드러나지 않는다.
- 또 하나. `main()`에 `EXTRA`의 인덱스가 도표 페이지를 가리키면 멈추는 단언을 넣었다. 016에서 실제로 났던
  사고라, 다음 권에서 조용히 되풀이되지 않게 소리 나는 자리를 만들어 두었다.

## 권리·개인정보

본문과 도표는 실존 작품을 인용·번역·모방하지 않고 이 fixture를 위해 새로 작성했다. 등장 장면은 특정
실존 동네·상호·인물과 연결되지 않는 일반적인 가상 일상이며 개인정보를 포함하지 않는다. 6.1에 적은
대로 주거 공간 내부와 개인을 특정할 수 있는 것은 본문에서 의도적으로 제외했다.

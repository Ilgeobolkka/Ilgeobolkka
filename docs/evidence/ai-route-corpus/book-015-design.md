# book-015 「오늘의 소음을 접어두기」 설계

[에세이 카테고리 계획](./essay-category-plan.md)의 15번을 만든 근거다. 정책·검증 계약은
[AI 경로 콘텐츠 코퍼스](../../ai-route-content-corpus.md)를 따르고, 이 문서는 그 계약 안에서 내린
선택과 이유만 적는다. 에세이 카테고리 다섯 번째 권이고, 이 카테고리에서 첫 소장 사례다.

## 대상 도서

- `bookId` 15, 카테고리 에세이. 제목·저자·소개는 `src/main/resources/demo/books.json`의 기존 값을
  유지한다 (저자 「가상 작가 015」, 소개 「도시의 소음과 고요를 관찰한 가상 에세이입니다」).
- `totalPageCount`는 3 → **50**으로 재제작했다.
- 화자는 이름 없는 「나」이고 무대는 가상의 도시 집이다. 실존 지명·상호·인물과 연결되지 않는다.

## 개념 범위

계획 문서가 이 권에 배정한 소음, 고요, 선택적 주의(집중), 도시의 배경음을 핵심 주제로 썼다.

- 16(우산 아래)과 갈리는 자리가 이 권의 조건이다. 16은 사람 사이에서 오간 말, 곧 소리의 내용을 다루고
  15는 소리의 존재 자체를 다룬다. 그래서 이 권에는 **누가 무슨 말을 했는지가 한 번도 나오지 않고**,
  사람의 소리도 말소리가 아니라 발소리와 문소리로만 나온다.
- 12·13·14와도 감각의 축이 다르다. 12는 시각, 13은 걸음, 14는 촉각이고 15는 청각이다.
- 11의 느림, 17의 감정 정리, 18의 실패, 20의 친절은 핵심 개념으로 쓰지 않았다.

## 이 책의 뼈대

「소음은 소리의 성질이 아니라 판정이고, 고요는 그 판정이 쉬는 상태다」가 이 권의 축이다. 1.1과 4.1이
그 두 정의를 각각 세우고 나머지가 그 사이를 잇는다.

- 1.1이 소음을 판정으로 정의하고, 1.2가 귀를 닫을 수 없다는 조건을 세운다. 이 둘 때문에 대응이 막는
  쪽이 아니라 듣는 쪽 조절로 갈 수밖에 없다.
- 2장이 배경음을, 3장이 골라 듣기를 다룬다. 2.3에서 배경화의 조건이 규칙성이 아니라 **설명 가능성**
  이라고 정정되는 자리가 이 권에서 가장 중요한 전환이다.
- 4.1이 고요를 판정이 쉬는 상태로 정의해 1.1과 짝을 이룬다. 4.3이 제목의 「접어두기」가 참기와 어떻게
  다른지를 적는다.
- 6장이 이 방법의 한계다. 소리를 내는 쪽과 무관하다는 것(6.1), 조용한 집이 비싸다는 것(6.2), 귀가
  저마다 다르다는 것(6.3)이다. 특히 6.2는 이 방법이 조건을 바꿀 수 없는 사람의 것이라는 점을 태도
  문제로 환원하지 않고 그대로 적었다.

## 장 구성 (50페이지, 목차 1 + 본문 49)

```
1장 소음이라는 말          p2–8    PREREQUISITE  소음이라는 말·귀를 닫을 수 없음·소리를 세기
2장 배경이 된 소리들       p9–15   CORE          배경음·멈춤이 들린다·소리의 지도
3장 골라 듣는 일           p16–23  CORE·COUNTER  골라 듣기·나머지 소리·골라 듣기의 실패
4장 고요라는 것            p24–30  CORE          고요·만드는 고요·접어 두기
5장 한 해의 소리 공책      p31–37  EXAMPLE       소리를 적는 법·못 적은 소리·소리를 늘어놓기
6장 접어 둘 수 없는 것     p38–44  COUNTERPOINT  남의 생활음·고요의 값·다른 귀
7장 오늘의 소음을 접어두기 p45–50  CONCLUSION    접어 둔 자리에 남은 것·소리에 남는 물음
```

이미지 4개: p8(스물셋 가운데 둘), p11(크기가 아니라 규칙성), p18(하나를 앞에 놓으면),
p37(여든셋 가운데 열). 생성 스크립트는 [`figures015.py`](./tools/figures015.py)다.

네 도표에서 색의 뜻을 고정했다 — 판정을 받은 소리는 언제나 주황이고 판정을 받지 않고 지나간 소리는
언제나 옅은 회색이다. 이 권의 주장이 「소음은 판정」이므로 그림마다 색의 뜻이 달라지면 네 장을 이어서
읽을 수 없다.

중복 그룹 1개: `noise-is-a-judgement` = [2, 45]. 소음을 판정이라고 부르기 시작하는 1.1 첫 페이지와, 한
해 뒤 그 말 하나를 바꾸는 데 한 해가 걸렸다고 적는 7.1 첫 페이지다. 재진술 페이지(45)에는 선수를 두지
않았다. 짝(2)을 선수로 걸면 45를 고른 경로에 2가 반드시 따라와 중복 그룹 규칙을 어기기 때문이며,
12·13·14번과 같은 처리다.

## 선수 관계 설계

1.1에서 둘로 갈라진다. 1.2(귀를 닫을 수 없음) → 2장·3장·4장·6.3이 한 갈래이고 1.3(소리를 세기) →
5장이 다른 갈래다. 2.1에서 다시 2.2·2.3·3.1이 갈라지고, 3.1에서 3.2·3.3·4.1이 갈라진다.

- 어느 후보 페이지도 선수 폐쇄가 7페이지를 넘지 않는다.
- 폐쇄 5페이지 이하인 후보 페이지가 일곱 개 장을 모두 덮는다 (기준 3개 장).
- 후보 페이지 49개 전부가 폐쇄 15페이지 이하다 (기준 75%).

QUICK 시나리오는 다섯 페이지가 상한이라 사슬을 얕게 잡아야 했다. 4.1을 3.1에 직접 붙여 1.1 → 1.2 →
2.1 → 3.1 → 4.1의 다섯 페이지 사슬이 그대로 정답 경로가 되게 했다.

## 검증

`corpus_lib.validate_book()` → `validate_fragment.py` → `merge_fragments.py` → `validate_manifest.py`를
차례로 통과했다.

- 50페이지(48~72), 7개 장(최소 6), 내용 역할 5종 모두 사용
- `TEXT` 본문 45페이지가 381~501자(평균 417.0자, 합계 18,766자)로 전량 345자 이상
- `estimatedReadingSeconds`에 60초로 눌린 페이지가 하나도 없음
- `FRONT_MATTER`(목차)와 `aiRouteCandidatePage=false`가 정확히 일치
- 선수 관계가 후보 제외 페이지를 가리키지 않음, 위상 정렬로 50페이지 전체 방문
- PDF 페이지 50개, 텍스트 46개, 이미지 4개(p8,11,18,37) — `pdfcheck.py`로 확인
- PDF 규격: A4, 705,486 bytes, PDF 1.4
- PDF SHA-256: `f7003c8d6dd6a360d3d5af49be4c9a5dfad22761e92e6e552adcb03dca9fb56f`

초고는 페이지당 311~424자(평균 341자)였다. 마흔다섯 페이지 전부에 `EXTRA` 문단을 더했고 페이지마다
다른 내용을 담았다. PDF는 Chrome Headless 출력이므로 다시 생성하면 바이트와 SHA-256이 달라질 수 있다.

## 평가 케이스: 소장·QUICK 시나리오

| 필드 | 값 |
| --- | --- |
| `caseId` | `case-book-015` |
| `purpose` | 이 책을 소장하고 있고, 집에서 들리는 소리 때문에 자꾸 하던 일이 끊기는데 이사를 갈 수는 없어서 우선 짧게 핵심만 잡고 싶다 |
| `owned` / `maxAdditionalInk` / `depth` | `true` / `null` / `QUICK` |
| `requiredConcepts` | 소음이라는 말, 귀를 닫을 수 없음, 배경음, 골라 듣기, 고요 |
| `helpfulConcepts` | 소리를 세기, 멈춤이 들린다, 소리의 지도, 나머지 소리, 접어 두기 |
| `referencePageNumbers` | 2, 5, 9, 16, 24 |
| `irrelevantPageNumbers` | 31~34 (공책을 어떻게 쓰고 못 적은 소리를 어떻게 세는지) |

QUICK은 다섯 페이지가 상한이라 정답이 다섯 자리를 넘을 수 없다. 필수 개념도 다섯으로 잡고 다섯
페이지가 하나씩 덮게 했다. 4.1 첫 페이지 하나를 고르면 선수 폐쇄가 나머지 넷을 그대로 끌고 오므로
경로가 남는 자리 없이 딱 맞는다. 목적 문장에 「우선 짧게 핵심만」을 넣어 QUICK을 고른 이유가 목적
안에서 읽히게 했다.

무관은 5.1·5.2 두 절이다. 두 절의 어느 문단도 이 사례의 필수·도움 개념을 주제로 삼지 않아 절째 뺐다.
같은 5장이라도 5.3은 무관이 아니다 — 한 해를 늘어놓는 이야기가 `소리의 지도`와 `접어 두기`를 직접
다루기 때문이다.

대체 페이지는 폐쇄가 QUICK 상한 5 이하인 열네 개다. 예산에 남는 자리가 없어 대체는 정답의 한 자리를
바꿔 끼우는 쓰임뿐이므로, 정답 다섯 페이지 각각의 같은 절 짝과 이웃 절 첫 페이지를 골랐다.

## 재현 조건

1. `python3 build015.py` — 원고와 조각 생성 (PDF SHA 없이 실행하면 자리표시자를 넣는다)
2. `python3 figures015.py pdfbuild015` — 도표 4개 SVG 생성
3. Chrome Headless로 각 SVG를 794×1123 PNG로 렌더링
4. `python3 build_pdf_generic.py 15 8,11,18,37 pdfbuild015` — 조판 HTML 생성
5. Chrome Headless `--print-to-pdf`로 PDF 출력, `pdfcheck.py`로 구성 확인
6. PDF를 `fixtures/content/ai-route-v2/pdfs/`에 두고 SHA-256을 인자로 `build015.py` 재실행
7. `merge_fragments.py 15`로 정본에 병합

## 검수

- 도표 네 장을 PNG로 렌더링해 눈으로 확인했고 셋을 고쳤다.
  - p8은 주황 동그라미 둘이 점선 테두리에 걸치고 그 이름표가 아래 설명 줄과 겹쳤다. 두 동그라미를
    위로 올리고 테두리를 늘렸다.
  - p18은 「위층」 동그라미가 앞자리 동그라미 뒤에 가려 보이지 않았고, 셋째 칸 이름표가 화면 왼쪽 밖으로
    잘렸다. 뒤쪽 동그라미 자리를 벌리고 칸을 오른쪽으로 옮겼다.
  - p37은 일흔세 개 짧은 막대가 세 줄로 그려졌는데 본문에는 한 줄로 이어진다고 적혀 있었다. 본문 쪽을
    그림에 맞췄다.
- 2.3에서 배경화의 조건을 규칙성에서 설명 가능성으로 정정하면서 2.1의 본문은 고치지 않았다. 2.1에서
  규칙성이라고 적고 2.3에서 「정확히는 설명되지 않는 소리가 배경이 되지 않는 것이었다」고 다시 적는
  순서가 실제로 알게 된 순서이고, 앞을 고치면 그 순서가 사라진다.
- 6.2(고요를 살 수 있는가)를 넣을지 오래 망설였다. 넣지 않으면 이 책이 마음가짐으로 소음을 해결하라는
  책이 된다. 넣고 나서 앞쪽 몇 군데의 단정적인 문장을 함께 낮췄다.
- 리뷰에서 지적받아 고친 것 하나. 이 권의 개념 이름을 이 권의 것으로 바꿨다. 「기록의 규칙」·「남는
  물음」·「남은 것」을 「소리를 적는 법」·「소리에 남는 물음」·「접어 둔 자리에 남은 것」으로 바꿨다. 세
  자리에 아홉 권이 똑같은 이름을 쓰고 있었는데, 이름이 겹치면 개념 이름만 보고 어느 권의 것인지 가릴 수 없고
  카테고리 안에서 개념이 서로 다르다는 것도 드러나지 않는다.
- 또 하나. `main()`에 `EXTRA`의 인덱스가 도표 페이지를 가리키면 멈추는 단언을 넣었다. 016에서 실제로 났던
  사고라, 다음 권에서 조용히 되풀이되지 않게 소리 나는 자리를 만들어 두었다.

## 권리·개인정보

본문과 도표는 실존 작품을 인용·번역·모방하지 않고 이 fixture를 위해 새로 작성했다. 이웃과 관련한
서술은 발소리·문소리처럼 특정 개인을 식별할 수 없는 범위로만 적었고, 대화 내용이나 생활 사정을 짐작하게
하는 서술은 넣지 않았다.

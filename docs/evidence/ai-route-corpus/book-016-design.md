# book-016 「우산 아래 나눈 짧은 문장」 설계

[에세이 카테고리 계획](./essay-category-plan.md)의 16번을 만든 근거다. 정책·검증 계약은
[AI 경로 콘텐츠 코퍼스](../../ai-route-content-corpus.md)를 따르고, 이 문서는 그 계약 안에서 내린
선택과 이유만 적는다. 에세이 카테고리 여섯 번째 권이다.

## 대상 도서

- `bookId` 16, 카테고리 에세이. 제목·저자·소개는 `src/main/resources/demo/books.json`의 기존 값을
  유지한다 (저자 「가상 작가 016」, 소개 「비 오는 날 만난 사람들의 문장을 담은 가상 에세이입니다」).
- `totalPageCount`는 4 → **50**으로 재제작했다.
- 등장하는 사람들은 모두 가상이고 이름이 없다. 나눈 말은 이 fixture를 위해 새로 쓴 것이며 실존 인물의
  발화를 옮기지 않았다.

## 개념 범위

계획 문서가 이 권에 배정한 우연한 만남, 비, 짧은 대화의 밀도, 타인에 대한 호기심을 핵심 주제로 썼다.

- 15(소음)와 갈리는 자리가 이 권의 조건이다. 15는 소리의 존재 자체를 다루고 사람의 소리도 발소리와
  문소리로만 나온다. 16은 반대로 **오간 말의 내용**을 다루며, 소리의 크기나 배경음은 나오지 않는다.
- 비는 1장에만 나온다. 이 자리를 만드는 조건일 뿐이고, 자리가 생긴 다음부터는 비가 아니라 그 자리에서
  오간 말이 대상이라는 것을 1.1에 적었다.
- 20(말하지 않은 친절)과 겹치지 않게 3.3에서 선을 그었다. 우산을 기울여 주는 것 같은 말 없는 주고받음이
  예순 번 넘게 있었지만 세기만 하고 다루지 않았고, 그 이유를 본문에 적었다.

## 이 책의 뼈대

「짧은 것이 부족한 것이 아니라 이 자리의 형식이다」가 이 권의 결론이고, 그 결론에 이르는 과정이 구조다.

- 1장이 자리의 조건 셋(같은 방향을 봄·끝이 정해지지 않음·아무 관계 없음)을 세운다. 이 셋이 뒤의
  모든 것을 규정한다.
- 2장이 실제로 오간 말의 길이와 내용을, 3장이 왜 짧은 말이 오래 남는지를 다룬다. 3.1의 답은 「기댈 데가
  없어서」이고, 이것이 제목의 짧은 문장을 부족함이 아니라 형식으로 만드는 근거다.
- 4.1이 2.2(먼저 말 걸기)와 3.1(말의 밀도)을 둘 다 받는다. 말을 나눠야 궁금해지고 그 말이 진해야
  궁금함이 남으므로 두 선수가 모두 필요하다. 이 권에서 선수가 둘인 유일한 절이다.
- 6장이 한계다. 한쪽만 기록한다는 것(6.1), 말 걸기가 누구에게나 안전하지 않다는 것(6.2), 기억이 말을
  고쳐 쓴다는 것(6.3)이다. 6.2는 이 관찰의 화자가 말을 걸기 쉬운 자리에 있는 사람이라는 점을 그대로
  적었다.
- 7.1이 1.1을 지나온 언어로 다시 말하고, 짧음에 대한 서술을 세 번 고쳐 쓴 경과를 적는 데서 닫는다.

## 장 구성 (50페이지, 목차 1 + 본문 49)

```
1장 비가 만드는 자리          p2–8    PREREQUISITE  비가 만드는 자리·비 오는 날의 속도·우연한 만남
2장 짧은 대화                 p9–15   CORE          짧은 대화·먼저 말 걸기·끝나는 방식
3장 말의 밀도                 p16–23  CORE          말의 밀도·기억나는 문장·말 밖의 것
4장 남이 궁금해지는 일        p24–30  CORE·COUNTER  남에 대한 궁금함·묻지 않기·다시 없음
5장 한 해의 문장들            p31–37  EXAMPLE       기록의 규칙·옮겨 적기·문장을 늘어놓기
6장 말을 걸면 안 되는 자리    p38–44  COUNTERPOINT  상대의 자리·안전하지 않은 말 걸기·기억이 고친 말
7장 우산 아래 나눈 짧은 문장  p45–50  CONCLUSION    남은 것·남는 물음
```

이미지 4개: p8(백마흔 번 가운데 서른두 번), p11(세 마디와 세 가지), p18(기댈 데가 없는 말),
p37(서른둘을 갈라 보면). 생성 스크립트는 [`figures016.py`](./tools/figures016.py)다.

네 도표에서 색의 뜻을 고정했다 — 말이 오간 것은 언제나 주황이고 말이 오가지 않은 것은 언제나 옅은
회색이다. 이 권의 세는 단위가 「말이 오간 서른두 번」이므로 색의 뜻이 흔들리면 네 장이 서로 다른 것을
세는 그림이 된다.

중복 그룹 1개: `rain-makes-a-place` = [2, 45]. 비가 모르는 사람들을 한자리에 세운다는 관찰을 세우는
1.1 첫 페이지와, 한 해 뒤 그 자리가 이름 없는 자리가 되었다고 다시 말하는 7.1 첫 페이지다. 재진술
페이지(45)에는 선수를 두지 않았다. 짝(2)을 선수로 걸면 45를 고른 경로에 2가 반드시 따라와 중복 그룹
규칙을 어기기 때문이며, 12~15번과 같은 처리다.

## 선수 관계 설계

1.1에서 둘로 갈라진다. 1.2(비 오는 날의 속도) → 5장·6.2, 1.3(우연한 만남) → 2장·3장·4장이다. 2.1에서
2.2·2.3·3.1이 갈라지고, 4.1이 2.2와 3.1을 다시 합친다.

- 어느 후보 페이지도 선수 폐쇄가 9페이지를 넘지 않는다.
- 폐쇄 5페이지 이하인 후보 페이지가 여섯 개 장을 덮는다 (기준 3개 장). 4장만 최소 폐쇄가 6인데,
  4.1이 두 갈래를 합치는 절이라 구조상 그렇게 된다.
- 후보 페이지 49개 전부가 폐쇄 15페이지 이하다 (기준 75%).

## 검증

`corpus_lib.validate_book()` → `validate_fragment.py` → `merge_fragments.py` → `validate_manifest.py`를
차례로 통과했다.

- 50페이지(48~72), 7개 장(최소 6), 내용 역할 5종 모두 사용
- `TEXT` 본문 45페이지가 352~466자(평균 403.8자, 합계 18,170자)로 전량 345자 이상
- `estimatedReadingSeconds`에 60초로 눌린 페이지가 하나도 없음
- `FRONT_MATTER`(목차)와 `aiRouteCandidatePage=false`가 정확히 일치
- 선수 관계가 후보 제외 페이지를 가리키지 않음, 위상 정렬로 50페이지 전체 방문
- PDF 페이지 50개, 텍스트 46개, 이미지 4개(p8,11,18,37) — `pdfcheck.py`로 확인
- PDF 규격: A4, 677,391 bytes, PDF 1.4
- PDF SHA-256: `b5bfee6446709863a5b3e45673bc97ba36616e427fccca5735e337120bdb2a9f`

PDF는 Chrome Headless 출력이므로 다시 생성하면 바이트와 SHA-256이 달라질 수 있다.

## 평가 케이스: 소장·BALANCED 시나리오

| 필드 | 값 |
| --- | --- |
| `caseId` | `case-book-016` |
| `purpose` | 이 책을 소장하고 있고, 비 오는 날 처마 밑에서 모르는 사람과 몇 마디 나눈 일이 오래 남는 이유를 찬찬히 짚어 보고 싶다 |
| `owned` / `maxAdditionalInk` / `depth` | `true` / `null` / `BALANCED` |
| `requiredConcepts` | 비가 만드는 자리, 우연한 만남, 짧은 대화, 먼저 말 걸기, 끝나는 방식, 말의 밀도, 기억나는 문장, 남에 대한 궁금함 |
| `helpfulConcepts` | 비 오는 날의 속도, 말 밖의 것, 묻지 않기, 다시 없음, 상대의 자리 |
| `referencePageNumbers` | 2, 7, 9, 12, 14, 16, 19, 24, 29, 38 |
| `irrelevantPageNumbers` | 31~34 (공책을 어떻게 쓰고 남의 말을 어떻게 옮겨 적는지) |

BALANCED는 열 페이지가 상한이고 정답 경로가 정확히 열 페이지다. 4.1이 두 갈래를 받으므로 4.1 계열을
고르면 먼저 말 걸기와 말의 밀도가 함께 따라온다. 거기에 3.2(기억나는 문장)와 2.3(끝나는 방식)을 더해
목적인 「오래 남는 이유」에 필요한 개념을 모두 덮었다.

무관은 5.1·5.2 두 절이다. 두 절의 어느 문단도 이 사례의 필수·도움 개념을 주제로 삼지 않아 절째 뺐다.
같은 5장이라도 5.3은 무관이 아니다 — 문장들을 늘어놓는 이야기가 `짧은 대화`와 `기억나는 문장`을 직접
다루기 때문이다.

대체 페이지는 폐쇄가 BALANCED 상한 10 이하인 열다섯 개다. 상한에 여유가 없어 대체는 정답의 한 자리를
바꿔 끼우는 쓰임뿐이므로, 정답 페이지 각각의 같은 절 짝과 이웃 절 첫 페이지를 골랐다.

## 재현 조건

1. `python3 build016.py` — 원고와 조각 생성 (PDF SHA 없이 실행하면 자리표시자를 넣는다)
2. `python3 figures016.py pdfbuild016` — 도표 4개 SVG 생성
3. Chrome Headless로 각 SVG를 794×1123 PNG로 렌더링
4. `python3 build_pdf_generic.py 16 8,11,18,37 pdfbuild016` — 조판 HTML 생성
5. Chrome Headless `--print-to-pdf`로 PDF 출력, `pdfcheck.py`로 구성 확인
6. PDF를 `fixtures/content/ai-route-v2/pdfs/`에 두고 SHA-256을 인자로 `build016.py` 재실행
7. `merge_fragments.py 16`으로 정본에 병합

## 검수

- **`EXTRA` 인덱스가 도표 페이지와 어긋난 것을 잡았다.** `EXTRA`는 `PAGES` 리스트 인덱스로 문단을
  덧붙이는데, 이 권의 도표는 인덱스 6·9·16·35에 있다. 처음 쓴 키는 9와 16과 35를 건너뛰지 않아서
  도표 페이지 셋(p11·p18·p37)의 본문 끝에 엉뚱한 문단이 붙고, 그 뒤 스물다섯 개가 한 칸씩 밀렸다.
  키를 다시 매겨 고쳤고 12~15번에도 같은 문제가 없는지 도표 페이지의 끝 문장으로 확인했다 (모두
  정상). 도표 본문은 「…가 있다.」로 끝나므로 이 검사는 한 줄로 가능하다.
- 도표 네 장을 PNG로 렌더링해 눈으로 확인했고 둘을 고쳤다.
  - p11은 「이 자리 이야기」 이름표가 원보다 넓어 원 밖으로 삐져나왔다. 이름을 원 위로 올리고 안에는
    횟수만 남겼다.
  - p18은 오른쪽 칸의 네모 스무 개가 아래 설명 줄과 겹쳤다. 줄 간격을 좁혀 위로 올렸다.
- 3.3(말이 아닌 것들)을 넣을지 오래 망설였다. 20번이 다룰 주제와 가까워서다. 세기만 하고 다루지 않기로
  하고 그 판단을 본문에 적는 쪽을 골랐다. 예순 번과 서른두 번을 나란히 두면 이 자리에서 오가는 것의
  대부분이 말이 아니라는 사실이 드러나는데, 그 사실을 빼면 서른두 번이 실제보다 커 보인다.

## 권리·개인정보

본문과 도표는 실존 작품을 인용·번역·모방하지 않고 이 fixture를 위해 새로 작성했다. 등장하는 발화는
모두 가상이며 실존 인물의 말을 옮기지 않았다. 이름·생김새·옷차림처럼 개인을 특정할 수 있는 서술은
본문에서 의도적으로 제외했고, 그 제외 자체를 5.1과 6.1에서 다뤘다.

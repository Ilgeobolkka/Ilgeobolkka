# book-017 「마음의 서랍을 정리하는 밤」 설계

[에세이 카테고리 계획](./essay-category-plan.md)의 17번을 만든 근거다. 정책·검증 계약은
[AI 경로 콘텐츠 코퍼스](../../ai-route-content-corpus.md)를 따르고, 이 문서는 그 계약 안에서 내린
선택과 이유만 적는다. 에세이 카테고리 일곱 번째 권이고, 이 카테고리에서 유일한 DEEP 사례다.

## 대상 도서

- `bookId` 17, 카테고리 에세이. 제목·저자·소개는 `src/main/resources/demo/books.json`의 기존 값을
  유지한다 (저자 「가상 작가 017」, 소개 「하루의 감정을 천천히 정리한 가상 에세이입니다」).
- `totalPageCount`는 5 → **50**으로 재제작했다.
- 화자는 이름 없는 「나」이고 무대는 가상의 방이다. 실존 인물·기관과 연결되지 않는다.

## 개념 범위

계획 문서가 이 권에 배정한 감정의 정리, 분류의 비유(서랍), 밤의 회고, 미해결의 수용을 핵심 주제로 썼다.

- 18(작은 실패)과 갈리는 자리가 이 권의 조건이다. 18은 실패라는 하나의 경험에 집중하고 정원이라는 다른
  은유를 쓴다. 17은 감정 전반을 다루고 은유가 서랍이다. 그래서 이 권에서 실패는 감정의 한 종류로만 잠깐
  나오고 따로 장을 갖지 않으며, 6.2에서 정원 비유를 시험했다가 「자라난다는 쪽이 강해서 다른 이야기가
  된다」고 적고 배제했다.
- 12~16과 감각의 축이 다르다. 앞의 다섯 권은 밖을 보거나 손안의 것을 보거나 사람을 만나는데, 17은
  하루가 끝난 뒤 안쪽을 본다.

## 이 책의 뼈대

「정리한다는 말이 치운다에서 어디에 있는지 알게 둔다로 바뀌는 것」이 이 권의 축이다.

- 1.2가 서랍 비유를 세우고 그 이유를 적는다. 정리·해결이라는 말이 제거의 뜻을 갖기 때문이다.
- 2장이 꺼내 놓기와 이름 붙이기, 3장이 다섯 칸에 나누어 넣기를 다룬다. 3.1의 물음 순서(끝났나 →
  할 수 있나 → 남이 정하나)가 이 방법의 실제 절차다.
- 4.1이 2.3(이름이 안 붙는 것)과 3.2(두 곳에 걸치는 것)를 둘 다 받는다. 이름이 안 붙고 갈리지도 않는
  것이 어느 서랍에도 안 들어가므로 두 선수가 모두 필요하다. 이 권에서 선수가 둘인 유일한 절이고,
  DEEP 경로가 깊어지는 자리다.
- 6장이 한계다. 정리가 오히려 나쁜 밤(6.1), 비유 자체의 한계 넷(6.2), 그리고 **혼자 할 수 없는 것**
  (6.3)이다. 6.3은 이 방법이 전문적 도움을 대신하지 않는다는 것을 본문 안에 적은 절이다.
- 7.1이 1.1을 지나온 언어로 다시 말하고, 줄어든 것이 감정이 아니라 같은 것을 다시 겪는 횟수였다는 데서
  닫는다.

## 장 구성 (50페이지, 목차 1 + 본문 49)

```
1장 밤에 앉는 자리              p2–8    PREREQUISITE  밤이라는 시각·서랍이라는 비유·하루치 분량
2장 꺼내 놓기                   p9–15   CORE          꺼내 놓기·감정에 이름 붙이기·이름 없는 것
3장 나누어 넣기                 p16–23  CORE·COUNTER  분류해 보기·섞여 있는 것·서랍의 개수
4장 안 들어가는 것들            p24–30  CORE          안 들어가는 것·열어 둔 서랍·다시 열림
5장 한 해의 밤들                p31–37  EXAMPLE       밤의 서식·못 적은 밤·밤을 늘어놓기
6장 정리되지 않는 것            p38–44  COUNTERPOINT  정리가 나쁜 밤·서랍 비유의 한계·혼자 할 수 없는 것
7장 마음의 서랍을 정리하는 밤   p45–50  CONCLUSION    정리가 남긴 것·서랍에 남는 물음
```

이미지 4개: p8(서랍 다섯과 하루치), p11(왼쪽과 오른쪽), p18(세 번 묻고 넣는다),
p37(이백일흔다섯 밤). 생성 스크립트는 [`figures017.py`](./tools/figures017.py)다.

네 도표에서 표기를 고정했다 — 다섯 서랍은 언제나 같은 순서로 놓이고, 미결을 뜻하는 것(모르겠는 서랍)은
언제나 점선이다. 이 권의 방법이 같은 다섯 칸을 되풀이해 쓰는 것이므로 순서가 흔들리면 네 장을 이어서
읽을 수 없다.

중복 그룹 1개: `sorting-is-not-solving` = [2, 45]. 이 일이 감정을 다스리는 방법이 아니라고 미리 적는
1.1 첫 페이지와, 한 해 뒤 정리한다는 말의 뜻이 바뀌었다고 적는 7.1 첫 페이지다. 재진술 페이지(45)에는
선수를 두지 않았다. 짝(2)을 선수로 걸면 45를 고른 경로에 2가 반드시 따라와 중복 그룹 규칙을 어기기
때문이며, 12~16번과 같은 처리다.

## 선수 관계 설계

이 권은 DEEP 사례라 다른 권보다 사슬을 깊게 잡았다. 1.1 → 1.2 → 1.3 → 2.1 → 2.2가 다섯 단 사슬이고,
2.2에서 2.3과 3.1로 갈라져 각각 내려간 뒤 4.1이 둘을 받는다.

- 어느 후보 페이지도 선수 폐쇄가 12페이지를 넘지 않는다.
- 폐쇄 5페이지 이하인 후보 페이지가 다섯 개 장을 덮는다 (기준 3개 장). 3·4장은 사슬 아래쪽이라 최소
  폐쇄가 6과 9다.
- 후보 페이지 49개 전부가 폐쇄 15페이지 이하다 (기준 75%).

## 검증

`corpus_lib.validate_book()` → `validate_fragment.py` → `merge_fragments.py` → `validate_manifest.py`를
차례로 통과했다.

- 50페이지(48~72), 7개 장(최소 6), 내용 역할 5종 모두 사용
- `TEXT` 본문 45페이지가 371~517자(평균 405.3자, 합계 18,239자)로 전량 345자 이상
- `estimatedReadingSeconds`에 60초로 눌린 페이지가 하나도 없음
- `FRONT_MATTER`(목차)와 `aiRouteCandidatePage=false`가 정확히 일치
- 선수 관계가 후보 제외 페이지를 가리키지 않음, 위상 정렬로 50페이지 전체 방문
- PDF 페이지 50개, 텍스트 46개, 이미지 4개(p8,11,18,37) — `pdfcheck.py`로 확인
- PDF 규격: A4, 711,584 bytes, PDF 1.4
- PDF SHA-256: `bd3760ef86c6960ee81ae2ed23218e1add101e233b6f2b96163b32d74f3a6962`

PDF는 Chrome Headless 출력이므로 다시 생성하면 바이트와 SHA-256이 달라질 수 있다.

## 평가 케이스: 소장·DEEP 시나리오

| 필드 | 값 |
| --- | --- |
| `caseId` | `case-book-017` |
| `purpose` | 이 책을 소장하고 있고, 밤마다 그날 있었던 일이 정리되지 않은 채 쌓이는 것 같아서 처음부터 끝까지 차근히 따라가며 방법을 익히고 싶다 |
| `owned` / `maxAdditionalInk` / `depth` | `true` / `null` / `DEEP` |
| `requiredConcepts` | 밤이라는 시각, 서랍이라는 비유, 하루치 분량, 꺼내 놓기, 감정에 이름 붙이기, 이름 없는 것, 분류해 보기, 섞여 있는 것, 안 들어가는 것 |
| `helpfulConcepts` | 서랍의 개수, 열어 둔 서랍, 다시 열림, 정리가 나쁜 밤, 혼자 할 수 없는 것 |
| `referencePageNumbers` | 2, 5, 7, 9, 12, 14, 16, 19, 22, 24, 27, 29, 38, 43 |
| `irrelevantPageNumbers` | 31~34 (공책 서식과 못 적은 밤을 세는 이야기) |

DEEP은 열다섯 페이지가 상한이고 이 권에서 가장 깊은 사슬을 그대로 따라가 열네 페이지가 됐다. 목적이
「처음부터 끝까지 차근히 따라가며」이므로 1장부터 순서대로 밟는 경로가 목적과 맞는다. 마지막에 6.1(정리가
나쁜 밤)과 6.3(혼자 할 수 없는 것)을 넣은 것은, 방법을 익히려는 목적이라면 쓰면 안 되는 자리를 함께
알아야 하기 때문이다. 한 자리가 남지만 그 자리를 6.2로 채우면 비유 이야기가 방법 이야기보다 뒤에
붙어 순서가 어색해져서 대체 페이지로 돌렸다.

무관은 5.1·5.2 두 절이다. 두 절의 어느 문단도 이 사례의 필수·도움 개념을 주제로 삼지 않아 절째 뺐다.
같은 5장이라도 5.3은 무관이 아니다 — 한 해를 늘어놓는 이야기가 `분류해 보기`와 `다시 열림`을 직접
다루기 때문이다.

대체 페이지는 폐쇄가 DEEP 상한 15 이하인 열다섯 개다. 정답 페이지 각각의 같은 절 짝을 중심으로 골랐고,
5장은 무관이라 빼고 7장은 결론이라 뺐다.

## 재현 조건

1. `python3 build017.py` — 원고와 조각 생성 (PDF SHA 없이 실행하면 자리표시자를 넣는다)
2. `python3 figures017.py pdfbuild017` — 도표 4개 SVG 생성
3. Chrome Headless로 각 SVG를 794×1123 PNG로 렌더링
4. `python3 build_pdf_generic.py 17 8,11,18,37 pdfbuild017` — 조판 HTML 생성
5. Chrome Headless `--print-to-pdf`로 PDF 출력, `pdfcheck.py`로 구성 확인
6. PDF를 `fixtures/content/ai-route-v2/pdfs/`에 두고 SHA-256을 인자로 `build017.py` 재실행
7. `merge_fragments.py 17`로 정본에 병합

## 검수

- 도표 네 장을 PNG로 렌더링해 눈으로 확인했고 하나를 고쳤다. p37의 「이사한 두 달만 세 배」 이름표가
  주황 상자 밖으로 넘쳐서 상자를 넓혔다.
- 대체 페이지 목록에 정답 경로에 이미 든 p7이 들어가 있어 p8로 바꿨다. 검증기는 정답과 대체가 겹치는
  것을 막지 않지만, 대체는 정답의 한 자리를 대신하는 자리이므로 이미 경로에 있는 페이지를 넣으면 뜻이
  없다.
- 4.3 둘째 페이지의 `secondaryConcepts`가 `primaryConcepts`와 같아서 `안 들어가는 것`으로 바꿨다.
- 6.3(혼자 할 수 없는 것)을 넣을지 오래 망설였다. 넣지 않으면 이 책이 감정 문제 전반에 쓸 수 있는
  방법처럼 읽힌다. 겪지 않은 것을 짐작으로 적지 않으려고, 어떤 신호가 보이면 범위 밖인지만 적고 그
  뒤는 적지 않았다.
- 6.1 셋째 페이지(좋은 밤에도 안 하는 편이 나은 것)는 초고에 없었다. 반례 장이 나쁜 감정 쪽에만 있으면
  이 방법이 나쁜 것을 없애는 방법으로 읽히므로, 좋은 감정에서 같은 방법이 손해가 되는 자리를 넣었다.
- 리뷰에서 지적받아 고친 것 하나. 이 권의 개념 이름을 이 권의 것으로 바꿨다. 「기록의 규칙」·「남는
  물음」·「남은 것」·「이름 붙이기」·「비유의 한계」를 「밤의 서식」·「서랍에 남는 물음」·「정리가 남긴
  것」·「감정에 이름 붙이기」·「서랍 비유의 한계」로 바꿨다. 다섯 자리에 아홉 권이 똑같은 이름을 쓰고
  있었는데, 이름이 겹치면 개념 이름만 보고 어느 권의 것인지 가릴 수 없고 카테고리 안에서 개념이 서로
  다르다는 것도 드러나지 않는다.
- 또 하나. `main()`에 `EXTRA`의 인덱스가 도표 페이지를 가리키면 멈추는 단언을 넣었다. 016에서 실제로 났던
  사고라, 다음 권에서 조용히 되풀이되지 않게 소리 나는 자리를 만들어 두었다.
- 한 해 도표의 값을 만드는 방식을 바꿨다. 나머지 연산으로 칸을 고르면 그려지는 개수가 본문이 센 값과
  어긋나는데, p37이 그러고 있었다. 못 앉은 밤 아흔, 앉은 밤 이백일흔다섯이 5.2의 값이다. 같은 자리에서 특정
  두 달에 못 앉은 밤을 몰아 두던 것도 없앴다 — 본문이 몰렸다고 말하는 것은 셋째 서랍이지 못 앉은 밤이
  아닌데, 그림만 보면 두 이야기가 하나로 읽힌다. 이제 본문 수치를 상수로 두고 그 수만큼 정확히 고른 뒤
  단언으로 확인한다.

## 권리·개인정보

본문과 도표는 실존 작품을 인용·번역·모방하지 않고 이 fixture를 위해 새로 작성했다. 특정 인물·기관과
연결되지 않는 일반적인 가상 일상이며 개인정보를 포함하지 않는다. 이 책은 치료나 상담의 방법이 아니고,
그 경계를 6.3에서 본문 안에 적었다.

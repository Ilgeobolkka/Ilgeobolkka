# book-019 「저녁 여섯 시의 산책자」 설계

[에세이 카테고리 계획](./essay-category-plan.md)의 19번을 만든 근거다. 정책·검증 계약은
[AI 경로 콘텐츠 코퍼스](../../ai-route-content-corpus.md)를 따르고, 이 문서는 그 계약 안에서 내린
선택과 이유만 적는다. 에세이 카테고리 아홉 번째 권이다.

## 대상 도서

- `bookId` 19, 카테고리 에세이. 제목·저자·소개는 `src/main/resources/demo/books.json`의 기존 값을
  유지한다 (저자 「가상 작가 019」, 소개 「같은 시각의 산책에서 발견한 변화를 담은 가상 에세이입니다」).
- `totalPageCount`는 4 → **50**으로 재제작했다.
- 화자는 이름 없는 「나」이고 무대는 가상의 동네다. 실존 지명·상호·인물과 연결되지 않는다.

## 개념 범위

계획 문서가 이 권에 배정한 반복되는 시간, 변화 감지, 같은 길 다른 하루, 관찰의 축적을 핵심 주제로 썼다.
갈라야 할 자리가 둘이다.

- 12(창가)는 움직이지 않는 관찰이다. 19는 걷지만 같은 길만 걷는다. 12가 창틀로 테두리를 만든 자리에서
  19는 같은 경로와 같은 시각이 그 일을 한다.
- 13(낯선 골목)은 매번 다른 길로 들어가 낯섦이 익숙함으로 바뀌는 과정을 본다. 19는 방향이 반대로,
  **이미 익숙한 길에서 되풀이가 무엇을 쌓는지**를 본다. 그래서 이 권에는 낯섦이 핵심 개념으로 나오지
  않고, 3.3에서 쌓임이 무엇을 가리는지를 반례로 둔다. 6.3에서는 13번의 방법이 다른 성향에게 맞을
  것이라고 본문에 적어 두 권의 관계를 밝혔다.

## 이 책의 뼈대

「셋을 못 박고 하나만 남긴다」가 이 권의 방법이다.

- 1장이 시각·길·방향을 고정한다. 남는 변수가 날짜뿐일 때 달라진 까닭을 말할 수 있다는 것이 이 구조의
  근거다.
- 2장이 달라지는 것을 네 범주로 나눈다. 네 범주의 변화 주기가 서로 달라 견주는 간격도 달라진다는 것이
  2.3이다. 2.2는 자로 삼은 것이 달라지면 모른다는 문제를 함께 적었다.
- 3장이 되풀이가 쌓는 것과 가리는 것을 나란히 둔다. 3.1의 회차별 기록량 곡선(서른과 백 사이가 가장 낮음)
  이 이 권에서 가장 실용적인 발견이다.
- 4.1이 그날의 표시를 다룬다. 삼백여섯 번 가운데 마흔만 또렷하게 남고 나머지는 평소를 쌓는 데 쓰인다.
- 6장이 한계다. 길이 바뀌는 일(6.1), 여섯 시를 낼 수 없는 생활(6.2), 되풀이가 안 맞는 성향(6.3)이다.
- 7.1이 1.1을 지나온 언어로 다시 말하고, 얻은 눈이 이 길에서만 쓰이며 길이 없어지면 함께 없어진다는
  데서 닫는다.

## 장 구성 (50페이지, 목차 1 + 본문 49)

```
1장 여섯 시에 나선다        p2–8    PREREQUISITE  같은 시각·같은 길·걷는 규칙
2장 달라지는 것             p9–15   CORE          달라지는 것·달라지지 않는 것·견주는 눈
3장 쌓이는 관찰             p16–23  CORE·COUNTER  쌓이는 관찰·백 번째·쌓임의 대가
4장 같은 길 다른 하루       p24–30  CORE·COUNTER  그날의 표시·계절이 지나감·어긋난 날
5장 한 해의 산책            p31–37  EXAMPLE       기록의 규칙·걷지 못한 날·늘어놓기
6장 같은 길이 끝날 때       p38–44  COUNTERPOINT  바뀌는 길·시각을 지킬 수 없을 때·되풀이의 조건
7장 저녁 여섯 시의 산책자   p45–50  CONCLUSION    남은 것·남는 물음
```

이미지 4개: p8(고정한 셋과 남는 하나), p11(네 개의 다른 시계), p18(서른과 백 사이),
p37(삼백여섯 번). 생성 스크립트는 [`figures019.py`](./tools/figures019.py)다.

네 도표에서 표기를 고정했다 — 고정한 것은 언제나 굵은 실선이고 날마다 달라지는 것은 언제나 색이다.
이 권의 방법이 「셋을 못 박고 하나만 남긴다」이므로 이 구분이 흔들리면 네 장을 이어서 읽을 수 없다.

중복 그룹 1개: `same-hour-same-route` = [2, 45]. 시각을 하나로 정하기로 하는 1.1 첫 페이지와, 한 해 뒤
그 길이 여전히 늘 걷던 길이라고 다시 말하는 7.1 첫 페이지다. 재진술 페이지(45)에는 선수를 두지 않았다.
짝(2)을 선수로 걸면 45를 고른 경로에 2가 반드시 따라와 중복 그룹 규칙을 어기기 때문이며, 12~18번과
같은 처리다.

## 선수 관계 설계

1.1에서 둘로 갈라진다. 1.2(같은 길) → 2장·3장·4장·6.1이 한 갈래이고 1.3(걷는 규칙) → 5장이 다른
갈래다. 2.1에서 2.2·2.3·3.1이 갈라지고 3.1에서 3.2·3.3·4.1·6.3이 갈라진다.

- 어느 후보 페이지도 선수 폐쇄가 7페이지를 넘지 않는다.
- 폐쇄 5페이지 이하인 후보 페이지가 일곱 개 장을 모두 덮는다 (기준 3개 장).
- 후보 페이지 49개 전부가 폐쇄 15페이지 이하다 (기준 75%).

예산 5 시나리오라 사슬을 얕게 잡았다. 4.1을 3.1에 직접 붙여 1.1 → 1.2 → 2.1 → 3.1 → 4.1의 다섯 페이지
사슬이 그대로 정답 경로가 되게 했다. 12번·15번과 같은 방식이다.

## 검증

`corpus_lib.validate_book()` → `validate_fragment.py` → `merge_fragments.py` → `validate_manifest.py`를
차례로 통과했다.

- 50페이지(48~72), 7개 장(최소 6), 내용 역할 5종 모두 사용
- `TEXT` 본문 45페이지가 345~485자(평균 389.2자, 합계 17,512자)로 전량 345자 이상
- `estimatedReadingSeconds`에 60초로 눌린 페이지가 하나도 없음
- `FRONT_MATTER`(목차)와 `aiRouteCandidatePage=false`가 정확히 일치
- 선수 관계가 후보 제외 페이지를 가리키지 않음, 위상 정렬로 50페이지 전체 방문
- PDF 페이지 50개, 텍스트 46개, 이미지 4개(p8,11,18,37) — `pdfcheck.py`로 확인
- PDF 규격: A4, 674,776 bytes, PDF 1.4
- PDF SHA-256: `945326e72479a49fb006227372965de2403657378fd3cbfc538bf5fa4e717444`

PDF는 Chrome Headless 출력이므로 다시 생성하면 바이트와 SHA-256이 달라질 수 있다.

## 평가 케이스: 비소장·예산 5 시나리오

| 필드 | 값 |
| --- | --- |
| `caseId` | `case-book-019` |
| `purpose` | 이 책을 사지는 않았고, 늘 걷던 길을 걸으면서도 남는 것이 없다는 느낌이 들어 같은 길에서 무엇을 봐야 하는지 짧게 짚고 싶다 |
| `owned` / `maxAdditionalInk` / `depth` | `false` / `5` / `null` |
| `requiredConcepts` | 같은 시각, 같은 길, 달라지는 것, 쌓이는 관찰, 그날의 표시 |
| `helpfulConcepts` | 걷는 규칙, 달라지지 않는 것, 견주는 눈, 백 번째, 계절이 지나감 |
| `referencePageNumbers` | 2, 5, 9, 16, 24 |
| `irrelevantPageNumbers` | 31~34 (수첩을 어떻게 쓰고 못 나간 날을 어떻게 세는지) |

예산 5는 다섯 자리가 상한이라 필수 개념도 다섯으로 잡고 다섯 페이지가 하나씩 덮게 했다. 4.1 첫 페이지
하나를 고르면 선수 폐쇄가 나머지 넷을 그대로 끌고 오므로 경로가 남는 자리 없이 딱 맞는다. 목적 문장에
「짧게 짚고 싶다」를 넣어 예산 5를 고른 이유가 목적 안에서 읽히게 했다.

무관은 5.1·5.2 두 절이다. 두 절의 어느 문단도 이 사례의 필수·도움 개념을 주제로 삼지 않아 절째 뺐다.
같은 5장이라도 5.3은 무관이 아니다 — 삼백 번을 늘어놓는 이야기가 `계절이 지나감`을 직접 다루기 때문이다.

대체 페이지는 폐쇄가 상한 5 이하인 열네 개다. 예산에 남는 자리가 없어 대체는 정답의 한 자리를 바꿔
끼우는 쓰임뿐이므로, 정답 다섯 페이지 각각의 같은 절 짝과 이웃 절 첫 페이지를 골랐다.

## 재현 조건

1. `python3 build019.py` — 원고와 조각 생성 (PDF SHA 없이 실행하면 자리표시자를 넣는다)
2. `python3 figures019.py pdfbuild019` — 도표 4개 SVG 생성
3. Chrome Headless로 각 SVG를 794×1123 PNG로 렌더링
4. `python3 build_pdf_generic.py 19 8,11,18,37 pdfbuild019` — 조판 HTML 생성
5. Chrome Headless `--print-to-pdf`로 PDF 출력, `pdfcheck.py`로 구성 확인
6. PDF를 `fixtures/content/ai-route-v2/pdfs/`에 두고 SHA-256을 인자로 `build019.py` 재실행
7. `merge_fragments.py 19`로 정본에 병합

## 검수

- 도표 네 장을 PNG로 렌더링해 눈으로 확인했고 둘을 고쳤다.
  - p37은 처음에 합계 막대가 「나간 날」 띠와 겹치고, 빈칸이 몰린 세 자리의 이름표가 서로 붙어 읽히지
    않았다. 범례를 띠 위로 올리고 세 이름표를 지시선과 함께 띠 아래로 내렸으며 합계 막대를 훨씬 아래로
    옮겼다. 같은 자리에서 빈칸이 몰리는 구간의 날짜 범위도 서로 떨어지도록 다시 잡았다.
  - p18은 세 구간의 이름을 가로축 아래에 나란히 적었는데 왼쪽 두 구간이 좁아 글자가 겹쳤다. 이름을
    그래프 위쪽 범례로 모으고 본문도 그렇게 고쳤다.
- 3.3(쌓임이 가리는 것)에서 풀지 못한 문제를 그대로 남겼다. 지점을 무시해도 늘려도 안 됐고 셋째 방법을
  찾지 못했다. 푼 것처럼 적으면 이 방법을 쓰는 다음 사람이 같은 자리에서 다시 막힌다.
- 4.3(어긋난 날)을 반례로 둔 것이 이 권의 균형에 필요했다. 규칙을 어긴 쉰 날의 기록이 오히려 길다는
  사실을 빼면 고정이 늘 옳은 것처럼 읽힌다.

## 권리·개인정보

본문과 도표는 실존 작품을 인용·번역·모방하지 않고 이 fixture를 위해 새로 작성했다. 등장 장면은 특정
실존 동네·상호·인물과 연결되지 않는 일반적인 가상 일상이며 개인정보를 포함하지 않는다. 산책 중 마주친
사람은 수로만 세었고 개인을 특정할 수 있는 서술은 넣지 않았다.

# book-022 「파동의 기초: 흔들림에서 무늬까지」 설계

[과학 카테고리 계획](./science-category-plan.md)의 22번을 만든 근거다. 정책·검증 계약은
[AI 경로 콘텐츠 코퍼스](../../ai-route-content-corpus.md)를 따르고, 이 문서는 그 계약 안에서 내린
선택과 이유만 적는다.

이 문서는 책을 만든 뒤에 썼다. 아래의 수치와 구조는 현재 정본에서 그대로 확인한 것이고, 계획과
어긋난 자리는 어긋났다는 사실과 지금 상태를 적되 당시의 의도를 지어내지 않았다.

## 대상 도서

- `bookId` 22, 카테고리 과학. 저자·소개는 `src/main/resources/demo/books.json`의 기존 값을 유지한다.
- 제목은 `ai-route-v2` manifest의 `books[].title`이 정본이며 이 문서의 제목과 같다. 계획 문서의
  가제(「파동의 물리: 소리에서 전자기파까지」)와 다르다.
- 실존 연구자·실험·기관을 옮기지 않는다. 인물은 지우다.

## 계획과 어긋난 자리

계획이 적은 범위는 파동의 요소(파장·진동수·진폭), 횡파·종파, 소리, 전자기파 스펙트럼, 반사·굴절·회절
다섯이었다. 이 가운데 **전자기파 스펙트럼이 빠졌다.** 본문에 「전자기파」도 「스펙트럼」도 한 번도
나오지 않는다. 대신 계획에 없던 4장(중첩·간섭·정상파·맥놀이)이 들어가 책의 무게 중심이 되었다.

021이 스펙트럼을 다루므로 경계는 결과적으로 지켜졌지만, 항목을 뺀 시점의 판단은 기록이 남아 있지
않다. 나머지 넷은 그대로 들어갔다 — 파동의 요소는 1·2장, 횡파·종파는 2.4, 소리는 5.2, 반사·굴절·회절은
3장이다.

평가 케이스의 형태는 계획대로 「비소장 · 예산 10」이다.

## 개념 범위

이 책의 축은 **겹침**이다. 목적문이 "잔잔한 줄과 크게 이는 줄이 번갈아 생기는 까닭"을 묻고, 그 답은
간섭 무늬다. 그래서 1장에서 제자리 흔들림을 세우고, 2장에서 그것이 옮겨 가는 일을 파동이라 부르고,
4장에서 두 파동이 만나는 자리로 간다. 3장(반사·굴절·회절)은 그 사이에서 파동이 무언가를 만날 때
무슨 일이 일어나는지를 다룬다.

같은 카테고리에서 빛과 파동을 다루는 권과 경계를 두었다.

- 021(분광)은 도착한 빛을 갈라 성분과 운동을 읽는다. 022는 파동 자체의 성질만 다루므로 스펙트럼도
  흡수선도 나오지 않는다.
- 024(빛의 속도)는 신호가 도착하기까지의 시간을 다룬다. 022에서 속도는 파장과 진동수의 곱으로만
  나오고 유한한 속도가 만드는 지연 문제는 다루지 않는다.

## 장 구성 (49페이지, 목차 1 + 본문 48)

```
1장 제자리에서 흔들리는 것      p2–7    PREREQUISITE  진동·주파수·진폭
2장 흔들림이 옮겨 갈 때         p8–15   CORE          파동·매질·파장·횡파와 종파
3장 파동이 무언가를 만나면      p16–23  CORE          반사·굴절·회절·경계 조건
4장 파동끼리 만나면             p24–31  CORE          중첩·간섭·정상파·맥놀이
5장 실제로 재어 보기            p32–38  EXAMPLE       측정 방법·관측 절차·관측 기록
6장 그림이 어긋나는 순간        p39–46  COUNTERPOINT  파동의 오인·감쇠·불균일 매질·모형의 한계
7장 무엇을 그리고 무엇을 남기나 p47–49  CONCLUSION    종합과 남는 물음
```

이미지 6개: p5(제자리에서 오가는 움직임), p13(파장과 속도), p19(꺾이는 파동), p27(서로 키우고 지우고),
p29(제자리에 서는 파동), p36(그림으로 옮기기). 생성 스크립트는
[`figures022.py`](./tools/figures022.py)다.

중복 그룹 1개: `carrier-stays-put` = [11, 40]. "물질이 옮겨 가면 흐름이고 상태만 넘어가면 파동이다"를
2.2에서 정의로 세우고 6.1에서 가려내는 기준으로 다시 쓴다. 두 페이지 모두 절의 둘째 페이지이고,
40의 선수 폐쇄는 [2, 8, 10, 39, 40]이라 짝인 11을 지나지 않는다. 폐쇄가 짝을 지나면 40을 고른 경로에
11이 반드시 따라와 중복 그룹 규칙을 어긴다.

## 선수 관계 설계

1.1이 뿌리이고 1.2·1.3·2.1이 곧바로 거기 붙는다. 2.2·2.4는 2.1에 붙고 2.3만 2.1과 1.2 둘을 선수로
가진다 — 파장과 속도는 진동수를 알아야 곱으로 이어지기 때문이다. 3장은 3.1이 2.1에, 3.2·3.3이 2.3에
붙고 3.4는 3.1에서 이어진다. 4장은 4.1이 2.1에 붙고 4.2가 4.1에서, 4.4가 4.2에서 이어진다.

4.3(정상파)만 선수가 둘이다. 4.2(겹침)와 **3.1(되돌아오는 파동)**을 함께 건다. 정상파는 보내는 파동과
되돌아오는 파동의 겹침이라 겹침만으로는 서지 않는다. 이 간선이 없으면 정답 경로만 읽은 독자가 4.3에서
「되돌아오는 파동」을 처음 만나면서 이미 아는 것으로 취급받는다.

6장은 뒤에 있지만 앞 장에 직접 붙였다 — 6.1은 2.2, 6.2는 1.3, 6.3은 3.2, 6.4는 4.1이다. 반례는 그
주장이 세워진 자리에서 읽어야 뜻이 서고, 6장을 5장 뒤에 사슬로 이으면 폐쇄가 예산 안에 들어오지 못한다.

- 어느 후보 페이지도 선수 폐쇄가 7페이지를 넘지 않는다.
- 폐쇄 5페이지 이하인 후보 페이지가 일곱 개 장을 모두 덮는다 (기준 3개 장).
- 후보 페이지 48개 전부가 폐쇄 15페이지 이하다 (기준 75%).

## 검증

`corpus_lib.validate_book()` → `validate_fragment.py` → `merge_fragments.py` → `validate_manifest.py`를
차례로 통과했다.

- 49페이지(48~72), 7개 장(최소 6), 내용 역할 5종 모두 사용
- `TEXT` 본문 42페이지가 345~439자(평균 374자, 합계 15,716자)
- `estimatedReadingSeconds`에 60초로 눌린 페이지가 하나도 없음
- `FRONT_MATTER`(목차 p1)와 `aiRouteCandidatePage=false`가 정확히 일치
- 선수 관계가 후보 제외 페이지를 가리키지 않음, 위상 정렬로 49페이지 전체 방문
- PDF 페이지 49개, 텍스트 43개, 이미지 6개(p5,13,19,27,29,36) — `pdfcheck.py`로 확인
- PDF 실제 SHA-256이 manifest의 `pdfSha256`과 일치

## 평가 케이스: 비소장·예산 10 시나리오

| 필드 | 값 |
| --- | --- |
| `caseId` | `case-book-022` |
| `purpose` | 물결이 서로 만나면 잔잔한 줄과 크게 이는 줄이 번갈아 생기는데, 그 까닭을 흔들림에서부터 차근차근 이해하고 싶다 |
| `owned` / `maxAdditionalInk` / `depth` | `false` / `10` / `null` |
| `requiredConcepts` | 진동, 파동, 중첩, 간섭, 정상파 |
| `helpfulConcepts` | 주파수, 파장, 맥놀이, 관측 절차 |
| `referencePageNumbers` | 2, 4, 8, 12, 16, 24, 26, 28 |
| `allowedAlternativePageNumbers` | 3, 5, 9, 13, 17, 25, 27, 29, 33 |
| `irrelevantPageNumbers` | 20·21(회절), 41·42(감쇠) |

정답 경로는 선수 전이 폐쇄와 같고 8페이지여서 예산 10 안에 든다. 진동(2) → 주파수(4) → 파동(8) →
파장과 속도(12)를 지나 겹침(24) → 간섭(26) → 정상파(28)에 닿고, 정상파가 3.1(16)을 함께 선수로
가지므로 반사도 경로에 들어온다.

대체 페이지는 정답 여덟 자리의 같은 절 짝(3, 5, 9, 13, 17, 25, 27, 29)과 5.1의 둘째 페이지(33)다.
앞의 여덟은 짝과 `primaryConcepts`가 같아 개념 충족을 그대로 대신한다. 33은 `관측 절차`가 primary라 도움
개념을 그대로 덮는다.

무관은 두 절뿐이다. 회절(3.3)과 감쇠(6.2)는 간섭 무늬가 왜 생기는지와 이어지지 않는다. 절 단위로
골랐다 — 한 절을 무관과 무관 아님으로 가르면 무관이 아닌 페이지가 무관 페이지를 선수로 밟아야만
닿는 자리가 생긴다.

3.4(갇히는 파동)는 무관에 넣지 않았다. 개념표에는 `경계 조건`이 달려 있지만 본문은 양쪽 끝이 고정된
줄에서 허용되는 파장이 띄엄띄엄 정해지는 일 — 필수 개념인 정상파를 다른 이름으로 가르친다. 무관으로
두면 그 페이지를 고른 경로가 정상파를 제대로 덮고도 무관 추천으로 감점된다.

## 재현 조건

1. `python3 build022.py` — 원고와 조각 생성 (PDF SHA 없이 실행하면 자리표시자를 넣는다)
2. `python3 figures022.py pdfbuild022` — 도표 6개 SVG 생성
3. Chrome Headless로 각 SVG를 794×1123 PNG로 렌더링
4. `python3 build_pdf_generic.py 22 5,13,19,27,29,36 pdfbuild022` — 조판 HTML 생성
5. Chrome Headless `--print-to-pdf`로 PDF 출력, `pdfcheck.py`로 구성 확인
6. PDF를 `fixtures/content/ai-route-v2/pdfs/`에 두고 SHA-256을 인자로 `build022.py` 재실행
7. `merge_fragments.py --replace 22`로 정본에 병합

## 검수

- 정답 경로가 반사를 설명 없이 전제하고 있었다. 4.3의 선수가 4.2뿐이어서 정상파가 겹침 위에만
  서 있었다. 3.1을 선수로 걸어 정답 경로를 7페이지에서 8페이지로 늘렸고 예산 10 안에 그대로 든다.
  같은 이유로 3.1(16·17)을 무관에서 뺐다. 정답 경로가 지나는 절은 무관일 수 없다.
- 3.1이 정답 경로에 들어오면서 17만 같은 절 짝이 없는 페이지가 되어 대체에 넣었다. 되돌아온 물결이
  들어오는 물결과 마주친다는 이야기라 반사에서 중첩으로 넘어가는 다리이고, 선수 폐쇄가 4페이지라
  예산 안에서 고를 수 있다.
- 3.4를 무관에서 뺐다. 위의 평가 케이스 절에 이유를 적었다. 3.4는 정답에도 대체에도 넣지 않았다.
  채점기는 `primaryConcepts`로 개념 충족을 세는데 3.4의 primary는 `경계 조건`이라 정상파로 세어지지
  않아 정답의 한 자리를 대신할 수 없다.
- 공개 가이드 주제와 비공개 분석 텍스트를 서로 다른 문장으로 적었고, 주제문에 숫자를 쓰지 않았다.
- 본문·도표·평가 데이터에 실존 인물·작품·단체가 등장하지 않는다.

# book-023 「미생물 생태와 물질순환」 설계

[과학 카테고리 계획](./science-category-plan.md)의 23번을 만든 근거다. 정책·검증 계약은
[AI 경로 콘텐츠 코퍼스](../../ai-route-content-corpus.md)를 따르고, 이 문서는 그 계약 안에서 내린
선택과 이유만 적는다.

## 대상 도서

- `bookId` 23, 카테고리 과학. 저자·소개는 `src/main/resources/demo/books.json`의 기존 값을 유지한다.
- 제목은 `ai-route-v2` manifest의 `books[].title`이 정본이며 이 문서의 제목과 같다.
- 실존 연구소·연구자·종명을 옮기지 않는다. 무대는 가상의 「너른들 토양 조사소」, 인물은 하람과 유섭이다.
  021의 유안·해든, 026의 세연·진우, 027의 나린·도경과 겹치지 않는다.

## 개념 범위

계획 문서가 정한 범위(미생물 분류, 분해자와 물질순환, 발효, 항생제 내성)를 그대로 따른다. 같은
카테고리에 생물을 다루는 권이 셋이라 경계를 분명히 두었다.

- 026(생물발광)은 심해 동물이 스스로 내는 빛을 다룬다. 023에는 발광이 한 번도 나오지 않는다.
- 028(식물 신호전달)은 식물이 주고받는 화학 신호를 다룬다. 023은 식물을 순환의 한 자리로만 놓고
  식물이 무엇을 내보내는지는 다루지 않는다.
- 029(기후 데이터)는 자료를 읽는 방법론이다. 023의 5장도 조사 절차를 다루지만 흙 시료라는 구체적
  대상의 취급에 한정하고, 이동평균·추세 분리 같은 일반적 자료 처리는 다루지 않는다.
- 항생제 내성은 계획 문서가 이 권에 배정한 항목이라 4.1에 두되, 임상 이야기가 아니라 **선택압이 집단
  구성을 바꾸는 사례**로 다뤘다. 그래야 2.4(조건이 걸러 낸다)와 이어지고 이 책 안에서 겉돌지 않는다.

## 장 구성 (50페이지, 목차 1 + 본문 49)

```
1장 보이지 않는 다수        p2–9    PREREQUISITE  보이지 않는 다수·미생물의 갈래·보는 방법·사는 자리·자료의 성질
2장 무엇이 무엇을 하는가    p10–17  CORE          분해자·먹이와 산물·산소가 있고 없고·발효
3장 물질이 돌아오는 길      p18–24  CORE          물질순환·질소순환·탄소순환·끊긴 고리
4장 사람이 끼어든 자리      p25–32  COUNTERPOINT  약제 내성·농사와 흙·물의 부영양화·쌓인 탄소
5장 너른들 조사소의 한 계절 p33–40  EXAMPLE       조사 설계·시료 채취·값의 해석·기록 남기기
6장 잘못 읽기 쉬운 자리     p41–45  COUNTERPOINT  균에 대한 오해·효능 단정·측정의 한계
7장 결론: 도는 것이 남는다  p46–49  CONCLUSION    종합과 남는 물음
```

1장이 개념과 관측 한계를 함께 세운다. 이 분야에서 목록은 언제나 조사 방법의 목록이므로, 무엇을 아는지
말하기 전에 어떻게 아는지를 먼저 적어야 뒤의 서술이 부풀지 않는다.

이 책은 `COUNTERPOINT` 역할을 두 장에 걸쳐 쓴다. 4장은 사람의 개입이 순환을 어떻게 어긋나게 하는지,
6장은 사람의 인식이 이 대상을 어떻게 어긋나게 읽는지다. 앞의 것은 대상의 문제이고 뒤의 것은 서술의
문제라 한 장에 묶기 어려웠다.

이미지 6개: p7(방법마다 걸러지는 것이 다르다), p15(손가락 한 마디 안에서 갈린다), p21(들어오는 문과
나가는 문), p28(넣은 것이 다 남지는 않는다), p37(뜨는 순간 사라지는 것), p42(눈에 띄는 쪽과 큰 쪽).
여섯 도표에서 표기를 고정했다 — 산소가 닿는 자리는 밝은 색, 닿지 않는 자리는 어두운 색, 계에서
빠져나간 몫은 붉은 화살표, 죽었거나 확인되지 않은 것은 점선 윤곽이다. 생성 스크립트는
[`figures023.py`](./tools/figures023.py)다.

중복 그룹 1개: `invisible-majority` = [2, 46]. "눈에 보이는 것만으로는 생물을 헤아릴 수 없다"는 명제를
1.1에서 세우고 7.1에서 책을 지나온 언어로 재진술한다. 재진술 페이지(46)에는 선수를 두지 않았다. 짝(2)을
선수로 걸면 46을 고른 경로에 2가 반드시 따라와 중복 그룹 규칙을 어기기 때문이며, book-021·026·027과
같은 처리다.

## 선수 관계 설계

1.1(보이지 않는 다수)이 뿌리이고 1.2(미생물의 갈래)와 1.4(사는 자리)가 갈라진다. 2장은 1.2에서, 3장은
2.1(분해자)에서 시작한다. 4장은 두 갈래로 붙는다 — 4.1(약제 내성)은 2.4(발효)에, 4.2 이하는
3.2(질소순환)와 3.3(탄소순환)에 붙는다. 4.1이 발효에 붙는 것은 이 책의 논리 그대로다. 조건이 무엇을
남길지 정한다는 규칙을 발효에서 세우고, 약이 그 조건 노릇을 한다는 것이 4.1이다.

- 어느 후보 페이지도 선수 폐쇄가 8페이지를 넘지 않는다.
- 폐쇄 5페이지 이하인 후보 페이지가 여섯 개 장을 덮는다 (기준 3개 장).
- 후보 페이지 49개 전부가 폐쇄 15페이지 이하다 (기준 75%).

## 검증

`corpus_lib.validate_book()` → `validate_fragment.py` → `merge_fragments.py` → `validate_manifest.py`를
차례로 통과했다.

- 50페이지(48~72), 7개 장(최소 6), 내용 역할 5종 모두 사용
- `TEXT` 본문 43페이지가 345~437자(평균 378자, 합계 16,251자)로 전량 345자 이상
- `estimatedReadingSeconds`에 60초로 눌린 페이지가 하나도 없음
- `FRONT_MATTER`(목차)와 `aiRouteCandidatePage=false`가 정확히 일치
- 선수 관계가 후보 제외 페이지를 가리키지 않음, 위상 정렬로 50페이지 전체 방문
- PDF 페이지 50개, 텍스트 44개, 이미지 6개(p7,15,21,28,37,42) — `pdfcheck.py`로 확인
- PDF 실제 SHA-256이 manifest의 `pdfSha256`과 일치

초고는 44페이지·도표 다섯 장이어서 최소 48페이지와 권당 여섯 장 관례를 둘 다 못 맞췄다. 4·5·6장에
페이지 다섯을 더하고 5.2에 도표 한 장을 더해 맞췄다. 하한(345자)에 걸린 여섯 페이지는 문단을 새로 붙이지
않고 기존 마지막 문단을 늘려 고쳤다.

## 평가 케이스: 비소장·예산 5 시나리오

| 필드 | 값 |
| --- | --- |
| `caseId` | `case-book-023` |
| `purpose` | 이 책을 사지는 않았고, 죽은 것이 어떻게 다시 쓰이는 형태로 돌아가는지 그 큰 틀만 훑어보고 싶다 |
| `owned` / `maxAdditionalInk` / `depth` | `false` / `5` / `null` |
| `requiredConcepts` | 미생물의 갈래, 분해자, 물질순환, 질소순환 |
| `helpfulConcepts` | 보이지 않는 다수, 탄소순환, 먹이와 산물 |
| `referencePageNumbers` | 2, 4, 10, 18, 20 |
| `irrelevantPageNumbers` | 33~36(조사 설계와 시료 채취), 40(기록 보존) — 순환의 큰 틀만 보려는 이 목적과 무관하고, 이 케이스의 필수·도움 개념을 하나도 쓰지 않는다 |

이 케이스는 예산이 다섯뿐이라 정답 경로가 곧 한 줄기 사슬이다. 보이지 않는 다수(2) → 미생물의 갈래(4)
→ 분해자(10) → 물질순환(18) → 질소순환(20)으로, 각 절의 첫 페이지만 타고 내려간다. 다섯 자리로 이 책의
뼈대를 훑는 최단 경로이고, 실제로 이보다 짧은 경로로는 네 필수 개념을 덮을 수 없다.

도움 개념 셋 가운데 경로에 있는 것은 보이지 않는 다수뿐이다. 나머지 둘(탄소순환, 먹이와 산물)은 이
목적에 도움이 되지만 예산 안에 들어오지 못했다. 예산이 빠듯한 케이스에서 도움 개념이 남는 것은 자연스러운
결과이므로 대체 페이지에 3.3(탄소순환) 두 페이지를 넣어, 다른 배분을 고르면 그쪽을 볼 수 있게 했다.

## 재현 조건

1. `python3 build023.py` — 원고와 조각 생성 (PDF SHA 없이 실행하면 자리표시자를 넣는다)
2. `python3 figures023.py pdfbuild023` — 도표 6개 SVG 생성
3. Chrome Headless로 각 SVG를 794×1123 PNG로 렌더링
4. `python3 build_pdf_generic.py 23 7,15,21,28,37,42 pdfbuild023` — 조판 HTML 생성
5. Chrome Headless `--print-to-pdf`로 PDF 출력, `pdfcheck.py`로 구성 확인
6. PDF를 `fixtures/content/ai-route-v2/pdfs/`에 두고 SHA-256을 인자로 `build023.py` 재실행
7. `merge_fragments.py`로 정본에 병합

## 검수

- 여섯 도표를 PNG로 렌더링해 눈으로 확인했고 다섯을 고쳤다. p21은 두 문 화살표가 흙 안의 상자들을
  가로질렀고 굵기를 8로 준 탓에 화살촉만 커다랗게 보였다 — 문을 공기와 흙 사이의 빈 띠에만 그리고 굵기를
  줄였다. 같은 그림의 설명에 회전 방향을 반대로 적어 둔 것도 고쳤다. p15는 이름표를 밝은 띠 위에 얹어
  읽히지 않았고 산물 상자로 가는 화살표가 알갱이를 가로질렀다 — 이름표를 바깥으로 빼고 상자를 아래로
  옮겼다. p28은 막대 옆 이름이 두 막대의 경계와 어긋나 축처럼 보였고 화살표 하나가 몸통과 촉의 색이
  달랐다 — 범례로 바꾸고 화살촉 색을 맞췄다. p37은 도구 그림이 칸 제목을 가로질렀고, p42는 화살표가 칠하지
  않은 칸을 가리키고 아래 문구가 막대와 겹쳤다.
- 공개 가이드 주제와 비공개 분석 텍스트를 서로 다른 문장으로 적었고, 주제문에 숫자를 쓰지 않았다.
- 본문·도표·평가 데이터에 실존 인물·작품·단체·종명이 등장하지 않는다.

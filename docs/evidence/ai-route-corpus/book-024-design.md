# book-024 「빛의 속도가 만드는 시간과 인과」 설계

[과학 카테고리 계획](./science-category-plan.md)의 24번을 만든 근거다. 정책·검증 계약은
[AI 경로 콘텐츠 코퍼스](../../ai-route-content-corpus.md)를 따르고, 이 문서는 그 계약 안에서 내린
선택과 이유만 적는다.

## 대상 도서

- `bookId` 24, 카테고리 과학. 저자·소개는 `src/main/resources/demo/books.json`의 기존 값을 유지한다.
- 제목은 `ai-route-v2` manifest의 `books[].title`이 정본이며 이 문서의 제목과 같다.
- 실존 연구자·실험·기관을 옮기지 않는다. 무대는 가상의 「사슬재 신호 실험실」, 인물은 다온과 예찬이다.
  021의 유안·해든, 023의 하람·유섭, 026의 세연·진우, 027의 나린·도경과 겹치지 않는다.

## 개념 범위

계획 문서가 정한 범위(빛의 유한한 속도, 광년, 과거를 본다, 인과율과 동시성, 시간지연 기초)를 따르되
마지막 항목은 방향만 적고 들어가지 않았다. 이유는 아래 「4.3에서 멈춘 이유」에 적는다.

같은 카테고리에서 빛을 다루는 권이 셋이라 경계를 분명히 두었다.

- 021(분광)은 도착한 빛을 갈라 읽어 성분과 운동과 거리를 알아낸다. 024는 빛이 **도착하기까지의 시간**만
  본다. 그래서 이 책에는 스펙트럼도 흡수선도 없고, 021이 다룬 시차와 광도로 재는 거리도 다시 설명하지
  않는다. 1.4에서 이 경계를 본문에 직접 적어 두었다.
- 022(파동)는 파장·진동수·반사·굴절을 정의한다. 024에서 빛은 소식을 나르는 것일 뿐이라 파동의 요소가
  한 번도 나오지 않는다.
- 027(중력)과는 겹치지 않는다. 024가 다루는 것은 신호의 전달이지 힘이 아니다.

## 4.3에서 멈춘 이유

계획 문서는 시간지연 기초를 이 권에 넣었다. 본문에서는 4.3에 방향만 한 절로 적고 들어가지 않았다.

지연이 만드는 동시성·순서·인과 문제는 신호가 오는 데 시간이 든다는 사실 하나에서 전부 따라 나온다.
관측자의 운동 상태에 따라 시간이 다르게 잰다는 결론은 거기서 한 걸음 더 나가야 하고, 그 한 걸음에는
이 책이 쓰지 않은 도구가 필요하다. 도구를 들여오면 앞의 사슬이 끊기고, 끊긴 자리에서 독자는 결론만
받아들이게 된다.

대신 4.3에 한 절을 더 두어 **이 책의 결론이 그 뒤에서도 남는가**를 다뤘다. 측정값은 재는 쪽에 따라
달라지지만 사건 쌍이 어느 경우에 속하는가는 달라지지 않는다는 점이다. 이렇게 두면 이 책이 다음 이야기의
바닥 노릇을 하고 끝난다.

## 장 구성 (49페이지, 목차 1 + 본문 48)

```
1장 소식은 저절로 오지 않는다   p2–9    PREREQUISITE  소식의 지연·빠르기의 차이·재는 방법·범위의 경계
2장 본다는 것은 늦게 받는 것이다 p10–15  CORE          과거를 본다·거리와 시간·지연의 쓸모
3장 동시라는 말의 어려움         p16–22  CORE          동시의 문제·순서의 뒤바뀜·흔들리지 않는 것
4장 먼저와 나중을 가르는 것      p23–29  CORE          인과의 조건·영향의 범위·시간의 흐름
5장 사슬재 실험실의 나흘         p30–37  EXAMPLE       실험 계획·장치 준비·값의 해석·기록 남기기
6장 잘못 읽기 쉬운 자리          p38–45  COUNTERPOINT  지금이라는 오해·순서의 오해·빨라 보이는 것·측정의 한계
7장 결론                          p46–49  CONCLUSION    종합과 남는 물음
```

이 책은 한 줄로 이어진다. 지연이 있으면 동시가 흔들리고, 동시가 흔들리면 순서가 갈리고, 순서가 갈리면
인과의 조건이 나온다. 앞 절을 건너뛰면 다음 절이 서지 않으므로 선수 관계도 대체로 사슬 모양이다.

이미지 6개: p7(같은 사건, 다른 도착), p13(한 화면, 여러 때), p19(어디서 보느냐에 따라 갈린다),
p26(닿는 자리와 닿지 않는 자리), p33(두 번 재서 빼면 남는 것), p41(고칠 수 있는 어긋남과 없는 답).
여섯 도표에서 축 방향을 고정했다 — 가로 시간 축은 왼쪽이 이르고 오른쪽이 늦다, 세로 시간 축은 아래가
이르고 위가 늦다, 빛이 지나간 길은 굵은 실선, 소식이 닿지 못하는 자리는 점선이다. 생성 스크립트는
[`figures024.py`](./tools/figures024.py)다.

중복 그룹 1개: `news-takes-time` = [2, 46]. "무슨 일이 일어난 때와 그것을 아는 때가 다르다"는 명제를
1.1에서 세우고 7.1에서 책을 지나온 언어로 재진술한다. 재진술 페이지(46)에는 선수를 두지 않았다. 짝(2)을
선수로 걸면 46을 고른 경로에 2가 반드시 따라와 중복 그룹 규칙을 어기기 때문이며, book-021·023·026·027과
같은 처리다.

## 선수 관계 설계

1.1 → 1.2 → 1.3의 사슬을 세우고 거기서 셋이 갈라진다. 2장은 1.1에, 3장과 5장은 1.3에 붙는다. 3장은
3.1 → 3.2 → 3.3의 사슬이고 4장은 3.3에서 이어진다. 6장은 각 오해가 겨냥하는 절에 직접 붙였다 —
6.1은 3.1(동시의 문제), 6.2는 3.2(순서의 뒤바뀜), 6.3은 4.1(인과의 조건)이다.

- 어느 후보 페이지도 선수 폐쇄가 10페이지를 넘지 않는다.
- 폐쇄 5페이지 이하인 후보 페이지가 여섯 개 장을 덮는다 (기준 3개 장).
- 후보 페이지 48개 전부가 폐쇄 15페이지 이하다 (기준 75%).

3장과 4장이 한 사슬로 이어져 있어 4장 끝의 폐쇄가 이 책에서 가장 깊다. 그래도 10페이지에 그친 것은
2장과 5장을 그 사슬에서 떼어 1장에 직접 붙였기 때문이다.

## 검증

`corpus_lib.validate_book()` → `validate_fragment.py` → `merge_fragments.py` → `validate_manifest.py`를
차례로 통과했다.

- 49페이지(48~72), 7개 장(최소 6), 내용 역할 5종 모두 사용
- `TEXT` 본문 42페이지가 352~411자(평균 378자, 합계 15,878자)로 전량 345자 이상
- `estimatedReadingSeconds`에 60초로 눌린 페이지가 하나도 없음
- `FRONT_MATTER`(목차)와 `aiRouteCandidatePage=false`가 정확히 일치
- 선수 관계가 후보 제외 페이지를 가리키지 않음, 위상 정렬로 49페이지 전체 방문
- PDF 페이지 49개, 텍스트 43개, 이미지 6개(p7,13,19,26,33,41) — `pdfcheck.py`로 확인
- PDF 실제 SHA-256이 manifest의 `pdfSha256`과 일치

초고는 39페이지여서 최소 48페이지에 못 미쳤다. 절마다 두 번째 페이지가 필요한 자리를 골라 열 페이지를
더했다. 하한(345자)에 걸린 열한 페이지는 문단을 새로 붙이지 않고 마지막 문단을 늘려 고쳤다.

## 평가 케이스: 소장·BALANCED 시나리오

| 필드 | 값 |
| --- | --- |
| `caseId` | `case-book-024` |
| `purpose` | 이 책을 소장하고 있는데, 먼저와 나중이 왜 어떤 경우에는 흔들리고 어떤 경우에는 흔들리지 않는지를 제대로 알고 싶다 |
| `owned` / `maxAdditionalInk` / `depth` | `true` / `null` / `BALANCED` |
| `requiredConcepts` | 소식의 지연, 빠르기의 차이, 재는 방법, 동시의 문제, 순서의 뒤바뀜, 흔들리지 않는 것 |
| `helpfulConcepts` | 과거를 본다, 인과의 조건, 거리와 시간 |
| `referencePageNumbers` | 2, 4, 6, 16, 18, 21~24 |
| `irrelevantPageNumbers` | 32(장치 준비), 34~37(값의 해석과 기록) — 순서와 인과의 논리만 보려는 이 목적과 무관하고, 이 케이스의 필수·도움 개념을 하나도 쓰지 않는다 |

5.1 둘째 페이지(31)를 뺐다. 개념표에 `동시의 문제`가 달려 있고 본문도 두 시계를 맞추는 정확도를 정면으로 다룬다. 필수 개념을 다루는 페이지는 무관 페이지가 될 수 없어 5.4 둘째 페이지(37)로 바꿨다.

정답 경로는 선수 전이 폐쇄와 같고 9페이지여서 BALANCED 상한 10 안에 든다. 소식의 지연(2) →
빠르기의 차이(4) → 재는 방법(6)의 사슬을 타고 3장으로 들어가, 동시의 문제(16) → 순서의 뒤바뀜(18) →
흔들리지 않는 것(21, 22)을 지나 인과의 조건(23, 24)에 닿는다. 이 책이 한 줄로 이어진다는 구조가
경로에 그대로 남아 있다.

이 케이스는 필수 개념이 여섯으로 이 코퍼스에서 가장 많다. 목적 자체가 사슬의 끝을 묻는 것이라 앞 고리를
하나라도 빼면 답이 되지 않기 때문이다. 그래도 상한을 넘지 않은 것은 각 절의 첫 페이지만으로 사슬이
이어지도록 절을 나눠 두었기 때문이다.

## 재현 조건

1. `python3 build024.py` — 원고와 조각 생성 (PDF SHA 없이 실행하면 자리표시자를 넣는다)
2. `python3 figures024.py pdfbuild024` — 도표 6개 SVG 생성
3. Chrome Headless로 각 SVG를 794×1123 PNG로 렌더링
4. `python3 build_pdf_generic.py 24 7,13,19,26,33,41 pdfbuild024` — 조판 HTML 생성
5. Chrome Headless `--print-to-pdf`로 PDF 출력, `pdfcheck.py`로 구성 확인
6. PDF를 `fixtures/content/ai-route-v2/pdfs/`에 두고 SHA-256을 인자로 `build024.py` 재실행
7. `merge_fragments.py`로 정본에 병합

## 검수

- 여섯 도표를 PNG로 렌더링해 눈으로 확인했고 둘을 고쳤다. p13은 화살표의 도착점 계산이 엉켜 세 화살표가
  보는 사람이 아닌 엉뚱한 자리로 향했고 오른쪽 눈금 띠가 그림과 이어지지 않았다 — 화살표를 모두 사람 쪽으로
  모으고 눈금 띠를 양쪽 화살표로 바꿨다. p33은 먼 거울과 그 이름표가 화면 오른쪽 밖으로 나갔고 가까운
  거울 이름표가 부제와 겹쳤다 — 거리를 줄이고 두 줄을 아래로 내렸다.
- 도표 여섯 장의 `IMAGE` 페이지 본문을 렌더링 결과와 한 줄씩 맞춰 다시 썼다. AI 경로에서는 이 본문이
  그림을 대신하므로 어긋나면 그대로 오답이 된다. p33은 세 막대를 「두 막대 오른쪽에 세 번째 막대」로 적었으나
  실제로는 위아래로 놓여 있고, p41은 두 칸의 이름표를 왼쪽 여백에 적었다고 했으나 칸 안 모서리에 있으며 아래
  상자 문구도 달랐다.
- 1.2의 소리 속도 비유를 고쳤다. 「한 시간에 서울에서 부산쯤」은 실제의 사분의 일이다. 이 책은 정확한 값을
  다루지 않지만 값을 적은 이상 자릿수는 맞아야 한다.
- 3.2와 4.1의 낱말을 이 책 자신의 정의에 맞췄다. 이 책은 「보는 자리」를 거리에 따른 지연의 문제로 세워
  두고, 지연을 빼면 발생 순서가 되돌아온다고 3.2에서 말한다. 그런데 같은 3.2의 첫 문단이 「먼저 일어났는지가
  보는 자리에 따라 달라진다」고 적고, 4.1은 순서가 정해지지 않는 짝을 두고도 「보는 자리에 따라 앞뒤가
  달라진다」고 적어 3.3·6.2와 어긋났다. 3.2는 도착 순서로, 4.1은 「애초에 먼저와 나중이 없다」로 바꿨다.
- 공개 가이드 주제와 비공개 분석 텍스트를 서로 다른 문장으로 적었고, 주제문에 숫자를 쓰지 않았다.
- 본문·도표·평가 데이터에 실존 인물·작품·단체가 등장하지 않는다.
- 021이 다룬 스펙트럼·흡수선·시차·광도가 본문에 한 번도 나오지 않는지 낱말 단위로 확인했다. 파장은 두 번
  나오는데 둘 다 1.4에서 「이 책이 다루지 않는 것」으로 적은 자리다.

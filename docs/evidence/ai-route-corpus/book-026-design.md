# book-026 「생물발광의 화학과 생태」 설계

[과학 카테고리 계획](./science-category-plan.md)의 26번을 만든 근거다. 정책·검증 계약은
[AI 경로 콘텐츠 코퍼스](../../ai-route-content-corpus.md)를 따르고, 이 문서는 그 계약 안에서 내린
선택과 이유만 적는다.

## 대상 도서

- `bookId` 26, 카테고리 과학. 저자·소개는 `src/main/resources/demo/books.json`의 기존 값을 유지한다.
- 제목은 `ai-route-v2` manifest의 `books[].title`이 정본이며 이 문서의 제목과 같다.
- 실존 조사선·연구자·종 이름을 옮기지 않는다. 무대는 가상의 조사선 「물마루호」, 인물은 세연과 진우다.
  021의 유안·해든, 027의 나린·도경과 겹치지 않는다.

## 개념 범위

계획 문서가 정한 범위(생물발광 화학반응, 심해 환경, 발광의 생태적 기능)를 그대로 따른다. 같은
카테고리에 생물을 다루는 권이 셋이라 경계를 분명히 두었다.

- 023(미생물 생태)은 분해자와 물질순환, 발효, 항생제 내성을 다룬다. 026에서 발광 세균이 2.4에 나오지만
  **숙주 동물이 빌려 쓰는 빛**으로만 나오고 미생물 분류나 물질순환은 다루지 않는다.
- 028(식물 신호전달)은 식물이 주고받는 화학 신호를 다룬다. 026의 3장은 동물이 빛으로 주고받는 신호이며,
  신호 일반론을 세우지 않고 발광이라는 매체에 한정한다.
- 021(분광)이 다룬 파장·스펙트럼 읽기는 여기서 다시 설명하지 않는다. 4.2에서 색마다 물속 도달 거리가
  다르다는 사실을 쓰지만 파장을 정의하지 않고 색 이름으로만 쓴다.
- 2.3에서 색이 바뀌는 물질을 다루되 그 물질의 구조나 이름은 다루지 않는다. 이 책이 필요로 하는 것은
  "받은 빛을 더 긴 파장 쪽으로만 내놓는다"는 방향성 하나다.

## 장 구성 (50페이지, 목차 1 + 본문 49)

```
1장 어둠이라는 조건        p2–10   PREREQUISITE  어두운 세계·스스로 내는 빛·차가운 빛·발광 관찰법·관찰의 제약
2장 빛을 만드는 반응       p11–18  CORE          발광 물질과 효소·반응 조건·빛의 색·빌린 발광
3장 그 빛을 무엇에 쓰는가  p19–26  CORE          반대조명·짝 찾기·방어와 유인·쓰임의 다양성
4장 사는 자리가 정하는 것  p27–34  CORE          깊이와 빛·물의 여과·수직 이동·바닥 환경
5장 물마루호의 열흘        p35–41  EXAMPLE       조사 계획·채집·어둠 속 측정·기록 남기기
6장 잘못 읽기 쉬운 자리    p42–46  COUNTERPOINT  발광의 동일시·기능 단정·미지의 영역
7장 결론: 어둠에서 빛을 읽는다  p47–50  CONCLUSION  종합과 남는 물음
```

1장이 어둠이라는 조건과 관찰의 한계를 함께 세운다. 이 책에서 한계를 앞에 두는 것은 뒤에서 계속 쓰이기
때문이다 — 3장의 쓰임 판정도, 6장의 오해도 모두 "어떤 조건에서 얻은 기록인가"로 돌아온다.

2장이 화학, 3장이 기능, 4장이 환경이다. 셋의 순서는 의존 관계 그대로다. 무엇에 쓰는지 말하려면 어떤
빛인지 알아야 하고, 어느 쓰임이 성립하는지는 사는 자리가 정한다.

이미지 6개: p7(같은 밝기, 다른 값), p16(한 번 더 거치면 색이 바뀐다), p22(아래에서 보면 사라지고 옆에서
보면 보인다), p31(붉은 쪽부터 사라진다), p39(붉은 등 하나만 켠 방), p45(본 것과 말할 수 있는 것).
여섯 도표에서 색 쓰임을 고정했다 — 생물이 내는 빛은 청록, 색이 바뀐 빛은 초록, 열로 빠져나간 몫은
회갈색, 판정이 확정되지 않은 것은 점선 테두리다. 생성 스크립트는 [`figures026.py`](./tools/figures026.py)다.

중복 그룹 1개: `dark-is-the-default` = [2, 47]. "바다는 대부분 어둡고 그 어둠이 이 책 전체의 조건이다"는
명제를 1.1에서 세우고 7.1에서 책을 지나온 언어로 재진술한다. 재진술 페이지(47)에는 선수를 두지 않았다.
짝(2)을 선수로 걸면 47을 고른 경로에 2가 반드시 따라와 중복 그룹 규칙을 어기기 때문이며, book-021·027과
같은 처리다.

## 선수 관계 설계

1.1(어두운 세계)이 뿌리이고 여기서 셋이 갈라진다. 1.2(스스로 내는 빛)로 가는 줄기가 2장을 낳고,
3.1(반대조명)과 4.1(깊이와 빛)은 1.1에 직접 붙는다. 3장과 4장이 2장을 거치지 않는 것은 이 책의 구조
그대로다 — 빛을 무엇에 쓰는지와 어디서 쓰는지는 그 빛이 어떤 반응에서 나왔는지를 몰라도 읽을 수 있다.

- 어느 후보 페이지도 선수 폐쇄가 6페이지를 넘지 않는다. 이 책은 이 카테고리에서 폐쇄가 가장 얕다.
- 폐쇄 5페이지 이하인 후보 페이지가 일곱 개 장을 모두 덮는다 (기준 3개 장).
- 후보 페이지 49개 전부가 폐쇄 15페이지 이하다 (기준 75%).

폐쇄가 얕은 것은 의도한 결과다. 소장·DEEP 케이스는 상한이 15페이지인데, 폐쇄가 깊으면 선수만으로
상한이 차서 실제로 고를 수 있는 페이지가 줄어든다. 이 책은 여러 갈래를 얕게 두어 열다섯 자리를 내용으로
채울 수 있게 했다.

## 검증

`corpus_lib.validate_book()` → `validate_fragment.py` → `merge_fragments.py` → `validate_manifest.py`를
차례로 통과했다.

- 50페이지(48~72), 7개 장(최소 6), 내용 역할 5종 모두 사용
- `TEXT` 본문 43페이지가 354~479자(평균 396자, 합계 17,053자)로 전량 345자 이상
- `estimatedReadingSeconds`가 65~85초로 60초에 눌린 페이지가 하나도 없음
- `FRONT_MATTER`(목차)와 `aiRouteCandidatePage=false`가 정확히 일치
- 선수 관계가 후보 제외 페이지를 가리키지 않음, 위상 정렬로 50페이지 전체 방문
- PDF 페이지 50개, 텍스트 44개, 이미지 6개(p7,16,22,31,39,45) — `pdfcheck.py`로 확인
- PDF 실제 SHA-256이 manifest의 `pdfSha256`과 일치

이 책의 글자 수 구간(354~460자)은 021·027(415~550자)보다 낮다. 문단을 넷으로 유지하되 문장을 짧게 쓴
결과이고, 60초로 눌리는 페이지가 없으므로 정본 기준(345자)은 만족한다. 069~070에서 하던 대로 짧은
페이지에 마무리 문단을 일괄로 덧붙이지 않은 것은 의도적이다 — 예술 6권 검토에서 같은 형태의 마무리
문단을 여러 페이지에 붙였다가 문구가 겹쳐 도로 걷어낸 적이 있다. 길이를 맞추려고 같은 말을 되풀이하는
것보다 짧은 채로 두는 편이 낫다.

## 평가 케이스: 소장·DEEP 시나리오

| 필드 | 값 |
| --- | --- |
| `caseId` | `case-book-026` |
| `purpose` | 이 책을 소장하고 있는데, 심해 생물이 어떤 반응으로 빛을 만들고 그 빛을 무엇에 쓰는지를 제대로 익히고 싶다 |
| `owned` / `maxAdditionalInk` / `depth` | `true` / `null` / `DEEP` |
| `requiredConcepts` | 스스로 내는 빛, 발광 물질과 효소, 빛의 색, 반대조명, 짝 찾기 |
| `helpfulConcepts` | 어두운 세계, 반응 조건, 방어와 유인, 쓰임의 다양성 |
| `referencePageNumbers` | 2, 4, 5, 11~13, 15, 17, 19~21, 23~26 |
| `irrelevantPageNumbers` | 35~36(조사 계획), 37~38(채집 절차), 41(기록 보존) — 화학과 쓰임만 보려는 이 목적과 무관하고, 이 케이스의 필수·도움 개념을 하나도 쓰지 않는다 |

마지막 자리를 한 번 42로 적어 두었다. 기록 보존은 5.4이고 41이며, 42는 6.1의 오해 페이지로 `빛의 색`을 secondary로 달고 있어 무관 페이지가 될 수 없다. 41로 고쳤다.

정답 경로는 선수 전이 폐쇄와 같고 정확히 15페이지여서 DEEP 상한을 남김없이 쓴다. 어두운 세계(2)에서
스스로 내는 빛(4, 5)으로 가고, 거기서 반응 쪽 줄기(11~13, 15, 17)와 쓰임 쪽 줄기(19~21, 23~26)가 갈라진다.
두 줄기가 1.1에서 함께 나오되 서로를 거치지 않는다는 이 책의 구조가 경로에 그대로 남아 있다.

5장에서만 무관 페이지를 고른 것은 27번과 같은 이유다. 4장과 6장은 이 목적과 개념이 이어져 있어 무관으로
두면 답이 흐려진다. 실제로 무관한 것은 조사선의 진행 절차뿐이다.

## 재현 조건

1. `python3 build026.py` — 원고와 조각 생성 (PDF SHA 없이 실행하면 자리표시자를 넣는다)
2. `python3 figures026.py pdfbuild026` — 도표 6개 SVG 생성
3. Chrome Headless로 각 SVG를 794×1123 PNG로 렌더링
4. `python3 build_pdf_generic.py 26 7,16,22,31,39,45 pdfbuild026` — 조판 HTML 생성
5. Chrome Headless `--print-to-pdf`로 PDF 출력, `pdfcheck.py`로 구성 확인
6. PDF를 `fixtures/content/ai-route-v2/pdfs/`에 두고 SHA-256을 인자로 `build026.py` 재실행
7. `merge_fragments.py`로 정본에 병합

## 검수

- 7장을 다시 썼다. 아홉 권의 결론이 「구분은 넷이다 — 첫째…넷째」와 「답하지 못한 물음을 세 갈래로」와
  「장비 없이 확인할 수 있는 것이 있다」라는 같은 네 자리를 쓰고 있었다. 이 권의 7장은 관찰 하나에서 말할 수 있는 것과 없는 것을 갈라 적는 형태로 바꿨다.
- 5.4도 다시 썼다. 여섯 권이 「…이 끝나면 남는 것은 묶음이다」로 열고 「버린 회차도 남긴다 — 남은 것만 보면
  매끄러웠던 것처럼 보인다」로 이어지는 같은 틀이었다. 이 권에서 실제로 되살릴 수 없는 것이 무엇인지에서
  다시 출발하고, 빠진 회차가 결과를 **어느 쪽으로** 기울이는지까지 적었다.
- 여섯 도표를 PNG로 렌더링해 눈으로 확인했고 셋을 고쳤다. p7은 처음에 빛 막대의 길이를 광원마다 다르게
  그려 놓고 "같은 밝기에서 견준다"고 적어 그림과 설명이 어긋났다 — 빛 막대를 셋 다 같은 길이로 맞추고
  열 막대만 다르게 그렸다. p16은 파장 이동 방향을 화살표 하나에 가위표를 얹어 나타내 되는 쪽인지 안 되는
  쪽인지가 갈리지 않았다 — 되는 방향과 안 되는 방향을 각각 한 줄씩 그렸다. p39는 붉은 등의 빛이 작업대가
  아닌 빈 자리를 비추고 등 이름이 방 테두리에 걸렸다 — 이름 자리를 옮겼다.
- p39는 그 뒤 한 번 더 고쳤다. 이름은 옮겼으나 빛무리는 그대로여서 여전히 빈 바닥을 비추고 있었고, 도표
  안의 「작업대 쪽만 비춘다」는 문구와 어긋났다. 등을 왼쪽으로 옮기고 빛무리를 기울여 통과 두 장치에 닿게
  했다. 방의 왼쪽은 어두운 채로 남는다.
- 도표 여섯 장의 `IMAGE` 페이지 본문을 렌더링 결과와 한 줄씩 맞춰 다시 썼다. p7의 본문이 특히 문제였다.
  빛 막대를 같은 길이로 고친 뒤에도 본문은 「촛불의 빛 막대는 아주 짧게」라고 적고 있어, 고치기 전 그림을
  설명하고 있었다. 이 본문은 manifest에도 PDF에도 실리지 않는 원고 기록이지만, 도표를 다시
  만들거나 검토할 때 기대는 유일한 글 기록이라 그림만 고치고 두면 고친 뜻이 없다.
- p7의 막대 길이는 실제 비율이 아니다. 촛불과 생물발광의 실제 차이는 한 화면에 담기지 않아 차이의
  방향만 나타냈고, 그 사실을 도표 안에 적어 두었다.
- 공개 가이드 주제와 비공개 분석 텍스트를 서로 다른 문장으로 적었고, 주제문에 숫자를 쓰지 않았다.
- 본문·도표·평가 데이터에 실존 인물·작품·단체·종명이 등장하지 않는다.

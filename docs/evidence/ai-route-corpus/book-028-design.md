# book-028 「식물의 신호전달과 균근 네트워크」 설계

[과학 카테고리 계획](./science-category-plan.md)의 28번을 만든 근거다. 정책·검증 계약은
[AI 경로 콘텐츠 코퍼스](../../ai-route-content-corpus.md)를 따르고, 이 문서는 그 계약 안에서 내린
선택과 이유만 적는다.

## 대상 도서

- `bookId` 28, 카테고리 과학. 저자·소개는 `src/main/resources/demo/books.json`의 기존 값을 유지한다.
- 제목은 `ai-route-v2` manifest의 `books[].title`이 정본이며 이 문서의 제목과 같다.
- 실존 연구자·연구소·종명을 옮기지 않는다. 무대는 가상의 「너울숲 식물 조사소」, 인물은 다래와 윤슬이다.
  021·023·024·025·026·027의 인물과 겹치지 않는다.

## 개념 범위

계획 문서가 정한 범위(식물의 화학적 신호, 균근 네트워크, 식물호르몬)를 그대로 따른다.

- 023(미생물 생태)은 분해자와 물질순환, 발효, 약제 내성을 다룬다. 028의 4장에 균류가 나오지만 **식물과
  물질을 주고받는 상대**로만 나오고 분해자로서의 역할이나 물질순환은 다루지 않는다.
- 026(생물발광)은 동물이 빛으로 주고받는 신호를 다룬다. 028은 화학 물질에 한정하며 신호 일반론을 세우지
  않는다.
- 025(구름)가 다룬 대기 확산은 3.1에서 물질이 바람을 타고 퍼진다는 한 문장으로만 쓰고 원리를 다시 세우지
  않는다.

## 이 책이 특별히 조심한 자리

이 주제는 대중적으로 널리 옮겨 적히는 자리라 확인된 것보다 넓은 문장이 자주 만들어진다. 그래서 1.3에
**무엇을 신호라 부를 수 있는가**를 세 조건으로 먼저 못박고, 6장 전체를 그 기준으로 오해를 되짚는 데 썼다.

- 6.1은 방출을 이타적 의도로 읽는 오해를 다룬다. 확인된 것은 방출과 수신 반응까지이고 발신자의 의도는
  별개 물음이라는 점을 밝힌다.
- 6.2는 지하 물질 이동을 돌봄으로 읽는 오해를 세 단계로 나누어 짚는다. 건너간 것과 쓸모가 있었던 것,
  보낸 쪽이 보낸 것과 균류가 옮긴 것, 의도된 이동과 농도 차이를 따른 이동이다.
- 6.1의 둘째 페이지는 의인화된 어휘 자체를 다룬다. 본문에서 되도록 「내보낸다·받는다·달라진다」를 쓴 것이
  이 판단의 결과다.

## 장 구성 (49페이지, 목차 1 + 본문 48)

```
1장 움직이지 못하는 것의 사정  p2–9    PREREQUISITE  움직이지 못함·느끼는 방식·신호 물질·자료의 성질
2장 스스로를 움직이는 신호      p10–17  CORE          빛을 향한 굽음·위아래 감각·안으로 번지는 신호·성장 조절
3장 밖으로 내보내는 신호        p18–25  CORE          공기 중 신호·받는 쪽·내보내는 조건·뿌리에서 나가는 것
4장 뿌리에서 이어지는 것        p26–33  CORE          균근·지하 연결·오가는 것·균류의 몫
5장 너울숲 조사소의 두 해       p34–39  EXAMPLE       조사 설계·연결 확인·값의 해석·기록 남기기
6장 잘못 읽기 쉬운 자리         p40–45  COUNTERPOINT  의도의 오해·나눔의 오해·측정의 한계
7장 결론                         p46–49  CONCLUSION    종합과 남는 물음
```

1장이 조건과 기준을 함께 세운다. 2장은 몸 안에서, 3장은 공기로, 4장은 흙 밑으로 나아가며 신호가 닿는
범위가 점점 넓어진다. 3장과 4장의 대비가 이 책의 뼈대다 — 공기 길은 멀리 가되 주소가 없고, 흙 길은 좁게
가되 상대가 정해져 있다.

이미지 6개: p7(셋이 다 있어야 신호다), p13(같은 쪽에 몰리고 반대로 굽는다), p21(내보낸 쪽은 받는 쪽을
고르지 못한다), p29(흙 밑에서 이어져 있다), p37(흙은 똑같이 건드리고 구멍만 다르게), p43(건너갔다는
관찰에서 갈라지는 길). 여섯 도표에서 표기를 고정했다 — 식물은 초록, 균류의 실은 흙빛 가는 선, 확인된
것은 실선 테두리, 확인되지 않은 것은 점선 테두리와 물음표다. 생성 스크립트는
[`figures028.py`](./tools/figures028.py)다.

중복 그룹 1개: `rooted-but-responsive` = [2, 46]. "자리를 옮길 수 없다는 조건이 식물의 모든 대응을
정한다"는 명제를 1.1에서 세우고 7.1에서 책을 지나온 언어로 재진술한다. 재진술 페이지(46)에는 선수를 두지
않았다. 짝(2)을 선수로 걸면 46을 고른 경로에 2가 반드시 따라와 중복 그룹 규칙을 어기기 때문이며,
book-021·023·024·025·026·027과 같은 처리다.

## 선수 관계 설계

1.1 → 1.2 → 1.3의 사슬을 세우고 1.3에서 2장 뒷부분과 3장이 갈라진다. 3장은 3.1 → 3.2 → 3.3 → 3.4의
사슬이고 4장이 3.4에서 이어진다. 뿌리에서 물질을 내보낸다는 사실을 세운 뒤라야 균류가 그것에 이끌려 온다는
4.1이 성립하기 때문이다.

- 어느 후보 페이지도 선수 폐쇄가 13페이지를 넘지 않는다. 3장과 4장이 한 사슬로 이어져 4장 끝이 가장 깊다.
- 폐쇄 5페이지 이하인 후보 페이지가 여섯 개 장을 덮는다 (기준 3개 장).
- 후보 페이지 48개 전부가 폐쇄 15페이지 이하다 (기준 75%).

## 검증

`corpus_lib.validate_book()` → `validate_fragment.py` → `merge_fragments.py` → `validate_manifest.py`를
차례로 통과했다.

- 49페이지(48~72), 7개 장(최소 6), 내용 역할 5종 모두 사용
- `TEXT` 본문 42페이지가 348~422자(평균 379자, 합계 15,912자)로 전량 345자 이상
- `estimatedReadingSeconds`에 60초로 눌린 페이지가 하나도 없음
- `FRONT_MATTER`(목차)와 `aiRouteCandidatePage=false`가 정확히 일치
- 선수 관계가 후보 제외 페이지를 가리키지 않음, 위상 정렬로 49페이지 전체 방문
- PDF 페이지 49개, 텍스트 43개, 이미지 6개(p7,13,21,29,37,43) — `pdfcheck.py`로 확인
- PDF 실제 SHA-256이 manifest의 `pdfSha256`과 일치

초고는 35페이지·도표 다섯 장이어서 최소 48페이지와 권당 여섯 장 관례를 둘 다 못 맞췄다. 절마다 두 번째
페이지가 필요한 자리를 골라 열세 페이지를 더하고 5.2에 도표 한 장을 더했다. 하한(345자)에 걸린
페이지에는 `EXTRA` 문단을 더했고, 025에서와 같이 페이지마다 다른 내용을 담았다.

## 평가 케이스: 소장·QUICK 시나리오

| 필드 | 값 |
| --- | --- |
| `caseId` | `case-book-028` |
| `purpose` | 이 책을 소장하고 있는데, 식물이 무언가를 내보내 이웃에게 닿는다는 이야기의 뼈대만 짧게 훑고 싶다 |
| `owned` / `maxAdditionalInk` / `depth` | `true` / `null` / `QUICK` |
| `requiredConcepts` | 움직이지 못함, 느끼는 방식, 신호 물질, 공기 중 신호, 받는 쪽 |
| `helpfulConcepts` | 안으로 번지는 신호, 내보내는 조건, 균근 |
| `referencePageNumbers` | 2, 4, 6, 18, 20 |
| `irrelevantPageNumbers` | 34~35·37(조사 설계와 연결 확인), 38~39(값의 해석과 기록) — 뼈대만 훑으려는 이 목적과 무관하고, 이 케이스의 필수·도움 개념을 하나도 쓰지 않는다 |

5.2 둘째 페이지(36)를 뺐다. 개념표에 도움 개념인 `균근`이 달려 있어 무관 페이지가 될 수 없다. 같은 절의 셋째 페이지(37)로 바꿨다.

QUICK 상한은 다섯 페이지다. 정답 경로가 정확히 다섯이 되도록 각 절의 첫 페이지만으로 사슬이 이어지게
절을 나눴다. 움직이지 못함(2) → 느끼는 방식(4) → 신호 물질(6)의 사슬을 타고 공기 중 신호(18)와 받는
쪽(20)에 닿는다. 다섯 자리로 이 책의 제목이 말하는 두 가지 가운데 앞의 것(신호전달)을 훑는 최단
경로이고, 뒤의 것(균근)은 상한 안에 들어오지 않는다.

그래서 균근은 도움 개념에만 둔다. 목적 자체가 뼈대만 훑는 것이라 이 배제는 케이스의 결함이 아니라
QUICK이라는 시나리오가 뜻하는 바다.

대체 페이지는 처음에 3.3·3.4·4.1의 첫 페이지를 넣었다가 바꿨다. 정답 경로가 이미 상한을 꽉 채운 다섯
페이지여서, 대체 페이지도 선수 폐쇄가 다섯 이하여야 정답의 한 자리를 대신해 고를 수 있다. 그 셋은 폐쇄가
다섯을 넘어 어느 배분으로도 닿지 못하는 죽은 값이었다. 폐쇄가 각각 2·3·4·4·5인 자리로 바꿨다.

6장을 무관 페이지에 넣지 않은 것은 의도적이다. 6장은 3장에서 다룬 내용을 어떻게 읽어야 하는지를 다루므로
이 목적과 정면으로 관련된다. 실제로 무관한 것은 조사소의 진행 절차뿐이다.

## 재현 조건

1. `python3 build028.py` — 원고와 조각 생성 (PDF SHA 없이 실행하면 자리표시자를 넣는다)
2. `python3 figures028.py pdfbuild028` — 도표 6개 SVG 생성
3. Chrome Headless로 각 SVG를 794×1123 PNG로 렌더링
4. `python3 build_pdf_generic.py 28 7,13,21,29,37,43 pdfbuild028` — 조판 HTML 생성
5. Chrome Headless `--print-to-pdf`로 PDF 출력, `pdfcheck.py`로 구성 확인
6. PDF를 `fixtures/content/ai-route-v2/pdfs/`에 두고 SHA-256을 인자로 `build028.py` 재실행
7. `merge_fragments.py`로 정본에 병합

정답 경로·무관 페이지·대체 페이지는 025와 같이 절 이름에서 페이지 번호를 찾아 `main()`에서 계산한다.

## 검수

- 여섯 도표를 PNG로 렌더링해 눈으로 확인했고 넷을 고쳤다. p43은 세 상자가 서로 겹치고 문장이 글자 수로
  잘려 어색한 자리에서 끊겼다 — 상자를 벌리고 줄을 직접 나눴다. p29는 균사가 흩어진 조각으로만 보여 이어진
  그물로 읽히지 않았고 두 이름표가 겹쳤다 — 긴 물결선으로 다시 그리고 이름표를 뿌리와 그물 사이 빈 띠로
  옮겼다. p37은 이름표가 칸 테두리에 걸렸고 도표 안 부제가 제목과 같은 문장이었다. p21은 같은 이름표가 두
  번 나왔다.
- 5장의 가림막 설명이 절마다 달랐던 것을 하나로 맞췄다. 5.1은 「뿌리와 균사를 막되 물은 통과시키는 것」과
  「아예 다 막는 것」 두 종류라고 적었는데, 5.2와 p37 도표는 「구멍이 촘촘한 막」과 「성긴 막」이고 성긴
  막은 균사가 지나간다고 그린다. 앞의 설명에는 균사가 지나가는 대조가 아예 없어 5.2의 판정 논리가
  성립하지 않는다. 셋 다 도표에 맞춰 구멍 크기로 갈리는 두 종류로 통일했다.
- 도표 여섯 장의 `IMAGE` 페이지 본문을 렌더링 결과와 한 줄씩 맞춰 다시 썼다. p13은 도표가 줄기와 뿌리를
  띠로 그리고 중력 축을 왼쪽에 세웠는데 본문은 세포 모양으로 설명하고 있었고, p21은 세 화살표가 가리키는
  대상의 자리가 본문과 달랐다.
- 공개 가이드 주제와 비공개 분석 텍스트를 서로 다른 문장으로 적었고, 주제문에 숫자를 쓰지 않았다.
- 본문·도표·평가 데이터에 실존 인물·작품·단체·종명이 등장하지 않는다.

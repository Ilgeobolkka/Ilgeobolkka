# book-029 「기후 데이터를 읽는 방법」 설계

[과학 카테고리 계획](./science-category-plan.md)의 29번을 만든 근거다. 정책·검증 계약은
[AI 경로 콘텐츠 코퍼스](../../ai-route-content-corpus.md)를 따르고, 이 문서는 그 계약 안에서 내린
선택과 이유만 적는다.

## 대상 도서

- `bookId` 29, 카테고리 과학. 저자·소개는 `src/main/resources/demo/books.json`의 기존 값을 유지한다.
- 제목은 `ai-route-v2` manifest의 `books[].title`이 정본이며 이 문서의 제목과 같다.
- 실존 기관·연구자·자료를 옮기지 않는다. 무대는 가상의 「돌미르 기후자료실」, 인물은 예린과 태오다.
  021·023·024·025·026·027·028의 인물과 겹치지 않는다.

## 개념 범위

경계가 둘이라 이 권은 다른 권보다 범위가 좁다.

- 계획 문서의 「29번의 범위 조정」대로 **상관과 인과, 표본편향은 경제 [book-050](./book-050-design.md)이
  한 권 전체로 다뤘으므로** 여기서 다시 세우지 않는다. 그래서 이 책에는 교란변수도 역인과도 나오지 않고,
  4장의 편중 논의도 관측망의 공간 배치라는 구체적 문제에 한정한다.
- 025(구름)는 대기 현상 자체의 물리를 다룬다. 029는 **자료를 다루는 법**만 다루므로 응결도 강수 과정도
  나오지 않는다. 3장에서 기온과 강수를 견주지만 물리가 아니라 변동 폭의 차이로만 다룬다.
- 024(빛의 속도)가 다룬 측정과 규약 문제와도 겹치지 않는다. 029의 선택은 규약이 아니라 처리 방식의
  선택이다.

## 장 구성 (48페이지, 목차 1 + 본문 47)

```
1장 값 하나로는 아무것도 말하지 못한다  p2–9    PREREQUISITE  값 하나의 한계·평균의 성질·기준 기간·자료의 출처
2장 흔들림과 흐름을 가르는 일           p10–17  CORE          흔들림과 흐름·이동평균·평활의 대가·방향의 판정
3장 날씨와 기후를 가르는 기준           p18–23  CORE          날씨와 기후·분포의 이동·필요한 기간
4장 자료가 만들어진 사정                 p24–31  COUNTERPOINT  지점의 배치·둘레의 변화·방법의 변화·빈자리 채우기
5장 돌미르 자료실의 한 해                p32–37  EXAMPLE       정리 계획·지점 선별·값의 처리·함께 내는 것
6장 잘못 읽기 쉬운 자리                  p38–44  COUNTERPOINT  두 시점의 오해·한 지점의 오해·보정의 오해·측정의 한계
7장 결론                                  p45–48  CONCLUSION    종합과 남는 물음
```

이 책은 `COUNTERPOINT`를 두 장에 걸쳐 쓴다. 4장은 자료가 만들어지는 과정에서 생기는 문제이고 6장은 그
자료를 읽는 쪽에서 생기는 문제다. 앞은 만드는 쪽의 문제이고 뒤는 읽는 쪽의 문제라 한 장에 묶기 어려웠다.
book-023과 같은 이유의 같은 처리다.

이미지 6개: p7(기준을 옮기면 그림이 달라진다), p13(몇 해로 묶느냐가 그림을 정한다), p21(가운데는 조금,
끝은 크게), p29(이웃과 견주면 튄 자리가 보인다), p37(곡선 하나 뒤에 붙는 것들), p41(고르는 방식이 결론을
만든다). 여섯 도표에서 표기를 고정했다 — 원래 값은 가는 회색 선, 눌러 만든 곡선은 짙은 파랑 굵은 선,
기준선은 주황 점선, 잘못 읽기 쉬운 자리는 붉은색이다.

여섯 도표가 **같은 계열 하나**를 쓴다. 그림마다 다른 자료를 쓰면 도표끼리 견주는 뜻이 흐려지고, 이 책의
주제 자체가 같은 자료가 처리에 따라 다르게 보인다는 것이기 때문이다. 생성 스크립트는
[`figures029.py`](./tools/figures029.py)다.

중복 그룹 1개: `one-number-says-nothing` = [2, 45]. "값 하나로는 아무것도 말할 수 없다"는 명제를 1.1에서
세우고 7.1에서 책을 지나온 언어로 재진술한다. 재진술 페이지(45)에는 선수를 두지 않았다. 짝(2)을 선수로
걸면 45를 고른 경로에 2가 반드시 따라와 중복 그룹 규칙을 어기기 때문이며, 앞선 여섯 권과 같은 처리다.

## 선수 관계 설계

1.1 → 1.2에서 셋이 갈라진다. 1.3(기준 기간), 2.1(흔들림과 흐름), 그리고 3.1(날씨와 기후)이다. 4장과
5장은 1.4(자료의 출처)에 붙는다. 6장은 각 오해가 겨냥하는 절에 직접 붙였다 — 6.1은 2.1, 6.2는 4.1,
6.3은 4.3, 6.4는 4.4다.

- 어느 후보 페이지도 선수 폐쇄가 8페이지를 넘지 않는다.
- 폐쇄 5페이지 이하인 후보 페이지가 일곱 개 장을 모두 덮는다 (기준 3개 장).
- 후보 페이지 47개 전부가 폐쇄 15페이지 이하다 (기준 75%).

## 검증

`corpus_lib.validate_book()` → `validate_fragment.py` → `merge_fragments.py` → `validate_manifest.py`를
차례로 통과했다.

- 48페이지(48~72), 7개 장(최소 6), 내용 역할 5종 모두 사용
- `TEXT` 본문 41페이지가 345~428자(평균 381자, 합계 15,640자)로 전량 345자 이상
- `estimatedReadingSeconds`에 60초로 눌린 페이지가 하나도 없음
- `FRONT_MATTER`(목차)와 `aiRouteCandidatePage=false`가 정확히 일치
- 선수 관계가 후보 제외 페이지를 가리키지 않음, 위상 정렬로 48페이지 전체 방문
- PDF 페이지 48개, 텍스트 42개, 이미지 6개(p7,13,21,29,37,41) — `pdfcheck.py`로 확인
- PDF 실제 SHA-256이 manifest의 `pdfSha256`과 일치

초고는 35페이지·도표 다섯 장이었다. 절마다 두 번째 페이지가 필요한 자리를 골라 열세 페이지를 더하고
5.4에 도표 한 장을 더했다. 하한(345자)에 걸린 서른 페이지에는 `EXTRA` 문단을 더했고, 025·028과 같이
페이지마다 다른 내용을 담았다.

## 평가 케이스: 소장·BALANCED 시나리오

| 필드 | 값 |
| --- | --- |
| `caseId` | `case-book-029` |
| `purpose` | 이 책을 소장하고 있는데, 오르내리는 값에서 방향을 읽어 내는 방법과 그 방법이 감추는 것을 제대로 익히고 싶다 |
| `owned` / `maxAdditionalInk` / `depth` | `true` / `null` / `BALANCED` |
| `requiredConcepts` | 값 하나의 한계, 평균의 성질, 흔들림과 흐름, 이동평균, 평활의 대가, 방향의 판정 |
| `helpfulConcepts` | 기준 기간, 날씨와 기후, 두 시점의 오해 |
| `referencePageNumbers` | 2, 4, 10, 12, 14~16 |
| `irrelevantPageNumbers` | 32~36(자료실의 진행 절차) — 방법과 그 한계만 보려는 이 목적과 무관하고, 이 케이스의 필수·도움 개념을 하나도 쓰지 않는다 |

정답 경로는 선수 전이 폐쇄와 같고 7페이지여서 BALANCED 상한 10 안에 든다. 값 하나의 한계(2) →
평균의 성질(4)에서 2장으로 들어가 흔들림과 흐름(10) → 이동평균(12) → 평활의 대가(14, 15) →
방향의 판정(16)으로 이어진다. 목적이 「방법과 그 방법이 감추는 것」이라 2.2와 2.3이 짝으로 들어가야
하고, 실제로 경로가 그 짝을 함께 담는다.

도움 개념 셋은 모두 경로 밖이다. 기준 기간(1.3)과 날씨와 기후(3.1)는 이 목적에 도움이 되지만 2장의
사슬과는 다른 갈래이고, 두 시점의 오해(6.1)는 2장에서 세운 내용을 적용하는 자리다. 셋 모두 대체 페이지에
넣어 다른 배분을 고르면 볼 수 있게 했다.

4장과 6장을 무관 페이지에 넣지 않은 것은 의도적이다. 둘 다 「그 방법이 감추는 것」과 정면으로 이어진다.
실제로 무관한 것은 자료실의 진행 절차뿐이다.

## 재현 조건

1. `python3 build029.py` — 원고와 조각 생성 (PDF SHA 없이 실행하면 자리표시자를 넣는다)
2. `python3 figures029.py pdfbuild029` — 도표 6개 SVG 생성
3. Chrome Headless로 각 SVG를 794×1123 PNG로 렌더링
4. `python3 build_pdf_generic.py 29 7,13,21,29,37,41 pdfbuild029` — 조판 HTML 생성
5. Chrome Headless `--print-to-pdf`로 PDF 출력, `pdfcheck.py`로 구성 확인
6. PDF를 `fixtures/content/ai-route-v2/pdfs/`에 두고 SHA-256을 인자로 `build029.py` 재실행
7. `merge_fragments.py`로 정본에 병합

정답 경로·무관 페이지·대체 페이지는 025·028과 같이 절 이름에서 페이지 번호를 찾아 `main()`에서 계산한다.

## 검수

- 여섯 도표를 PNG로 렌더링해 눈으로 확인했고 넷을 고쳤다. p13은 양쪽 끝의 그늘진 자리에 「끝은 만들 수
  없다」고만 적었는데 그 자리에도 다섯 해 곡선은 그려져 있어 설명과 그림이 어긋났다 — 「삼십 해 곡선은」을
  앞에 붙였다. p21은 끝자락 넓이 비교가 곡선 아래 색칠만으로는 몇 배인지 읽히지 않았고 이름표가 겹쳤다 —
  세로 막대로 다시 그리고 자리를 벌렸다. p29는 두 지점 선이 어긋난 자리 앞에서 완전히 포개져 비현실적으로
  보였고 이름표가 위 그래프 설명과 겹쳤다 — 이웃 지점에 작은 차이를 섞고 아래 그래프를 내렸다. p41은
  「자료는 하나다」가 아래 그래프의 축 이름과 겹쳤다.
- 공개 가이드 주제와 비공개 분석 텍스트를 서로 다른 문장으로 적었고, 주제문에 숫자를 쓰지 않았다.
- 본문·도표·평가 데이터에 실존 인물·기관·자료가 등장하지 않는다.
- 경제 050이 다룬 상관·인과·교란변수·표본편향·역인과·생존편향이 본문에 한 번도 나오지 않는지 낱말 단위로
  확인했다.

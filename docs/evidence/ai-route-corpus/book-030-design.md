# book-030 「달의 위상과 조석고정」 설계

[과학 카테고리 계획](./science-category-plan.md)의 30번을 만든 근거다. 정책·검증 계약은
[AI 경로 콘텐츠 코퍼스](../../ai-route-content-corpus.md)를 따르고, 이 문서는 그 계약 안에서 내린
선택과 이유만 적는다. 과학 카테고리의 마지막 권이다.

## 대상 도서

- `bookId` 30, 카테고리 과학. 저자·소개는 `src/main/resources/demo/books.json`의 기존 값을 유지한다.
- 제목은 `ai-route-v2` manifest의 `books[].title`이 정본이며 이 문서의 제목과 같다.
- 실존 관측소·연구자·탐사를 옮기지 않는다. 무대는 가상의 「달여울 관측 모임」, 인물은 소루와 한별이다.
  021·023·024·025·026·027·028·029의 인물과 겹치지 않는다.

## 개념 범위

계획 문서가 정한 대로 **027이 세운 규칙을 달이라는 한 사례에 적용하되 027에서 다루지 않은 달 고유의
현상**만 다룬다.

- 027(중력과 운동)이 만유인력의 크기를 정하는 규칙, 궤도운동, 붙잡히는 조건을 세웠다. 030은 그 규칙을
  다시 세우지 않는다. 6.3에서 달에 공기가 없는 까닭을 다루되 붙잡히는 조건 자체는 027의 몫으로 두고
  결과만 쓴다고 본문에 적었다.
- 022(파동)가 정의한 반사·굴절은 다시 설명하지 않는다. 4.3에서 지구 공기가 빛을 휘어 들여보낸다고
  쓰되 굴절의 원리를 세우지 않는다.
- 025(구름)가 다룬 대기의 물리와도 겹치지 않는다. 030에서 공기는 있고 없음의 문제로만 나온다.

## 이 책의 뼈대

이 권은 서로 다른 두 물음을 **갈라 다루는 것** 자체를 구조로 삼았다. 위상(모양이 달라지는 일)과
조석고정(한쪽만 보이는 일)은 자주 섞여 설명되는데, 둘은 원인이 전혀 다르다.

- 2장이 위상, 3장이 조석고정이다. 두 장은 서로를 선수로 두지 않고 각각 1장에 붙는다.
- 1.2를 「어디서 보느냐가 정한다」로 두어 세 시점(바깥·지구·달)을 오가는 것을 이 책의 기본 도구로
  삼았다. 6장의 오해 대부분이 이 자리를 빠뜨린 데서 나온다는 것을 본문에 적었다.
- 7.1에서 두 물음이 「보는 자리」라는 하나의 답으로 모인다.

## 장 구성 (49페이지, 목차 1 + 본문 48)

```
1장 늘 같은 얼굴          p2–7    PREREQUISITE  같은 얼굴·보는 자리·빛과 그림자
2장 모양이 달라지는 까닭  p8–14   CORE          위상의 원리·밝기의 성질·안 보이는 날
3장 한쪽만 보이는 까닭    p15–20  CORE          도는 주기·조석고정·느려지는 자전
4장 가려지는 날           p21–29  CORE          가림 현상·기울어진 길·붉어지는 달·크기의 우연
5장 달여울 모임의 한 달   p30–36  EXAMPLE       관측 계획·빠진 날·기록 정리·기록 남기기
6장 잘못 읽기 쉬운 자리   p37–45  COUNTERPOINT  그림자 오해·뒷면 오해·공기 없음·관측의 한계
7장 결론                   p46–49  CONCLUSION    종합과 남는 물음
```

이미지 6개: p5(같은 순간, 세 가지 모습), p10(배치가 모양을 정한다), p18(앞서 나가면 되돌려진다),
p25(기울어 있어 대개 빗나간다), p36(한 달을 늘어놓으면), p40(밝은 절반과 보이는 절반은 다르다).

여섯 도표에서 표기를 고정했다 — 햇빛은 언제나 왼쪽에서 오는 평행한 주황 화살표이고, 달의 밝은 절반은
어느 그림에서나 왼쪽이다. 이 고정이 이 책에서는 표기 관례 이상의 뜻을 가진다. 위상이 달의 변화가 아니라
배치의 변화라는 것이 이 책의 핵심 주장이므로, 그림마다 밝은 쪽을 바꾸면 그 주장이 그림에서 무너진다.
생성 스크립트는 [`figures030.py`](./tools/figures030.py)다.

중복 그룹 1개: `always-the-same-face` = [2, 46]. "달은 늘 같은 쪽을 보인다"는 관찰을 1.1에서 세우고
7.1에서 책을 지나온 언어로 재진술한다. 재진술 페이지(46)에는 선수를 두지 않았다. 짝(2)을 선수로 걸면
46을 고른 경로에 2가 반드시 따라와 중복 그룹 규칙을 어기기 때문이며, 앞선 일곱 권과 같은 처리다.

## 선수 관계 설계

1.1에서 두 갈래가 갈라진다. 1.2 → 1.3 → 2장(위상)과 1.1 → 3.1(조석고정)이다. 두 갈래가 서로를 거치지
않는 것이 이 책의 구조 그대로다. 4장은 2.1에 붙고 5장은 1.2에 붙는다. 6장은 각 오해가 겨냥하는 절에
직접 붙였다.

- 어느 후보 페이지도 선수 폐쇄가 8페이지를 넘지 않는다.
- 폐쇄 5페이지 이하인 후보 페이지가 일곱 개 장을 모두 덮는다 (기준 3개 장).
- 후보 페이지 48개 전부가 폐쇄 15페이지 이하다 (기준 75%).

## 검증

`corpus_lib.validate_book()` → `validate_fragment.py` → `merge_fragments.py` → `validate_manifest.py`를
차례로 통과했다.

- 49페이지(48~72), 7개 장(최소 6), 내용 역할 5종 모두 사용
- `TEXT` 본문 42페이지가 346~419자(평균 377자, 합계 15,826자)로 전량 345자 이상
- `estimatedReadingSeconds`에 60초로 눌린 페이지가 하나도 없음
- `FRONT_MATTER`(목차)와 `aiRouteCandidatePage=false`가 정확히 일치
- 선수 관계가 후보 제외 페이지를 가리키지 않음, 위상 정렬로 49페이지 전체 방문
- PDF 페이지 49개, 텍스트 43개, 이미지 6개(p5,10,18,25,36,40) — `pdfcheck.py`로 확인
- PDF 실제 SHA-256이 manifest의 `pdfSha256`과 일치

초고는 32페이지·도표 다섯 장이었다. 절마다 두 번째 페이지가 필요한 자리를 골라 열여섯 페이지를 더하고
4.2에 도표 한 장을 더했다. 하한(345자)에 걸린 페이지에는 `EXTRA` 문단을 더했고, 025·028·029와 같이
페이지마다 다른 내용을 담았다.

## 평가 케이스: 비소장·예산 10 시나리오

| 필드 | 값 |
| --- | --- |
| `caseId` | `case-book-030` |
| `purpose` | 이 책을 사지는 않았고, 달의 모양이 왜 달라지는지와 왜 한쪽만 보이는지 두 가지를 갈라서 이해하고 싶다 |
| `owned` / `maxAdditionalInk` / `depth` | `false` / `10` / `null` |
| `requiredConcepts` | 같은 얼굴, 보는 자리, 빛과 그림자, 위상의 원리, 도는 주기, 조석고정 |
| `helpfulConcepts` | 밝기의 성질, 가림 현상, 그림자 오해 |
| `referencePageNumbers` | 2, 4, 6, 8, 9, 15, 17 |
| `irrelevantPageNumbers` | 30~34(모임의 진행 절차) — 두 물음을 갈라 이해하려는 이 목적과 무관하고, 이 케이스의 필수·도움 개념을 하나도 쓰지 않는다 |

무관 페이지를 5장 전체에서 5.2와 5.4로 줄였다. 5.1의 첫 페이지는 무늬가 늘 같은 자리에 있는지 확인하는
항목을 세워 `같은 얼굴`을 직접 다루고, 5.3의 둘째 페이지는 새벽에 뜬 달의 방향이 저녁과 다르다는 이야기라
`보는 자리`를 다룬다. 둘 다 이 케이스의 필수 개념이다. 절을 반으로 가르지 않으려고 두 절을 통째로 뺐다.
같은 자리에서 5.1 둘째 페이지의 `같은 얼굴` 태그도 고쳤다. 여럿이 그린 그림의 버릇을 맞추는 이야기여서
`기록 정리`가 맞다.

목적이 「두 가지를 갈라서」이므로 정답 경로가 두 갈래를 모두 담아야 한다. 같은 얼굴(2)에서 갈라져
한쪽은 보는 자리(4) → 빛과 그림자(6) → 위상의 원리(8, 9)로, 다른 쪽은 도는 주기(15) → 조석고정(17)로
간다. 두 갈래가 1.1에서만 만나고 서로를 거치지 않는다는 이 책의 구조가 경로 모양에 그대로 남아 있다.

예산 10에 경로가 7이라 세 자리가 남는다. 목적이 두 갈래를 갈라 보는 것이라 어느 한쪽을 더 깊이 파는
쪽으로 남은 자리를 쓰기보다, 대체 페이지에 두 갈래의 이어지는 절(2.2·2.3·3.3)과 4장·6장의 첫 페이지를
두어 어느 쪽으로든 갈 수 있게 했다.

## 재현 조건

1. `python3 build030.py` — 원고와 조각 생성 (PDF SHA 없이 실행하면 자리표시자를 넣는다)
2. `python3 figures030.py pdfbuild030` — 도표 6개 SVG 생성
3. Chrome Headless로 각 SVG를 794×1123 PNG로 렌더링
4. `python3 build_pdf_generic.py 30 5,10,18,25,36,40 pdfbuild030` — 조판 HTML 생성
5. Chrome Headless `--print-to-pdf`로 PDF 출력, `pdfcheck.py`로 구성 확인
6. PDF를 `fixtures/content/ai-route-v2/pdfs/`에 두고 SHA-256을 인자로 `build030.py` 재실행
7. `merge_fragments.py`로 정본에 병합

정답 경로·무관 페이지·대체 페이지는 025·028·029와 같이 절 이름에서 페이지 번호를 찾아 `main()`에서
계산한다.

## 검수

- 여섯 도표를 PNG로 렌더링해 눈으로 확인했고 다섯을 고쳤다. 이 권은 그림이 곧 내용이라 고칠 것이 가장
  많았다.
  - p10은 지구가 보는 모양을 여덟 자리에서 모두 같은 방향으로 그려 위쪽 절반의 자리들이 틀렸다. 위쪽
    자리에서는 보는 사람의 왼쪽이 해 쪽이고 아래쪽 자리에서는 오른쪽이 해 쪽이라, 밝은 쪽이 위아래
    절반에서 반대로 그려져야 한다.
  - p5는 달을 궤도 오른쪽 끝(다 찬 자리)에 두고 지구에서 본 모습은 반달로 그려 두 칸이 서로 어긋났다.
    달을 궤도 위쪽으로 옮겨 반달과 앞뒤를 맞췄다.
  - p40은 「지구를 향한 절반」 화살표가 두 칸에서 같은 쪽을 가리켰다. 지구가 달의 어느 쪽에 있는지에
    따라 반대가 되어야 한다. 이름표가 칸 밖으로 잘리던 것도 함께 고쳤다.
  - p25는 만나는 자리를 눈대중으로 찍어 기울어진 타원과 어긋났다. 타원이 가로선과 만나는 자리를
    계산해서 찍도록 바꿨다.
  - p18은 이름표가 서로 겹치고 되돌리는 힘의 방향이 읽히지 않았다.
- p25와 p36을 한 번 더 고쳤다. p25는 두 칸에 「만나는 자리」를 똑같이 그려 두어, 만나는 자리가 늘 그림자
  축 위에 놓인다는 뜻이 됐다. 그러면 보름마다 가림이 일어나야 하고 「대개 빗나간다」는 제목과 정면으로
  어긋난다. 위 칸에서는 만나는 자리를 빼고 달이 평면에서 벗어난 높이만 표시했다. p36은 빈칸 여섯 개 가운데
  셋에만 까닭을 적어 두고 「그 아래에 까닭을 적었다」고 했으며, 아래 문구는 「빈칸이 새벽에 몰렸다」고
  적었는데 실제로는 흐림이 셋이었다. 여섯 개의 까닭을 이어진 묶음 단위로 모두 적고 문구를 그림에 맞췄다.
- 도표 여섯 장의 `IMAGE` 페이지 본문을 렌더링 결과와 한 줄씩 맞춰 다시 썼다. p5는 지구에서 본 달을
  「오른쪽 절반만 밝게」라고 적었으나 실제로는 왼쪽이 밝고, 이 책이 여섯 도표에서 밝은 쪽을 왼쪽으로
  고정한 것과도 어긋났다.
- 3.3의 `EXTRA` 문단 둘이 뒤바뀌어 있던 것을 되돌렸다. 첫 페이지가 아직 나오지 않은 「두 방법」을 가리키고
  있었다.
- 6.3 본문에서 다른 권을 코퍼스 번호로 가리키던 자리를 고쳤다. 독자가 읽는 본문에 내부 식별자를 노출할
  이유가 없어 「중력을 다루는 다른 책」으로 바꿨다.
- 공개 가이드 주제와 비공개 분석 텍스트를 서로 다른 문장으로 적었고, 주제문에 숫자를 쓰지 않았다.
- 본문·도표·평가 데이터에 실존 인물·기관·탐사가 등장하지 않는다.

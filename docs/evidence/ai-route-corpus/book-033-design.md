# book-033 「청동 종이 울리던 시대」 설계

[역사 카테고리 계획](./history-category-plan.md)의 33번을 만든 근거다. 정책·검증 계약은
[AI 경로 콘텐츠 코퍼스](../../ai-route-content-corpus.md)를 따르고, 이 문서는 그 계약 안에서 내린
선택과 이유만 적는다.

## 대상 도서

- `bookId` 33, 카테고리 역사. 저자·소개는 `src/main/resources/demo/books.json`의 기존 값을 유지한다.
- 제목은 `ai-route-v2` manifest의 `books[].title`이 정본이며 계획 문서의 제목과 같다.
- 실존 국가·의례·유물을 옮기지 않는다. 무대는 가상의 울림왕국과 수도 종루성, 국가의례 종울림제와
  거기 걸린 청동 종들이다. 연구자는 가온이며 앞선 권들의 인물과 겹치지 않는다.

계획이 정한 범위(국가의례의 사회적 기능, 명문 해석, 절기와 통치 정당성, 의례 참여 계층)가 모두
들어갔다. 평가 시나리오도 계획대로 「비소장 · 예산 10」이다.

## 개념 범위

이 책의 축은 **되풀이가 만드는 것**이다. 명문에 적힌 좋은 말을 읽는 일보다 누가 어디에 서는지가
여러 해에 걸쳐 어떻게 옮겨 갔는지를 따라가는 일이 이 물음에 더 가깝다는 것이 4장의 결론이고 책
전체의 결론이다. 그래서 이 책에서 정당성은 주장하는 문장이 아니라 **묻지 않게 된 상태**로 정의된다.

계획이 지정한 경계를 지켰다.

- 34(장부)는 숫자와 결락을 다룬다. 33의 자료는 물건과 그 위의 짧은 글이라 셈할 것이 거의 없고,
  대신 크기·두께·자리처럼 값으로 견줄 수 없는 것을 다룬다.
- 38(벽화)도 문자 아닌 사료를 읽지만 그림의 반복 모티프를 해석한다. 33은 그림을 다루지 않고
  물건의 형태와 배치를 다룬다.
- 31(편년체)은 형식이 시간을 어떻게 자르는지를 본다. 33은 형식이 굳어 있다는 사실을 오히려 자료로
  쓴다. 2.1 둘째 페이지에 그 차이를 본문으로 적었다.

## 장 구성 (49페이지, 목차 1 + 본문 48)

```
1장 종은 무엇을 위해 걸렸나  p2–7    PREREQUISITE  의례 기물·명문·제작 주체
2장 새긴 글을 읽는 법        p8–15   CORE          명문의 구성·명문의 화자·결손 판독·개주
3장 절기가 정하는 날         p16–23  CORE          의례의 절기·의례 중단·의례 변경·의례의 범위
4장 누가 그 자리에 섰나      p24–31  CORE          참여 계층·자리의 이동·배제·정당성
5장 종루성의 한 해를 따라    p32–38  EXAMPLE       기물 조사·교차 대조·의례 표·읽기 기록
6장 종이 말하지 않는 것      p39–46  COUNTERPOINT  기물의 잔존·선언과 실행·소리의 부재·물질 사료의 쓸모
7장 소리가 그친 뒤에         p47–49  CONCLUSION    정당성·기물의 잔존·물질 사료의 쓸모
```

6.3(소리의 부재)을 따로 둔 것이 이 권의 특징이다. 의례를 다루면서 정작 의례의 알맹이인 소리와
몸짓은 남지 않는다는 사실을 한 절로 세워, 이 책이 무엇을 다루지 못하는지를 본문 안에서 밝힌다.
상상으로 채우면 글은 생생해지고 자료는 사라진다는 것이 그 절의 요지다.

이미지 6개: p7(두 가지 묶음), p13(읽은 자리와 짐작한 자리), p22(소리가 닿는 데까지),
p30(되풀이가 만드는 것), p35(말과 물자를 맞대면), p43(남은 것과 남지 않은 것). 생성 스크립트는
[`figures033.py`](./tools/figures033.py)다.

중복 그룹 1개: `carved-is-intent-not-fact` = [11, 42]. "새긴 것은 이루어진 일이 아니라 이루려던
일이다"를 2.2에서 명문을 읽는 규칙으로 세우고 6.2에서 대조 결과를 해석하는 규칙으로 다시 쓴다.
42의 선수 폐쇄는 [2, 4, 8, 24, 30, 41, 42]라 짝인 11을 지나지 않는다. 지나면 42를 고른 경로에
11이 반드시 따라와 중복 그룹 규칙을 어긴다.

## 선수 관계 설계

1.1이 뿌리이고 1.2·1.3·3.1·4.1·5.1·6.4가 곧바로 거기 붙는다. 2장은 1.2에서 시작해 2.1로 가고
2.2·2.3이 2.1에 붙는다. 2.4만 1.3(제작 주체)에서 이어진다 — 다시 새긴 자국을 가려내는 일은 글이
아니라 만든 손의 흔적을 읽는 일이기 때문이다.

**4.4만 선수가 둘이다.** 4.1(참여 계층)과 2.1(명문의 구성)을 함께 건다. 의례가 한 일을 말하려면
누가 어디에 섰는가와 무엇을 새겼는가가 둘 다 있어야 한다. 이 사례의 정답 경로가 그 두 갈래를 모두
탄다.

6장은 뒤에 있지만 앞 장에 직접 붙였다 — 6.1은 1.2, 6.2는 4.4, 6.3은 3.1, 6.4는 1.1이다. 6.2만
4장 끝에 붙는데, 새긴 대로 되었는지를 묻는 일은 의례가 한 일을 먼저 세운 뒤에야 성립하기 때문이다.

- 어느 후보 페이지도 선수 폐쇄가 7페이지를 넘지 않는다.
- 폐쇄 5페이지 이하인 후보 페이지가 일곱 개 장을 모두 덮는다 (기준 3개 장).
- 후보 페이지 48개 전부가 폐쇄 15페이지 이하다 (기준 75%).

## 검증

`corpus_lib.validate_book()` → `validate_fragment.py` → `merge_fragments.py` → `validate_manifest.py`를
차례로 통과했다.

- 49페이지(48~72), 7개 장(최소 6), 내용 역할 5종 모두 사용
- `TEXT` 본문 42페이지가 345~375자(평균 357자, 합계 15,001자)
- `estimatedReadingSeconds`에 60초로 눌린 페이지가 하나도 없음
- `FRONT_MATTER`(목차 p1)와 `aiRouteCandidatePage=false`가 정확히 일치
- 선수 관계가 후보 제외 페이지를 가리키지 않음, 위상 정렬로 49페이지 전체 방문
- PDF 페이지 49개, 텍스트 43개, 이미지 6개(p7,13,22,30,35,43) — `pdfcheck.py`로 확인
- PDF 실제 SHA-256이 manifest의 `pdfSha256`과 일치

## 평가 케이스: 비소장·예산 10 시나리오

| 필드 | 값 |
| --- | --- |
| `caseId` | `case-book-033` |
| `purpose` | 이 책을 사지는 않았고, 남은 종과 거기 새긴 글로 그 시대의 통치가 어떻게 당연해졌는지를 읽어 보고 싶다 |
| `owned` / `maxAdditionalInk` / `depth` | `false` / `10` / `null` |
| `requiredConcepts` | 의례 기물, 명문, 명문의 구성, 참여 계층, 정당성 |
| `helpfulConcepts` | 제작 주체, 의례의 절기, 배제, 물질 사료의 쓸모 |
| `referencePageNumbers` | 2, 4, 8, 24, 30 |
| `allowedAlternativePageNumbers` | 3, 5, 9, 17, 25, 29, 31 |
| `irrelevantPageNumbers` | 12·13(결손 판독), 14·15(개주), 37(읽기 기록), 43·44(소리의 부재) |

정답 경로는 선수 전이 폐쇄와 같고 5페이지여서 예산 10 안에 넉넉히 든다. 의례 기물(2)에서 명문(4)과
참여 계층(24)이 갈라지고, 명문에서 명문의 구성(8)으로 간 뒤, 8과 24가 함께 정당성(30)으로 모인다.
다섯 페이지로 다섯 필수 개념을 모두 덮는다.

정답 다섯 자리 가운데 짝이 있는 넷(2→3, 4→5, 8→9, 24→25, 30→31)을 모두 대체에 넣었고, 도움 개념인
`의례의 절기`(17)와 `배제`(29)를 더했다. 일곱 페이지 모두 선수 폐쇄가 6 이하라 예산 10 안에서 고를
수 있다.

무관은 절 단위로 골랐다. 결손 판독과 개주는 명문을 다루는 판독 절차이고, 읽기 기록은 조사를 남기는
방법이며, 소리의 부재는 남지 않은 것을 다루는 자리다. 넷 다 통치가 어떻게 당연해졌는지를 묻는 이
목적 밖이고 필수·도움 개념을 primary로 달지 않는다.

## 재현 조건

1. `python3 build033.py` — 원고와 조각 생성 (PDF SHA 없이 실행하면 자리표시자를 넣는다)
2. `python3 figures033.py pdfbuild033` — 도표 6개 SVG 생성
3. Chrome Headless로 각 SVG를 794×1123 PNG로 렌더링
4. `python3 build_pdf_generic.py 33 7,13,22,30,35,43 pdfbuild033` — 조판 HTML 생성
5. Chrome Headless `--print-to-pdf`로 PDF 출력, `pdfcheck.py`로 구성 확인
6. PDF를 `fixtures/content/ai-route-v2/pdfs/`에 두고 SHA-256을 인자로 `build033.py` 재실행
7. `merge_fragments.py 33`로 정본에 병합

## 검수

- 초고는 42개 `TEXT` 페이지 **전부**가 하한에 걸렸다. 31번은 24쪽, 32번은 40쪽이었다. 마지막 문단을
  늘리는 방식으로 세 차례에 나눠 고쳤다.
- 도표 여섯 장을 PNG로 렌더링해 눈으로 확인했고 셋을 고쳤다.
  - p7은 붉은 세로선이 위 띠의 상자 글자를 가로질렀고, **라벨이 뒤집혀 있었다.** 그 경계에서 두 종은
    명문의 같은 묶음에 들고 공방의 다른 묶음에 든다 — 「같은 손, 다른 이름」이 아니라 「같은 이름,
    다른 손」이다. 선을 상자 뒤로 보내고 라벨을 고쳤다.
  - p13은 본문이 「빈 네모가 가장 많다」고 했는데 그림에서는 읽은 글자가 압도적으로 많았다. 분포를
    다시 잡아 짐작 불가가 48, 읽은 글자가 34, 짐작한 글자가 8이 되게 했다.
  - p30은 네 배치도의 바깥 원이 서로 닿았다. 반지름을 줄였다.
- 도표 본문 두 곳을 그림에 맞춰 고쳤다. p22는 원의 경계를 「흐릿한 띠」라 했으나 옅은 선이고,
  p35는 여섯 쌍 가운데 「넷이 비슷하다」고 했으나 셋이 비슷하고 하나는 아래 막대가 더 길다.
- 다른 권과 겹치는 일곱 어절이 넷 있었다. 그 가운데 하나는 **031과 절 제목까지 같았다**(5.4 읽은
  것을 적어 두는 법). 이 권의 절을 「손에 남은 것을 적어 두는 법」으로 바꾸고 본문도 물건을 만지는
  일에 맞게 다시 썼다. 나머지 셋도 표현을 바꿔 0으로 만들었다.
- `ContentBatchConverterTest`의 코퍼스 재고 단언을 갱신했다. 도서 45→46, 페이지 1847→1896,
  이미지 211→217이다.
- 공개 가이드 주제와 비공개 분석 텍스트를 서로 다른 문장으로 적었고, 주제문에 숫자를 쓰지 않았다.
- 본문·도표·평가 데이터에 실존 인물·작품·단체가 등장하지 않는다.

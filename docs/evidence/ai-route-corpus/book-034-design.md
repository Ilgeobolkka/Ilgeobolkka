# book-034 「장부로 읽는 사회사: 기록에서 구조로」 설계

[역사 카테고리 계획](./history-category-plan.md)의 34번을 만든 근거다. 정책·검증 계약은
[AI 경로 콘텐츠 코퍼스](../../ai-route-content-corpus.md)를 따르고, 이 문서는 그 계약 안에서 내린
선택과 이유만 적는다.

이 문서는 책을 만든 뒤에 썼다. 아래의 수치와 구조는 현재 정본에서 그대로 확인한 것이고, 계획과
어긋난 자리는 어긋났다는 사실과 지금 상태를 적되 당시의 의도를 지어내지 않았다.

## 대상 도서

- `bookId` 34, 카테고리 역사. 저자·소개는 `src/main/resources/demo/books.json`의 기존 값을 유지한다.
- 제목은 `ai-route-v2` manifest의 `books[].title`이 정본이며 이 문서의 제목과 같다. 계획 문서의
  가제(「겨울 왕국의 세금 장부」)와 다르다.
- 실존 국가·사료·연구자를 옮기지 않는다. 무대는 가상의 「설강국」과 그 북쪽 고을 「북영」이다.

## 계획과 어긋난 자리

계획 문서는 왕국 「설한왕국」, 수도 「백상성」, 사료 「설한왕국 세장」을 적었다. 본문은 설강국과 북영을
쓰고 사료에 고유명을 붙이지 않았다. 이름을 되돌리려면 PDF를 다시 만들어야 하고 PDF는 `pdfSha256`으로
정본에 묶여 있다. 이름이 다른 것 자체가 계약을 어기지는 않으므로 여기 적어 두고 그대로 둔다.

평가 케이스도 다르다. 계획은 「비소장 · 예산 15」였고 실제는 「소장 · QUICK」이다. 목적문이 "짧게 핵심만
짚고 싶다"로 서 있어 QUICK(상한 5페이지)과 맞물리지만, 계획을 바꾼 시점의 판단은 기록이 남아 있지 않다.

## 개념 범위

계획이 정한 범위(세목 분류, 계층별 세 부담, 장부 누락의 해석, 흉년과 세수 변화)를 따른다. 이 책의
축은 **적히지 않은 것을 어떻게 다루는가**다. 숫자를 읽는 법(2장)에서 시작해 사회 구조 추정(3·4장)으로
가되, 6장 전체를 장부가 말하지 않는 것에 쓴다.

같은 카테고리에서 사료 해석을 다루는 권과 경계를 두었다.

- 33(의례·명문)은 물질과 의례로 통치 정당성을 읽는다. 34는 숫자와 결락만 다루므로 의례가 나오지 않는다.
- 36(서신)은 개인 기록으로 사건을 복원한다. 34의 사료는 국가가 징수를 위해 만든 장부라 기록 주체와
  기록 목적이 다르다. 34는 서신도 개인 기록도 다루지 않는다.

## 장 구성 (49페이지, 목차 1 + 본문 48)

```
1장 남은 것과 사라진 것        p2–7    PREREQUISITE  기록의 목적·잔존 편향·기록 주체
2장 장부를 읽는 법             p8–15   CORE          기재 항목·조세 항목·결락·비교 기준
3장 장부에서 사회로            p16–23  CORE          부담의 분포·납부 수단·납부 시기·체납
4장 겨울이라는 조건            p24–31  CORE          계절 일정·감면·인구 이동·변경 부담
5장 실제로 읽어 보기           p32–38  EXAMPLE       한 해 읽기·두 해 견주기·표로 정리
6장 장부가 말하지 않는 것      p39–46  COUNTERPOINT  기록의 침묵·수치 왜곡·단일 사료·그래도 읽는 이유
7장 무엇을 읽고 무엇을 남기나  p47–49  CONCLUSION    종합과 남는 물음
```

1장에서 2장으로 가는 길이 이 책의 뼈대다. 남은 자료가 무작위가 아니라는 사실(1.2)을 먼저 세우고,
그 위에서 빈칸을 읽는 법(2.3)을 다루고, 마지막에 적히지 않은 사람들(6.1)로 되돌아온다. 세 자리가
한 줄로 이어져 있어 이 케이스의 정답 경로도 그 줄을 탄다.

이미지 6개: p5(기록이 걸러지는 단계), p9(장부 한 장의 짜임), p17(부담을 큰 쪽부터 늘어세우면),
p25(한 해의 일정), p36(두 해를 나란히 놓는 표), p42(숫자가 밀리는 자리). 생성 스크립트는
[`figures034.py`](./tools/figures034.py)다.

중복 그룹 1개: `silence-is-not-absence` = [13, 40]. "적히지 않음을 없음으로 읽지 않는다"를 2.3에서
빈칸과 영의 차이로 세우고 6.1에서 자료 전체 수준으로 재진술한다. 재진술 페이지(40)에는 짝(13)을
선수로 걸지 않았다. 걸면 40을 고른 경로에 13이 반드시 따라와 중복 그룹 규칙을 어기기 때문이며,
book-021·023·024·026·027과 같은 처리다.

## 선수 관계 설계

1.1이 뿌리이고 1.2·1.3·2.1이 곧바로 거기 붙는다. 2.2·2.3·2.4는 2.1에 붙어 2장이 얕게 퍼진다.
3장은 3.1·3.2가 2.2에, 3.3이 2.1에 붙고 3.4만 3.1에서 이어진다. 4장은 4.1이 2.1에, 4.4가 2.2에,
4.2·4.3이 3.4에 붙는다. 5장은 5.1이 2.1에, 5.2가 2.4에 붙고 나머지 셋은 5.1에서 갈린다.

6장은 뒤에 있지만 앞 장에 직접 붙였다 — 6.1과 6.4는 1.2(잔존 편향), 6.2는 1.3(기록 주체), 6.3은
2.4(비교 기준)다. 반례는 그 주장이 세워진 자리에서 읽어야 뜻이 서고, 6장을 5장 뒤에 사슬로 이으면
6.1의 폐쇄가 5장 전체를 끌고 와 QUICK 상한 안에 들어오지 못한다.

- 어느 후보 페이지도 선수 폐쇄가 7페이지를 넘지 않는다.

- 폐쇄 5페이지 이하인 후보 페이지가 일곱 개 장을 모두 덮는다 (기준 3개 장).
- 후보 페이지 48개 전부가 폐쇄 15페이지 이하다 (기준 75%).

## 검증

`corpus_lib.validate_book()` → `validate_fragment.py` → `merge_fragments.py` → `validate_manifest.py`를
차례로 통과했다.

- 49페이지(48~72), 7개 장(최소 6), 내용 역할 5종 모두 사용
- `TEXT` 본문 42페이지가 344~410자(평균 370자, 합계 15,541자)
- `estimatedReadingSeconds`에 60초로 눌린 페이지가 하나도 없음
- `FRONT_MATTER`(목차 p1)와 `aiRouteCandidatePage=false`가 정확히 일치
- 선수 관계가 후보 제외 페이지를 가리키지 않음, 위상 정렬로 49페이지 전체 방문
- PDF 페이지 49개, 텍스트 43개, 이미지 6개(p5,9,17,25,36,42) — `pdfcheck.py`로 확인
- PDF 실제 SHA-256이 manifest의 `pdfSha256`과 일치

## 평가 케이스: 소장·QUICK 시나리오

| 필드 | 값 |
| --- | --- |
| `caseId` | `case-book-034` |
| `purpose` | 옛 장부에 이름이 없는 사람들을 어떻게 헤아려야 하는지, 짧게 핵심만 짚고 싶다 |
| `owned` / `maxAdditionalInk` / `depth` | `true` / `null` / `QUICK` |
| `requiredConcepts` | 기록의 목적, 잔존 편향, 기재 항목, 결락, 기록의 침묵 |
| `helpfulConcepts` | 기록 주체, 조세 항목, 비교 기준, 부담의 분포 |
| `referencePageNumbers` | 2, 4, 8, 12, 39 |
| `allowedAlternativePageNumbers` | 3, 5, 9, 13, 40, 43, 44 |
| `irrelevantPageNumbers` | 18~21(납부 수단과 시기), 24~27(계절 일정과 감면), 30·31(변경 부담) |

정답 경로는 선수 전이 폐쇄와 같고 5페이지여서 QUICK 상한 5에 꼭 맞는다. 사슬이 아니라 기록의
목적(2)에서 갈라지는 두 갈래다. 한 갈래는 잔존 편향(4)에서 기록의 침묵(39)으로 가고, 다른 갈래는
기재 항목(8)에서 결락(12)으로 간다. 남은 것이 왜 치우쳐 있는지와 빈칸을 어떻게 읽는지를 따로
세운 뒤 목적에서 만나게 한 구조다. 상한이 가장 빡빡한 사례라 여유가 한 페이지도 없다.

무관 페이지는 절 단위로 골랐다. 한 절을 무관과 무관 아님으로 가르면 무관이 아닌 페이지가 무관
페이지를 선수로 밟아야만 닿는 자리가 생긴다. 4.3(이동과 도망)은 무관에 넣지 않았다. 떠난 사람의
줄이 다음 해 장부에서 사라진다는 이야기라 이 목적의 필수 개념인 기록의 침묵·결락과 정면으로
이어진다.

대체 페이지는 정답 다섯 자리의 같은 절 짝(3, 5, 9, 13, 40)과 6.3의 두 페이지(43, 44)다. 앞의
다섯은 짝과 `primaryConcepts`가 같아 개념 충족을 그대로 대신한다. 6.3은 다르다. `단일 사료의
한계`가 primary라 필수 개념을 대신 덮지는 못하고, 43이 `비교 기준`을 secondary로 달 뿐이다. 하나의
장부만으로 무엇을 말할 수 있는지가 이 목적에 닿아 있어 골라도 감점하지 않는 자리로 두었다. 일곱
페이지 모두 선수 폐쇄가 5 이하라 QUICK 상한 안에서 고를 수 있다.

## 재현 조건

1. `python3 build034.py` — 원고와 조각 생성 (PDF SHA 없이 실행하면 자리표시자를 넣는다)
2. `python3 figures034.py pdfbuild034` — 도표 6개 SVG 생성
3. Chrome Headless로 각 SVG를 794×1123 PNG로 렌더링
4. `python3 build_pdf_generic.py 34 5,9,17,25,36,42 pdfbuild034` — 조판 HTML 생성
5. Chrome Headless `--print-to-pdf`로 PDF 출력, `pdfcheck.py`로 구성 확인
6. PDF를 `fixtures/content/ai-route-v2/pdfs/`에 두고 SHA-256을 인자로 `build034.py` 재실행
7. `merge_fragments.py --replace 34`로 정본에 병합

## 검수

- 4.1과 4.2가 첫 페이지만 무관이어서 둘째 페이지(25, 27)가 무관 페이지를 선수로 밟아야만 닿았다.
  절 단위로 맞췄다. 같은 결함이 다른 일곱 권에 열 곳 더 있었고 함께 고쳤다.
- `build034.py`가 p4에 `silence-is-not-absence` 태그를 달고 있어 빌드가 실패하는 상태였다. p40의 선수
  폐쇄가 p4를 지나 중복 그룹 규칙에 걸린다. 그 그룹은 「적히지 않음을 없음으로 읽지 않는다」이고 p4는
  무엇이 살아남았는가(잔존 편향)라 다른 말이며 정본에도 없었다. 떼어내니 스크립트 출력이 정본과
  완전히 일치한다.
- 도표 여섯 장의 `IMAGE` 페이지 본문을 렌더링 결과와 맞춰 다시 썼다. 여섯 장 모두 「~그린다」는 지시문
  형식이었고 실제 그림과 어긋난 대목이 있었다. p5는 없는 화살표를 적었고(띠 사이는 사선 연결선이다),
  p9도 없는 화살표를 적었으며, p25는 화살표 방향이 위아래가 아니라 세로선을 향한 가로 방향이고, p42는
  상자가 세로로 놓여 있는데 「왼쪽에서 오른쪽으로」라고 적었다. 여섯 장 전부 부제와 아래 요지 상자가
  본문에 빠져 있었다.
- 이 본문은 manifest에 실리지 않는다. `AiRouteContentManifest.Page`에 본문 필드가 없고, PDF의 `IMAGE`
  페이지는 PNG만 그린다(`build_pdf_generic.py`). 그래서 이 값은 AI 경로에도 독자에게도 닿지 않는
  원고 기록이며, 도표를 다시 만들거나 검토할 때 쓰는 자료다.
- 공개 가이드 주제와 비공개 분석 텍스트를 서로 다른 문장으로 적었고, 주제문에 숫자를 쓰지 않았다.
- 본문·도표·평가 데이터에 실존 인물·작품·단체가 등장하지 않는다.

# book-035 「다섯 다리를 건넌 제국」 설계

[역사 카테고리 계획](./history-category-plan.md)의 35번을 만든 근거다. 정책·검증 계약은
[AI 경로 콘텐츠 코퍼스](../../ai-route-content-corpus.md)를 따르고, 이 문서는 그 계약 안에서 내린
선택과 이유만 적는다.

## 대상 도서

- `bookId` 35, 카테고리 역사. 저자·소개는 `src/main/resources/demo/books.json`의 기존 값을 유지한다.
- 제목은 `ai-route-v2` manifest의 `books[].title`이 정본이며 계획 문서의 제목과 같다.
- 실존 국가·교량·유적을 옮기지 않는다. 무대는 가상의 연교제국과 그 강에 놓인 다섯 다리
  물푸레교·자작교·소나무교·버들교·은행교다.
- **연구자 인물을 두지 않았다.** 31·32·33은 각각 이름을 가진 연구자를 세웠으나 이 권부터는 두지
  않는다. 사료가 사람이 아니라 구조물이라 서술을 방법과 물건만으로 세울 수 있고, 권이 늘수록 이름을
  겹치지 않게 짓는 품만 커지기 때문이다.

계획이 정한 범위(다리의 군사·행정 기능, 교통망과 중앙집권, 건설 순서가 보여 주는 팽창 경로, 유지보수
기록)가 모두 들어갔다. 평가 시나리오도 계획대로 「소장 · QUICK」이다.

## 절 제목의 틀을 바꾼 까닭

31·32·33은 5·6·7장에서 같은 틀을 썼다 — 「…을 적어 두는 법」, 「그래도 …하는 까닭」, 「다음에 …할
사람에게」다. 계약은 역할 다섯 종만 요구하고 절 제목은 강제하지 않는데도 세 권이 겹쳤고, 33에서는
31과 절 제목이 글자까지 같은 자리가 나왔다.

이 권부터는 방법론에 맞춰 다르게 짠다. 5장은 다리 앞에 서서 재는 순서로, 6장은 돌이 말하지 않는
것으로, 7장은 강 건너에서 되돌아보는 자리로 두었다. 절 제목도 「재고 남긴 것을 다시 쓰려면」,
「돌로 알 수 있는 데까지」, 「아직 놓이지 않은 다리」처럼 이 책의 재료에서 나온 말로 붙였다.

## 개념 범위

이 책의 축은 **놓인 차례가 뻗어 나간 방향을 그린다**는 명제다. 32가 여럿을 나란히 놓아 원인과 조건을
가르는 책이라면, 35는 하나의 계열이 놓인 순서에서 방향을 읽는 책이다.

계획이 지정한 경계를 지켰다.

- 37(교역로 경제사)도 길을 다루지만 상인의 조직과 금융장치를 본다. 35는 국가가 놓은 것만 다루고
  장사와 상단이 본문에 나오지 않는다.
- 32(항구)는 쇠퇴를 다루고 35는 팽창을 다룬다. 32의 원인은 지형이고 35의 주체는 국가다.
- 33(의례)과 마찬가지로 물질을 사료로 삼지만, 33은 되풀이되는 행위를, 35는 한 번 놓이고 남는 구조물을
  다룬다. 그래서 33은 시기별 배치의 이동을 보고 35는 놓인 차례를 본다.

## 장 구성 (49페이지, 목차 1 + 본문 48)

```
1장 다리는 무엇을 잇는가        p2–7    PREREQUISITE  구조물의 기능·교통망·구조물 사료
2장 다섯 다리를 읽는 법         p8–15   CORE          건설 시점·입지·규모·부담 배분
3장 순서가 그리는 지도          p16–23  CORE          건설 순서·팽창 경로·미가설 지점·기능 변화
4장 잇는 힘과 쥐는 힘           p24–31  CORE          군사와 행정·중앙집권·통제·지배의 범위
5장 물푸레교 앞에서             p32–38  EXAMPLE       실측·보수 이력·겹쳐 그리기·측정 기록
6장 돌이 말하지 않는 것         p39–46  COUNTERPOINT  잔존 구조물·건설과 이용·비공식 통행·구조물 사료의 쓸모
7장 강 건너에서 되돌아보기      p47–49  CONCLUSION    팽창 경로·잔존 구조물·구조물 사료의 쓸모
```

3.3(건너뛴 자리)이 이 권의 특징이다. 놓인 다리만이 아니라 놓기 좋았는데 비워 둔 자리를 함께 세어,
뻗어 나간 방향과 멈춘 자리를 같은 지도에 올린다. 6.2(놓인 것과 쓰인 것)는 그 지도를 다시 흔든다 —
다섯 가운데 셋은 크게 놓였는데 바닥돌이 거의 닳지 않았다.

이미지 6개: p6(돌에서 읽히는 것), p12(다섯의 크기), p20(놓이지 않은 자리), p27(걸리는 시간이 줄면),
p34(아래에서 위로 어려지는 돌), p45(돌이 닿는 데까지). 생성 스크립트는
[`figures035.py`](./tools/figures035.py)다.

중복 그룹 1개: `order-draws-the-map` = [19, 47]. "놓인 차례가 뻗어 나간 방향을 그린다"를 3.2에서 이 책의
명제로 세우고 7.1에서 결론으로 다시 쓴다. 47의 선수 폐쇄는 [2, 8, 16, 18, 47]이라 짝인 19를 지나지
않는다. 지나면 47을 고른 경로에 19가 반드시 따라와 중복 그룹 규칙을 어긴다.

## 선수 관계 설계

1.1이 뿌리이고 1.2·1.3·2.1·4.1·6.4가 곧바로 거기 붙는다. 2장은 2.1에서 2.2·2.3이 갈라지고 2.4만
1.2에 붙는다.

3장이 이 책의 사슬이다. 2.1 → 3.1 → 3.2 → 3.3으로 이어지고 3.4는 3.1에서 갈라진다. **4.2(중앙집권)가
3.2(팽창 경로)에 붙는 것이 이 책의 핵심 간선이다.** 다리가 다스리는 힘을 늘렸다는 이야기는 뻗어 나간
방향 위에 서고, 방향 없이 힘만 말하면 어디로 늘어난 힘인지가 빠진다. 이 사례의 정답 경로가 그 사슬을
그대로 탄다.

6장은 뒤에 있지만 앞 장에 직접 붙였다 — 6.1은 1.3, 6.2는 2.3, 6.3은 1.2, 6.4는 1.1이다. 6장을 5장 뒤에
사슬로 이으면 폐쇄가 QUICK 상한을 넘는다.

- 어느 후보 페이지도 선수 폐쇄가 7페이지를 넘지 않는다.
- 폐쇄 5페이지 이하인 후보 페이지가 일곱 개 장을 모두 덮는다 (기준 3개 장).
- 후보 페이지 48개 전부가 폐쇄 15페이지 이하다 (기준 75%).

## 검증

`corpus_lib.validate_book()` → `validate_fragment.py` → `merge_fragments.py` → `validate_manifest.py`를
차례로 통과했다.

- 49페이지(48~72), 7개 장(최소 6), 내용 역할 5종 모두 사용
- `TEXT` 본문 42페이지가 344~389자(평균 362자, 합계 15,222자)
- `estimatedReadingSeconds`에 60초로 눌린 페이지가 하나도 없음
- `FRONT_MATTER`(목차 p1)와 `aiRouteCandidatePage=false`가 정확히 일치
- 선수 관계가 후보 제외 페이지를 가리키지 않음, 위상 정렬로 49페이지 전체 방문
- PDF 페이지 49개, 텍스트 43개, 이미지 6개(p6,12,20,27,34,45) — `pdfcheck.py`로 확인
- PDF 실제 SHA-256이 manifest의 `pdfSha256`과 일치

## 평가 케이스: 소장·QUICK 시나리오

| 필드 | 값 |
| --- | --- |
| `caseId` | `case-book-035` |
| `purpose` | 이 책을 소장하고 있는데, 다리가 놓인 순서만으로 제국이 어디로 뻗어 나갔는지를 짧게 핵심만 짚고 싶다 |
| `owned` / `maxAdditionalInk` / `depth` | `true` / `null` / `QUICK` |
| `requiredConcepts` | 구조물의 기능, 건설 시점, 건설 순서, 팽창 경로, 중앙집권 |
| `helpfulConcepts` | 교통망, 입지, 군사와 행정, 지배의 범위 |
| `referencePageNumbers` | 2, 8, 16, 18, 26 |
| `allowedAlternativePageNumbers` | 3, 5, 9, 10, 17, 19 |
| `irrelevantPageNumbers` | 14·15(부담 배분), 28·29(통제), 37(측정 기록), 43·44(비공식 통행) |

정답 경로는 선수 전이 폐쇄와 같고 5페이지여서 QUICK 상한 5에 꼭 맞는다. 구조물의 기능(2) → 건설
시점(8) → 건설 순서(16) → 팽창 경로(18) → 중앙집권(26)의 한 줄 사슬이다. 이 코퍼스에서 정답 경로가
갈라지지 않고 한 줄로 이어지는 드문 사례이고, 3장이 이 책에서 유일하게 사슬로 짜인 장이기 때문이다.

**4.2의 짝인 27은 대체 페이지에 넣지 않았다.** 선수 폐쇄가 6페이지라 QUICK 상한 5로는 어느 배분으로도
고를 수 없다. 나머지 정답 네 자리의 짝(3, 9, 17, 19)은 모두 상한 안에 들어 넣었고, 도움 개념인
`교통망`(5)과 `입지`(10)를 더했다.

무관은 절 단위로 골랐다. 부담 배분은 누가 냈는가의 문제이고, 통제는 막는 쪽의 이야기이며, 측정 기록은
재고 남기는 절차이고, 비공식 통행은 다리를 피해 다닌 쪽이다. 넷 다 어디로 뻗어 나갔는지를 묻는 이
목적 밖이고 필수·도움 개념을 primary로 달지 않는다.

## 재현 조건

1. `python3 build035.py` — 원고와 조각 생성 (PDF SHA 없이 실행하면 자리표시자를 넣는다)
2. `python3 figures035.py pdfbuild035` — 도표 6개 SVG 생성
3. Chrome Headless로 각 SVG를 794×1123 PNG로 렌더링
4. `python3 build_pdf_generic.py 35 6,12,20,27,34,45 pdfbuild035` — 조판 HTML 생성
5. Chrome Headless `--print-to-pdf`로 PDF 출력, `pdfcheck.py`로 구성 확인
6. PDF를 `fixtures/content/ai-route-v2/pdfs/`에 두고 SHA-256을 인자로 `build035.py` 재실행
7. `merge_fragments.py 35`로 정본에 병합

## 검수

- 초고에서 **1.2에 페이지가 하나 빠져 전체가 한 칸 밀렸다.** 48페이지로 나와 도표 자리도 계획과
  어긋났다. 1.2의 둘째 페이지를 채워 49페이지로 맞췄다.
- 초고 42쪽 가운데 39쪽이 하한에 걸려 마지막 문단을 늘리는 방식으로 두 차례에 나눠 고쳤다.
- 도표 여섯 장을 PNG로 렌더링해 눈으로 확인했고 둘을 고쳤다. p45는 바깥 반원이 화면 밖으로 잘려
  나갔다 — 반지름을 줄이고 안쪽 고리의 네 항목을 두 줄로 나눴다. p34는 물 높이 띠가 층 이름표를
  가로질렀다 — 띠를 짧게 하고 이름표를 띠 위로 올렸다.
- 도표 본문 세 곳을 그림에 맞춰 고쳤다. p12는 아치 폭을 「셋째가 가장 넓고 넷째가 가장 좁다」고
  적었는데 실제는 반대다(아치가 많을수록 좁다). p27은 도읍 점의 자리를 잘못 적었고, p45는 고리 안
  항목의 배치를 다시 적었다.
- 다른 권과 겹치는 일곱 어절이 처음에 넷, 고치는 과정에서 새로 생긴 것까지 합쳐 모두 아홉 자리
  있었다. **대부분이 도표 설명의 상투 문구다** — 「…가 작게 붙어 있다」, 「눈금과 숫자는 없다. 맨 아래
  상자에」 꼴이다. 고칠 때마다 앞 권에서 쓴 다른 표현과 다시 부딪혀 네 차례를 돌았고, 결국 도표마다
  다른 말로 적어 0으로 만들었다.
- `ContentBatchConverterTest`의 코퍼스 재고 단언을 갱신했다. 도서 46→47, 페이지 1896→1945,
  이미지 217→223이다.
- 공개 가이드 주제와 비공개 분석 텍스트를 서로 다른 문장으로 적었고, 주제문에 숫자를 쓰지 않았다.
- 본문·도표·평가 데이터에 실존 인물·작품·단체가 등장하지 않는다.

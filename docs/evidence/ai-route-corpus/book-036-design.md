# book-036 「편지로 복원한 어느 봄」 설계

[역사 카테고리 계획](./history-category-plan.md)의 36번을 만든 근거다. 정책·검증 계약은
[AI 경로 콘텐츠 코퍼스](../../ai-route-content-corpus.md)를 따르고, 이 문서는 그 계약 안에서 내린
선택과 이유만 적는다.

## 대상 도서

- `bookId` 36, 카테고리 역사. 저자·소개는 `src/main/resources/demo/books.json`의 기존 값을 유지한다.
- 제목은 `ai-route-v2` manifest의 `books[].title`이 정본이며 계획 문서의 제목과 같다.
- 실존 인물·마을·서한을 옮기지 않는다. 무대는 가상의 물빛마을이고 편지를 주고받은 사람은 다형과
  은설이다. 계획 문서가 지정한 이름을 그대로 썼다.
- **두 사람은 사료 속 인물이지 읽는 쪽의 인물이 아니다.** 035부터 연구자 인물을 두지 않기로 했고 이
  권도 그대로 따른다. 다형과 은설은 편지를 쓴 사람이지 편지를 읽는 사람이 아니다.

계획이 정한 범위(서신 사료의 주관성과 교차검증, 미시사적 시점, 개인 서한이 드러내는 사회적 사건)가
모두 들어갔다. 평가 시나리오도 계획대로 「소장 · BALANCED」다.

## 도표 본문의 틀을 미리 정한 까닭

035에서 권 사이 겹치는 일곱 어절이 아홉 자리 나왔고 네 차례를 돌며 고쳤다. 거의 다 도표 설명의 상투
문구였다 — 「…가 작게 붙어 있다」, 「눈금과 숫자는 없다. 맨 아래 상자에」 꼴이다. 고칠 때마다 앞 권에서
쓴 다른 표현과 다시 부딪혔다.

이 권부터는 도표 본문의 첫 문장과 끝 문장 틀을 권 전용으로 미리 정하고 쓴다. 이 권은 첫 문장을
"제목 밑에 '…'가 잔글씨로 놓여 있다"로, 끝 문장을 "치수와 날짜는 적지 않았다. 그림 맨 끝 상자에
'…'가 있다"로 고정했다. 결과로 이 권의 겹침은 도표에서 0이고 본문에서 한 자리만 나왔다.

## 개념 범위

이 책의 축은 **적히지 않은 일이 적는 방식에 남는다**는 명제다. 편지 어디에도 그 봄의 일이 무엇인지
적혀 있지 않은데, 문장의 길이와 안부의 길이와 화제가 한꺼번에 달라지는 구간이 있다.

계획이 지정한 경계를 지켰다.

- 34(장부)는 국가가 징수를 위해 만든 문서를, 33(의례)은 국가가 보이기 위해 만든 물건을 다룬다. 36의
  사료는 두 사람이 서로에게만 보이려고 쓴 글이다. 세 권의 기록 목적이 서로 다르다.
- 31(편년체)은 형식이 시간을 자르는 방식을 본다. 36은 형식이 없는 자료에서 시간을 세운다. 날짜가
  없는 편지 열아홉 통의 때를 좁히는 일이 5.2 한 절을 차지한다.

## 장 구성 (49페이지, 목차 1 + 본문 48)

```
1장 편지는 누구에게 쓰는가   p2–7    PREREQUISITE  수신자·서신의 시차·서신의 잔존
2장 한 통을 읽는 법          p8–15   CORE          생략과 전제·공유된 배경·주관성·반복 질문
3장 두 사람의 편지를 맞대기  p16–23  CORE          왕복 순서·결락된 왕복·엇갈린 서술·제삼자 서신
4장 봄에 무슨 일이 있었나    p24–31  CORE          사건의 그림자·미시와 거시·미시사적 시점·사례의 범위
5장 물빛마을의 그 봄을 따라  p32–38  EXAMPLE       정렬·연대 추정·사건 재구성·복원 기록
6장 편지가 속이는 자리       p39–46  COUNTERPOINT  화자의 한계·의도된 서신·선별된 잔존·서신 사료의 쓸모
7장 편지를 접으며            p47–49  CONCLUSION    미시사적 시점·사례의 범위·서신 사료의 쓸모
```

6.2(남기려고 쓴 편지)가 이 권의 특징이다. 봄이 끝난 뒤 먼 친척에게 보낸 넷은 결이 다르다 — 설명이
지나치게 친절하고 그 봄이 한 방향으로 정리되어 있다. 이 넷을 사건 자료에서 빼는 대신 **기억이 만들어진
과정의 자료로 옮겼다.** 하나였던 묶음이 겪은 봄과 기억된 봄의 두 층이 된다.

이미지 6개: p7(한 집 다락에 남은 것), p15(되풀이된 네 물음), p21(같은 날, 두 문장),
p30(두 층에 적힌 같은 봄), p36(결이 바뀐 자리), p44(세 번 걸러진 묶음). 생성 스크립트는
[`figures036.py`](./tools/figures036.py)다.

중복 그룹 1개: `letter-carries-its-standpoint` = [12, 39]. "한 사람의 편지는 그 사람이 서 있던 자리를
함께 담는다"를 2.3에서 주관성을 다루는 규칙으로 세우고 6.1에서 화자가 둘뿐이라는 한계로 다시 쓴다.
39의 선수 폐쇄는 [2, 6, 39]라 짝인 12를 지나지 않는다.

## 선수 관계 설계

1.1이 뿌리이고 1.2·1.3·2.1·6.4가 곧바로 거기 붙는다. 2장은 2.1에서 2.2·2.3이 갈라지고 2.4는 2.2에서
이어진다. 3장은 1.2(쓴 날과 닿은 날)에서 시작해 3.1로 가고 3.2·3.3·3.4가 3.1에 붙는다.

**4.1(편지에 비친 사건)만 선수가 둘이다.** 2.1(생략과 전제)과 3.1(왕복 순서)을 함께 건다. 결의 변화를
보려면 한 통을 읽는 법과 오간 차례가 둘 다 있어야 한다. 순서 없이는 변화가 보이지 않고, 읽는 법
없이는 무엇이 결인지 알 수 없다. 4장은 그 뒤로 4.1 → 4.2 → 4.3 → 4.4의 사슬이고 이 사례의 정답 경로가
그 사슬을 탄다.

6장은 뒤에 있지만 앞 장에 직접 붙였다 — 6.1과 6.3은 1.3, 6.2는 2.3, 6.4는 1.1이다.

- 어느 후보 페이지도 선수 폐쇄가 9페이지를 넘지 않는다.
- 폐쇄 5페이지 이하인 후보 페이지가 일곱 개 장을 모두 덮는다 (기준 3개 장).
- 후보 페이지 48개 전부가 폐쇄 15페이지 이하다 (기준 75%).

## 검증

`corpus_lib.validate_book()` → `validate_fragment.py` → `merge_fragments.py` → `validate_manifest.py`를
차례로 통과했다.

- 49페이지(48~72), 7개 장(최소 6), 내용 역할 5종 모두 사용
- `TEXT` 본문 42페이지가 344~382자(평균 356자, 합계 14,978자)
- `estimatedReadingSeconds`에 60초로 눌린 페이지가 하나도 없음
- `FRONT_MATTER`(목차 p1)와 `aiRouteCandidatePage=false`가 정확히 일치
- 선수 관계가 후보 제외 페이지를 가리키지 않음, 위상 정렬로 49페이지 전체 방문
- PDF 페이지 49개, 텍스트 43개, 이미지 6개(p7,15,21,30,36,44) — `pdfcheck.py`로 확인
- PDF 실제 SHA-256이 manifest의 `pdfSha256`과 일치

## 평가 케이스: 소장·BALANCED 시나리오

| 필드 | 값 |
| --- | --- |
| `caseId` | `case-book-036` |
| `purpose` | 이 책을 소장하고 있는데, 개인이 주고받은 편지만으로 그해 봄에 무슨 일이 있었는지를 어떻게 세우는지 제대로 알고 싶다 |
| `owned` / `maxAdditionalInk` / `depth` | `true` / `null` / `BALANCED` |
| `requiredConcepts` | 수신자, 생략과 전제, 왕복 순서, 사건의 그림자, 미시사적 시점 |
| `helpfulConcepts` | 서신의 시차, 주관성, 엇갈린 서술, 미시와 거시 |
| `referencePageNumbers` | 2, 4, 8, 16, 24, 26, 28 |
| `allowedAlternativePageNumbers` | 3, 5, 9, 17, 25, 27, 29 |
| `irrelevantPageNumbers` | 14·15(반복 질문), 37(복원 기록), 41·42(의도된 서신), 43·44(선별된 잔존) |

정답 경로는 선수 전이 폐쇄와 같고 7페이지여서 BALANCED 상한 10 안에 든다. 수신자(2)에서 서신의
시차(4)와 생략과 전제(8)가 갈라지고, 시차에서 왕복 순서(16)로 간 뒤, 8과 16이 함께 사건의
그림자(24)로 모인다. 거기서 미시와 거시(26) → 미시사적 시점(28)으로 이어진다.

정답 일곱 자리의 짝(3, 5, 9, 17, 25, 27, 29)을 모두 대체에 넣었다. 일곱 페이지 모두 선수 폐쇄가
9 이하라 BALANCED 상한 안에서 고를 수 있어 하나도 빠지지 않았다.

무관은 절 단위로 골랐다. 반복 질문은 되풀이를 세는 절차이고, 복원 기록은 판단을 남기는 방법이며,
의도된 서신과 선별된 잔존은 자료가 걸러진 방식이다. 넷 다 그 봄의 사건을 세우는 이 목적 밖이고
필수·도움 개념을 primary로 달지 않는다.

## 재현 조건

1. `python3 build036.py` — 원고와 조각 생성 (PDF SHA 없이 실행하면 자리표시자를 넣는다)
2. `python3 figures036.py pdfbuild036` — 도표 6개 SVG 생성
3. Chrome Headless로 각 SVG를 794×1123 PNG로 렌더링
4. `python3 build_pdf_generic.py 36 7,15,21,30,36,44 pdfbuild036` — 조판 HTML 생성
5. Chrome Headless `--print-to-pdf`로 PDF 출력, `pdfcheck.py`로 구성 확인
6. PDF를 `fixtures/content/ai-route-v2/pdfs/`에 두고 SHA-256을 인자로 `build036.py` 재실행
7. `merge_fragments.py 36`로 정본에 병합

## 검수

- PR 리뷰에서 비교 주장 두 곳이 틀린 것을 확인해 지웠다. 「폐쇄 9는 가장 깊은 축」은 67·66·64번이
  훨씬 깊어 뜻이 정반대였고, 「짝이 하나도 안 빠진 드문 사례」는 17건이 그렇다.
- 초고 42쪽 가운데 41쪽이 하한에 걸려 마지막 문단을 늘리는 방식으로 세 차례에 나눠 고쳤다.
- 도표 여섯 장을 PNG로 렌더링해 눈으로 모두 확인했다. 그림 자체는 고칠 자리가 없었다. **앞 다섯 권과
  달리 도표를 한 장도 다시 그리지 않은 첫 권이다.**
- 도표 본문 두 곳을 그림에 맞춰 고쳤다. p36은 네 층의 차례를 「아래에서부터」라 적었는데 그림은 위에서
  아래로이고, 같은 페이지에서 붉은 테두리 안이 「비어 있다」고 했는데 실제로는 짙어진 칸이 들어 있다.
- 다른 권과 겹치는 일곱 어절이 한 자리 나왔다. 035의 7.1과 맺음 문장 틀이 같았다(「…말하지 않는다.
  두 물음은 다르고 뒤의 물음에는…」). 도표 틀을 미리 정한 덕에 035의 아홉 자리에서 한 자리로 줄었다.
- `ContentBatchConverterTest`의 코퍼스 재고 단언을 갱신했다. 도서 47→48, 페이지 1945→1994,
  이미지 223→229이다.
- 공개 가이드 주제와 비공개 분석 텍스트를 서로 다른 문장으로 적었고, 주제문에 숫자를 쓰지 않았다.
- 본문·도표·평가 데이터에 실존 인물·작품·단체가 등장하지 않는다.

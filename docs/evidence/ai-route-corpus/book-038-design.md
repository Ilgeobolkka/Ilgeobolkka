# book-038 「벽화 속 사람들의 식탁」 설계

[역사 카테고리 계획](./history-category-plan.md)의 38번을 만든 근거다. 정책·검증 계약은
[AI 경로 콘텐츠 코퍼스](../../ai-route-content-corpus.md)를 따르고, 이 문서는 그 계약 안에서 내린
선택과 이유만 적는다.

## 대상 도서

- `bookId` 38, 카테고리 역사. 저자·소개는 `src/main/resources/demo/books.json`의 기존 값을 유지한다.
- 제목은 `ai-route-v2` manifest의 `books[].title`이 정본이며 계획 문서의 제목과 같다.
- 실존 유적·벽화·도상을 옮기지 않는다. 무대는 가상의 채화왕국과 그 궁 채원궁의 벽화, 그것을 그린
  화가 계층 채장이다. 035부터 연구자 인물을 두지 않으며 이 권도 그대로 따른다.

계획이 정한 범위(도상 해석의 방법, 벽화와 문헌의 교차검증, 시각 자료로 식생활 추론, 해석의 한계)가
모두 들어갔다. 평가 시나리오도 계획대로 「비소장 · 예산 5」다.

## 개념 범위

이 책의 축은 **그린 것은 있었던 것이 아니라 그리기로 한 것**이다. 1.2에서 세우고 6.2에서 이중의
거름으로 다시 밀며, 7.1에서 이 책의 결론이 식품이 아니라 좌석의 차례에 모이는 까닭이 된다.

계획이 지정한 경계를 지켰다.

- 33(의례)도 국가가 보이려고 만든 것을 다루지만 대상이 의례라는 절차다. 38은 그림 자체의 되풀이되는
  모양을 세고, 33에 나오는 절차·순서 같은 말 대신 모티프·배치·색을 쓴다.
- 34(장부)·36(편지)은 글로 된 자료를 읽는다. 38의 자료에는 글이 거의 없고, 그래서 4장 전체가 글과
  그림을 맞대는 절차에 쓰인다.

## 장 구성 (49페이지, 목차 1 + 본문 48)

```
1장 그림은 무엇을 적는가     p2–7    PREREQUISITE  시각 사료·화가의 자리·벽화의 자리
2장 되풀이되는 것을 센다     p8–15   CORE          반복 모티프·배치·색의 구분·크기의 위계
3장 상 위에 놓인 것          p16–23  CORE          식품 도상·도상의 결락·기물 도상·식사 장면
4장 그림과 글을 맞대기       p24–31  CORE          교차 대조·도상의 단독 증언·불일치 해석·식생활 추론
5장 채원궁의 한 벽 앞에서    p32–38  EXAMPLE       구획 관찰·모티프 집계·개작 흔적·관찰 도면
6장 그림이 속이는 자리       p39–46  COUNTERPOINT  벽화의 잔존·도상의 선택·재현과 실제·시각 사료의 쓸모
7장 벽에서 물러서서          p47–49  CONCLUSION    식생활 추론·벽화의 잔존·시각 사료의 쓸모
```

4.4가 이 권의 매듭이다. 벽에서 식생활로 넘어가는 걸음을 셋으로 못박고(되풀이되는 것만, 자리와
짝지어, 글과 맞댈 수 있는 것부터), 그 셋을 밟았을 때 채원궁의 벽이 안전하게 받치는 문장이 넷뿐임을
적는다. 넷 다 무엇을 먹었는가가 아니라 어떤 차례로 앉았는가에 관한 것이고, 이 어긋남이 7.1의
결론이 된다.

이미지 6개: p7(세 자리의 벽), p13(색이 나뉘어 있다), p21(굽이 높은 그릇은 어디에 놓이는가),
p29(네 칸 가운데 셋만 셀 수 있다), p35(나누어 세면 다르게 보인다), p43(벽에 닿기까지 세 번
걸러진다). 생성 스크립트는 [`figures038.py`](./tools/figures038.py)다.

036에서 도입한 **권 전용 도표 문장 틀**을 이어 쓴다. 이 권은 첫 문장을 "제목 밑줄 아래에 '…'가 작은
글씨로 딸려 있다"로, 끝 문장을 "크기와 수는 재어 적지 않았다. 그림 맨 아래 칸에 '…'가 있다"로
고정했다. 결과로 이 권의 도표 겹침은 0이다.

중복 그룹 1개: `painted-is-chosen` = [5, 41]. "그린 것은 있었던 것이 아니라 그리기로 한 것이다"를
1.2에서 자료의 성격으로 세우고 6.2에서 이중의 거름을 여는 문장으로 다시 쓴다. 41의 선수 폐쇄는
[2, 4, 41]이라 짝인 5를 지나지 않는다.

## 선수 관계 설계

1.1이 뿌리이고 1.2·1.3·2.1·6.4가 곧바로 거기 붙는다. 2장은 2.1에서 2.2·2.3이 갈라지고 2.4는
2.2에서 이어진다. 3장은 2.1에서 3.1로 가고 3.2·3.3이 3.1에 붙으며 3.4만 2.2에 붙는다. 4장은
3.1 → 4.1 → 4.2 → 4.3의 사슬이고 이 사례의 정답 경로가 그 사슬의 앞머리를 탄다.

**4.4만 선수가 둘이다.** 4.1(교차 대조)과 3.4(식사 장면)를 함께 건다. 벽에서 식생활로 넘어가려면
글과 맞대는 절차와 상 둘레의 짜임이 둘 다 있어야 한다. 맞댐 없이는 무엇이 받쳐지는지 모르고, 상
둘레 없이는 넘어갈 것이 남지 않는다.

6장은 뒤에 있지만 앞 장에 직접 붙였다 — 6.1은 1.3, 6.2는 1.2, 6.3은 4.3, 6.4는 1.1이다.

- 어느 후보 페이지도 선수 폐쇄가 8페이지를 넘지 않는다.
- 폐쇄 5페이지 이하인 후보 페이지가 일곱 개 장을 모두 덮는다 (기준 3개 장).
- 후보 페이지 48개 전부가 폐쇄 15페이지 이하다 (기준 75%).

## 검증

`corpus_lib.validate_book()` → `validate_fragment.py` → `merge_fragments.py` → `validate_manifest.py`를
차례로 통과했다.

- 49페이지(48~72), 7개 장(최소 6), 내용 역할 5종 모두 사용
- `TEXT` 본문 42페이지가 348~423자(평균 370자, 합계 15,569자)
- `estimatedReadingSeconds`에 60초로 눌린 페이지가 하나도 없음
- `FRONT_MATTER`(목차 p1)와 `aiRouteCandidatePage=false`가 정확히 일치
- 선수 관계가 후보 제외 페이지를 가리키지 않음, 위상 정렬로 49페이지 전체 방문
- PDF 페이지 49개, 텍스트 43개, 이미지 6개(p7,13,21,29,35,43) — `pdfcheck.py`로 확인
- PDF 실제 SHA-256이 manifest의 `pdfSha256`과 일치

## 평가 케이스: 비소장·예산 5 시나리오

| 필드 | 값 |
| --- | --- |
| `caseId` | `case-book-038` |
| `purpose` | 이 책은 아직 소장하지 않았고 잉크도 다섯만 쓸 수 있는데, 벽에 그려진 그림만으로 그 시대의 식탁을 어디까지 말할 수 있는지 알고 싶다 |
| `owned` / `maxAdditionalInk` / `depth` | `false` / `5` / `null` |
| `requiredConcepts` | 시각 사료, 반복 모티프, 식품 도상, 교차 대조, 도상의 단독 증언 |
| `helpfulConcepts` | 배치, 색의 구분, 도상의 결락, 불일치 해석 |
| `referencePageNumbers` | 2, 8, 16, 24, 26 |
| `allowedAlternativePageNumbers` | 3, 9, 10, 12, 17, 18, 25 |
| `irrelevantPageNumbers` | 14·15(크기의 위계), 37(관찰 도면), 41·42(도상의 선택), 43·44(재현과 실제) |

정답 경로는 선수 전이 폐쇄와 같고 정확히 **5페이지**여서 예산 5를 남김없이 쓴다. 시각 사료(2) →
반복 모티프(8) → 식품 도상(16) → 교차 대조(24) → 도상의 단독 증언(26)의 한 줄기 사슬이다. 한 자리도
바꿔 넣을 여지가 없어 예산 상한이 실제로 조이는 사례다.

대체는 일곱이고 모두 선수 폐쇄가 5페이지 이하다. 정답 다섯 자리의 짝(3, 9, 17, 25)에 배치(10)와
색의 구분(12)과 도상의 결락(18)의 첫 페이지를 더했다. 4.2의 짝인 27은 폐쇄가 6페이지라 예산을
넘어서 뺐다 — **정답의 짝이 예산 때문에 빠지는 이 코퍼스의 몇 안 되는 자리다.**

**도표 페이지는 정답과 대체에서 뺐다.** 코퍼스에는 도표를 정답이나 대체에 넣은 사례가 스물셋
있어 강제되는 규칙은 아니다. 38·39·40 세 권에서 일관되게 고른 방침이고, 도표의 본문은
독자에게 닿지 않아 읽을거리로 권하기에 맞지 않다고 보았다.

무관은 절 단위로 골랐다. 크기의 위계는 그리는 관습이고, 관찰 도면은 본 것을 남기는 방법이며,
도상의 선택과 재현과 실제는 자료가 걸러진 방식이다. 넷 다 그림으로 식탁을 어디까지 말할 수 있는지를
묻는 이 목적 밖이고 필수·도움 개념을 primary로 달지 않는다. 2.4와 5.4와 6.2와 6.3은 본문에서도
앞뒤 장의 해석과 곧바로 이어지지 않는다고 밝혔다.

## 재현 조건

1. `python3 build038.py` — 원고와 조각 생성 (PDF SHA 없이 실행하면 자리표시자를 넣는다)
2. `python3 figures038.py pdfbuild038` — 도표 6개 SVG 생성
3. Chrome Headless로 각 SVG를 794×1123 PNG로 렌더링
4. `python3 build_pdf_generic.py 38 7,13,21,29,35,43 pdfbuild038` — 조판 HTML 생성
5. Chrome Headless `--print-to-pdf`로 PDF 출력, `pdfcheck.py`로 구성 확인
6. PDF를 `fixtures/content/ai-route-v2/pdfs/`에 두고 SHA-256을 인자로 `build038.py` 재실행
7. `merge_fragments.py 38`로 정본에 병합

## 검수

- 초고 42쪽 가운데 41쪽이 하한에 걸려 마지막 문단을 늘리는 방식으로 두 차례에 나눠 고쳤다.
- 도표 여섯 장을 PNG로 렌더링해 눈으로 모두 확인했고 셋을 고쳤다. p07은 복도 도형이 궁 평면 위로
  삐져나갔고 아래 절반이 비어 있었다. p21은 짧은 굽 그릇에서 나온 점선 하나가 표시된 자리를 뚫고
  지나가 위로 돌려 붙였다. p29는 빗금이 칸 밖으로 뻗어 이름표를 덮어 `clipPath`로 잘랐다.
- **도표 본문 두 곳을 그림보다 먼저 고쳤다.** p07은 '보는 사람'을 짙기 칸의 한 줄로 적었는데 사람은
  짙기로 나타낼 수 없어 칸 머리의 이름으로 옮겼고, p13은 테두리 친 예외 칸을 붉은색×그릇으로
  적었는데 본문이 말하는 예외는 옷에 쓰인 푸른색이라 푸른색×옷으로 바로잡았다.
- 다른 권과 겹치는 일곱 어절이 한 자리 나왔다. 2.4의 「이 책의 다른 장과 곧바로 이어지지는 않는다」가
  037의 같은 문장과 겹쳤다. 표현을 바꿔 0으로 만들었다. 본문을 고쳤으므로 PDF를 다시 출력하고
  SHA-256을 다시 받아 `--replace`로 병합했다.
- `ContentBatchConverterTest`의 코퍼스 재고 단언을 갱신했다. 도서 49→50, 페이지 2043→2092,
  이미지 235→241이다.
- 공개 가이드 주제와 비공개 분석 텍스트를 서로 다른 문장으로 적었고, 주제문에 숫자를 쓰지 않았다.
- 본문·도표·평가 데이터에 실존 인물·작품·단체가 등장하지 않는다.

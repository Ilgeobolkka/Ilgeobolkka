# book-040 「북쪽 관문의 마지막 겨울」 설계

[역사 카테고리 계획](./history-category-plan.md)의 40번을 만든 근거다. 정책·검증 계약은
[AI 경로 콘텐츠 코퍼스](../../ai-route-content-corpus.md)를 따르고, 이 문서는 그 계약 안에서 내린
선택과 이유만 적는다.

## 대상 도서

- `bookId` 40, 카테고리 역사. 저자·소개는 `src/main/resources/demo/books.json`의 기존 값을 유지한다.
- 제목은 `ai-route-v2` manifest의 `books[].title`이 정본이며 계획 문서의 제목과 같다.
- 실존 국경·조약·도시를 옮기지 않는다. 무대는 가상의 국경도시 북관성과 그 선을 사이에 둔 두 나라
  잔영국·명하국이다. 035부터 연구자 인물을 두지 않으며 이 권도 그대로 따른다.

계획이 정한 범위(국경 조약의 변경, 변경도시의 이중적 정체성, 국경 재획정의 정치적 배경, 변경사료의
신뢰성)가 모두 들어갔다. 평가 시나리오도 계획대로 「비소장 · 예산 10」이다.

## 개념 범위

이 책의 축은 **도시를 비운 것은 물길도 길도 아니고 두 나라가 다시 그은 선**이라는 것이다. 국경을
지리가 아니라 두 나라가 합의한 말로 보고, 말이 바뀌자 도시가 살던 방식이 사라지는 과정을 따라간다.

계획이 지정한 경계를 지켰다.

- 32(항구)도 도시의 쇠퇴를 다루지만 원인이 퇴적과 항로다. 40의 원인은 조약 재협상이라는 정치적
  결정이고, 그래서 4.4에서 이 쇠퇴가 되돌릴 수 있는 종류였다고 못박는다.
- 34(장부)·36(편지)이 한 갈래 자료를 깊이 읽는 데 비해 40은 성격이 다른 세 갈래(조약문·초소 일지·
  도시 문서)를 맞대는 데 3장과 4장을 쓴다.

## 장 구성 (49페이지, 목차 1 + 본문 48)

```
1장 선은 어디에 있었나     p2–7    PREREQUISITE  경계의 성격·변경도시·변경 사료
2장 두 나라가 적어 둔 것   p8–15   CORE          조약문·조약의 두 판본·경계 문언·문서의 형식
3장 초소가 적어 둔 것      p16–23  CORE          초소 일지·일지의 선택·왕래 기록·사료 대조
4장 선이 움직인 까닭       p24–31  CORE          재협상·교환의 셈·귀속 변경·국경 이동의 결과
5장 북관성의 마지막 겨울   p32–38  EXAMPLE       일지 추적·이주와 잔류·이중 정체성·근거 표시
6장 변경 사료가 감추는 것  p39–46  COUNTERPOINT  승자의 기록·일지의 잔존·주민의 부재·변경사의 쓸모
7장 선을 다시 보며         p47–49  CONCLUSION    국경 이동의 결과·승자의 기록·변경사의 쓸모
```

**4장이 이 권에서 유일하게 절 페이지 수가 고르지 않다** — 4.1(2), 4.2(3), 4.3(2), 4.4(1)이다.
4.2에 도표를 넣으면서 세 페이지가 되었고, 4.4는 한 페이지로 줄여 여덟 페이지를 맞췄다. 그 결과
정답 경로의 마지막 페이지(31)에는 같은 절의 짝이 없다.

4.1이 이 권의 매듭이다. 명하국이 든 명분은 마른 내가 사라졌다는 것인데, 마른 내가 언제 사라졌는지는
아무도 적어 두지 않았다. 그래서 물어야 할 것이 **언제 사라졌는가가 아니라 왜 그해에 말을 꺼냈는가**로
바뀌고, 답은 조약문 밖의 두 문서(새로 난 길, 남으로 옮긴 군사)에 있다. 빌미와 까닭을 가르는 이 걸음이
4장 전체에 쓰인다.

이미지 6개: p7(세 갈래로 남은 것), p14(조약문의 겉모양), p20(열두 해의 오감), p28(넓이로 세면,
사람으로 세면), p34(백열두 날의 떠남), p45(선 위의 한 점을 볼 때). 생성 스크립트는
[`figures040.py`](./tools/figures040.py)다.

036에서 도입한 권 전용 도표 문장 틀을 이어 쓴다. 이 권은 첫 문장을 "그림 첫머리에 '…'가 한 줄로 걸려
있다"로, 끝 문장을 "거리와 인원은 자로 재어 넣지 않았다. 그림 끝의 좁은 칸에 '…'가 놓여 있다"로
고정했다.

중복 그룹 1개: `line-moved-not-the-river` = [31, 47]. "도시를 비운 것은 물길도 길도 아니고 두 나라가
다시 그은 선이다"를 4.4에서 쇠퇴의 성격으로 세우고 7.1에서 책 전체의 결론으로 다시 쓴다. **7.1의
선수를 4.4가 아니라 4.3에 걸었다.** 4.4에 걸면 47의 선수 폐쇄가 짝인 31을 지나 중복 그룹 충돌이
난다.

## 선수 관계 설계

1.1이 뿌리이고 1.2·1.3·2.1·6.4가 곧바로 거기 붙는다. 2장은 2.1에서 2.2·2.3이 갈라지고 2.4는 2.3에서
이어진다. 3장은 1.3 → 3.1에서 시작한다 — 초소 일지를 읽으려면 그것이 어떤 목적으로 만들어진 자료인지
먼저 알아야 한다.

**선수가 둘인 절이 둘이다.** 3.4(사료 대조)는 3.2(일지의 선택)와 2.3(경계 문언)을 함께 건다 — 일지와
조약을 맞대려면 일지가 무엇을 빼는지와 조약의 말이 몇 가지로 읽히는지가 둘 다 있어야 한다.
4.3(귀속 변경)은 4.2(교환의 셈)와 1.2(변경도시)를 함께 건다 — 도시가 넘어간다는 것이 무슨 일인지는
그 도시가 두 나라에 걸쳐 있었다는 사실을 알아야 보인다.

- 어느 후보 페이지도 선수 폐쇄가 9페이지를 넘지 않는다.
- 폐쇄 5페이지 이하인 후보 페이지가 일곱 개 장을 모두 덮는다 (기준 3개 장).
- 후보 페이지 48개 전부가 폐쇄 15페이지 이하다 (기준 75%).

## 검증

`corpus_lib.validate_book()` → `validate_fragment.py` → `merge_fragments.py` → `validate_manifest.py`를
차례로 통과했다.

- 49페이지(48~72), 7개 장(최소 6), 내용 역할 5종 모두 사용
- `TEXT` 본문 42페이지가 345~375자(평균 356자, 합계 14,965자)

- PDF 페이지 49개, 텍스트 43개, 이미지 6개(p7,14,20,28,34,45) — `pdfcheck.py`로 확인
- PDF 실제 SHA-256이 manifest의 `pdfSha256`과 일치

## 평가 케이스: 비소장·예산 10 시나리오

| 필드 | 값 |
| --- | --- |
| `caseId` | `case-book-040` |
| `purpose` | 이 책은 아직 소장하지 않았고 잉크는 열까지 쓸 수 있는데, 국경에 있던 도시 하나가 왜 비었는지를 조약과 초소 일지로 어떻게 세우는지 알고 싶다 |
| `owned` / `maxAdditionalInk` / `depth` | `false` / `10` / `null` |
| `requiredConcepts` | 경계의 성격, 조약문, 재협상, 귀속 변경, 국경 이동의 결과 |
| `helpfulConcepts` | 변경도시, 조약의 두 판본, 교환의 셈, 경계 문언, 사료 대조 |
| `referencePageNumbers` | 2, 4, 8, 10, 24, 26, 29, 31 |
| `allowedAlternativePageNumbers` | 3, 5, 9, 11, 12, 22, 25, 27, 30 |
| `irrelevantPageNumbers` | 14·15(문서의 형식), 37(근거 표시), 41·42(일지의 잔존), 43·44(주민의 부재) |

정답 경로는 선수 전이 폐쇄와 같고 **8페이지**로 예산 10 안에 든다. 경계의 성격(2)에서 변경도시(4)와
조약문(8)이 갈라지고, 조약문 쪽이 조약의 두 판본(10) → 재협상(24) → 교환의 셈(26)으로 이어진 뒤
귀속 변경(29)에서 두 갈래가 다시 모여 국경 이동의 결과(31)로 끝난다. 갈라졌다가 모이는 이 모양이
이 책의 논지 그대로다 — 도시가 넘어간다는 것을 알려면 조약의 셈과 그 도시의 성격이 둘 다 있어야 한다.

대체 아홉 가운데 일곱(3, 5, 9, 11, 25, 27, 30)은 정답의 짝이고 둘(12, 22)은 도움 개념인 경계 문언과
사료 대조의 첫 페이지다. **정답의 마지막 페이지 31에는 짝이 없다** — 4.4가 한 페이지짜리 절이기
때문이다. 짝이 없는 정답 페이지 자체는 이 코퍼스에 흔하다.

**도표 페이지는 정답과 대체에서 뺐다.** 코퍼스에는 도표를 정답이나 대체에 넣은 사례가 스물셋
있어 강제되는 규칙은 아니다. 38·39·40 세 권에서 일관되게 고른 방침이고, 도표의 본문은
독자에게 닿지 않아 읽을거리로 권하기에 맞지 않다고 보았다.

무관은 절 단위로 골랐다. 문서의 형식은 문서의 겉모양이고, 근거 표시는 셈을 남기는 방법이며, 일지의
잔존과 주민의 부재는 자료가 걸러진 방식이다. 넷 다 도시가 왜 비었는지를 세우는 이 목적 밖이고
필수·도움 개념을 primary로 달지 않는다. 2.4와 5.4와 6.2와 6.3은 본문에서도 앞뒤 장의 흐름과 곧바로
이어지지 않는다고 밝혔다.

## 재현 조건

1. `python3 build040.py` — 원고와 조각 생성 (PDF SHA 없이 실행하면 자리표시자를 넣는다)
2. `python3 figures040.py pdfbuild040` — 도표 6개 SVG 생성
3. Chrome Headless로 각 SVG를 794×1123 PNG로 렌더링
4. `python3 build_pdf_generic.py 40 7,14,20,28,34,45 pdfbuild040` — 조판 HTML 생성
5. Chrome Headless `--print-to-pdf`로 PDF 출력, `pdfcheck.py`로 구성 확인
6. PDF를 `fixtures/content/ai-route-v2/pdfs/`에 두고 SHA-256을 인자로 `build040.py` 재실행
7. `merge_fragments.py 40`로 정본에 병합

## 검수

- 초고 42쪽 전부가 하한에 걸려 마지막 문단을 늘리는 방식으로 두 차례에 나눠 고쳤다.
- 중복 그룹을 처음에 4.3 **둘째** 페이지에 달았는데 그 페이지에는 짝이 되는 명제가 없었다. 명제가
  실제로 적힌 4.4로 옮기고 7.1의 선수를 4.4에서 4.3으로 바꿔 폐쇄 충돌을 피했다.
- 도표 여섯 장을 PNG로 렌더링해 눈으로 모두 확인했고 넷을 고쳤다. p07은 오른쪽 설명이 마지막 칸 위에
  겹쳐 격자를 좁혔다. **p28은 두 저울이 모두 반대로 기울어 있었다** — 본문은 위 저울이 왼쪽으로, 아래
  저울이 오른쪽으로 기운다고 적었는데 그림은 정반대였다. p34는 시기 이름표가 막대와 겹쳐 띠 아래로
  내렸다. p45는 위 띠가 점선 자리에서 색이 바뀌지 않았고 아래 띠가 점선보다 오른쪽에서 시작했다.
- **p28과 p45의 어긋남은 본문이 맞고 그림이 틀린 경우였다.** 앞 권들에서는 그림이 맞고 본문이 틀린
  자리가 많았는데 이 권은 반대였다. 어느 쪽이 맞는지는 그때마다 읽고 정한다.
- 다른 권과 겹치는 일곱 어절이 하나도 없다. 036·038·039에 이어 네 번째다.
- 세 권 리뷰에서 **설계 문서의 사실과 다른 주장 세 곳**을 코퍼스를 다시 세어 잡아냈다. 039의
  「가장 얕다」와 「드문 구성」, 040의 「대체가 정답보다 하나 적다」가 모두 틀렸다. 코퍼스 전체를
  세어 확인하지 않은 비교급은 앞으로 쓰지 않는다.
- **작업 도중 이 저장소의 워킹 트리 브랜치가 다른 세션에 의해 바뀌어 있었다.** 40번 병합이 엉뚱한
  브랜치의 manifest 위에 얹혀 44권이 되었고, 그 변경을 되돌린 뒤 `git worktree`로 별도 디렉터리를
  만들어 `claude/history-category` 위에서 다시 병합했다. 공용 워킹 트리는 건드리지 않았다.
- `ContentBatchConverterTest`의 코퍼스 재고 단언을 갱신했다. 도서 51→52, 페이지 2141→2190,
  이미지 247→253이다.
- 공개 가이드 주제와 비공개 분석 텍스트를 서로 다른 문장으로 적었고, 주제문에 숫자를 쓰지 않았다.
- 본문·도표·평가 데이터에 실존 인물·작품·단체가 등장하지 않는다.

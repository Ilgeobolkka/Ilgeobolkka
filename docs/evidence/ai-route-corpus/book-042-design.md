## 개념 범위

거래비용(정보 탐색·상대 확인·약속 이행의 세 갈래), 신뢰, 평판, 반복게임, 계약, 도덕적 해이.
047(가격이론)·041(분업·비교우위)과 겹치지 않습니다.

## 장 구성 (49페이지, 목차 1 + 본문 48)

```
1장 거래에는 왜 비용이 드는가            p2–9    PREREQUISITE  거래비용
2장 믿을 사람을 알아보는 법: 신호와 평판  p10–16  CORE          신뢰·평판
3장 계약: 약속을 문서로 만들기           p17–26  CORE          계약
4장 도덕적 해이                          p26–32  CORE          도덕적 해이
5장 신뢰가 무너질 때: 반복게임           p33–39  COUNTERPOINT  반복게임
6장 신뢰를 만드는 제도들                 p40–45  COUNTERPOINT  신뢰 제도
7장 결론: 가격표에 없는 값               p46–48  CONCLUSION    신뢰·거래비용
```

이미지 4개: p8(거래비용 세 갈래), p21(계약 집행 비용 그래프), p28(보험과 도덕적 해이 표),
p39(신뢰 붕괴 그래프).

중복 그룹 1개: `trust-is-hidden-cost` = [2, 46]. "거래에는 왜 비용이 드는가"(1.1)의 도입부와
"신뢰의 값을 매기기 어려운 이유"(7.1)가 신뢰가 숨은 비용이라는 같은 명제를 다른 위치에서
재진술합니다.

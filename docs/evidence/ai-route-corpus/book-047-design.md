# book-047 「가격 형성의 원리: 수요·공급과 시장실패」 구조 설계

SCRUM-485 `ai-route-v2` 코퍼스 파일럿 1권의 ①단계 산출물입니다. 장·절 구성, 개념 지도, 선수 관계
그래프, 중복 그룹, 평가 케이스 골격을 확정하고 검토받기 위한 문서이며, 본문 원고와 페이지별
메타데이터는 ②단계, PDF 조립과 검증은 ③단계에서 작성합니다.

정본은 [AI 경로 콘텐츠 코퍼스](../../ai-route-content-corpus.md)이며, 이 문서와 정본이 어긋나면
정본을 따릅니다.

## 개념 지도와 선수 관계

선수 관계는 `선수 페이지 -> 의존 페이지` 방향입니다. manifest의 `prerequisitePageNumbers[]`에는 각
페이지가 의존하는 **앞선** 페이지 번호를 기록합니다.

### 개념 수준 위계

```
희소성 ─→ 기회비용 ─┬─→ 수요 ─→ 수요의 법칙 ─→ 수요곡선 ─┐
                    │                                      ├─→ 균형가격 ─┬─→ 탄력성 ─→ 탄력성과 매출
                    └─→ 공급 ─→ 공급의 법칙 ─→ 공급곡선 ─┘             │
                                                                          └─→ 초과수요 ─→ 가격상한제 ─┬─→ 암시장
                                                                                                       └─→ 가격하한제
균형의 한계 ─→ 외부효과 ─┬─→ 공공재
                          └─→ 정보 비대칭
```

## 공개 가이드 주제 작성 기준

`aiPublicGuideTopic`은 정본 완료 조건에 따라 **원문·결론·수치·사례 결과를 담지 않습니다.** 페이지가
무엇을 다루는지만 알리는 짧은 주제문으로 작성합니다.

| --- | --- |

표시 대상이 데스크톱 웹 뷰어이므로 한 페이지가 화면 하나를 채울 밀도로 작성합니다.

| 형식 | 기준 |
| --- | --- |
| `TEXT` | 500~700자, 문단 6~8개 |
| `IMAGE` | 도표 명세와 표시 요소 목록 |
| 목차 | 장 7개와 절 34개의 제목·시작 페이지 |

## 목차 페이지

1페이지에 장 7개와 절 34개를 시작 페이지 번호와 함께 싣습니다. 페이지 번호는 원고에서 직접
적지 않고 최종 배열에서 산출하므로 본문이 늘거나 줄어도 목차가 어긋나지 않습니다.

구조 페이지라 본문과 성격이 다릅니다. `contentRole`은 `FRONT_MATTER`,
`aiRouteCandidatePage`는 `false`이며 두 값은 서로 어긋날 수 없습니다. 후보에서 빠지므로 임베딩을
만들지 않고 다른 페이지의 선수 관계 대상이나 평가 정답으로도 쓰이지 않습니다.

`aiAnalysisText`는 경제 개념이 아니라 "이 페이지는 목차이며 본문 설명을 담지 않는다"는 사실만
서술했습니다. 스키마로 이미 제외되지만, 후보 필터가 잘못 동작하더라도 어떤 독서 목적과 유사도가
높지 않도록 이중으로 막아 둔 것입니다. `evaluation.json`의 `irrelevantPageNumbers`에도 넣어 경로에
추천되면 무관 추천으로 세도록 했습니다.

## 예상 독서 시간 기준

`estimatedReadingSeconds`는 고정값이 아니라 실제 본문 길이에서 산출합니다. 본문 분량이 바뀌면 값도
따라 바뀌므로 둘이 어긋나지 않습니다.

| 형식 | 산출 방식 |
| --- | --- |
| `TEXT` | 분당 330자 기준으로 환산한 뒤 5초 단위 반올림, 최소 60초 |
| `IMAGE` | 45초 고정 (도표 이해 시간) |
| 목차 | 40초 고정 (훑어보기) |

분당 330자는 설명문을 곱씹으며 읽는 속도를 가정한 값입니다. 이 도서에서는 `TEXT` 페이지가 평균
106초, 도서 전체가 약 93분으로 산출됩니다.

## 평가 케이스

`evaluation.json`에는 도서당 대표 목적 1개만 두므로 파일럿은 일곱 시나리오 중 **1개만 커버합니다.**
나머지 여섯 시나리오는 89권 확장 시 `bookId`에 배분합니다.

| 필드 | 값 |
| --- | --- |
| `caseId` | `case-book-047` |
| `bookId` | 47 |
| `purpose` | 작은 가게를 열려는데 물건값을 어떤 기준으로 정해야 할지 알고 싶다 |
| `owned` | `false` |
| `maxAdditionalInk` | 10 |
| `depth` | `null` |
| `activeRentalPageNumbers` | `[]` |

정답 데이터입니다. 개념 충족을 우선 판정하므로 페이지 번호보다 개념 목록이 기준입니다.

| 필드 | 값 |
| --- | --- |
| `requiredConcepts` | 수요의 법칙, 공급의 법칙, 균형가격, 수요의 가격탄력성 |
| `helpfulConcepts` | 기회비용, 초과수요, 탄력성과 매출 |
| `requiredPrerequisites` | 13→25, 21→25, 25→35 |
| `irrelevantPageNumbers` | 1, 52, 53, 54, 55 |
| `duplicatePageGroups` | [28, 44], [2, 56] |
| `referencePageNumbers` | 11, 13, 19, 21, 25, 37, 40 |
| `allowedAlternativePageNumbers` | 12, 20, 26, 38, 41 |

`irrelevantPageNumbers`에는 시장실패를 다루는 네 페이지와 목차 페이지가 들어갑니다. 시장실패는
이 목적("값을 어떻게 정하는가")과 직접 관련이 없고, 목차는 경로에 추천되어서는 안 되는
구조 페이지입니다. 정답 필드는 후보 검색이나 경로 구성 입력으로 사용하지 않습니다.

임베딩을 전량 재생성해야 하므로 `ai-route-v2` 안에서는 변경하지 않습니다.

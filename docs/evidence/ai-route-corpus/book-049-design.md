## 개념 범위

최종 산출, 국내총생산, 성장률, 실질 성장률, 복리, 생산성, 노동생산성, 인적자본, 자본 감가,
자원제약, 지속가능성. 카테고리 계획이 정한 배분(GDP, 성장률 계산, 생산성, 인적자본, 자원제약과
지속가능성)을 그대로 따랐습니다.

## 인접한 세 권과의 경계

이 책은 경제 카테고리에서 가장 마지막에 만들어져 세 권과 경계를 맞춰야 했습니다.

- **45번(화폐와 신용창조)**: 2.2에서 명목과 실질을 가르지만, 물가를 어떻게 재는지는 다루지 않습니다.
  값을 걷어 내야 한다는 사실과 걷어 낸 뒤의 숫자를 실질이라 부른다는 것까지만 쓰고, 기준 연도를
  고르는 문제로 좁혔습니다. 장바구니와 가중치는 45번에 남아 있습니다.
- **50번(상관과 인과)**: 5장에서 십 년치 자료를 읽지만 추론의 일반 규칙은 쓰지 않습니다. 교란변수나
  역인과 같은 말이 등장하지 않고, 대신 총량을 분모로 나눠 보는 이 책 고유의 도구만 씁니다. 5.2의
  해석에 확인하지 못한 부분이 있다고 적은 것도, 50번의 언어를 빌리지 않고 같은 조심성을 표현한
  자리입니다.
- **41번(분업과 비교우위)**: 3.4에서 생산성이 오르는 갈래를 도구·방법·사람 셋으로 나누는데, 분업은
  방법의 한 갈래로만 언급하고 설명하지 않습니다.

## 장 구성 (53페이지, 목차 1 + 본문 52)

```
1장 한 해 동안 만들어 낸 것    p2–9    PREREQUISITE  최종 산출·국내총생산
2장 늘었다는 말의 뜻           p10–18  CORE          성장률·실질·복리
3장 생산성: 무엇으로 나누는가   p19–25  CORE          생산성·노동생산성
4장 사람에 쌓이는 것           p26–33  COUNTERPOINT  인적자본
5장 너리골의 십 년             p34–41  EXAMPLE       실제 자료 읽기
6장 줄어드는 것을 쓰는 성장     p42–48  COUNTERPOINT  자원제약·감가·지속가능성
7장 결론: 성장은 잣대다        p49–53  CONCLUSION    전체 개념 통합
```

배경은 가상 지역 "너리골"과 가상 인물(재이, 성호, 별하, 윤슬)이며 실존 지역·기관·인물을 모방하지
않습니다.

이미지 6개: p8(쌀·가루·빵 세 단계와 중복을 걷어 내는 두 방법), p14(명목 성장률을 값의 몫과 양의 몫으로
쌓은 막대), p23(같은 산출을 세 분모로 나눈 세 선), p30(사람에게 쌓인 것과 도구의 값어치가 서로 다른
모양으로 오르내리는 그림), p38(너리골 십 년의 총량·사람 수·한 사람당 세 줄), p46(자라는 만큼 거두는
경우와 헐어 쓰는 경우). 총량을 붉은 계열, 나눈 값을 파랑, 투입과 사람 수를 회색으로 고정해 여섯
도표에서 같은 뜻으로 씁니다.

중복 그룹은 없습니다. 처음에는 `measure-not-goal` = [9, 51]로 묶었습니다 — "이 숫자는 만들어 낸 것의
크기를 재는 잣대일 뿐 잘 사는지의 총합이 아니다"라는 명제를 1.5에서 세우고 7.2에서 재진술하기
때문입니다. 그러나 51의 선수(9, 47) 중 47도 9를 거치므로, 51을 고른 경로에는 9가 반드시 따라옵니다.
book-046처럼 짝을 부모로 바꿔도 47이 다시 9를 끌어와 해소되지 않습니다. 한쪽이 다른 쪽의 선수인 두
페이지는 "둘 중 하나만 고르는" 대체 관계가 아니므로, 선수 관계는 그대로 두고 그룹 표시를 지웠습니다
(book-034에서 같은 판단을 했습니다).

## 선수 관계 설계

1.2(최종 산출)를 6장의 뿌리로, 1.5(국내총생산)를 2·3장의 뿌리로 두고, 5·7장은 2.1과 3.1에서
갈라집니다. 어느 후보 페이지도 선수 폐쇄가 10페이지를 넘지 않습니다.

- 폐쇄 5페이지 이하인 후보 페이지가 여섯 개 장을 덮습니다 (기준 3개 장).
- 후보 페이지 52개 전부가 폐쇄 15페이지 이하입니다 (기준 75%).

## 검증

`corpus_lib.validate_book()` → `validate_fragment.py` → `merge_fragments.py` →
`validate_manifest.py` → `selftest.py` 순으로 모두 통과했습니다.

- 53페이지(목차 1 + 본문 52), 7개 장, 내용 역할 5종 모두 사용
- `TEXT` 본문 46페이지가 501~558자(평균 524자, 합계 24,108자)로 전량 500자 이상
- `FRONT_MATTER`(목차)와 `aiRouteCandidatePage=false`가 정확히 일치
- 선수 관계가 후보 제외 페이지를 가리키지 않음, 위상 정렬로 53페이지 전체 방문
- PDF 페이지 53개, 텍스트 47개, 이미지 6개(p8,14,23,30,38,46) — `pdfcheck.py`로 확인
- PDF 실제 SHA-256이 manifest의 `pdfSha256`과 일치

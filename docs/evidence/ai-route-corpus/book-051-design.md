# book-051 「의심에서 시작하는 철학」 설계·검수 근거

SCRUM-485 90권 확장 중 철학 카테고리 첫 번째 도서입니다. 다른 도서 작업과 공유
`manifest.json`·`evaluation.json`에서 충돌하지 않도록 단일 도서 fragment로 작성한 뒤 병합했습니다.

## 대상 도서

| 필드 | 값 | 처리 |
| --- | --- | --- |
| `bookId` | 51 | 유지 |
| `category` | 철학 | 유지 |
| `title` | 의심에서 시작하는 철학 | 카테고리 톤에 맞게 갱신 |
| `author` | 가상 작가 051 | 유지 |
| `description` | 일상의 질문을 통해 생각의 태도를 탐색하는 가상 철학서입니다. | 유지 |
| `totalPageCount` | 3 → **50** | 재제작 |

저자·카테고리·소개는 `src/main/resources/demo/books.json`의 기존 값을 유지했습니다. 제목은 철학
카테고리 제목 갱신에 따른 새 값이며 정본은 `ai-route-v2` manifest의 `books[].title`입니다.
`books.json`은 `initial-v1` 동결 fixture이므로 고치지 않습니다.

## 개념 범위와 서술 원칙

[`philosophy-category-plan.md`](./philosophy-category-plan.md)가 book-051에 배정한 회의적 태도,
전제의 검토, 질문을 멈추지 않는 탐구 방법을 핵심 주제로 사용했습니다. 같은 카테고리의 다른 도서에
배정된 선택과 책임(52), 기억과 인격 동일성(53), 언어의 한계(54), 타인의 마음(55), 좋은 삶(56),
시간과 존재(57), 규칙과 예외(58), 무지의 자각(59), 관점의 복수성(60)은 핵심 개념으로 확장하지
않았습니다.

계획이 요구한 대로 실존 철학자 이름과 학파 명칭을 쓰지 않고, 사고 실험과 가상 인물의 대화로 논지를
전개했습니다. 가상 인물은 소민·우재·은결 셋이며 기존 코퍼스에서 쓰지 않은 이름입니다. 인물 이름은
대화가 내용 자체인 6장 사례에만 두고, 1~5·7장의 서술은 인물에 기대지 않고 직접 서술합니다. 인물
이름은 대화가 내용 자체인 6장 사례에만 두고, 1~5·7장의 서술은 인물에 기대지 않고 직접 서술합니다.
귀류법, 반례, 개념 구분, 사고 실험 같은 보편적 논증 방법은 그 절차를 설명하는 방식으로 다뤘고,
결론을 단정하는 대신 각 방법이 부딪히는 난점(무한 후퇴, 전면 회의의 자기 지시, 선택적 의심, 의심의
비용)을 5장 전체에 따로 두었습니다.

59권과의 경계는 다음과 같이 잡았습니다. 이 권은 "물음을 세우고 전제를 찾아 검토하고 어디서 멈출지
정하는 절차"를 다루고, "내가 모른다는 사실을 아는 상태"와 그로부터 배움이 시작되는 구조는 다루지
않습니다.

## 장 구성

50페이지는 목차 1페이지와 본문 49페이지로 구성합니다.

| 장 | 페이지 | 중심 역할 | 내용 |
| --- | --- | --- | --- |
| 1장 의심은 어디서 시작되는가 | 2~8 | `PREREQUISITE` | 의심의 정의, 물음의 발생, 믿음의 목록과 배경 가정 |
| 2장 전제를 찾아내는 법 | 9~15 | `PREREQUISITE`·`CORE` | 전제와 근거의 구분, 숨은 전제 탐색, 전제 교체 |
| 3장 의심의 절차 | 16~22 | `CORE` | 반례, 귀류, 개념 구분, 사고 실험 |
| 4장 의심이 멈추는 자리 | 23~29 | `COUNTERPOINT`·`CORE` | 무한 후퇴와 순환, 잠정적 승인, 행위의 시간 제약 |
| 5장 의심이 실패하는 방식 | 30~36 | `COUNTERPOINT` | 전면 회의, 선택적 의심과 문턱, 의심의 비용 |
| 6장 세 사람의 대화 | 37~43 | `EXAMPLE` | 약속·지도·저울 세 사례에 앞 장의 절차를 적용 |
| 7장 다시 묻기 위하여 | 44~50 | `CONCLUSION` | 네 걸음 절차의 요약, 과소·과잉 적용, 묻기의 지속 |

TEXT 본문 45페이지는 모두 4문단이며 388~537자, 평균 467.5자입니다. 본문 합계는 21,038자입니다.
개념을 정의한 뒤 그 방법이 통하지 않는 조건을 별도 페이지로 배치했고, 6장에서는 앞선 절차를 세 개의
가상 대화에 다시 적용했습니다.

## 이미지 페이지

이미지 4개는 원고 설명에 대응하는 새 SVG 도표를
[`figures051.py`](./tools/figures051.py)로 작성하고 PNG로 렌더링해 PDF에 넣었습니다. 네 도표는
검토로 이어지는 갈래를 진한 선, 검토를 지우는 갈래를 옅은 선, 말해지지 않은 것을 점선으로 그려 같은
표기를 씁니다.

| 페이지 | 도표 | 검수 초점 |
| --- | --- | --- |
| 8 | 어긋난 곳에서 물음이 생긴다 | 물음으로 올라가는 갈래와 합리화로 지워지는 갈래의 분리 |
| 13 | 말해진 것과 말해지지 않은 것 | 명시된 주장 한 층과 미명시 조건 세 층의 실선·점선 구분 |
| 25 | 물음은 세 가지로만 끝난다 | 무한 진행·순환·정지 중 정지에만 하위 화살표가 없음 |
| 36 | 어느 쪽으로 기울어 있는가 | 물음의 총량이 아니라 분포와 문턱 격차 |

도표 4개를 원본 크기 PNG로 확인했습니다. 최종 PDF 50페이지 전체를 접촉 시트로 훑고, 목차와 마지막
페이지를 원본 크기로 다시 확인해 글자 잘림·겹침·깨진 한글과 본문 넘침이 없음을 확인했습니다.

## 구조 메타데이터

- 내용 역할 5종을 모두 사용했습니다. `FRONT_MATTER`는 목차 1페이지에만 사용합니다.
- 목차만 `aiRouteCandidatePage=false`이고 나머지 49페이지는 모두 `true`입니다.
- 선수 관계 49개는 절 식별자로 설계한 뒤 최종 페이지 번호로 계산했으며, 자기 참조·범위 밖 참조·
  순환이 없습니다. 최대 전이 폐쇄는 7페이지이고 후보 전체가 폐쇄 15페이지 이하입니다.
- `doubt-as-method` 중복 그룹은 2페이지의 "의심은 판정이 아니라 절차"라는 규정과 44페이지의 결론부
  재진술만 연결합니다. 44페이지가 든 7.1절에는 선수 절을 두지 않았습니다. 선수를 걸면 그 폐쇄가 2페이지를
  포함해 같은 중복 그룹 페이지가 폐쇄 안에 둘 생기고, 그 후보는 어떤 예산으로도 고를 수 없게 됩니다.
- `aiPublicGuideTopic`은 원문 결론이나 사례 결과를 옮기지 않은 별도 공개 안내 문장입니다.

## 평가 케이스: 소장·QUICK

카테고리 계획이 book-051에 배정한 시나리오입니다.

| 필드 | 값 |
| --- | --- |
| `caseId` | `case-book-051` |
| `purpose` | 이 책을 소장하고 있는데, 무엇을 의심이라 부르는지와 주장 아래 놓인 조건을 찾아 검토하는 방법의 핵심만 짧게 잡고 싶다 |
| `owned` / `maxAdditionalInk` / `depth` | `true` / `null` / `QUICK` |
| `requiredConcepts` | 의심, 믿음의 목록, 전제, 반례, 무한 후퇴 |
| `helpfulConcepts` | 의심의 계기, 숨은 전제, 귀류, 잠정적 승인 |
| `referencePageNumbers` | 2, 6, 9, 16, 23 |
| `allowedAlternativePageNumbers` | 3, 10, 17, 20, 30 |
| `irrelevantPageNumbers` | 32, 33, 40, 41, 42, 43 |

정답 경로는 16·23페이지를 씨앗으로 두고 전이적 선수 폐쇄를 펼친 5페이지이며 QUICK 상한과 정확히
같습니다. 다섯 페이지가 서로 다른 네 개 장에 걸쳐 필수 개념 5종을 덮습니다. 대체 페이지 다섯은 모두
폐쇄가 5페이지 이하라 정답 한 자리를 실제로 대신할 수 있습니다(각각 2·4·5·4·3페이지).

무관 페이지는 절 단위로 잡았습니다. 5.2절(한쪽만 의심할 때)과 6.2·6.3절(지도와 길, 저울과 눈금)은
필수·도움 개념을 `primaryConcepts`로 달지 않고, 정답·대체 페이지의 선수 폐쇄가 이 페이지들을 지나지
않습니다. 목적 문장에는 책 제목이나 정답 페이지 번호를 넣지 않았습니다.

## 권리·개인정보

본문과 도표는 실존 작품을 인용·번역·모방하지 않고 이 fixture를 위해 새로 작성했습니다. 실존 철학자,
학파, 저작과 특정 개인을 가리키는 이름이나 개인정보를 포함하지 않습니다. 소민·우재·은결은 가상
인물입니다.

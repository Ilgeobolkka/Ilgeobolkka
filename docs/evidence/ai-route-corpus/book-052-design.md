# book-052 「선택과 책임: 되돌릴 수 없는 결정」 설계·검수 근거

SCRUM-485 90권 확장 중 철학 카테고리 두 번째 도서입니다. 다른 도서 작업과 공유
`manifest.json`·`evaluation.json`에서 충돌하지 않도록 단일 도서 fragment로 작성한 뒤 병합했습니다.

## 개념 범위와 서술 원칙

[`philosophy-category-plan.md`](./philosophy-category-plan.md)가 book-052에 배정한 선택의 불가역성,
반사실적 대안에 대한 책임, 후회와 정당화를 핵심 주제로 사용했습니다. 계획이 명시적으로 제외한
**자유의지의 형이상학적 성립 여부**는 1.5절에서 논의 범위 밖임을 밝히고 다루지 않습니다. 행위를 정할 때
규칙과 예외 중 무엇을 따를지의 구조는 058의 몫이므로 이 권은 **이미 내린 선택에 대한 책임 소재**에
한정했습니다.

051과의 경계는 다음과 같습니다. 051은 주장의 전제를 검토하는 절차를 다루고 052는 이미 닫힌 결정을
사후에 어떻게 가를지를 다룹니다. 두 권 모두 기록을 강조하지만 기록 대상이 다릅니다 — 051은 무엇을
묻고 어디서 멈췄는지를, 052는 무엇을 기준으로 골랐고 무엇이 운의 몫이었는지를 남깁니다.

실존 철학자 이름과 학파 명칭을 쓰지 않고 사고 실험과 가상 인물의 대화로 전개했습니다. 가상 인물은
노아·하율이며 기존 코퍼스에서 쓰지 않은 이름입니다. 인물 이름은 대화가 내용 자체인 6장 사례에만
두고, 1~5·7장의 서술은 인물에 기대지 않고 직접 서술합니다. 인물 이름은 대화가 내용 자체인 6장
사례에만 두고, 1~5·7장의 서술은 인물에 기대지 않고 직접 서술합니다.

## 장 구성

50페이지는 목차 1페이지와 본문 49페이지로 구성합니다.

| 장 | 페이지 | 중심 역할 | 내용 |
| --- | --- | --- | --- |
| 1장 선택은 언제 선택이 되는가 | 2~9 | `PREREQUISITE` | 선택의 성립 조건, 대안의 세 층위, 유보의 성격, 논의 범위 |
| 2장 되돌릴 수 없다는 것 | 10~16 | `PREREQUISITE`·`CORE` | 복원 비용, 잠금 지점, 가역성 설계 |
| 3장 가지 않은 길 | 17~23 | `CORE` | 반사실 구성, 비교 불가능성, 결과 판단과 과정 판단 |
| 4장 책임은 어디까지인가 | 24~30 | `CORE` | 귀속 대상, 예견·회피 교집합, 운, 책임 분담과 위임 |
| 5장 후회의 자리 | 31~37 | `COUNTERPOINT` | 후회의 구조, 사후 정당화, 매몰 투입, 자책과 책임 |
| 6장 세 가지 결정 | 38~44 | `EXAMPLE` | 이주 결정, 공동 결정, 장기 유보 사례 |
| 7장 고른 뒤에 하는 일 | 45~50 | `CONCLUSION` | 절차 요약, 평가 기준, 실패 방향, 결정의 축적 |

TEXT 본문 45페이지는 모두 4문단이며 358~500자, 평균 418.1자입니다. 본문 합계는 18,813자로 모든
페이지가 `estimatedReadingSeconds`의 60초 하한(345자)을 넘습니다.

## 구조 메타데이터

- 내용 역할 5종을 모두 사용했습니다. `FRONT_MATTER`는 목차 1페이지에만 사용합니다.
- 목차만 `aiRouteCandidatePage=false`이고 나머지 49페이지는 모두 `true`입니다.
- 선수 관계 49개는 절 식별자로 설계한 뒤 최종 페이지 번호로 계산했습니다. 최대 전이 폐쇄는
  6페이지이고 후보 전체가 폐쇄 15페이지 이하이며, 폐쇄 5페이지 이하인 후보가 7개 장을 모두 덮습니다.
- `choice-and-what-follows` 중복 그룹은 2페이지의 선택 성립 조건 규정과 45페이지의 결론부 재진술만
  연결합니다. 45페이지가 든 7.1절에는 선수 절을 두지 않았습니다 — 선수를 걸면 폐쇄가 2페이지를 포함해
  같은 중복 그룹 페이지가 폐쇄 안에 둘 생기고, 그 후보는 어떤 예산으로도 고를 수 없게 됩니다.
- `aiPublicGuideTopic`은 원문 결론이나 사례 결과를 옮기지 않은 별도 공개 안내 문장입니다.

## 평가 케이스: 비소장·예산 0

카테고리 계획이 book-052에 배정한 시나리오입니다.

| 필드 | 값 |
| --- | --- |
| `caseId` | `case-book-052` |
| `purpose` | 잉크를 더 쓸 수 없는데, 이미 열어 둔 페이지 안에서 무엇을 선택이라 부르는지와 되돌릴 수 없게 된 결정의 몫이 어디까지인지를 가리고 싶다 |
| `owned` / `maxAdditionalInk` / `depth` | `false` / `0` / `null` |
| `activeRentalPageNumbers` | 2, 3, 4, 10, 11, 17, 24, 25 |
| `requiredConcepts` | 선택, 대안의 조건, 불가역성, 반사실, 책임의 대상 |
| `helpfulConcepts` | 잠금, 결과 판단, 운, 후회 |
| `referencePageNumbers` | 2, 4, 10, 17, 24 |
| `allowedAlternativePageNumbers` | 3, 11, 25 |
| `irrelevantPageNumbers` | 33, 34, 41, 42, 43, 44 |

예산 0이므로 정답 경로의 선수 폐쇄 전체가 활성 대여 안에 들어야 합니다. 대여 목록은 폐쇄 5페이지에
같은 절의 이어지는 페이지 셋(3·11·25)을 더해 잡았고, 그 셋이 대체 페이지가 됩니다. 추가 차감은
0페이지입니다.

무관 페이지는 절 단위로 잡았습니다. 5.2절(정당화의 유혹), 6.2절(함께 정하기), 6.3절(미루기의 값)은
필수·도움 개념을 `primaryConcepts`로 달지 않고, 정답·대체 페이지의 선수 폐쇄가 이 페이지들을 지나지
않습니다. 목적 문장에는 책 제목이나 정답 페이지 번호를 넣지 않았습니다.

## 권리·개인정보

본문과 도표는 실존 작품을 인용·번역·모방하지 않고 이 fixture를 위해 새로 작성했습니다. 실존 철학자,
학파, 저작과 특정 개인을 가리키는 이름이나 개인정보를 포함하지 않습니다. 노아·하율은 가상 인물입니다.

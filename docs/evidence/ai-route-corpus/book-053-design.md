# book-053 「기억과 인격 동일성」 설계·검수 근거

SCRUM-485 90권 확장 중 철학 카테고리 세 번째 도서입니다. 다른 도서 작업과 공유
`manifest.json`·`evaluation.json`에서 충돌하지 않도록 단일 도서 fragment로 작성한 뒤 병합했습니다.

## 대상 도서

| 필드 | 값 | 처리 |
| --- | --- | --- |
| `bookId` | 53 | 유지 |
| `category` | 철학 | 유지 |
| `title` | 기억과 인격 동일성 | 카테고리 톤에 맞게 갱신 |

저자·카테고리·소개는 `src/main/resources/demo/books.json`의 기존 값을 유지했습니다. 제목의 정본은

않습니다.

## 개념 범위와 서술 원칙

[`philosophy-category-plan.md`](./philosophy-category-plan.md)가 book-053에 배정한 기억의 오류 가능성,
인격 동일성의 기준, 연속성과 단절을 핵심 주제로 사용했습니다. 계획이 정한 대로 **시간 속에서 존재가
지속하는 방식 일반**은 057의 몫이므로 다루지 않고, 기억에 근거한 동일 인격 판정에 한정했습니다. 타인의
내면에 닿을 수 있는지는 055의 몫이므로 이 권은 자기 자신의 동일성만 다룹니다.

051·052와의 경계는 이렇습니다. 051은 주장의 전제를 검토하는 절차, 052는 이미 닫힌 결정의 책임 소재,
053은 그 책임이 걸리는 주체가 같은 사람인지의 판정입니다. 052가 결정의 시점을 문제 삼는 반면 053은
결정한 사람과 지금 사람의 관계를 문제 삼습니다.

실존 철학자 이름과 학파 명칭을 쓰지 않았습니다. 3.4절의 배 판자 이야기처럼 널리 알려진 사고 실험은
이름을 붙이지 않고 구조만 서술했습니다. 가상 인물은 서아·채원이며 기존 코퍼스에서 쓰지 않은
이름입니다. 인물 이름은 대화가 내용 자체인 6장 사례에만 두고, 1~5·7장의 서술은 인물에 기대지 않고
직접 서술합니다. 인물 이름은 대화가 내용 자체인 6장 사례에만 두고, 1~5·7장의 서술은 인물에 기대지
않고 직접 서술합니다.

## 장 구성

49페이지는 목차 1페이지와 본문 48페이지로 구성합니다.

| 장 | 페이지 | 중심 역할 | 내용 |
| --- | --- | --- | --- |
| 1장 나는 어제의 나인가 | 2~8 | `PREREQUISITE` | 판정이 요구되는 세 맥락, 중첩 연쇄, 세 척도 |
| 2장 기억이라는 증거 | 9~15 | `PREREQUISITE`·`CORE` | 기억의 재구성, 수정 방향, 허위 기억 |
| 3장 이어짐과 끊김 | 16~22 | `CORE` | 기억의 사슬, 단절의 세 유형, 시점 차이, 점진적 변화 |
| 4장 네 가지 사고 실험 | 23~29 | `CORE` | 기억 이전, 분기, 복수 후보, 전면적 기억 상실 |
| 5장 기억만으로는 부족하다 | 30~36 | `COUNTERPOINT` | 기준의 순환, 망각과 귀속, 외부 기억, 비기억적 연속 |
| 6장 세 사람의 사정 | 37~43 | `EXAMPLE` | 오래된 편지, 기억이 흐려진 이웃, 기억 못 하는 잘못 |
| 7장 같은 사람이라는 말 | 44~49 | `CONCLUSION` | 요약, 판정 불가의 인정, 기억을 대하는 태도, 이어 가는 실천 |

TEXT 본문 44페이지는 모두 4문단이며 349~444자, 평균 397.2자입니다. 본문 합계는 17,475자로 모든
페이지가 `estimatedReadingSeconds`의 60초 하한(345자)을 넘습니다.

## 구조 메타데이터

- 내용 역할 5종을 모두 사용했습니다. `FRONT_MATTER`는 목차 1페이지에만 사용합니다.
- 목차만 `aiRouteCandidatePage=false`이고 나머지 48페이지는 모두 `true`입니다.
- 선수 관계 48개는 절 식별자로 설계한 뒤 최종 페이지 번호로 계산했습니다. 최대 전이 폐쇄는
  6페이지이고 후보 전체가 폐쇄 15페이지 이하이며, 폐쇄 5페이지 이하인 후보가 7개 장을 모두 덮습니다.
- `same-person-question` 중복 그룹은 2페이지의 물음 제시와 44페이지의 결론부 재진술만 연결합니다.
  44페이지가 든 7.1절에는 선수 절을 두지 않았습니다 — 선수를 걸면 폐쇄가 2페이지를 포함해 같은 중복
  그룹 페이지가 폐쇄 안에 둘 생기고, 그 후보는 어떤 예산으로도 고를 수 없게 됩니다.
- `aiPublicGuideTopic`은 원문 결론이나 사례 결과를 옮기지 않은 별도 공개 안내 문장입니다.

## 평가 케이스: 비소장·예산 5

카테고리 계획이 book-053에 배정한 시나리오입니다.

| 필드 | 값 |
| --- | --- |
| `caseId` | `case-book-053` |
| `purpose` | 기억을 근거로 예전의 나와 지금의 내가 같은 사람이라고 말할 수 있는지, 그 기억이 다시 쓰인다는 사실이 그 판단을 어떻게 흔드는지 알고 싶다 |
| `owned` / `maxAdditionalInk` / `depth` | `false` / `5` / `null` |
| `requiredConcepts` | 인격 동일성, 연속성, 기억의 기능, 재구성, 시점의 차이 |
| `helpfulConcepts` | 동일성의 기준, 오기억, 기억의 사슬, 단절 |
| `referencePageNumbers` | 2, 4, 9, 11, 20 |
| `allowedAlternativePageNumbers` | 3, 10, 12, 22, 28 |
| `irrelevantPageNumbers` | 34, 35, 40, 41, 42, 43 |

정답 경로는 11·20페이지를 씨앗으로 두고 전이적 선수 폐쇄를 펼친 5페이지이며 예산 5와 정확히
같습니다. 활성 대여가 없으므로 다섯 페이지 전부가 차감 대상입니다. 대체 페이지 다섯은 폐쇄가 각각
2·3·4·3·3페이지로 모두 예산 안에 듭니다.

무관 페이지는 절 단위로 잡았습니다. 5.3절(남이 대신 기억할 때), 6.2절(되찾은 이름), 6.3절(오래전의
일)은 필수·도움 개념을 `primaryConcepts`로 달지 않고, 정답·대체 페이지의 선수 폐쇄가 이 페이지들을
지나지 않습니다. 목적 문장에는 책 제목이나 정답 페이지 번호를 넣지 않았습니다.

## 권리·개인정보

본문과 도표는 실존 작품을 인용·번역·모방하지 않고 이 fixture를 위해 새로 작성했습니다. 실존 철학자,
학파, 저작과 특정 개인을 가리키는 이름이나 개인정보를 포함하지 않습니다. 서아·채원은 가상 인물입니다.

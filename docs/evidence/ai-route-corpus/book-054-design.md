# book-054 「말할 수 있는 것과 말할 수 없는 것」 설계·검수 근거

SCRUM-485 90권 확장 중 철학 카테고리 네 번째 도서입니다. 다른 도서 작업과 공유
`manifest.json`·`evaluation.json`에서 충돌하지 않도록 단일 도서 fragment로 작성한 뒤 병합했습니다.

## 대상 도서

| 필드 | 값 | 처리 |
| --- | --- | --- |
| `bookId` | 54 | 유지 |
| `category` | 철학 | 유지 |
| `title` | 말할 수 있는 것과 말할 수 없는 것 | 카테고리 톤에 맞게 갱신 |
| `author` | 가상 작가 054 | 유지 |
| `description` | 침묵과 언어의 경계를 탐구하는 가상 철학서입니다. | 유지 |
| `totalPageCount` | 3 → **49** | 재제작 |

저자·카테고리·소개는 `src/main/resources/demo/books.json`의 기존 값을 유지했습니다. 제목의 정본은
`ai-route-v2` manifest의 `books[].title`입니다.

## 개념 범위와 서술 원칙

[`philosophy-category-plan.md`](./philosophy-category-plan.md)가 book-054에 배정한 언어로 표현할 수
있는 것과 없는 것의 경계, 침묵의 의미, 말하기의 한계를 핵심 주제로 사용했습니다. 계획이 정한 대로
**타인의 내면에 접근할 수 있는지**는 055의 몫이므로 다루지 않았습니다. 이 권이 다루는 대상은 사람이
아니라 언어 자체입니다. 여러 관점이 대화에서 부딪히고 조정되는 과정은 060의 몫이므로 다루지 않습니다.

이 권의 축은 "말할 수 없다"를 네 종류로 가르는 것입니다. 이름이 없어서, 겪어야 알아서, 말하면
달라져서, 말하지 않기로 해서입니다. 앞의 둘은 능력, 셋째는 시점, 넷째는 선택의 문제이며 종류마다 다른
방법이 대응합니다. 5장은 이 한계가 검토 회피(표현 불가 주장)와 과신(언어 과신) 양쪽으로 잘못 쓰이는
방식을 다룹니다.

실존 철학자 이름과 학파 명칭을 쓰지 않았습니다. 가상 인물은 시후·준서이며 기존 코퍼스에서 쓰지 않은
이름입니다. 인물 이름은 대화가 내용 자체인 6장 사례에만 두고, 1~5·7장의 서술은 인물에 기대지 않고
직접 서술합니다. 인물 이름은 대화가 내용 자체인 6장 사례에만 두고, 1~5·7장의 서술은 인물에 기대지
않고 직접 서술합니다.

## 장 구성

49페이지는 목차 1페이지와 본문 48페이지로 구성합니다.

| 장 | 페이지 | 중심 역할 | 내용 |
| --- | --- | --- | --- |
| 1장 말이 닿는 자리 | 2~8 | `PREREQUISITE` | 언어의 세 기능, 분절, 경험과 언어의 간극 |
| 2장 말할 수 없는 것들 | 9~15 | `PREREQUISITE`·`CORE` | 미명명, 체험적 앎, 네 유형, 발화에 의한 변형 |
| 3장 경계를 그리는 방법 | 16~22 | `CORE` | 우회 지시, 비유, 공유 경험, 조어 |
| 4장 침묵 | 23~29 | `CORE` | 침묵의 네 사태, 의미 조건, 절제, 강요된 침묵 |
| 5장 한계를 잘못 쓰는 방식 | 30~36 | `COUNTERPOINT` | 표현 불가 주장, 모호함의 이용, 언어 과신 |
| 6장 세 자리의 말 | 37~43 | `EXAMPLE` | 아픈 사람 곁, 가르치는 자리, 사과하는 자리 |
| 7장 말과 침묵을 함께 쓰기 | 44~49 | `CONCLUSION` | 요약, 침묵 다루기, 실패 지점, 언어의 확장 |

TEXT 본문 44페이지는 모두 4문단이며 345~441자, 평균 374.5자입니다. 초안에서 345자에 못 미치던
다섯 페이지를 보강해 `estimatedReadingSeconds`가 60초 하한에 눌리는 페이지를 없앴습니다.

## 구조 메타데이터

- 내용 역할 5종을 모두 사용했습니다. `FRONT_MATTER`는 목차 1페이지에만 사용합니다.
- 목차만 `aiRouteCandidatePage=false`이고 나머지 48페이지는 모두 `true`입니다.
- 선수 관계 48개는 절 식별자로 설계한 뒤 최종 페이지 번호로 계산했습니다. 최대 전이 폐쇄는
  7페이지이고 후보 전체가 폐쇄 15페이지 이하이며, 폐쇄 5페이지 이하인 후보가 7개 장을 모두 덮습니다.
- `what-language-reaches` 중복 그룹은 2페이지의 세 기능 제시와 44페이지의 결론부 재진술만
  연결합니다. 44페이지가 든 7.1절에는 선수 절을 두지 않았습니다.
- `aiPublicGuideTopic`은 원문 결론이나 사례 결과를 옮기지 않은 별도 공개 안내 문장입니다.

## 평가 케이스: 소장·BALANCED

카테고리 계획이 book-054에 배정한 시나리오입니다.

| 필드 | 값 |
| --- | --- |
| `caseId` | `case-book-054` |
| `purpose` | 이 책을 소장하고 있는데, 어떤 것이 왜 말로 옮겨지지 않는지 그 종류를 갈라 보고 곧장 말할 수 없을 때 쓸 수 있는 방법까지 차근히 익히고 싶다 |
| `owned` / `maxAdditionalInk` / `depth` | `true` / `null` / `BALANCED` |
| `requiredConcepts` | 말의 기능, 경험과 언어, 미명명, 체험적 앎, 우회 지시, 비유, 침묵의 구분 |
| `helpfulConcepts` | 지시와 분절, 침묵의 의미, 조어, 공유 경험 |
| `referencePageNumbers` | 2, 4, 6, 9, 11, 16, 18, 23, 25, 30 |
| `allowedAlternativePageNumbers` | 3, 10, 12, 22, 26 |
| `irrelevantPageNumbers` | 32, 33, 40, 41, 42, 43 |

정답 경로는 18·25·30페이지를 씨앗으로 두고 전이적 선수 폐쇄를 펼친 10페이지이며 BALANCED 상한과
정확히 같습니다. 열 페이지가 다섯 개 장에 걸쳐 필수 개념 7종을 덮습니다. 대체 페이지 다섯은 폐쇄가
각각 2·4·4·4·3페이지로 상한 안에 듭니다.

무관 페이지는 절 단위로 잡았습니다. 5.2절(흐린 말의 편리함), 6.2절(가르치는 자리), 6.3절(사과하는
자리)은 필수·도움 개념을 `primaryConcepts`로 달지 않고, 정답·대체 페이지의 선수 폐쇄가 이 페이지들을
지나지 않습니다.

## 권리·개인정보

본문과 도표는 실존 작품을 인용·번역·모방하지 않고 이 fixture를 위해 새로 작성했습니다. 실존 철학자,
학파, 저작과 특정 개인을 가리키는 이름이나 개인정보를 포함하지 않습니다. 시후·준서는 가상 인물입니다.

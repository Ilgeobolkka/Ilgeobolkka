# book-055 「타인의 마음은 알 수 있는가」 설계·검수 근거

SCRUM-485 90권 확장 중 철학 카테고리 다섯 번째 도서입니다. 다른 도서 작업과 공유
`manifest.json`·`evaluation.json`에서 충돌하지 않도록 단일 도서 fragment로 작성한 뒤 병합했습니다.

## 대상 도서

| 필드 | 값 | 처리 |
| --- | --- | --- |
| `bookId` | 55 | 유지 |
| `category` | 철학 | 유지 |
| `title` | 타인의 마음은 알 수 있는가 | 카테고리 톤에 맞게 갱신 |
| `author` | 가상 작가 055 | 유지 |
| `description` | 타인을 이해하는 가능성을 묻는 가상 철학서입니다. | 유지 |

저자·카테고리·소개는 `src/main/resources/demo/books.json`의 기존 값을 유지했습니다. 제목의 정본은
`ai-route-v2` manifest의 `books[].title`입니다.

## 개념 범위와 서술 원칙

[`philosophy-category-plan.md`](./philosophy-category-plan.md)가 book-055에 배정한 타인의 마음에 대한
접근 가능성, 공감의 근거와 한계, 추론과 직접 경험의 차이를 핵심 주제로 사용했습니다.

카테고리 안의 인접 권과는 이렇게 나눴습니다. 053은 자기 자신의 동일성을 다루고 055는 타인의 내면을
다룹니다. 054는 언어 자체의 표현 한계를 다루고 055는 사람의 내면에 닿는 문제를 다룹니다 — 054에서
말이 못 하는 일을 다뤘다면 여기서는 말이 아니라 짐작과 공감이 하는 일을 다룹니다. 여러 관점이
대화에서 부딪히고 조정되는 과정은 060의 몫이므로 다루지 않습니다.

이 권의 축은 셋입니다. 첫째, 일인칭 접근은 특수하지만 무오류가 아니며 안과 밖이 서로 다른 것을 본다는
것. 둘째, 짐작에는 자기를 본뜨는 갈래와 상황을 읽는 갈래가 있고 각각 다른 방향으로 실패한다는 것.
셋째, 공감은 판정의 근거가 아니라 신호이며 공감과 이해를 섞으면 이해하기 자체를 그만두게 된다는 것입니다.

실존 철학자 이름과 학파 명칭을 쓰지 않았습니다. 가상 인물은 예준·도윤이며 기존 코퍼스에서 쓰지 않은
이름입니다. 인물 이름은 대화가 내용 자체인 6장 사례에만 두고, 1~5·7장의 서술은 인물에 기대지 않고
직접 서술합니다. 인물 이름은 대화가 내용 자체인 6장 사례에만 두고, 1~5·7장의 서술은 인물에 기대지
않고 직접 서술합니다.

## 장 구성

49페이지는 목차 1페이지와 본문 48페이지로 구성합니다.

| 장 | 페이지 | 중심 역할 | 내용 |
| --- | --- | --- | --- |
| 1장 다른 사람의 안쪽 | 2~8 | `PREREQUISITE` | 일인칭 접근, 외부 관찰 항목, 표현과 내면의 불일치 |
| 2장 어떻게 짐작하는가 | 9~15 | `PREREQUISITE`·`CORE` | 유추, 두 갈래의 구조, 상황 추론, 즉각적 읽기 |
| 3장 공감 | 16~22 | `CORE` | 공감의 기능, 재료, 한계, 이해와의 구분 |
| 4장 짐작이 어긋나는 방식 | 23~29 | `COUNTERPOINT` | 투사, 오독의 네 단계, 익숙함의 함정, 미확인 추정 |
| 5장 물어보는 일 | 30~36 | `CORE` | 질문의 한계와 형식, 자기 보고, 질문 불가, 확인 단계 |
| 6장 세 자리의 짐작 | 37~43 | `EXAMPLE` | 오해가 자란 두 주, 아이의 말, 십 년의 인상 |
| 7장 알 수 없음과 함께 살기 | 44~49 | `CONCLUSION` | 요약, 물음의 전환, 실패 지점, 짐작의 실천 |

TEXT 본문 44페이지는 모두 4문단이며 346~434자, 평균 370.6자입니다. 초안에서 345자에 못 미치던 열한
페이지를 보강했고, 인물 이름을 걷어낸 뒤 다시 짧아진 세 페이지는 `EXTRA` 표로 마지막 문단에 한
문장씩 이어 붙였습니다. `estimatedReadingSeconds`가 60초 하한에 눌리는 페이지는 없습니다.

## 이미지 페이지

이미지 4개는 원고 설명에 대응하는 새 SVG 도표를 [`figures055.py`](./tools/figures055.py)로 작성하고
PNG로 렌더링해 PDF에 넣었습니다. 네 도표는 닿는 자리를 진한 선, 닿지 못하는 자리를 물음표, 확인으로
되돌아가는 길을 점선으로 그려 같은 표기를 씁니다.

| 페이지 | 도표 | 검수 초점 |
| --- | --- | --- |
| 8 | 두 자리에서 보이는 것이 다르다 | 내부 시선이 비켜 가는 자리와 외부 시선이 멈추는 겉면 |
| 11 | 짐작은 두 갈래로 간다 | 두 경로의 적용 범위와 실패 방향, 공통으로 남는 확인 |
| 25 | 어긋남은 네 단계 어디서나 생긴다 | 세 번의 옮김에서 새는 곳과 확인의 되돌림 경로 |
| 36 | 확인에는 단계가 있다 | 단계별 비용과 오류 감소, 확인 없이 굳는 갈래 |

도표 4개를 원본 크기 PNG로 확인했습니다. 최종 PDF 49페이지 전체를 접촉 시트로 훑어 글자 잘림·겹침·
본문 넘침이 없음을 확인했습니다.

## 구조 메타데이터

- 내용 역할 5종을 모두 사용했습니다. `FRONT_MATTER`는 목차 1페이지에만 사용합니다.
- 목차만 `aiRouteCandidatePage=false`이고 나머지 48페이지는 모두 `true`입니다.
- 선수 관계 48개는 절 식별자로 설계한 뒤 최종 페이지 번호로 계산했습니다. 최대 전이 폐쇄는
  6페이지이고 후보 전체가 폐쇄 15페이지 이하이며, 폐쇄 5페이지 이하인 후보가 7개 장을 모두 덮습니다.
- `other-minds-question` 중복 그룹은 2페이지의 물음 제시와 44페이지의 결론부 재진술만 연결합니다.
  44페이지가 든 7.1절에는 선수 절을 두지 않았습니다.
- `aiPublicGuideTopic`은 원문 결론이나 사례 결과를 옮기지 않은 별도 공개 안내 문장입니다.

## 평가 케이스: 비소장·예산 10

카테고리 계획이 book-055에 배정한 시나리오입니다.

| 필드 | 값 |
| --- | --- |
| `caseId` | `case-book-055` |
| `purpose` | 다른 사람의 속마음에 어디까지 닿을 수 있는지, 겉으로 보이는 것에서 안쪽을 짐작하는 방법과 그 짐작이 어긋나는 자리를 함께 알고 싶다 |
| `owned` / `maxAdditionalInk` / `depth` | `false` / `10` / `null` |
| `requiredConcepts` | 일인칭 접근, 행동의 관찰, 표현과 내면, 유추, 상황 추론, 공감, 투사, 질문의 한계 |
| `helpfulConcepts` | 공감의 근거, 공감의 한계, 익숙함의 함정, 자기 보고 |
| `referencePageNumbers` | 2, 4, 6, 9, 12, 16, 18, 23, 28, 30 |
| `allowedAlternativePageNumbers` | 3, 5, 10, 14, 20 |
| `irrelevantPageNumbers` | 34, 35, 40, 41, 42, 43 |

정답 경로는 12·18·23·28·30페이지를 씨앗으로 두고 전이적 선수 폐쇄를 펼친 10페이지이며 예산 10과
정확히 같습니다. 활성 대여가 없으므로 열 페이지 전부가 차감 대상입니다. 열 페이지가 다섯 개 장에
걸쳐 필수 개념 8종을 덮습니다.

무관 페이지는 절 단위로 잡았습니다. 5.3절(물을 수 없는 자리), 6.2절(아이의 말), 6.3절(오래 함께 일한
사람)은 필수·도움 개념을 `primaryConcepts`로 달지 않고, 정답·대체 페이지의 선수 폐쇄가 이 페이지들을
지나지 않습니다.

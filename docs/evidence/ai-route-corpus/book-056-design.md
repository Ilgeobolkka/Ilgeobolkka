# book-056 「좋은 삶은 무엇으로 이루어지는가」 설계·검수 근거

SCRUM-485 90권 확장 중 철학 카테고리 여섯 번째 도서입니다. 다른 도서 작업과 공유
`manifest.json`·`evaluation.json`에서 충돌하지 않도록 단일 도서 fragment로 작성한 뒤 병합했습니다.

## 대상 도서

| 필드 | 값 | 처리 |
| --- | --- | --- |
| `bookId` | 56 | 유지 |
| `category` | 철학 | 유지 |

`ai-route-v2` manifest의 `books[].title`입니다.

## 개념 범위와 서술 원칙

[`philosophy-category-plan.md`](./philosophy-category-plan.md)가 book-056에 배정한 행복을 이루는
조건(즐거움·성취·관계)의 구성 요소, 측정 가능성, 조건들의 상충을 핵심 주제로 사용했습니다. 계획이 정한
대로 **행위 판단**은 다루지 않습니다 — 이미 내린 선택의 책임은 052, 행위를 정할 때의 규칙과 예외는
058의 몫입니다. 이 권은 좋은 삶의 구성 요소 자체와 그 요소를 잴 수 있는지에 한정했습니다.

이 권의 축은 셋입니다. 첫째, 좋은 삶에 대한 물음이 재료·배분·판정 주체 세 층으로 갈린다는 것. 둘째,
세 재료가 각각 다른 방식으로 불충분하다는 것 — 즐거움은 익숙해지고, 성취는 어려움을 요구하며 끝나면
비고, 관계는 값을 치러야 생기고 기준을 좁힙니다. 셋째, 재는 자를 바꾸면 순위가 뒤바뀌고 두 결과가 모두
정확할 수 있다는 것입니다.

6장에서 셋을 시간이라는 공통 자원 위에서 부딪히게 두고, 결론에서 배분을 중요도 판단이 아니라 시간
할당으로 다루는 방법을 제시했습니다. 좋은 삶이 무엇인지는 정하지 않았고, 정할 수 없는 물음이라는 것이
이 책의 답에 가깝습니다.

실존 철학자 이름과 학파 명칭을 쓰지 않았습니다. 가상 인물은 하린·나윤이며 기존 코퍼스에서 쓰지 않은
이름입니다. 인물 이름은 대화가 내용 자체인 6장 사례에만 두고, 1~5·7장의 서술은 인물에 기대지 않고
직접 서술합니다. 인물 이름은 대화가 내용 자체인 6장 사례에만 두고, 1~5·7장의 서술은 인물에 기대지
않고 직접 서술합니다.

## 장 구성

49페이지는 목차 1페이지와 본문 48페이지로 구성합니다.

| 장 | 페이지 | 중심 역할 | 내용 |
| --- | --- | --- | --- |
| 1장 무엇을 묻고 있는가 | 2~8 | `PREREQUISITE` | 물음의 세 층, 순간과 전체, 기준의 출처 |
| 2장 즐거움 | 9~15 | `PREREQUISITE`·`CORE`·`COUNTERPOINT` | 즐거움의 두 기능, 적응, 종류, 단독 불충분성 |
| 3장 성취 | 16~22 | `CORE`·`COUNTERPOINT` | 성취의 조건, 목표 이후, 숙련, 공허와 미달성 |
| 4장 관계 | 23~29 | `CORE`·`COUNTERPOINT` | 관계의 기준, 비용, 세 재료의 얽힘, 관계의 제약 |
| 5장 잴 수 있는가 | 30~36 | `COUNTERPOINT` | 자기 보고, 누락 항목, 척도 선택, 비교 가능성 |
| 6장 부딪히는 조건들 | 37~43 | `EXAMPLE` | 재료 간·시점 간·자타 간 상충 사례 |
| 7장 답 없이 사는 법 | 44~49 | `CONCLUSION` | 요약, 측정에 대한 정리, 배분의 실천 |

TEXT 본문 44페이지는 모두 4문단이며 345~434자, 평균 370.8자입니다. 초안에서 345자에 못 미치던
서른한 페이지는 `EXTRA` 표로 마지막 문단에 한 문장씩 이어 붙여 보강했습니다. 새 문단을 만들지 않아
문단 넷 구성은 그대로이고, 재현 시에도 같은 결과가 나옵니다.

## 구조 메타데이터

- 내용 역할 5종을 모두 사용했습니다. `FRONT_MATTER`는 목차 1페이지에만 사용합니다.
- 목차만 `aiRouteCandidatePage=false`이고 나머지 48페이지는 모두 `true`입니다.
- 선수 관계 48개는 절 식별자로 설계한 뒤 최종 페이지 번호로 계산했습니다. 최대 전이 폐쇄는
  6페이지이고 후보 전체가 폐쇄 15페이지 이하이며, 폐쇄 5페이지 이하인 후보가 7개 장을 모두 덮습니다.
- `what-makes-a-good-life` 중복 그룹은 2페이지의 재료 제시와 44페이지의 결론부 재진술만 연결합니다.
  44페이지가 든 7.1절에는 선수 절을 두지 않았습니다.
- `aiPublicGuideTopic`은 원문 결론이나 사례 결과를 옮기지 않은 별도 공개 안내 문장입니다.

## 평가 케이스: 소장·DEEP

카테고리 계획이 book-056에 배정한 시나리오입니다.

| 필드 | 값 |
| --- | --- |
| `caseId` | `case-book-056` |
| `purpose` | 이 책을 소장하고 있는데, 좋은 삶을 이루는 재료가 무엇이고 그것들을 잴 수 있는지, 재료들이 서로 부딪힐 때 무엇을 기준으로 나눌지까지 깊이 보고 싶다 |
| `owned` / `maxAdditionalInk` / `depth` | `true` / `null` / `DEEP` |
| `requiredConcepts` | 좋은 삶, 순간과 전체, 즐거움, 적응, 성취, 관계, 자기 보고 측정, 측정의 누락, 조건의 상충 |
| `helpfulConcepts` | 즐거움의 종류, 숙련, 관계의 비용, 비교 가능성, 척도의 선택 |
| `referencePageNumbers` | 2, 4, 9, 11, 13, 16, 19, 23, 25, 28, 30, 32, 34, 35, 37 |
| `allowedAlternativePageNumbers` | 3, 10, 17, 24, 31 |
| `irrelevantPageNumbers` | 21, 22, 40, 41, 42, 43 |

정답 경로는 열한 개 씨앗 페이지의 전이적 선수 폐쇄를 펼친 15페이지이며 DEEP 상한과 정확히 같습니다.
열다섯 페이지가 여섯 개 장에 걸쳐 필수 개념 9종을 덮습니다.

무관 페이지는 절 단위로 잡았습니다. 3.4절(성취가 비어 있을 때), 6.2절(지금과 나중), 6.3절(나와 곁)은
필수·도움 개념을 `primaryConcepts`로 달지 않고, 정답·대체 페이지의 선수 폐쇄가 이 페이지들을 지나지
않습니다.

## 권리·개인정보

본문과 도표는 실존 작품을 인용·번역·모방하지 않고 이 fixture를 위해 새로 작성했습니다. 실존 철학자,
학파, 저작과 특정 개인을 가리키는 이름이나 개인정보를 포함하지 않습니다. 하린·나윤은 가상 인물입니다.

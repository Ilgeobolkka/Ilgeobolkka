# book-057 「시간과 존재: 지속과 변화」 설계·검수 근거

SCRUM-485 90권 확장 중 철학 카테고리 일곱 번째 도서입니다. 다른 도서 작업과 공유
`manifest.json`·`evaluation.json`에서 충돌하지 않도록 단일 도서 fragment로 작성한 뒤 병합했습니다.

## 대상 도서

| 필드 | 값 | 처리 |
| --- | --- | --- |
| `bookId` | 57 | 유지 |
| `category` | 철학 | 유지 |
| `title` | 시간과 존재: 지속과 변화 | 카테고리 톤에 맞게 갱신 |
| `author` | 가상 작가 057 | 유지 |
| `description` | 시간과 존재의 관계를 문장으로 풀어낸 가상 철학서입니다. | 유지 |
| `totalPageCount` | 3 → **49** | 재제작 |

저자·카테고리·소개는 `src/main/resources/demo/books.json`의 기존 값을 유지했습니다. 제목의 정본은
`ai-route-v2` manifest의 `books[].title`입니다.

## 개념 범위와 서술 원칙

[`philosophy-category-plan.md`](./philosophy-category-plan.md)가 book-057에 배정한 시간의
경험(현재·과거·미래의 비대칭), 존재의 지속과 변화, 순간과 전체의 관계를 핵심 주제로 사용했습니다.

053과의 경계는 계획이 정한 그대로입니다. 053은 기억이라는 특정 기준에 근거한 동일 인격 판정에
한정하고, 057은 시간 경험과 지속 일반을 다룹니다. 그래서 이 권의 3장은 사람이 아니라 물건과 일에서
지속의 조건을 세우고, 사람의 정체성 물음으로 좁히지 않습니다. 056이 순간과 전체를 좋은 삶의 재료를
세는 자리에서 다뤘다면 여기서는 존재론적 물음으로 다룹니다 — 전체가 어느 순간에도 통째로 있지 않은데
전체에 대해 말할 수 있는 이유를 묻습니다.

이 권의 축은 넷입니다. 현재의 이중적 규정(폭이 없어야 지금이고 폭이 있어야 겪는다), 과거와 미래의
비대칭과 그 과장, 이어짐의 세 조건(끊기지 않음·하나임·조금씩임)과 그 정도성, 변화와 지속이 반대가
아니라 짝이라는 것입니다.

실존 철학자 이름과 학파 명칭을 쓰지 않았습니다. 가상 인물은 세아·온유이며 기존 코퍼스에서 쓰지 않은
이름입니다. 인물 이름은 대화가 내용 자체인 6장 사례에만 두고, 1~5·7장의 서술은 인물에 기대지 않고
직접 서술합니다.

## 장 구성

49페이지는 목차 1페이지와 본문 48페이지로 구성합니다.

| 장 | 페이지 | 중심 역할 | 내용 |
| --- | --- | --- | --- |
| 1장 시간을 겪는다는 것 | 2~8 | `PREREQUISITE` | 현재의 특권과 폭, 흐름의 두 뜻, 시간 측정 |
| 2장 지나간 것과 올 것 | 9~15 | `PREREQUISITE`·`CORE` | 과거의 확정성, 미래의 미확정, 비대칭과 그 과장 |
| 3장 무엇이 지속하는가 | 16~22 | `CORE`·`COUNTERPOINT` | 지속과 닮음의 구분, 부분 교체, 연속의 세 조건 |
| 4장 변화 | 23~29 | `CORE`·`COUNTERPOINT` | 변화의 성립 조건, 변화 속도, 정체 |
| 5장 순간과 전체 | 30~36 | `COUNTERPOINT` | 현재의 폭, 전체의 회고적 성립, 서사적 묶음 |
| 6장 세 가지 시간 | 37~43 | `EXAMPLE` | 기다림, 되풀이, 남은 시간 |
| 7장 시간 안에서 | 44~49 | `CONCLUSION` | 요약, 실패 지점, 눈금·두 값·이어 갈 것의 실천 |

TEXT 본문 44페이지는 모두 4문단이며 346~400자, 평균 366.1자입니다. 초안에서 345자에 못 미치던
서른두 페이지는 `EXTRA` 표로 마지막 문단에 한 문장씩 이어 붙여 보강했습니다.

## 구조 메타데이터

- 내용 역할 5종을 모두 사용했습니다. `FRONT_MATTER`는 목차 1페이지에만 사용합니다.
- 목차만 `aiRouteCandidatePage=false`이고 나머지 48페이지는 모두 `true`입니다.
- 선수 관계 48개는 절 식별자로 설계한 뒤 최종 페이지 번호로 계산했습니다. 최대 전이 폐쇄는
  6페이지이고 후보 전체가 폐쇄 15페이지 이하이며, 폐쇄 5페이지 이하인 후보가 7개 장을 모두 덮습니다.
- `now-and-what-lasts` 중복 그룹은 2페이지의 현재 규정과 44페이지의 결론부 재진술만 연결합니다.
  44페이지가 든 7.1절에는 선수 절을 두지 않았습니다.
- `aiPublicGuideTopic`은 원문 결론이나 사례 결과를 옮기지 않은 별도 공개 안내 문장입니다.

## 평가 케이스: 비소장·예산 15

카테고리 계획이 book-057에 배정한 시나리오입니다.

| 필드 | 값 |
| --- | --- |
| `caseId` | `case-book-057` |
| `purpose` | 시간을 겪는다는 것이 무엇인지와 지나간 쪽과 올 쪽이 왜 다른지, 그리고 무엇이 같은 것으로 남고 무엇이 달라지는지를 이어서 보고 싶다 |
| `owned` / `maxAdditionalInk` / `depth` | `false` / `15` / `null` |
| `requiredConcepts` | 현재, 흐름의 경험, 과거, 미래, 시간의 비대칭, 지속, 변화, 순간의 폭, 전체의 자리 |
| `helpfulConcepts` | 부분 교체, 연속의 조건, 변화의 속도, 정체, 서사적 묶음 |
| `referencePageNumbers` | 2, 4, 9, 11, 13, 16, 18, 20, 23, 26, 28, 30, 32, 35, 37 |
| `allowedAlternativePageNumbers` | 3, 10, 12, 17, 24 |
| `irrelevantPageNumbers` | 22, 40, 41, 42, 43 |

정답 경로는 열 개 씨앗 페이지의 전이적 선수 폐쇄를 펼친 15페이지이며 예산 15와 정확히 같습니다.
활성 대여가 없으므로 열다섯 페이지 전부가 차감 대상이고, 여섯 개 장에 걸쳐 필수 개념 9종을 덮습니다.

무관 페이지는 절 단위로 잡았습니다. 3.4절(지속하지 않는 것들), 6.2절(되풀이되는 시간), 6.3절(남는
시간)은 필수·도움 개념을 `primaryConcepts`로 달지 않고, 정답·대체 페이지의 선수 폐쇄가 이 페이지들을
지나지 않습니다.

## 권리·개인정보

본문과 도표는 실존 작품을 인용·번역·모방하지 않고 이 fixture를 위해 새로 작성했습니다. 실존 철학자,
학파, 저작과 특정 개인을 가리키는 이름이나 개인정보를 포함하지 않습니다. 세아·온유는 가상 인물입니다.

# book-058 「규칙과 예외: 약속을 지키는 이유」 설계·검수 근거

`manifest.json`·`evaluation.json`에서 충돌하지 않도록 단일 도서 fragment로 작성한 뒤 병합했습니다.

## 개념 범위와 서술 원칙

[`philosophy-category-plan.md`](./philosophy-category-plan.md)가 book-058에 배정한 규칙의 일반성과
예외의 정당화, 약속을 지키는 이유, 결과와 원칙의 충돌을 핵심 주제로 사용했습니다.

052와의 경계는 계획이 정한 그대로입니다. 052는 이미 벌어진 선택에 대한 책임 소재를 다루고, 058은
행위를 정할 때 규칙과 예외 중 무엇을 따를지의 구조를 다룹니다. 그래서 이 권에는 사후 귀속이나 운의
몫이 나오지 않고, 판단 이전에 무엇을 미리 정해 둘지가 중심에 있습니다.

051과의 겹침도 확인했습니다. 051의 6.1절이 약속을 소재로 삼았지만 그것은 의심 절차를 보이는 사례였고
"지켜야 한다"의 다의성을 가르는 데서 끝납니다. 058은 그 다의성을 다시 다루지 않고 약속의 구속력이
어디서 오는지, 어떤 조건에서 해제되는지를 규칙의 문제로 다룹니다.

이 권의 축은 넷입니다. 규칙이 판단과 합의를 대신하며 그 대가로 부적합 사례가 반드시 생긴다는 것,
예외가 위반과 다르려면 세 조건이 필요하다는 것, 약속이 없던 매임을 스스로 만드는 일이라는 것, 그리고
결과와 원칙이 대개 같은 답을 내므로 갈리는 좁은 자리만 미리 정해 두면 된다는 것입니다.

실존 철학자 이름과 학파 명칭을 쓰지 않았습니다. 가상 인물은 새롬·다솜이며 기존 코퍼스에서 쓰지 않은
이름입니다. 인물 이름은 대화가 내용 자체인 6장 사례에만 두고, 1~5·7장의 서술은 인물에 기대지 않고
직접 서술합니다. 인물 이름은 대화가 내용 자체인 6장 사례에만 두고, 1~5·7장의 서술은 인물에 기대지
않고 직접 서술합니다.

## 장 구성

49페이지는 목차 1페이지와 본문 48페이지로 구성합니다.

| 장 | 페이지 | 중심 역할 | 내용 |
| --- | --- | --- | --- |
| 1장 규칙이 하는 일 | 2~8 | `PREREQUISITE` | 판단·합의의 대체, 일반성의 대가, 준수의 세 이유 |
| 2장 예외 | 9~15 | `PREREQUISITE`·`CORE` | 예외와 위반의 구분, 세 조건, 사전 예외 |
| 3장 약속 | 16~22 | `CORE` | 약속의 성립과 구속력, 해제 조건, 규칙과의 차이 |
| 4장 결과와 원칙 | 23~29 | `CORE`·`COUNTERPOINT` | 두 기준의 이점과 약점, 충돌 범위, 배합 |
| 5장 규칙이 실패하는 방식 | 30~36 | `COUNTERPOINT` | 형식주의, 예외의 상례화, 사문화 |
| 6장 세 자리의 판단 | 37~43 | `EXAMPLE` | 기한 규칙, 못 지킨 약속, 규칙 개정 자리 |
| 7장 규칙 아래에서 | 44~49 | `CONCLUSION` | 요약, 두 붕괴 방향, 규칙·예외·약속의 실천 |

TEXT 본문 44페이지는 모두 4문단이며 346~386자, 평균 365.2자입니다. 초안에서 345자에 못 미치던
서른세 페이지는 `EXTRA` 표로 마지막 문단에 한 문장씩 이어 붙여 보강했습니다.

## 구조 메타데이터

- 내용 역할 5종을 모두 사용했습니다. `FRONT_MATTER`는 목차 1페이지에만 사용합니다.
- 목차만 `aiRouteCandidatePage=false`이고 나머지 48페이지는 모두 `true`입니다.
- 선수 관계 48개는 절 식별자로 설계한 뒤 최종 페이지 번호로 계산했습니다. 최대 전이 폐쇄는
  7페이지이고 후보 전체가 폐쇄 15페이지 이하이며, 폐쇄 5페이지 이하인 후보가 7개 장을 모두 덮습니다.
- `rules-and-exceptions` 중복 그룹은 2페이지의 규칙 규정과 44페이지의 결론부 재진술만 연결합니다.
  44페이지가 든 7.1절에는 선수 절을 두지 않았습니다.
- `aiPublicGuideTopic`은 원문 결론이나 사례 결과를 옮기지 않은 별도 공개 안내 문장입니다.

## 평가 케이스: 비소장·예산 10

카테고리 계획이 book-058에 배정한 시나리오입니다.

| 필드 | 값 |
| --- | --- |
| `caseId` | `case-book-058` |
| `purpose` | 규칙이 왜 일반적으로 만들어지는지와 예외를 인정할 수 있는 조건이 무엇인지, 그리고 약속을 지켜야 하는 이유가 어디서 오는지를 함께 알고 싶다 |
| `owned` / `maxAdditionalInk` / `depth` | `false` / `10` / `null` |
| `requiredConcepts` | 규칙, 일반성, 준수의 이유, 예외, 예외의 조건, 약속, 약속의 구속력, 결과 기준, 원칙 기준 |
| `helpfulConcepts` | 사전 예외, 약속의 해제, 기준의 충돌, 형식주의 |
| `referencePageNumbers` | 2, 4, 7, 9, 11, 16, 18, 23, 25, 30 |
| `allowedAlternativePageNumbers` | 3, 5, 10, 17, 24 |
| `irrelevantPageNumbers` | 32, 33, 40, 41, 42, 43 |

정답 경로는 여섯 개 씨앗 페이지의 전이적 선수 폐쇄를 펼친 10페이지이며 예산 10과 정확히 같습니다.
활성 대여가 없으므로 열 페이지 전부가 차감 대상이고, 다섯 개 장에 걸쳐 필수 개념 9종을 덮습니다.

무관 페이지는 절 단위로 잡았습니다. 5.2절(예외가 규칙이 될 때), 6.2절(못 지키게 된 약속), 6.3절(규칙을
고치는 자리)은 필수·도움 개념을 `primaryConcepts`로 달지 않고, 정답·대체 페이지의 선수 폐쇄가 이
페이지들을 지나지 않습니다.

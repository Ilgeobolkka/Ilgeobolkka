# book-059 「안다는 것은 무엇인가」 설계·검수 근거

SCRUM-485 90권 확장 중 철학 카테고리 아홉 번째 도서입니다. 다른 도서 작업과 공유
`manifest.json`·`evaluation.json`에서 충돌하지 않도록 단일 도서 fragment로 작성한 뒤 병합했습니다.

## 대상 도서

| 필드 | 값 | 처리 |
| --- | --- | --- |
| `bookId` | 59 | 유지 |
| `category` | 철학 | 유지 |
| `title` | 안다는 것은 무엇인가 | 카테고리 톤에 맞게 갱신 |
| `author` | 가상 작가 059 | 유지 |
| `description` | 무지와 배움의 의미를 살펴보는 가상 철학서입니다. | 유지 |
| `totalPageCount` | 3 → **49** | 재제작 |

저자·카테고리·소개는 `src/main/resources/demo/books.json`의 기존 값을 유지했습니다. 제목의 정본은
`ai-route-v2` manifest의 `books[].title`입니다.

## 개념 범위와 서술 원칙

[`philosophy-category-plan.md`](./philosophy-category-plan.md)가 book-059에 배정한 무지의 자각,
알고 있다는 것의 근거, 배움이 시작되는 지점을 핵심 주제로 사용했습니다.

051과의 경계는 계획이 정한 그대로입니다. 051은 의심하는 절차, 곧 주장의 전제를 찾아 검토하고 어디서
멈출지 정하는 순서를 다룹니다. 059는 "내가 모른다는 사실을 아는 상태"와 그로부터 배움이 시작되는
구조에 집중합니다. 그래서 이 권에는 전제 검토나 반례 찾기가 나오지 않고, 무지의 유형과 그것을
알아채는 방법이 그 자리를 차지합니다.

이 권의 축은 넷입니다. 앎의 성립 조건 가운데 다룰 수 있는 것은 근거뿐이라는 것, 모른다는 말이 넷으로
갈리며 그중 첫째만 자기 안에서 다룰 수 없다는 것, 배움이 그 첫째가 둘째로 옮겨 가는 자리에서
시작한다는 것, 그리고 익숙함·이해감·빌린 앎이 겉에서 앎과 구별되지 않아 시험해야 갈린다는 것입니다.

실존 철학자 이름과 학파 명칭을 쓰지 않았습니다. 가상 인물은 슬기·여원이며 기존 코퍼스에서 쓰지 않은
이름입니다.

## 장 구성

49페이지는 목차 1페이지와 본문 48페이지로 구성합니다.

| 장 | 페이지 | 중심 역할 | 내용 |
| --- | --- | --- | --- |
| 1장 안다고 말할 때 | 2~8 | `PREREQUISITE` | 앎의 세 쓰임과 성립 조건, 근거의 네 종류, 확신 |
| 2장 모른다는 것 | 9~15 | `PREREQUISITE`·`CORE` | 무지의 네 유형, 무지의 무지, 자각 방법 |
| 3장 배움이 시작되는 자리 | 16~22 | `CORE`·`COUNTERPOINT` | 질문의 형성, 확장기와 심화기, 설명 시험, 정체 |
| 4장 무엇이 앎을 떠받치는가 | 23~29 | `CORE` | 경험·전언·실행적 앎과 근거의 다변화 |
| 5장 안다고 착각하는 방식 | 30~36 | `COUNTERPOINT` | 익숙함, 이해감, 빌린 앎 |
| 6장 세 자리의 배움 | 37~43 | `EXAMPLE` | 초심자, 숙련자, 가르치는 자리 |
| 7장 모르는 채로 | 44~49 | `CONCLUSION` | 요약, 착각의 구분, 기록·시험·근거 세기 |

TEXT 본문 44페이지는 모두 4문단이며 345~397자, 평균 366.9자입니다. 초안에서 345자에 못 미치던
서른여섯 페이지는 `EXTRA` 표로 마지막 문단에 한 문장씩 이어 붙여 보강했습니다.

## 구조 메타데이터

- 내용 역할 5종을 모두 사용했습니다. `FRONT_MATTER`는 목차 1페이지에만 사용합니다.
- 목차만 `aiRouteCandidatePage=false`이고 나머지 48페이지는 모두 `true`입니다.
- 선수 관계 48개는 절 식별자로 설계한 뒤 최종 페이지 번호로 계산했습니다. 최대 전이 폐쇄는
  5페이지이고 후보 전체가 폐쇄 15페이지 이하이며, 폐쇄 5페이지 이하인 후보가 7개 장을 모두 덮습니다.
  QUICK 상한이 5페이지이므로 이 권은 다른 권보다 선수를 특히 얕게 걸었습니다.
- `what-is-knowing` 중복 그룹은 2페이지의 앎 규정과 44페이지의 결론부 재진술만 연결합니다.
  44페이지가 든 7.1절에는 선수 절을 두지 않았습니다.
- `aiPublicGuideTopic`은 원문 결론이나 사례 결과를 옮기지 않은 별도 공개 안내 문장입니다.

## 평가 케이스: 소장·QUICK

카테고리 계획이 book-059에 배정한 시나리오입니다.

| 필드 | 값 |
| --- | --- |
| `caseId` | `case-book-059` |
| `purpose` | 이 책을 소장하고 있는데, 무엇을 안다고 말할 수 있는 근거가 무엇인지와 무엇을 모르는지 아는 일이 왜 배움의 출발점인지 핵심만 짧게 잡고 싶다 |
| `owned` / `maxAdditionalInk` / `depth` | `true` / `null` / `QUICK` |
| `requiredConcepts` | 앎, 앎의 근거, 무지의 종류, 무지의 무지, 배움의 시작 |
| `helpfulConcepts` | 확신, 무지의 자각, 앎의 확장, 익숙함의 착각 |
| `referencePageNumbers` | 2, 5, 9, 11, 16 |
| `allowedAlternativePageNumbers` | 3, 6, 10, 17, 23 |
| `irrelevantPageNumbers` | 34, 35, 40, 41, 42, 43 |

정답 경로는 네 개 씨앗 페이지의 전이적 선수 폐쇄를 펼친 5페이지이며 QUICK 상한과 정확히 같습니다.
다섯 페이지가 세 개 장에 걸쳐 필수 개념 5종을 덮습니다. 대체 페이지 다섯은 폐쇄가 각각 2·3·3·3·3
페이지로 모두 상한 안에 듭니다.

무관 페이지는 절 단위로 잡았습니다. 5.3절(남의 앎을 자기 앎으로), 6.2절(오래 해 온 자리),
6.3절(가르치는 자리)은 필수·도움 개념을 `primaryConcepts`로 달지 않고, 정답·대체 페이지의 선수
폐쇄가 이 페이지들을 지나지 않습니다.

## 권리·개인정보

본문과 도표는 실존 작품을 인용·번역·모방하지 않고 이 fixture를 위해 새로 작성했습니다. 실존 철학자,
학파, 저작과 특정 개인을 가리키는 이름이나 개인정보를 포함하지 않습니다. 슬기·여원은 가상 인물입니다.

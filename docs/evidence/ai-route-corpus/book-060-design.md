# book-060 「관점의 복수성과 대화의 조건」 설계·검수 근거

SCRUM-485 90권 확장 중 철학 카테고리 마지막 도서입니다. 다른 도서 작업과 공유
`manifest.json`·`evaluation.json`에서 충돌하지 않도록 단일 도서 fragment로 작성한 뒤 병합했습니다.
이 권으로 철학 카테고리 10권(`bookId` 51~60)이 완성됩니다.

## 대상 도서

| 필드 | 값 | 처리 |
| --- | --- | --- |
| `bookId` | 60 | 유지 |
| `category` | 철학 | 유지 |
| `title` | 관점의 복수성과 대화의 조건 | 카테고리 톤에 맞게 갱신 |
| `author` | 가상 작가 060 | 유지 |
| `description` | 서로 다른 관점이 만나는 대화를 담은 가상 철학서입니다. | 유지 |
| `totalPageCount` | 3 → **49** | 재제작 |

저자·카테고리·소개는 `src/main/resources/demo/books.json`의 기존 값을 유지했습니다. 제목의 정본은
`ai-route-v2` manifest의 `books[].title`입니다.

## 개념 범위와 서술 원칙

[`philosophy-category-plan.md`](./philosophy-category-plan.md)가 book-060에 배정한 관점의 복수성,
서로 다른 결론에 도달하는 대화, 합의 없는 이해의 가능성을 핵심 주제로 사용했습니다.

055와의 경계는 계획이 정한 그대로입니다. 055는 개별 타인의 내면에 닿을 수 있는지를 다루고 060은 여러
관점이 대화 속에서 부딪히고 조정되는 과정을 다룹니다. 그래서 이 권에는 짐작이나 공감이 나오지 않고,
결론이 갈리는 지점과 그 갈림을 다루는 절차가 그 자리를 차지합니다. 054가 언어 자체의 표현 한계를
다뤘다면 여기서는 말이 통하는 상황에서도 결론이 갈리는 이유를 다룹니다.

이 권의 축은 넷입니다. 관점이 다르다는 말에 세 가지가 섞여 있고 그중 중요도 차이만 자료로 좁혀지지
않는다는 것, 관점이 겪음·자리·주변이 만든 것이라 말로 바뀌지 않는다는 것, 동의하지 않고도 할 수 있는
절차가 셋 있다는 것, 그리고 이해된 불일치도 대화의 도착지라는 것입니다.

실존 철학자 이름과 학파 명칭을 쓰지 않았습니다. 가상 인물은 단우·늘봄이며 기존 코퍼스에서 쓰지 않은
이름입니다. 인물 이름은 대화가 내용 자체인 6장 사례에만 두고, 1~5·7장의 서술은 인물에 기대지 않고
직접 서술합니다. 인물 이름은 대화가 내용 자체인 6장 사례에만 두고, 1~5·7장의 서술은 인물에 기대지
않고 직접 서술합니다.

## 장 구성

49페이지는 목차 1페이지와 본문 48페이지로 구성합니다.

| 장 | 페이지 | 중심 역할 | 내용 |
| --- | --- | --- | --- |
| 1장 관점이란 무엇인가 | 2~8 | `PREREQUISITE` | 관점 차이의 세 유형, 형성 요인, 선택 가능 범위 |
| 2장 왜 다른 결론에 이르는가 | 9~15 | `PREREQUISITE`·`CORE` | 분기의 세 지점, 중요도 차이, 차이와 오류 |
| 3장 대화가 되는 조건 | 16~22 | `CORE`·`COUNTERPOINT` | 대화의 목적, 듣기, 입장 교대, 대화 불가 조건 |
| 4장 합의 없는 이해 | 23~29 | `CORE` | 이해와 동의, 네 도착점, 차이의 기록, 배분 |
| 5장 대화가 실패하는 방식 | 30~36 | `COUNTERPOINT` | 승패의 대화, 무차별 상대주의, 형식적 경청 |
| 6장 세 자리의 대화 | 37~43 | `EXAMPLE` | 두 사람의 갈림, 여덟 사람의 조정, 남은 차이 |
| 7장 다른 채로 함께 | 44~49 | `CONCLUSION` | 요약, 차이 판정 조건, 닫히는 두 방향, 실천 |

TEXT 본문 44페이지는 모두 4문단이며 345~406자, 평균 363.0자입니다. 초안에서 345자에 못 미치던
서른일곱 페이지는 `EXTRA` 표로 마지막 문단에 한 문장씩 이어 붙여 보강했습니다.

## 구조 메타데이터

- 내용 역할 5종을 모두 사용했습니다. `FRONT_MATTER`는 목차 1페이지에만 사용합니다.
- 목차만 `aiRouteCandidatePage=false`이고 나머지 48페이지는 모두 `true`입니다.
- 선수 관계 48개는 절 식별자로 설계한 뒤 최종 페이지 번호로 계산했습니다. 최대 전이 폐쇄는
  7페이지이고 후보 전체가 폐쇄 15페이지 이하이며, 폐쇄 5페이지 이하인 후보가 7개 장을 모두 덮습니다.
- `many-viewpoints` 중복 그룹은 2페이지의 관점 차이 유형 제시와 44페이지의 결론부 재진술만
  연결합니다. 44페이지가 든 7.1절에는 선수 절을 두지 않았습니다.
- `aiPublicGuideTopic`은 원문 결론이나 사례 결과를 옮기지 않은 별도 공개 안내 문장입니다.

## 평가 케이스: 비소장·예산 5

카테고리 계획이 book-060에 배정한 시나리오입니다.

| 필드 | 값 |
| --- | --- |
| `caseId` | `case-book-060` |
| `purpose` | 같은 사실을 보고도 왜 다른 결론에 이르는지와 그 차이를 두고 대화가 되려면 무엇이 필요한지를 알고 싶다 |
| `owned` / `maxAdditionalInk` / `depth` | `false` / `5` / `null` |
| `requiredConcepts` | 관점, 결론의 분기, 중요도의 차이, 대화의 목적, 듣기 |
| `helpfulConcepts` | 관점의 형성, 차이와 오류, 입장 교대, 이해와 동의 |
| `referencePageNumbers` | 2, 9, 11, 16, 18 |
| `allowedAlternativePageNumbers` | 3, 10, 12, 17, 20 |
| `irrelevantPageNumbers` | 34, 35, 40, 41, 42, 43 |

정답 경로는 네 개 씨앗 페이지의 전이적 선수 폐쇄를 펼친 5페이지이며 예산 5와 정확히 같습니다. 활성
대여가 없으므로 다섯 페이지 전부가 차감 대상이고, 세 개 장에 걸쳐 필수 개념 5종을 덮습니다.

무관 페이지는 절 단위로 잡았습니다. 5.3절(듣는 척하기), 6.2절(여럿이 정해야 할 때), 6.3절(끝내 갈린
자리)은 필수·도움 개념을 `primaryConcepts`로 달지 않고, 정답·대체 페이지의 선수 폐쇄가 이 페이지들을
지나지 않습니다.

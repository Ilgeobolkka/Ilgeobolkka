# book-061 「형태와 구도: 화면을 구성하는 원리」 설계·검수 근거

SCRUM-485 90권 확장 중 예술 카테고리 첫 번째 도서입니다. 다른 도서 작업과 공유
`manifest.json`·`evaluation.json`에서 충돌하지 않도록 단일 도서 fragment로 작성했습니다.

## 대상 도서

| 필드 | 값 | 처리 |
| --- | --- | --- |
| `bookId` | 61 | 유지 |
| `category` | 예술 | 유지 |
| `title` | 형태와 구도: 화면을 구성하는 원리 | 카테고리 톤에 맞게 갱신 |
| `author` | 가상 작가 061 | 유지 |

| `totalPageCount` | 5 → **52** | 재제작 |

저자·카테고리·소개는 `src/main/resources/demo/books.json`의 기존 값을 유지했습니다. 제목은 예술
카테고리 제목 갱신에 따른 새 값이며 정본은 `ai-route-v2` manifest의 `books[].title`입니다.
`books.json`은 `initial-v1` 동결 fixture이므로 고치지 않습니다.

## 개념 범위와 독자 수준

[`art-category-plan.md`](./art-category-plan.md)가 book-061에 배정한 점·선·면의 기본 형태요소,
화면 프레임과 구도, 대칭·비대칭 균형, 크기와 스케일 관계를 핵심 주제로 사용했습니다. 같은 카테고리의
다른 도서에 배정된 조명 설계, 음악의 쉼, 종이 조형, 색채 지각, 벽화, 사운드 디자인, 사진 프레이밍은
핵심 개념으로 확장하지 않았습니다.

실존 작가·작품·사조를 인용하거나 모방하지 않고 가상 화가 다혜와 그의 습작을 서술 장치로 사용했습니다.
그림을 처음 그리는 독자가 따라올 수 있도록 형태요소의 정의에서 시작해 배치 규칙, 무게의 균형,
화면 크기의 영향, 실제 작업 순서, 원리의 한계 순으로 개념을 확장했습니다.

52페이지는 목차 1페이지와 본문 51페이지로 구성합니다.

| 2장 화면이라는 틀: 프레임과 구도 | 8~15 | `CORE` | 프레임, 구도, 격자, 시선 동선, 배치 순서 |

적용했습니다.

## 구조 메타데이터

- 내용 역할 5종을 모두 사용했습니다(`PREREQUISITE` 5, `CORE` 23, `EXAMPLE` 11,
  `COUNTERPOINT` 9, `CONCLUSION` 3). `FRONT_MATTER`는 목차 1페이지에만 사용합니다.
- 목차만 `aiRouteCandidatePage=false`이고 나머지 51페이지는 모두 `true`입니다.
- 이 책은 절 하나가 페이지 하나에 대응합니다. 선수 관계 51개는 절 식별자로 설계한 뒤 최종 페이지
  번호로 계산했으며, 자기 참조·범위 밖 참조·순환이 없습니다.
- 1.6(7페이지)의 선수를 1.5(6페이지)에서 1.3(4페이지)으로 옮겼습니다. 1.6은 "화면에는 가장자리가 있고
  그 안쪽에서만 점·선·면이 의미를 가진다"이므로 점·선·면 세 요소만 전제하고, 1.4(도표)·1.5(세 요소를
  함께 보는 법)의 종합은 전제가 아닙니다. 원래 연결은 1장을 6단계 사슬로 만들어 2장·4장 첫 페이지의
  전이 폐쇄를 7페이지로 키웠고, 그래서 이 책이 [선수 밀도 상한](../../ai-route-content-corpus.md#도서-제작-기준)의
  "폐쇄 5페이지 이하인 페이지가 서로 다른 장 3개 이상"을 만족하지 못했습니다. 옮긴 뒤 1·2·4장이
  각각 폐쇄 1·5·5인 진입 페이지를 갖습니다.
- 대표 경로는 `[2, 3, 4, 9, 16, 17, 18, 50]`으로 비연속 배치했습니다.
- `intentional-imbalance` 중복 그룹은 21페이지의 "균형을 의도적으로 활용하기도 한다"는 언급과
  44페이지의 의도적 붕괴 본격 서술만 연결합니다.
- `aiPublicGuideTopic`은 원문 결론·수치·사례 결과를 옮기지 않은 별도 공개 안내 문장입니다.

## 평가 케이스: 비소장·예산 0

| 필드 | 값 |
| --- | --- |
| `caseId` | `case-book-061` |
| `purpose` | 그림을 처음 그리려는데 화면에 무엇을 어디에 놓아야 할지 막막하다. 가장 단순한 형태에서 시작해 화면을 채워 가는 순서와, 다 그린 뒤 한쪽으로 쏠려 보이지 않게 맞추는 기준을 이미 빌려 둔 앞부분 안에서 익히고 싶다 |

| `requiredConcepts` | 점, 선, 면, 구도, 균형, 대칭 균형, 비대칭 균형 |
| `helpfulConcepts` | 형태요소, 시각적 무게, 프레임 |

예산 0은 새로 페이지를 열 수 없으므로 대표 경로 8페이지가 모두 활성 대여 목록 안에 들어가도록
배정했습니다. 목적 문장에는 책 제목이나 정답 페이지 번호를 넣지 않았습니다.

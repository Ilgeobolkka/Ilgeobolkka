# book-063 「음악의 쉼과 프레이징」 설계

[예술 카테고리 계획](./art-category-plan.md)의 63번을 만든 근거다. 정책·검증 계약은
[AI 경로 콘텐츠 코퍼스](../../ai-route-content-corpus.md)를 따르고, 이 문서는 그 계약 안에서 내린
선택과 이유만 적는다.

## 대상 도서

- `bookId` 63, 카테고리 예술. 저자·소개는 `src/main/resources/demo/books.json`의 기존 값을 유지한다.
- 제목은 `ai-route-v2` manifest의 `books[].title`이 정본이며 이 문서의 제목과 같다.
- 실존 작곡가·작품·연주자를 옮기지 않는다. 무대는 가상의 「모래내 연습실」, 인물은 연주자 하윤과
  예강이다. 062의 해든소극장(도경·나린)과 겹치지 않는다.

## 개념 범위

계획 문서가 정한 범위(쉼표, 프레이징, 다이내믹, 침묵의 구조적 기능)를 그대로 따른다. 같은 카테고리에서
침묵을 다루는 권이 셋이라 경계를 분명히 두었다.

- 067(영상 사운드)의 무음은 화면 위에 얹히는 서사 장치다.
- 061(화면 구도)의 여백은 공간 예술의 배치 문제다.
- 063은 셋 가운데 유일하게 **흐르는 시간 안의 정지**를 다룬다. 그래서 여섯 도표가 모두 가로 시간축을
  쓰고, 공간이나 화면을 그린 도표가 하나도 없다.

## 장 구성 (51페이지, 목차 1 + 본문 50)

```
1장 소리가 멈추는 자리      p2–11   PREREQUISITE  침묵·박과 마디·쉼표·악구·강약
2장 악구를 나누는 일        p12–19  CORE          숨의 자리·경계·이음과 끊음·길이
3장 쉼에도 종류가 있다      p20–27  CORE          박 안의 쉼·긴 쉼·늘임·합주의 쉼
4장 강약이 만드는 구조      p28–35  CORE          상대성·점진적 변화·강약과 나눔·여린 구간
5장 연습실에서              p36–43  EXAMPLE       악보 표시·박 연습·합주·녹음
6장 규칙이 흔들리는 순간    p44–49  COUNTERPOINT  공간의 잔향·객석의 소리·연주 중 조정
7장 결론: 비어 있는 시간도 연주된다  p50–51  CONCLUSION  종합과 점검 물음
```

1장이 네 도구(쉼표·악구·강약·박)를 모두 세우고 2~5장이 하나씩 펼친다. 6장은 그 계획이 공간과 객석
때문에 흔들리는 세 경우를 다룬다. 062와 같은 뼈대이되 7장을 두 페이지로 줄였다. 이 책의 결론은 종합
하나면 충분하고, 남는 분량은 3장의 쉼 분류에 썼다.

이미지 6개: p8(같은 줄, 다른 나눔), p14(악구 하나의 모양), p23(굴곡인 쉼과 경계인 쉼),
p30(같은 폭, 다른 줄임), p38(어긋남은 쌓인다), p46(비어 있지 않은 정적). 소리가 있는 구간은 채운 도형,
없는 구간은 빈 도형으로 여섯 도표에서 고정했다. 생성 스크립트는 [`figures063.py`](./tools/figures063.py)다.

중복 그룹 1개: `silence-is-played` = [2, 50]. "소리가 없는 구간은 앞의 소리가 남아 있는 시간"이라는
명제를 1.1에서 세우고 7.1에서 책 전체를 지나온 언어로 재진술한다. 재진술 페이지(50)에는 선수를 두지
않았다. 짝(2)을 선수로 걸면 50을 고른 경로에 2가 반드시 따라와 중복 그룹 규칙을 어기기 때문이며,
book-062와 같은 처리다.

## 선수 관계 설계

1.1(침묵)을 1장 나머지 절의 뿌리로 두고, 2장은 1.4(악구)에서, 3장은 1.3(쉼표)에서, 4장은 1.5(강약)에서
갈라진다. 5장은 표시·박·합주·녹음이 각각 다루는 도구의 절에 붙였고, 6장은 흔들리는 대상의 절에 붙였다.

- 어느 후보 페이지도 선수 폐쇄가 5페이지를 넘지 않는다.
- 폐쇄 5페이지 이하인 후보 페이지가 일곱 개 장을 모두 덮는다 (기준 3개 장).
- 후보 페이지 50개 전부가 폐쇄 15페이지 이하다 (기준 75%).

3.3(늘임)만 3.2(긴 쉼)를 선수로 두어 두 단계 깊이가 된다. 늘임은 정해진 길이를 넘겨 두는 처리라 긴 쉼을
먼저 알아야 뜻이 서기 때문이다. 나머지는 모두 1장에 바로 붙였다.

## 검증

`corpus_lib.validate_book()` → `validate_fragment.py` → `merge_fragments.py` → `validate_manifest.py`를
차례로 통과했다.

- 51페이지(48~72), 7개 장(최소 6), 내용 역할 5종 모두 사용
- `TEXT` 본문 44페이지가 416~549자(평균 476자, 합계 20,934자)로 전량 345자 이상 — 60초로 눌리는
  페이지가 없다
- `FRONT_MATTER`(목차)와 `aiRouteCandidatePage=false`가 정확히 일치
- 선수 관계가 후보 제외 페이지를 가리키지 않음, 위상 정렬로 51페이지 전체 방문
- PDF 페이지 51개, 텍스트 45개, 이미지 6개(p8,14,23,30,38,46) — `pdfcheck.py`로 확인
- PDF 실제 SHA-256이 manifest의 `pdfSha256`과 일치

초고는 페이지당 335~459자였고 하한이 정본 기준(345자)에 미달했다. 062와 같은 방식으로 `EXTRA` 문단을
더해 416~549자로 맞췄다. 원고를 다시 쓰지 않고 문단만 더하므로 `PAGES`는 초고 그대로 남는다.

## 평가 케이스: 비소장·예산 15 시나리오

| 필드 | 값 |
| --- | --- |
| `caseId` | `case-book-063` |
| `purpose` | 이 책을 사지는 않았고, 악보를 어디서 끊어 읽어야 하는지와 쉼을 얼마나 두어야 하는지를 익히고 싶다 |
| `owned` / `maxAdditionalInk` / `depth` | `false` / `15` / `null` |
| `requiredConcepts` | 악구, 숨의 자리, 쉼표, 긴 쉼 |
| `helpfulConcepts` | 음악적 침묵, 악구의 경계, 박 안의 쉼, 늘임, 이음과 끊음 |
| `referencePageNumbers` | 2, 6, 8, 12~17, 20~25 |
| `irrelevantPageNumbers` | 28·30~31(셈여림의 상대성과 점진적 변화), 34~35(여린 구간) — 나눔과 쉼을 익히려는 이 목적과 무관 |

정답 경로는 선수 전이 폐쇄와 같고 정확히 15페이지여서 예산 15를 남김없이 쓴다. 침묵(2)과 쉼표(6),
악구(8)에서 갈라져 한 갈래는 숨의 자리와 경계와 이음(12~17)으로, 다른 갈래는 박 안의 쉼과 긴 쉼과
늘임(20~25)으로 이어진다.

시나리오는 계획 초안의 예산 10 대신 **예산 15**를 골랐다. 병합 직전 정본에서 예산 15가 2건으로 가장
적게 쓰인 축이었기 때문이다. 계획 문서의 배분표는 카테고리 안의 균형만 보고 적은 것이라, 정본 전체를
보고 정한다는 원칙을 그 문서에도 함께 적었다. 병합 후 20건의 분포는 예산 5만 2건이고 나머지 여섯
시나리오가 각 3건이다.

## 재현 조건

1. `python3 build063.py` — 원고와 조각 생성 (PDF SHA 없이 실행하면 자리표시자를 넣는다)
2. `python3 figures063.py pdfbuild063` — 도표 6개 SVG 생성
3. Chrome Headless로 각 SVG를 794×1123 PNG로 렌더링
4. `python3 build_pdf_generic.py 63 8,14,23,30,38,46 pdfbuild063` — 조판 HTML 생성
5. Chrome Headless `--print-to-pdf`로 PDF 출력, `pdfcheck.py`로 구성 확인
6. PDF를 `fixtures/content/ai-route-v2/pdfs/`에 두고 SHA-256을 인자로 `build063.py` 재실행
7. `merge_fragments.py`로 정본에 병합

## 검수

- 여섯 도표를 PNG로 렌더링해 눈으로 확인했다. 첫 렌더에서 p14는 박 띠가 곡선과 가로 범위가 달라
  "다섯 번째 박에 중심이 온다"는 설명과 그림이 어긋났고, p8은 네모 사이 간격이 좁아 끊는 자리를
  나타내는 세로선이 네모에 닿았다. 둘 다 고쳐 다시 렌더링했다.
- 공개 가이드 주제와 비공개 분석 텍스트를 서로 다른 문장으로 적었고, 주제문에 숫자를 쓰지 않았다.
- 본문·도표·평가 데이터에 실존 인물·작품·단체가 등장하지 않는다.

## 검토 반영

병합 뒤 세 갈래로 나눠 독립 검토를 받았다. 도메인 사실성, 평가 정답지, 카테고리 안 개념 경계다. 아래는 그
결과로 고친 것이고, 고치지 않기로 한 지적은 PR 본문에 적었다.

- 평가 정답지: 무관에서 p42·p43을 뺐다. 두 페이지의 `secondaryConcepts`가 이 케이스의 도움 개념(음악적 침묵·늘임)과
  겹치고 본문도 쉼의 길이를 다루는데 무관으로 찍혀 있었다. 대신 p30·p31(점진적 변화)을 넣었다.
- 평가 정답지: `helpfulConcepts`에 이음과 끊음을 더했다. 정답 경로의 p16·p17이 어느 개념 목록에도 없었다.
- 평가 정답지: 대체 페이지를 정답 페이지의 짝(p7·p9)으로 바꿨다. 다른 다섯 권이 쓰는 관례와 어긋나 있었다.
- 사실: "균등하게 줄이면 절반쯤에서 목표에 닿는다"를 지각의 문제로 고쳤다. 선형 변화는 정의상 끝에서 닿는다.
- 사실: 잔향이 긴 공간의 조정을 "짧은 쉼만 늘리고 긴 쉼은 크게 손대지 않는다"로 고쳤다. 여운은 긴 쉼의
  앞부분만 채우므로 종전 서술은 6장 뒷부분과 어긋났다.
- 사실: "쉼은 길이를 바꿔도 음악이 상하지 않는다"에 악구 경계라는 조건을 붙였다. 무조건적 서술은 이 책의
  핵심 주장과 충돌한다.

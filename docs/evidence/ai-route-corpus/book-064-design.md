## 개념 범위와 독자 수준

계획이 book-064에 배정한 접기 구조, 구조적 무게중심, 움직임의 기계적 유도, 재료의 물성을 핵심
주제로 사용했습니다. 실존 작가·작품·유파를 인용하지 않고 가상 작가 지우의 작업 과정을 서술
장치로 사용했습니다.

같은 카테고리 book-068과의 경계가 가장 중요합니다. 068은 매달려 회전하는 조형의 중력 배분과 바람
같은 자연 동력을 다루므로, 064는 **바닥에 접어 세운 구조물의 정적·기계적 안정**에만 한정했습니다.
매다는 방식, 자연 동력, 시간에 따른 형태 변화는 본문에서 명시적으로 제외했습니다(2페이지). 평면
화면의 구도를 다루는 book-061과도 대상이 입체 조형과 평면 화면으로 갈립니다.

## 장 구성

56페이지는 목차 1페이지와 본문 55페이지로 구성하며, 절 하나가 페이지 하나에 대응합니다.

| 장 | 페이지 | 중심 역할 | 내용 |
| --- | --- | --- | --- |
| 1장 종이라는 재료 | 2~8 | `PREREQUISITE` | 결, 굽힘과 탄성, 두께의 한계, 평면에서 입체로 |
| 2장 접기의 문법 | 9~16 | `PREREQUISITE`·`CORE` | 접선, 산접기와 골접기, 순서, 교차, 도면 |
| 3장 접힌 구조가 힘을 견디는 방식 | 17~24 | `CORE`·`COUNTERPOINT` | 주름이 만드는 강성, 하중 경로, 붕괴 방식 |
| 4장 스스로 서는 조형 | 25~33 | `CORE`·`EXAMPLE`·`COUNTERPOINT` | 무게중심, 지지면, 높이와 안정의 상충 |
| 5장 움직임을 만드는 장치 | 34~41 | `CORE`·`COUNTERPOINT` | 힌지, 링크, 자유도 제한, 접힌 자리의 피로 |
| 6장 실전: 서는 조형 만들기 | 42~48 | `EXAMPLE` | 조건 정하기부터 완성까지의 작업 순서 |
| 7장 접기로 풀리지 않는 문제 | 49~53 | `COUNTERPOINT` | 크기·시간·형태의 한계와 다른 재료 |
| 8장 결론: 접어서 세우기까지 | 54~56 | `CONCLUSION` | 개념의 연쇄 정리와 다음 작업을 위한 질문 |

TEXT 본문 49페이지는 모두 3문단이며 330~413자, 평균 369.8자입니다. 견디는 것(3장)과 서 있는
것(4장)을 다른 문제로 분리해 서술한 점이 이 책의 구성 축입니다.

## 구조 메타데이터

- 내용 역할 5종을 모두 사용했습니다(`PREREQUISITE` 8, `CORE` 27, `EXAMPLE` 8,
  `COUNTERPOINT` 9, `CONCLUSION` 3). `FRONT_MATTER`는 목차 1페이지에만 사용합니다.
- 목차만 `aiRouteCandidatePage=false`이고 나머지 55페이지는 모두 `true`입니다.
- 선수 관계 55개는 절 식별자로 설계한 뒤 최종 페이지 번호로 계산했으며, 자기 참조·범위 밖
  참조·순환이 없습니다. 장 사이를 건너뛰는 의존(예: 5장의 움직임 장치가 1장의 탄성을 선수로
  가짐)을 명시해 개념 연결을 드러냈습니다.
- 대표 경로는 `[4, 10, 18, 20, 25, 26, 31, 35, 37, 54]`로 비연속 배치했습니다.
- 제작 당시 `folding-limits` 중복 그룹으로 p16·p51을 연결했지만 p16이 p51의 직접 선수입니다. 두
  페이지는 결론이 비슷해도 근거가 다른 대체 페이지가 아니라 한계 개념을 확장하는 의존 관계이므로 중복
  표시를 제거하고 선수 관계는 유지합니다.

## 평가 케이스: 비소장·예산 15

> 아래는 제작 당시 기록이다. 정답 경로 10건을 선수 폐쇄 기준으로 다시 계산했으므로 시나리오·정답
> 경로·필수 개념의 현재 값은 [평가 정답 경로 재조정](./evaluation-replan.md)과
> `evaluation.json`을 따른다.

| 필드 | 값 |
| --- | --- |
| `caseId` | `case-book-064` |
| `purpose` | 종이를 접어 바닥에 스스로 서고 손으로 밀면 움직이는 조형을 만들어 보고 싶다. 어떤 것은 서고 어떤 것은 넘어지는 이유, 그리고 접은 자리가 어떻게 움직임의 축이 되는지를 원리부터 알고 싶다 |
| `owned` / `maxAdditionalInk` / `depth` | `false` / `15` / `null` |
| `requiredConcepts` | 접기 구조, 주름 구조, 강성, 무게중심, 지지면, 안정, 힌지 |
| `helpfulConcepts` | 산접기와 골접기, 하중, 자유도, 링크 |
| `referencePageNumbers` | 4, 10, 18, 20, 25, 26, 31, 35, 37, 54 |
| `allowedAlternativePageNumbers` | 17, 19, 27, 34, 36, 55 |

예산 15는 일곱 시나리오 중 가장 넉넉한 조건이므로, 재료·접기·구조·안정·움직임을 모두 거쳐 결론에
닿는 열 페이지를 대표 경로로 두었습니다. 목적 문장에는 책 제목이나 정답 페이지 번호를 넣지
않았습니다.

# book-065 「색채 지각과 배색의 원리」 설계

[예술 카테고리 계획](./art-category-plan.md)의 65번을 만든 근거다. 정책·검증 계약은
[AI 경로 콘텐츠 코퍼스](../../ai-route-content-corpus.md)를 따르고, 이 문서는 그 계약 안에서 내린
선택과 이유만 적는다.

## 대상 도서

- `bookId` 65, 카테고리 예술. 저자·소개는 `src/main/resources/demo/books.json`의 기존 값을 유지한다.
- 제목은 `ai-route-v2` manifest의 `books[].title`이 정본이며 이 문서의 제목과 같다.
- 실존 작가·작품·화풍을 옮기지 않는다. 무대는 가상의 「너울 공방」, 인물은 리안과 세오다.
  062(도경·나린)·063(하윤·예강)과 겹치지 않는다.

## 개념 범위

계획 문서가 정한 범위(색의 온감, 색채 대비, 색채 연상, 배색 조화)를 그대로 따른다. 같은 카테고리에서
색을 다루는 권이 셋이라 경계를 분명히 두었다.

- 062의 색온도는 조명기기가 내는 빛의 켈빈 값, 곧 광원의 물리량이다.
- 066의 색면 분할은 벽면에서 색이 차지하는 면적 배분 문제다.
- 065는 **보는 쪽에서 일어나는 일**만 다룬다. 같은 색이 무엇 옆에 놓이느냐에 따라 다르게 보이는
  현상이 책 전체의 주제이고, 6장에서만 조명을 다루되 켈빈 값이 아니라 "빛이 바뀌면 배색이 어떻게
  읽히는가"로 한정했다.

## 장 구성 (55페이지, 목차 1 + 본문 54)

```
1장 색은 혼자 있지 않다      p2–11   PREREQUISITE  관계성·세 성질·바탕과 도형·명도 대비·배색
2장 곁의 색이 바꾸는 것      p12–19  CORE          색조 대비·경계의 떨림·배색 구조·색 줄이기
3장 따뜻함과 차가움          p20–27  CORE          온감·온감의 경계·비율·계열 내 온감
4장 색이 부르는 것           p28–35  CORE          연상·배색 인상·관습적 배색·중립 배색
5장 공방에서 배색하기        p36–45  EXAMPLE       견본·세 색 배색·재료·기록·협업
6장 눈이 속는 자리           p46–51  COUNTERPOINT  조명·잔상과 피로·색각의 차이
7장 결론: 색은 관계로 정해진다  p52–55  CONCLUSION  종합과 점검 물음
```

1장이 다섯 개념을 세우고 2~4장이 관계·온감·연상으로 나누어 펼친다. 5장을 열 페이지로 둔 것은 이 책의
실무가 견본·재료·기록·협업으로 갈라져 다른 권보다 항목이 많기 때문이다.

이미지 6개: p8(같은 회색, 다른 바탕), p14(맞닿은 자리), p23(어느 쪽으로도 갈 수 있는 색),
p30(같은 색, 다른 이웃), p38(넓게·받치고·한 번만), p46(빛이 바뀌면). 여섯 도표 모두 "같은 색을 다른
이웃 옆에 놓는" 형태이고, 비교 대상 사이에 **같은 색의 가는 띠**를 이어 두었다. 이 띠가 없으면 도표가
주장하는 '같은 색'을 독자가 믿을 근거가 없다. 생성 스크립트는 [`figures065.py`](./tools/figures065.py)다.

중복 그룹 1개: `color-is-relation` = [2, 52]. "색은 혼자 있지 않고 곁의 색과 견주어 보인다"는 명제를
1.1에서 세우고 7.1에서 책 전체를 지나온 언어로 재진술한다. 재진술 페이지(52)에는 선수를 두지 않았다.
짝(2)을 선수로 걸면 52를 고른 경로에 2가 반드시 따라와 중복 그룹 규칙을 어기기 때문이며, book-062·063과
같은 처리다.

## 선수 관계 설계

1.1(관계성)을 1장 대부분과 2·3장의 뿌리로 두고, 1.4(명도 대비)만 1.2(세 성질)를 거치게 했다. 대비는 세
성질 가운데 밝기를 먼저 알아야 뜻이 서기 때문이다. 4장은 3.1(온감)에서, 5장은 1.2와 1.5에서, 6장은
1.2와 1.4에서 갈라진다.

- 어느 후보 페이지도 선수 폐쇄가 6페이지를 넘지 않는다.
- 폐쇄 5페이지 이하인 후보 페이지가 일곱 개 장을 모두 덮는다 (기준 3개 장).
- 후보 페이지 54개 전부가 폐쇄 15페이지 이하다 (기준 75%).

가장 깊은 곳은 5.5(협업)로 5.4 → 5.1 → 1.2 → 1.1을 거친다. 협업 절차는 기록을, 기록은 견본을, 견본은
색의 세 성질을 전제하므로 이 사슬은 실제 의존이다.

## 검증

`corpus_lib.validate_book()` → `validate_fragment.py` → `merge_fragments.py` → `validate_manifest.py`를
차례로 통과했다.

- 55페이지(48~72), 7개 장(최소 6), 내용 역할 5종 모두 사용
- `TEXT` 본문 48페이지가 369~555자(평균 438자, 합계 21,047자)로 전량 345자 이상 — 60초로 눌리는
  페이지가 없다
- `FRONT_MATTER`(목차)와 `aiRouteCandidatePage=false`가 정확히 일치
- 선수 관계가 후보 제외 페이지를 가리키지 않음, 위상 정렬로 55페이지 전체 방문
- PDF 페이지 55개, 텍스트 49개, 이미지 6개(p8,14,23,30,38,46) — `pdfcheck.py`로 확인
- PDF 실제 SHA-256이 manifest의 `pdfSha256`과 일치

초고는 페이지당 283~451자로 하한이 정본 기준(345자)에 크게 미달했다. 062·063과 같은 방식으로 `EXTRA`
문단을 더해 369~555자로 맞췄다.

## 평가 케이스: 소장·QUICK 시나리오

| 필드 | 값 |
| --- | --- |
| `caseId` | `case-book-065` |
| `purpose` | 이 책을 소장하고 있는데, 같은 색이 자리에 따라 다르게 보이는 이유만 빠르게 짚고 싶다 |
| `owned` / `maxAdditionalInk` / `depth` | `true` / `null` / `QUICK` |
| `requiredConcepts` | 색의 관계성, 색의 세 성질, 명도 대비 |
| `helpfulConcepts` | 바탕과 도형, 배색, 색조 대비 |
| `referencePageNumbers` | 2, 4, 5, 8, 9 |
| `irrelevantPageNumbers` | 28~29·32~33(연상과 관습), 40~41·44~45(재료와 협업 절차) — 원인만 빠르게 짚으려는 이 목적과 무관 |

정답 경로는 선수 전이 폐쇄와 같고 정확히 5페이지여서 QUICK 상한을 남김없이 쓴다. 관계성(2)에서 세
성질(4, 5)로, 세 성질에서 명도 대비(8, 9)로 이어지는 최단 사슬이며 이 책에서 가장 깊은 갈래가 아니라
가장 곧은 갈래다. QUICK은 다섯 페이지뿐이라 갈라지는 경로를 담을 수 없다.

시나리오는 계획 초안대로 **소장·QUICK**을 유지했다. 병합 직전 분포에서 예산 5가 2건으로 가장 적었지만,
이 책은 QUICK에 맞는 곧은 사슬을 1장에 갖고 있어 초안이 그대로 맞았다. 남은 세 권(68·69·70)에서 예산 5를
채운다. 병합 후 21건의 분포는 QUICK 4건, 예산 5가 2건, 나머지 다섯 시나리오가 각 3건이다.

## 재현 조건

1. `python3 build065.py` — 원고와 조각 생성 (PDF SHA 없이 실행하면 자리표시자를 넣는다)
2. `python3 figures065.py pdfbuild065` — 도표 6개 SVG 생성
3. Chrome Headless로 각 SVG를 794×1123 PNG로 렌더링
4. `python3 build_pdf_generic.py 65 8,14,23,30,38,46 pdfbuild065` — 조판 HTML 생성
5. Chrome Headless `--print-to-pdf`로 PDF 출력, `pdfcheck.py`로 구성 확인
6. PDF를 `fixtures/content/ai-route-v2/pdfs/`에 두고 SHA-256을 인자로 `build065.py` 재실행
7. `merge_fragments.py`로 정본에 병합

## 검수

- 여섯 도표를 PNG로 렌더링해 눈으로 확인했다. 색을 주제로 하는 책이라 도표가 주장하는 '같은 색'이
  실제로 같은지가 검수의 핵심이고, 여섯 도표 모두 비교 대상을 같은 색의 띠로 이어 그 사실을 그림 안에서
  확인할 수 있게 했다.
- 공개 가이드 주제와 비공개 분석 텍스트를 서로 다른 문장으로 적었고, 주제문에 숫자를 쓰지 않았다.
- 본문·도표·평가 데이터에 실존 인물·작품·단체가 등장하지 않는다.

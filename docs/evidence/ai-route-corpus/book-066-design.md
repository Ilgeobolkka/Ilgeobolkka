## 개념 범위와 독자 수준

계획이 book-066에 배정한 벽면 스케일과 건축 표면(요철·재질), 관람 거리와 시야각, 색면 분할,
지역성·맥락 반영을 핵심 주제로 사용했습니다. 실존 작가·작품·유파·도시를 인용하지 않고 가상 작가
재하의 작업 과정을 서술 장치로 사용했습니다(book-061은 다혜, book-064는 지우로 이름이 겹치지
않습니다).

같은 카테고리 세 권과의 경계가 이 책의 가장 중요한 제약이었고, 다음과 같이 나눴습니다.

- **book-061 「형태와 구도」와의 경계**: 061은 고정된 작은 화면과 정면 감상을 전제로 점·선·면을
  배치하는 구도 이론입니다. 066은 구도 이론을 다시 설명하지 않고, **작가가 고를 수 없는 화면**
  (이미 지어진 벽)과 **작가가 정할 수 없는 보는 자리**(지나가는 시선)라는 두 조건에서 출발합니다.
  061이 쓴 `구도`·`균형`·`시각적 무게`·`관람 거리` 같은 개념어를 재사용하지 않고, 대신
  `통행 거리`·`거리대`·`가독 단위`·`시야각`·`앙각`·`빗각 시야`로 어휘를 분리했습니다. 061의
  4장(크기와 스케일)이 화면을 키울 때 빈 공간의 무게가 달라지는 문제를 다루는 반면, 066의
  3장은 같은 "커진다"를 **몸과 도구와 시간의 문제**(한 번에 그을 수 있는 길이, 구획, 이음 오차)로
  다시 정의해 두 책이 같은 자리를 밟지 않게 했습니다(17페이지에서 명시).
- **book-065 「색채 지각과 배색의 원리」와의 경계**: 065는 색이 주는 심리적·정서적 반응을 다룹니다.
  066의 4장 색면 분할은 색의 느낌을 한 번도 설명하지 않고 **넓이 배분**만 다룹니다. 면을
  지배면·보조면·강조면으로 나누는 기준도 색상이 아니라 전체에서 차지하는 넓이 비율이며, 5.3의
  주변 색 환경도 옆 건물·간판과 **넓이를 두고 경쟁**하는 문제로만 서술했습니다.
- **book-062 「무대조명 설계의 기초」와의 경계**: 062의 조명 기기 색온도는 건드리지 않았습니다.
  066에서 빛이 등장하는 유일한 자리는 5.5인데, 광원의 성질이 아니라 **건너편 건물 그림자가 벽을
  가리는 시간대**라는 장소 조건으로만 다룹니다.

54페이지는 목차 1페이지와 본문 53페이지로 구성하며, 절 하나가 페이지 하나에 대응합니다.

| 2장 지나가며 보는 시선 | 9~16 | `CORE` | 통행 거리, 세 거리대, 시야각, 앙각, 빗각, 관찰 시간 |
| 3장 큰 표면에서 달라지는 것 | 17~23 | `CORE`·`COUNTERPOINT` | 구획, 이음 오차, 굴곡, 얼룩, 최소 굵기 |
| 4장 색면으로 화면을 나누다 | 24~31 | `CORE`·`COUNTERPOINT` | 색면 분할, 넓이 배분, 구조선, 개구부, 면 개수 상한 |
| 5장 벽이 놓인 자리 | 32~38 | `CORE`·`COUNTERPOINT` | 장소 맥락, 동선, 주변 색면, 그림자, 유지 관리 |
| 6장 실전: 모퉁이 벽 한 면 | 39~46 | `EXAMPLE` | 조건 정리부터 인계까지의 작업 순서 |

사람(2장)을 서로 다른 제약으로 분리한 뒤 4장에서 둘을 합쳐 화면 구성 규칙을 끌어내는 것이 이
책의 구성 축입니다.

도표 6개를 원본 크기 PNG로 직접 열어 확인했고, 초안에서 다음 네 가지 문제를 발견해 고친 뒤 다시
렌더링했습니다.

1. **7페이지 조사표** — 벽 윤곽 그림이 너무 넓어 오른쪽 설명 문구가 그림 위에 겹쳐 그려졌고,
   네 번째 칸의 설명이 가운데 정렬이라 왼쪽 항목 이름 칸("주의 구간") 위를 덮었습니다. 그림 폭을
   줄이고 설명을 모두 왼쪽 정렬로 바꿔 겹침을 없앴습니다.
2. **14페이지 각도** — 올려다본 경우의 가로 경계 두 줄이 아래쪽에 몰려 있어 간격이 위로 갈수록
   **넓어져** 보였습니다. 본문 설명(위로 갈수록 좁아진다)과 반대였으므로 두 줄의 높이를 올려
   간격이 아래로 갈수록 넓어지도록 다시 그렸습니다.
3. **20페이지 굴곡** — 굵기가 다른 네 띠 중 두 번째와 첫 번째의 설명이 똑같이 "점선처럼 끊긴다"로
   나와 단계 차이가 보이지 않았습니다. 네 단계를 각각 다른 문구로 나눴습니다.
4. **45페이지 세 지점** — 각 행의 설명 문구가 그림 아래에 놓여 바로 다음 행의 제목과 붙어 어느
   행에 속한 설명인지 읽히지 않았고, 맨 아래 행의 설명은 결론 상자와 겹쳤습니다. 설명을 각 행의
   제목 바로 아래로 옮기고, 그림 안에 있던 "한 번에 보이는 범위" 라벨은 그림 위를 덮으므로 행
   설명으로 흡수했습니다. 아울러 먼 거리대 그림에서 위쪽 세 면의 경계가 그대로 보여 "덩어리만
   보인다"는 설명과 어긋나던 문제를 고쳐, 먼 거리에서는 위쪽이 하나의 면으로 뭉치게 했습니다.

최종 PDF 54페이지의 목차(1페이지)와 본문 중 가장 긴 38페이지를 원본 크기 스크린샷으로 확인해
목차 넘침과 본문 넘침·글자 잘림이 없음을 확인했습니다.

## 구조 메타데이터

- 내용 역할 5종을 모두 사용했습니다(`PREREQUISITE` 7, `CORE` 27, `EXAMPLE` 8,
  `COUNTERPOINT` 8, `CONCLUSION` 3). `FRONT_MATTER`는 목차 1페이지에만 사용합니다.
- 목차만 `aiRouteCandidatePage=false`이고 나머지 53페이지는 모두 `true`입니다.
- 선수 관계 53개는 절 식별자로 설계한 뒤 최종 페이지 번호로 계산했으며, 자기 참조·범위 밖
  참조·순환이 없습니다. 장 사이를 건너뛰는 의존(예: 4장의 구조선이 1장의 개구부를, 6장의 표면
  대응이 3장의 얼룩과 굴곡을 선수로 가짐)을 명시해 개념 연결을 드러냈습니다.
- 대표 경로는 `[3, 10, 12, 17, 22, 24, 26, 28, 35, 52]`로 비연속 배치했습니다.
- `wall-detail-loss` 중복 그룹은 15페이지와 23페이지만 연결합니다. 두 페이지는 "촘촘한 세부는
  벽에서 전달되지 않는다"는 같은 결론에 이르지만 근거가 다릅니다. 15페이지는 **지나가는 사람에게
  주어지는 시간이 몇 초뿐**이라는 관찰 시간 근거를 쓰고, 23페이지는 **축소 도안에서는 또렷하던
  형태가 실제 크기·도구·표면에서 최소 굵기 아래로 내려간다**는 재현 근거를 씁니다. 23페이지
  본문에 두 근거가 다르다는 점을 명시해, 중복 후보 판정이 표현 반복이 아니라 근거 차이를 구분할
  수 있는지 시험하도록 남겨 두었습니다.

## 평가 케이스: 소장 · BALANCED

> 아래는 제작 당시 기록이다. 정답 경로 10건을 선수 폐쇄 기준으로 다시 계산했으므로 시나리오·정답
> 경로·필수 개념의 현재 값은 [평가 정답 경로 재조정](./evaluation-replan.md)과
> `evaluation.json`을 따른다.

| 필드 | 값 |
| --- | --- |
| `caseId` | `case-book-066` |
| `purpose` | 동네 큰길가의 낡은 벽에 그림을 그려 달라는 부탁을 받았다. 가까이서는 괜찮은데 길 건너에서 보면 뭉개져 버리는 이유, 울퉁불퉁하고 창이 뚫린 벽면을 어떻게 다뤄야 하는지, 색을 어느 정도 넓이로 나눠야 하는지를 원리부터 알고 싶다 |
| `owned` / `maxAdditionalInk` / `depth` | `true` / `null` / `BALANCED` |
| `requiredConcepts` | 공공 벽화, 표면 요철, 거리대, 시야각, 벽면 스케일, 색면 분할, 면적 배분, 구조선 |
| `helpfulConcepts` | 가독 단위, 앙각, 개구부, 장소 맥락, 동선, 지배면 |
| `referencePageNumbers` | 3, 10, 12, 17, 22, 24, 26, 28, 35, 52 |
| `allowedAlternativePageNumbers` | 4, 9, 11, 20, 25, 27, 30, 53 |
| `irrelevantPageNumbers` | 37, 50 |
| `duplicatePageGroups` | `[[15, 23]]` |

소장 · BALANCED는 잉크 제약이 없는 대신 깊이가 중간이므로, 표면 조건(3) → 보는 조건(10·12) →
큰 표면의 제약(17·22) → 색면 분할과 넓이 배분(24·26·28) → 장소 조건(35) → 결론(52)으로 각
장에서 하나씩만 골라 열 페이지를 대표 경로로 두었습니다. 무관 페이지는 유지·인계(37)와 조건
변화(50)로, 그림을 그리는 방법과 직접 이어지지 않는 사후 관리 쪽을 골랐습니다.

`requiredPrerequisites` 다섯 쌍은 조립 후 실제 DAG로 검산했습니다.

| before → after | 근거 |
| --- | --- |
| 10 → 17 | 세 거리대를 알아야 벽 크기가 왜 확대와 다른지 설명된다 |
| 20 → 22 | 굴곡이 형태를 먹는 과정이 최소 굵기를 정하는 두 조건 중 하나다 |
| 22 → 24 | 최소 굵기 아래가 사라지므로 선이 아니라 면을 쓴다 |
| 10 → 26 | 거리대 구분이 각 면을 어느 거리에 배정할지의 전제다 |
| 24 → 28 | 색면 분할을 정의한 뒤에야 경계를 구조선에 올리는 문제가 생긴다 |

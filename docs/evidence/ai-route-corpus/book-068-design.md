# book-068 「움직이는 조형: 균형과 자연 동력」 설계

[예술 카테고리 계획](./art-category-plan.md)의 68번을 만든 근거다. 정책·검증 계약은
[AI 경로 콘텐츠 코퍼스](../../ai-route-content-corpus.md)를 따르고, 이 문서는 그 계약 안에서 내린
선택과 이유만 적는다.

## 대상 도서

- `bookId` 68, 카테고리 예술. 저자·소개는 `src/main/resources/demo/books.json`의 기존 값을 유지한다.
- 제목은 `ai-route-v2` manifest의 `books[].title`이 정본이며 이 문서의 제목과 같다.
- 실존 작가·작품을 옮기지 않는다. 무대는 가상의 「바람결 작업실」, 인물은 하람과 진서다.
  062(도경·나린)·063(하윤·예강)·065(리안·세오)와 겹치지 않는다.

## 개념 범위

계획 문서가 정한 범위(매달린 균형, 자연 동력, 빛의 반사·굴절, 시간에 따른 형태 변화)를 그대로 따른다.
같은 카테고리 064(종이 조형)와 경계가 가장 가까워 계획 문서가 미리 정한 구분을 본문에서도 지켰다.

- 064는 바닥에 서서 스스로를 지탱하는 구조의 **정적 안정**을 다룬다. 접기와 세우기, 사람이 손으로
  움직이는 기계적 유도가 그 범위다.
- 068은 매달려 도는 구조의 **동적 균형**을 다룬다. 지지 방식이 반대이고 동력도 사람의 조작이 아니라
  공기의 흐름이므로, 이 책에는 접기·세우기·손으로 돌리기가 나오지 않는다.
- 1.1을 서는 것과 매달리는 것의 대조로 시작해 그 경계를 본문 첫 페이지에 못 박았다.

## 장 구성 (53페이지, 목차 1 + 본문 52)

```
1장 매달린 것은 다르게 선다   p2–11   PREREQUISITE  매달린 구조·무게중심·균형점·회전의 자유·자연 동력
2장 팔과 층                   p12–19  CORE          모빌 균형·다층 구조·지지점 조정·흔들림의 주기
3장 바람이 하는 일            p20–27  CORE          공기 흐름·수풍면·불규칙 회전·정지와 재개
4장 도는 동안 보이는 것       p28–35  CORE          보이는 형태·반사·그림자 변화·시간의 형태
5장 작업실에서 만들기         p36–43  EXAMPLE       재료 선택·시험 매달기·연결부·설치
6장 계획대로 돌지 않을 때     p44–49  COUNTERPOINT  공기 조건·마찰과 엉킴·관람자 접촉
7장 결론: 멈춰 있지 않은 균형 p50–53  CONCLUSION    종합과 점검 물음
```

1장이 다섯 개념을 세우고 2~4장이 균형·바람·보이는 것으로 나누어 펼친다. 6장은 그 계획이 공간·시간·사람
때문에 어긋나는 세 경우를 다룬다.

**이미지가 일곱 장이다.** 앞선 세 권은 여섯 장이었으나, 6장에서 공기 조건(p44)과 실 꼬임(p47)을 각각
그림으로 보여야 해서 하나를 더 두었다. 도표는 p8(매다는 자리가 정하는 것), p14(아래가 위의 한쪽이 된다),
p23(어디를 미느냐), p30(도는 동안의 반짝임), p38(매달아 보고 옮기기), p44(같은 조형, 다른 자리),
p47(감기는 실)이다. 지지점은 검은 원, 무게중심은 십자, 움직임은 곡선 화살표, 공기는 파란 화살표로 일곱
도표에서 고정했다. 생성 스크립트는 [`figures068.py`](./tools/figures068.py)다.

중복 그룹 1개: `balance-keeps-moving` = [2, 50]. "매달린 것은 가만히 있지 않는다"는 명제를 1.1에서
세우고 7.1에서 책 전체를 지나온 언어로 재진술한다. 재진술 페이지(50)에는 선수를 두지 않았다. 짝(2)을
선수로 걸면 50을 고른 경로에 2가 반드시 따라와 중복 그룹 규칙을 어기기 때문이며, book-062·063·065와
같은 처리다.

## 선수 관계 설계

1.1(매달린 구조)을 뿌리로 두고 1.2(무게중심) → 1.3(균형점)의 사슬을 만들었다. 균형점은 무게중심을 알아야
성립하므로 이 두 단계는 실제 의존이다. 2장은 1.3에서, 3장은 1.5(자연 동력)에서, 4장은 1.4(회전의 자유)에서
갈라진다.

- 어느 후보 페이지도 선수 폐쇄가 6페이지를 넘지 않는다.
- 폐쇄 5페이지 이하인 후보 페이지가 일곱 개 장을 모두 덮는다 (기준 3개 장).
- 후보 페이지 52개 전부가 폐쇄 15페이지 이하다 (기준 75%).

## 검증

`corpus_lib.validate_book()` → `validate_fragment.py` → `merge_fragments.py` → `validate_manifest.py`를
차례로 통과했다.

- 53페이지(48~72), 7개 장(최소 6), 내용 역할 5종 모두 사용
- `TEXT` 본문 45페이지가 419~633자(평균 476자, 합계 21,402자)로 전량 345자 이상
- `FRONT_MATTER`(목차)와 `aiRouteCandidatePage=false`가 정확히 일치
- 선수 관계가 후보 제외 페이지를 가리키지 않음, 위상 정렬로 53페이지 전체 방문
- PDF 페이지 53개, 텍스트 46개, 이미지 7개(p8,14,23,30,38,44,47) — `pdfcheck.py`로 확인
- PDF 실제 SHA-256이 manifest의 `pdfSha256`과 일치

**이 권부터 본문을 처음부터 문단 넷으로 썼다.** 062·063·065는 초고가 짧아 `EXTRA` 문단을 덧붙이는 과정을
거쳤는데, 그 보정을 매번 하느니 처음부터 길게 쓰는 편이 빨랐다. 그 결과 이 권에는 `EXTRA`가 없다.

## 평가 케이스: 비소장·예산 5 시나리오

| 필드 | 값 |
| --- | --- |
| `caseId` | `case-book-068` |
| `purpose` | 이 책을 사지는 않았고, 매달아 만드는 조형에서 균형을 어떻게 맞추는지 기본만 확인하고 싶다 |
| `owned` / `maxAdditionalInk` / `depth` | `false` / `5` / `null` |

정답 경로는 선수 전이 폐쇄와 같고 정확히 5페이지여서 예산 5를 남김없이 쓴다. 매달린 구조(2)에서
무게중심(4)으로, 무게중심에서 균형점(6)으로, 균형점에서 모빌 균형(12, 13)으로 이어지는 곧은 사슬이다.

시나리오는 계획 초안의 예산 10 대신 **예산 5**를 골랐다. 병합 직전 정본에서 예산 5가 2건으로 가장 적게
쓰인 축이었기 때문이다. 병합 후 22건의 분포는 QUICK 4건, 나머지 여섯 시나리오가 각 3건으로 고르다.

## 재현 조건

1. `python3 build068.py` — 원고와 조각 생성 (PDF SHA 없이 실행하면 자리표시자를 넣는다)
2. `python3 figures068.py pdfbuild068` — 도표 7개 SVG 생성
3. Chrome Headless로 각 SVG를 794×1123 PNG로 렌더링
4. `python3 build_pdf_generic.py 68 8,14,23,30,38,44,47 pdfbuild068` — 조판 HTML 생성
5. Chrome Headless `--print-to-pdf`로 PDF 출력, `pdfcheck.py`로 구성 확인
6. PDF를 `fixtures/content/ai-route-v2/pdfs/`에 두고 SHA-256을 인자로 `build068.py` 재실행
7. `merge_fragments.py`로 정본에 병합

## 검수

- 일곱 도표를 PNG로 렌더링해 눈으로 확인했다. p14는 첫 렌더에서 **무거운 쪽이 긴 팔에 걸린 그림**이
  나왔다. 아래층 전체가 달린 오른쪽이 무거운데 오른쪽 팔을 길게 그려, 본문이 말하는 규칙과 그림이
  반대였다. 매다는 점을 오른쪽으로 옮겨 고쳤다. 같은 그림에서 지시 화살표가 점선 상자를 가로질러 아래층을
  가리던 것도 짧은 지시선으로 바꿨다.
- 공개 가이드 주제와 비공개 분석 텍스트를 서로 다른 문장으로 적었고, 주제문에 숫자를 쓰지 않았다.
- 본문·도표·평가 데이터에 실존 인물·작품·단체가 등장하지 않는다.

## 검토 반영

병합 뒤 세 갈래로 나눠 독립 검토를 받았다. 도메인 사실성, 평가 정답지, 카테고리 안 개념 경계다. 아래는 그
결과로 고친 것이고, 고치지 않기로 한 지적은 PR 본문에 적었다.

- 사실(치명): 2.3이 연직축 회전을 중력 복원력으로 설명하고 있었다. 중력은 그 축에 토크를 만들지 않으므로
  몇 바퀴를 도는지는 관성·마찰·실의 비틀림이 정한다. 이 책 3.4가 이미 옳게 적고 있어 서로 어긋나 있었다.
  기울어짐과 회전을 나눠 다시 썼고, 같은 혼동이 파생된 1.1·2.2도 함께 고쳤다.
- 사실(치명): 4.2의 반사 관측 방향이 뒤집혀 있었다. 창을 등지고 보는 자리에서 자주 보이고 마주 보는 자리에서
  드물게 보이는 것이 맞다.
- 사실(치명): 3.2의 바람개비 비유가 앞 문장과 반대였다. 날개는 모두 같은 방향으로 기울어야 힘이 합쳐진다.
- 사실: 5.1에서 비우는 방향이 결론과 반대였다. 가장자리를 남기면 무게가 축에서 멀어진다.
- 사실: 1.2의 "세 번째 상태"가 두 경우만 서술한 뒤 나와 경우를 하나 더 적었고, 3.3의 "유일한 방법"을
  "가장 확실한 방법"으로 완화했으며, 4.3의 그림자 확대 근거를 광원–조형과 광원–벽의 거리 비로 고쳤다.
- 겹침: 1.2의 추선법 설명이 064와 같아, 매달아 정착 자세를 보는 방법으로 줄였다. 1.4와 2.4의 흔들림 주기
  중복도 1.4 쪽을 소개로 줄였다.

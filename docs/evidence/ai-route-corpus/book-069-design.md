# book-069 「사진의 프레이밍과 시선」 설계

[예술 카테고리 계획](./art-category-plan.md)의 69번을 만든 근거다. 정책·검증 계약은
[AI 경로 콘텐츠 코퍼스](../../ai-route-content-corpus.md)를 따르고, 이 문서는 그 계약 안에서 내린
선택과 이유만 적는다.

## 대상 도서

- `bookId` 69, 카테고리 예술. 저자·소개는 `src/main/resources/demo/books.json`의 기존 값을 유지한다.
- 제목은 `ai-route-v2` manifest의 `books[].title`이 정본이며 이 문서의 제목과 같다.
- 실존 사진가·작품을 옮기지 않는다. 무대는 가상의 「골목 스튜디오」, 인물은 윤오와 초아다.
  062~068의 인물과 겹치지 않는다.

## 개념 범위

계획 문서가 정한 범위(프레이밍, 시선의 방향, 크롭과 네거티브 스페이스, 연작·시퀀스 구성)를 그대로
따른다. 같은 카테고리 061(화면 구도)과 경계가 가장 가까워 계획 문서가 정한 구분을 본문 첫 페이지에서
못 박았다.

- 061은 빈 화면에 형태를 배치해 **채우는** 문제다.
- 069는 이미 있는 장면에서 무엇을 남길지 **덜어 내는** 문제다.
- 방향이 반대이므로 이 책에는 형태를 그려 넣는 이야기가 없고, 언제나 눈앞에 이미 있는 것을 전제한다.
  1.1을 "그리는 사람은 무엇을 넣을지 정하고 찍는 사람은 무엇을 남길지 정한다"는 대조로 열었다.

## 장 구성 (55페이지, 목차 1 + 본문 54)

```
1장 자르는 일에서 시작한다  p2–11   PREREQUISITE  프레이밍·포함과 배제·가장자리·응시선·네거티브 스페이스
2장 무엇을 뺄 것인가        p12–19  CORE          배제의 기준·경계 처리·겹침과 층·이중 프레임
3장 시선이 만드는 방향      p20–27  CORE          응시의 힘·시선 유도·진행 방향 여백·시선의 관계
4장 찍은 뒤에 고르기        p28–35  CORE          크롭·화면 비율·촬영과 크롭·여백 배분
5장 여러 장으로 말하기      p36–45  EXAMPLE       연작·시퀀스·반복과 변주·묶음의 크기·편집 기록
6장 프레임이 감추는 것      p46–51  COUNTERPOINT  맥락 상실·의미 변형·관람자 해석
7장 결론: 사진은 고르는 일이다  p52–55  CONCLUSION  종합과 점검 물음
```

책 전체가 "고르는 일"을 세 단계로 반복한다. 찍기 전에 고르고(1~3장), 찍은 뒤에 고르고(4장), 묶으면서
고른다(5장). 6장은 그 고르기가 사실을 어떻게 바꾸는지를 다루는 반론 장이다.

이미지 6개: p8(보는 쪽을 비워 두기), p14(절반만 걸린 자리), p23(눈이 지나가는 길),
p30(같은 장면, 다른 비율), p38(순서가 만드는 이야기), p46(두 걸음 옆의 사실). 화면의 테두리는 실선
직사각형, 자를 후보는 점선 직사각형, 시선과 눈이 지나가는 길은 점선 화살표로 여섯 도표에서 고정했다.
생성 스크립트는 [`figures069.py`](./tools/figures069.py)다.

중복 그룹 1개: `photo-is-choosing` = [2, 52]. "사진은 이미 있는 세계에서 무엇을 남길지 고르는 일"이라는
명제를 1.1에서 세우고 7.1에서 책 전체를 지나온 언어로 재진술한다. 재진술 페이지(52)에는 선수를 두지
않았다. 짝(2)을 선수로 걸면 52를 고른 경로에 2가 반드시 따라와 중복 그룹 규칙을 어기기 때문이며,
book-062·063·065·068과 같은 처리다.

## 선수 관계 설계

1.1(프레이밍)을 뿌리로 두고 1.2(포함과 배제) → 1.3(가장자리)의 사슬을 만들었다. 가장자리는 무엇을 뺄지
정한 뒤에야 다룰 수 있으므로 이 두 단계는 실제 의존이다. 3장은 1.4(응시선)에서, 4장은 1.2에서, 5장은
1.1에서, 6장은 1.1·1.5·4.1에서 갈라진다.

- 어느 후보 페이지도 선수 폐쇄가 5페이지를 넘지 않는다.
- 폐쇄 5페이지 이하인 후보 페이지가 일곱 개 장을 모두 덮는다 (기준 3개 장).
- 후보 페이지 54개 전부가 폐쇄 15페이지 이하다 (기준 75%).

## 검증

`corpus_lib.validate_book()` → `validate_fragment.py` → `merge_fragments.py` → `validate_manifest.py`를
차례로 통과했다.

- 55페이지(48~72), 7개 장(최소 6), 내용 역할 5종 모두 사용
- `TEXT` 본문 48페이지가 422~531자(평균 469자, 합계 22,517자)
- `FRONT_MATTER`(목차)와 `aiRouteCandidatePage=false`가 정확히 일치
- 선수 관계가 후보 제외 페이지를 가리키지 않음, 위상 정렬로 55페이지 전체 방문
- PDF 페이지 55개, 텍스트 49개, 이미지 6개(p8,14,23,30,38,46) — `pdfcheck.py`로 확인
- PDF 실제 SHA-256이 manifest의 `pdfSha256`과 일치

초고는 346~499자였다. 하한이 정본 기준(345자)을 한 글자 차이로 넘겼는데, 그 언저리에 몰리면 나중에 한
문장만 손봐도 하한이 깨진다. 420자에 못 미친 34페이지에 `EXTRA` 문단을 더해 여유를 두었다.

`validate_book`이 처음 실행에서 p27을 잡았다. 공개 가이드 주제문이 분석 텍스트 안에 그대로 들어 있어
거부됐고, 분석 텍스트의 첫 문장을 다시 써서 통과했다. 두 값을 비슷한 문장으로 쓰면 쉽게 걸리는 검사다.

## 평가 케이스: 소장·BALANCED 시나리오

| 필드 | 값 |
| --- | --- |
| `caseId` | `case-book-069` |
| `purpose` | 이 책을 소장하고 있는데, 화면의 가장자리를 어떻게 다루고 인물의 시선을 어디에 두어야 하는지를 제대로 익히고 싶다 |
| `owned` / `maxAdditionalInk` / `depth` | `true` / `null` / `BALANCED` |
| `requiredConcepts` | 프레이밍, 가장자리, 경계 처리, 응시의 힘, 시선 유도 |
| `helpfulConcepts` | 포함과 배제, 응시선, 네거티브 스페이스, 배제의 기준 |
| `referencePageNumbers` | 2, 4, 6, 8, 14, 15, 20, 21, 22, 23 |
| `irrelevantPageNumbers` | 36~37·42~45(연작 구성과 편집 절차) — 프레임과 시선만 익히려는 이 목적과 무관 |

정답 경로는 선수 전이 폐쇄와 같고 정확히 10페이지여서 BALANCED 상한을 남김없이 쓴다. 프레이밍(2)에서
두 갈래로 갈라진다. 한 갈래는 포함과 배제(4) → 가장자리(6) → 경계 처리(14, 15)로, 다른 갈래는
응시선(8) → 응시의 힘(20, 21) → 시선 유도(22, 23)로 이어진다.

시나리오는 계획 초안의 예산 5 대신 **소장·BALANCED**를 골랐다. 예산 5는 바로 앞 권인 68번이 가져가
분포가 이미 고르게 맞춰졌고, 이 책은 두 갈래가 열 페이지에서 만나는 구조라 BALANCED에 맞았다.

## 재현 조건

1. `python3 build069.py` — 원고와 조각 생성 (PDF SHA 없이 실행하면 자리표시자를 넣는다)
2. `python3 figures069.py pdfbuild069` — 도표 6개 SVG 생성
3. Chrome Headless로 각 SVG를 794×1123 PNG로 렌더링
4. `python3 build_pdf_generic.py 69 8,14,23,30,38,46 pdfbuild069` — 조판 HTML 생성
5. Chrome Headless `--print-to-pdf`로 PDF 출력, `pdfcheck.py`로 구성 확인
6. PDF를 `fixtures/content/ai-route-v2/pdfs/`에 두고 SHA-256을 인자로 `build069.py` 재실행
7. `merge_fragments.py`로 정본에 병합

## 검수

- 여섯 도표를 PNG로 렌더링해 눈으로 확인했다. p46은 첫 렌더에서 **자를 후보를 나타낸 점선 프레임이 실제
  장면 밖으로 삐져나갔고**, 넓은 쪽 프레임이 혼자 있는 사람을 담지 않아 본문이 말하는 두 선택지와
  어긋났다. 두 프레임을 장면 안으로 넣고 넓은 쪽이 두 요소를 함께 담도록 고쳤다.
- 공개 가이드 주제와 비공개 분석 텍스트를 서로 다른 문장으로 적었고, 주제문에 숫자를 쓰지 않았다.
- 본문·도표·평가 데이터에 실존 인물·작품·단체가 등장하지 않는다.

## 검토 반영

병합 뒤 세 갈래로 나눠 독립 검토를 받았다. 도메인 사실성, 평가 정답지, 카테고리 안 개념 경계다. 아래는 그
결과로 고친 것이고, 고치지 않기로 한 지적은 PR 본문에 적었다.

- 겹침: 3.2가 061의 구도 동선과 같은 일반 원리를 설명하고 있었다. 사진가는 선을 그릴 수 없고 이동으로만
  각도를 바꾼다는 관점으로 절을 다시 조준했다.
- 사실: 1.3과 2.2의 "절반이 가장 나쁘다"에 주인공이 아닌 방해 요소라는 조건을 붙였다. 1.2가 절반 잘림을
  의도적 기법으로 쓰고 있어 조건 없는 단정이 서로 충돌했다. p14 도표 문구도 함께 고쳤다.
- 사실: 4.2의 "넓게 잡으면 초점과 노출이 흔들린다"에 자동 초점·자동 측광이라는 조건을 붙였다.

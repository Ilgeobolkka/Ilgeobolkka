# book-090 「별이 가까운 사막의 밤」 설계

[여행 카테고리 계획](./travel-category-plan.md)의 90번을 만든 근거다. 정책·검증 계약은
[AI 경로 콘텐츠 코퍼스](../../ai-route-content-corpus.md)를 따르고, 이 문서는 그 계약 안에서 내린
선택과 이유만 적는다.

## 대상 도서

- `bookId` 90, 카테고리 여행. 저자·소개는 `src/main/resources/demo/books.json`의 기존 값을 유지한다.
- 제목은 `ai-route-v2` manifest의 `books[].title`이 정본이며 이 문서의 제목과 같다.
- 실존 국가·도시·지명을 쓰지 않는다. 무대는 가상의 재모래사막과 그 안의 오아시스 마을 물빛마을이다.
  인물은 안내인 사한과 동행 나린, 물빛마을의 지완이며 081~089의 인물과 겹치지 않는다.

## 개념 범위

계획 문서가 정한 범위(안내인과 함께 건조한 사막을 나흘 걷는 도보 여행)를 그대로 따른다.

- 084(숲길 사흘)와 같은 도보 여행이라 지형과 판단 근거를 갈랐다. 084는 젖은 지형에서 시야가 막힌 채
  길을 잃지 않는 법이고, 090은 마른 지형에서 하늘이 열린 채 기온과 물을 다루는 법이다. 084에는 물이
  넘쳐 문제였고 090에서는 물이 모자라 문제다.
- 087(고원 마을)과 같은 오지이지만 087은 소식이 오가는 속도를 다루고 090은 하루가 나뉘는 방식을
  다룬다. 090의 마을은 목적지가 아니라 물을 얻는 중간 지점이다.
- 이 권에만 있는 축은 **하루가 둘로 끊긴다**는 것이다. 낮의 일곱 시간과 밤의 잠 사이에 걷는 두
  덩어리가 있고, 2장과 3장이 그 두 덩어리를 각각 맡는다. 다른 아홉 권에서는 하루가 이어진다.

## 장 구성 (49페이지, 목차 1 + 본문 48)

```
1장 재모래사막            p2–11   PREREQUISITE  낮밤 온도차·오아시스·모래 지형·동행과 안내인·사막의 짐
2장 낮                    p12–19  CORE          걷는 시각·그늘 만들기·물 배분·모래바람
3장 밤                    p20–27  CORE          밤의 냉각·별로 방향·야영 자리·밤의 잠
4장 오아시스              p28–35  CORE          오아시스 마을·물 규칙·휴식일·구간 준비
5장 나흘의 사막           p36–41  EXAMPLE       첫날·둘째 날·셋째 날 기록·나흘 정리
6장 이 방법이 통하지 않을 때 p42–47 COUNTERPOINT 흐린 밤·단독 행·여름 사막
7장 결론: 사막의 시간     p48–49  CONCLUSION    종합
```

초고는 페이지당 273~426자로 나와 기존 도서의 하한에 미달했다. 081~089와 같이 짧은 페이지마다 문단을
하나씩 더해 335~449자로 올렸다. 더한 문단은 모두 앞 문단의 원칙을 현장에서 어떻게 쓰는지 적은
것이고, 같은 말을 되풀이하지 않았다.

이미지 6개: p7(같은 거리, 다른 시간), p15(하루의 네 토막), p21(맑을수록 춥다), p29(물에서 멀어지는
순서), p37(나흘의 자리), p43(무엇으로 방향을 잡는가). 걷는 시간과 더운 낮은 진한 색, 멈춰 있는
시간과 식은 밤은 옅은 색으로 고정했다. 생성 스크립트는 [`figures090.py`](./tools/figures090.py)다.

중복 그룹 1개: `two-seasons-a-day` = [2, 48]. "사막의 하루에는 두 계절이 들어 있다"는 명제를 1.1에서
기온에 관한 말로 세우고 7.1에서 시간에 관한 말로 재진술한다. 재진술 페이지(48)에는 선수를 두지
않았다. 짝(2)을 선수로 걸면 48을 고른 경로에 2가 반드시 따라와 중복 그룹 규칙을 어기기 때문이며,
book-081~089와 같은 처리다.

## 선수 관계 설계

1.1(낮밤 온도차)을 뿌리로 두고 1.2(오아시스)와 2.1(걷는 시각)과 3.1(밤의 냉각)이 갈라진다. 평가가
BALANCED라 열 페이지 안에 낮과 밤을 모두 담아야 해서, 낮 줄기(1.2 → 2.3 물 배분)와 밤 줄기(3.1 →
3.2 별로 방향)를 나란히 두고 뿌리에서만 만나게 했다. 087의 한 줄기(DEEP)와도, 085·089의 얕은 한
줄기(QUICK)와도 다른 모양이다.

- 어느 후보 페이지도 선수 폐쇄가 5페이지를 넘지 않는다.
- 폐쇄 5페이지 이하인 후보 페이지가 일곱 개 장을 모두 덮는다 (기준 3개 장).
- 후보 페이지 48개 전부가 폐쇄 15페이지 이하다 (기준 75%).

## 검증

`corpus_lib.validate_book()` → `validate_fragment.py` → `merge_fragments.py` → `validate_manifest.py`를
차례로 통과했다.

- 49페이지(48~72), 7개 장(최소 6), 내용 역할 5종 모두 사용
- `TEXT` 본문 42페이지가 335~449자(평균 391자, 합계 16,433자)
- `FRONT_MATTER`(목차)와 `aiRouteCandidatePage=false`가 정확히 일치
- 선수 관계가 후보 제외 페이지를 가리키지 않음, 위상 정렬로 49페이지 전체 방문
- PDF 페이지 49개, 텍스트 43개, 이미지 6개(p7,15,21,29,37,43) — `pdfcheck.py --book 90`으로 확인
- PDF 실제 SHA-256이 manifest의 `pdfSha256`과 일치

## 평가 케이스: 소장·BALANCED 시나리오

| 필드 | 값 |
| --- | --- |
| `caseId` | `case-book-090` |
| `purpose` | 이 책을 소장하고 있는데, 안내인과 함께 사막을 며칠 걸을 계획이다. 낮과 밤의 기온차가 하루를 어떻게 나누는지와 언제 걷고 물을 어떻게 나누어 마시는지, 그리고 밤에 별로 방향을 잡는 법을 이어서 익히고 싶다 |
| `owned` / `maxAdditionalInk` / `depth` | `true` / `null` / `BALANCED` |
| `requiredConcepts` | 낮밤 온도차, 오아시스, 걷는 시각, 물 배분, 밤의 냉각, 별로 방향 |
| `helpfulConcepts` | 모래 지형, 그늘 만들기, 야영 자리, 동행과 안내인 |
| `referencePageNumbers` | 2, 4, 5, 12, 13, 16, 17, 20, 22, 23 |
| `irrelevantPageNumbers` | 32·33(휴식일), 44·45(단독 행), 46·47(여름 사막) — 안내인과 함께 걷는 며칠의 낮밤을 익히려는 목적과 무관. 절 단위로 넣어 짝 페이지를 쪼개지 않는다 |
| `allowedAlternativePageNumbers` | 3, 14, 25 |

정답 경로는 선수 전이 폐쇄와 같고 정확히 10페이지여서 BALANCED 상한을 남김없이 쓴다. 낮밤
온도차(2)에서 오아시스(4, 5)와 걷는 시각(12, 13)과 물 배분(16, 17)이, 그리고 밤의 냉각(20)에서 별로
방향(22, 23)이 갈라져 내려간다. 목적이 낮과 밤을 함께 묻기 때문에 한 줄기로는 담을 수 없었다.

시나리오는 계획 문서가 배정한 **소장·BALANCED**를 그대로 썼다. 병합 후 43건의 분포는 BALANCED가
8건, QUICK이 7건, DEEP·예산 10이 각 6건, 예산 0·예산 5·예산 15가 각 5건이다.

## 재현 조건

1. `python3 build090.py` — 원고와 조각 생성 (PDF SHA 없이 실행하면 자리표시자를 넣는다)
2. `python3 figures090.py pdfbuild090` — 도표 6개 SVG 생성
3. Chrome Headless로 각 SVG를 794×1123 PNG로 렌더링
4. `python3 build_pdf_generic.py 90 7,15,21,29,37,43 pdfbuild090` — 조판 HTML 생성
5. Chrome Headless `--print-to-pdf`로 PDF 출력, `pdfcheck.py --book 90`으로 구성 확인
6. PDF를 `fixtures/content/ai-route-v2/pdfs/`에 두고 SHA-256을 인자로 `build090.py` 재실행
7. `merge_fragments.py 90`으로 정본에 병합
8. `sync_readme.py --add 90 여행`으로 fixture README의 수치와 표를 다시 계산

## 검수

- 여섯 도표를 PNG로 렌더링해 눈으로 확인하고 셋을 고쳤다. p7은 모래언덕 이름표를 경로 화살표가
  가로질러 위로 옮겼고, p21은 되돌아온 열을 설명하는 줄이 화살표를 덮어 지면 아래로 내렸으며,
  p37은 돌아 나온 방향의 이름표가 화살표 위에 얹혀 아래로 내렸다.
- p43의 분석 텍스트가 그림과 어긋나 고쳤다. 그림에서는 흐린 밤에 세 수단이 함께 막히는데 분석에는
  동시에 무효가 되지 않는다고 적혀 있었다. 그림을 정본으로 삼아 분석을 고쳤다.
- 조판한 PDF의 구성을 `pdfcheck.py`로 확인했다.
- 공개 가이드 주제와 비공개 분석 텍스트를 서로 다른 문장으로 적었고, 주제문에 숫자를 쓰지 않았다.
- 본문·도표·평가 데이터에 실존 국가·도시·지명·인물이 등장하지 않는다.
- 6.2에 혼자 걷지 말라고 적는 대신 혼자 걷겠다면 무엇을 미리 정해 두어야 하는지를 적었다. 6.3에는
  이 나흘이 봄의 기록이며 여름과 겨울에는 같은 계획이 서지 않는다고 밝혔다.

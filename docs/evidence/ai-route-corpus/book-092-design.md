# book-092 「미루는 마음과 협상하기」 설계

[자기계발 카테고리 계획](./self-help-category-plan.md)의 92번을 만든 근거다. 정책·검증 계약은
[AI 경로 콘텐츠 코퍼스](../../ai-route-content-corpus.md)를 따르고, 이 문서는 그 계약 안에서 내린
선택과 이유만 적는다. 앞 권은 [book-091](./book-091-design.md)이다.

## 대상 도서

- `bookId` 92, 카테고리 자기계발. 제목·저자·소개는 `src/main/resources/demo/books.json`의 기존 값을
  유지한다.
- 제목은 `ai-route-v2` manifest의 `books[].title`이 정본이며 이 문서의 제목과 같다.
- 실존 인물·단체를 옮기지 않는다. 무대는 가상의 자격시험 준비 모임 「모퉁이 스터디」, 인물은 다온과
  세진이다. 091의 낮은책상 사무실·유하·태오와 겹치지 않는다.

## 개념 범위

계획 문서가 정한 원리(미루는 행동의 심리적 원인을 파악하고 자신과 협상하기)와 하위 개념(회피 동기,
완벽주의, 불확실성 회피, 내면의 자기대화)을 그대로 따른다.

- 091이 "일을 어떻게 쪼개는가"라면 92는 "쪼갠 일도 왜 시작되지 않는가"다. 그래서 이 권은 일을 쪼개는
  방법을 설명하지 않고 이미 쪼갠 상태를 전제한다. 3.2에서 분량을 줄이는 대목이 나오지만 이것은 분해
  기준이 아니라 오늘 하루의 요구를 낮추는 협상이고, 낮추는 근거도 작업 구조가 아니라 착수 문턱이다.
- 95(완벽하지 않은 시작)와 완벽주의를 공유한다. 92의 완벽주의는 **미루는 이유**로만 다루고(2.3), 낮은
  완성도로 착수하는 방법 자체는 95의 몫이라 여기서는 오늘의 기준을 정하는 한 문장까지만 다룬다.
- 94(기록)와 97(회고)에 닿는 자리는 4.4와 5.4다. 여기서 적는 것은 습관으로서의 기록이나 주간 회고가
  아니라 미룬 날의 조건 한 줄이며, 목적도 축적이 아니라 다음 협상의 재료다.
- 감정과 동기의 층위만 다루고 환경 통제(93)나 측정(99)은 다루지 않는다.

## 장 구성 (50페이지, 목차 1 + 본문 49)

```
1장 미루는 순간에 일어나는 일  p2–11   PREREQUISITE  미루기·회피 동기·단기 보상·불확실성 회피·현재 편향
2장 원인을 가려내기            p12–19  CORE          원인 분류·혐오 과제·완벽주의·불확실성
3장 자신과 협상하기            p20–27  CORE          자기 협상·기준 낮추기·부분 착수·보상 설계
4장 말을 바꾸기                p28–35  CORE          내면의 자기대화·자기 비난·실행 의도·사후 해석
5장 어떤 저녁                  p36–42  EXAMPLE       지연 관찰·원인 확인·협상 실행·반복 관찰
6장 협상이 통하지 않을 때      p43–48  COUNTERPOINT  의도적 지연·기준 붕괴·도움이 필요한 신호
7장 결론: 미루는 나와 함께 가기 p49–50 CONCLUSION    종합
```

1장이 미루는 순간의 구조를 세우고, 2장이 원인을 셋으로 가르고, 3~4장이 조건과 말이라는 두 갈래의
대응을 편다. 5장은 한 사람의 저녁 하나를 관찰에서 협상까지 따라간다. 6장은 방법이 통하지 않는 세
경우를 다루며, 그 가운데 6.3은 전반적 활동 저하 상태를 이 책의 범위 밖으로 명시하고 전문가의 도움을
권한다. 자기계발 서적이 심리 상태를 다룰 때 넘지 말아야 할 선이라 반례 장에 자리를 따로 두었다.

이미지 4개: p6(지금 줄고 나중에 는다), p12(어느 쪽에서 막혔는가), p24(흥정표), p32(언제 무엇을 할지
적힌 문장). 네 도표의 형식을 두 곡선 비교·판정 흐름도·두 열 대응표·문장 도해로 모두 다르게 잡았다.
091이 여섯 도표를 쓴 것과 달리 넷으로 줄인 것은 이 권의 내용이 대부분 문장과 대화로 이뤄져 있어
그림으로 얻는 것이 적기 때문이다. 생성 스크립트는 [`figures092.py`](./tools/figures092.py)다.

중복 그룹 1개: `not-laziness-but-a-moment` = [2, 49]. "미루는 것은 성격이 아니라 특정한 일 앞에서
일어나는 선택"이라는 명제를 1.1에서 세우고 7.1에서 재진술한다. 재진술 페이지(49)에는 선수를 두지
않았다. 짝(2)을 선수로 걸면 49를 고른 경로에 2가 반드시 따라와 중복 그룹 규칙을 어기기 때문이며,
091과 같은 처리다.

## 선수 관계 설계

1.1(미루기)을 뿌리로 두고 1.2(회피 동기)가 갈라진 뒤 2장이 거기서 나온다. 3장(협상)과 4장(말)은
2장을 거치지 않고 1.1에서 바로 갈라진다. 원인을 가려내지 않아도 협상과 말 바꾸기는 각각 읽을 수
있고, 두 장을 2장 뒤에 매달면 어느 경로든 폐쇄가 커져 예산 5 사례를 만들 수 없기 때문이다.

- 어느 후보 페이지도 선수 폐쇄가 5페이지를 넘지 않는다. 91권(최대 7)보다 얕다.
- 폐쇄 5페이지 이하인 후보 페이지가 일곱 개 장을 모두 덮는다 (기준 3개 장).
- 후보 페이지 49개 전부가 폐쇄 15페이지 이하다 (기준 75%).

6장의 세 절은 각각 자기가 반박하는 대상에 붙였다. 6.1(미루는 편이 옳은 경우)은 1.3(단기 보상),
6.2(기준 붕괴)는 3.2(기준 낮추기), 6.3(도움이 필요한 신호)은 1.4(불확실성 회피)다.

## 검증

`corpus_lib.validate_book()` → `validate_fragment.py` → `merge_fragments.py` → `validate_manifest.py`를
차례로 통과했다.

- 50페이지(48~72), 7개 장(최소 6), 내용 역할 5종 모두 사용
- `TEXT` 본문 45페이지가 345~416자(평균 378자, 합계 17,011자)로 전량 345자 이상
- `FRONT_MATTER`(목차)와 `aiRouteCandidatePage=false`가 정확히 일치
- 선수 관계가 후보 제외 페이지를 가리키지 않음, 위상 정렬로 50페이지 전체 방문
- PDF 페이지 50개, 텍스트 46개, 이미지 4개(p6,12,24,32) — `pdfcheck.py`로 확인
- PDF 실제 SHA-256이 manifest의 `pdfSha256`과 일치

초고에서 네 페이지(39·40·45·47)가 345자에 못 미쳤다. 091과 같이 `EXTRA` 문단을 붙이지 않고 마지막
문단을 늘려 고쳤다.

## 평가 케이스: 비소장·예산 5 시나리오

| 필드 | 값 |
| --- | --- |
| `caseId` | `case-book-092` |
| `purpose` | 해야 할 일을 자꾸 미루는데 왜 그런지 모르겠다. 잘 해내고 싶은 마음 때문에 시작을 못 하는 것 같은데, 잉크를 조금만 써서 미루는 원인을 가려내는 방법까지만 알고 싶다 |
| `owned` / `maxAdditionalInk` / `depth` | `false` / `5` / `null` |
| `activeRentalPageNumbers` | 없음 |
| `requiredConcepts` | 미루기, 회피 동기, 원인 분류, 완벽주의 |
| `helpfulConcepts` | 단기 보상, 불확실성 회피, 자기 협상, 기준 낮추기 |
| `referencePageNumbers` | 2, 4, 12, 16, 17 |
| `irrelevantPageNumbers` | 28~35(4장 전체) — 원인을 가려내는 데까지만 쓰겠다는 목적 밖이다. 절 단위로 넣어 짝 페이지를 쪼개지 않는다 |
| `allowedAlternativePageNumbers` | 5, 15, 19 |

정답 경로는 2.3(잘하고 싶은 일)의 두 번째 페이지 하나를 씨앗으로 잡은 선수 폐쇄이고 정확히 5페이지라
예산을 남김없이 쓴다. 1.1(미루기) → 1.2(회피 동기) → 2.1(원인 분류) → 2.3(완벽주의)으로 이어지는
사슬이 목적문이 말하는 "잘 해내고 싶은 마음 때문에 시작을 못 한다"에 정확히 대응한다.

대체 페이지 셋은 각각 1.2·2.2·2.4의 두 번째 페이지다. 폐쇄가 3~5페이지라 예산 5 안에서 실제로 고를
수 있고, 셋 다 원인을 가려내는 다른 갈래를 다루므로 정답의 한 자리를 대신해도 목적을 채운다.

## 재현 조건

1. `python3 build092.py` — 원고와 조각 생성 (PDF SHA 없이 실행하면 자리표시자를 넣는다)
2. `python3 figures092.py pdfbuild092` — 도표 4개 SVG 생성
3. Chrome Headless로 각 SVG를 794×1123 PNG로 렌더링
4. `python3 build_pdf_generic.py 92 6,12,24,32 pdfbuild092` — 조판 HTML 생성
5. Chrome Headless `--print-to-pdf`로 PDF 출력, `pdfcheck.py`로 구성 확인
6. PDF를 `fixtures/content/ai-route-v2/pdfs/`에 두고 SHA-256을 인자로 `build092.py` 재실행
7. `merge_fragments.py 92`로 정본에 병합

## 검수

- 네 도표를 PNG로 렌더링해 눈으로 확인했다. p6은 두 곡선의 시작점이 같고 마감에서 뒤집히는 것이
  도표의 전부라, 화살표 두 개가 각각 "지금"과 "나중"의 차이를 가리키는지를 중점으로 봤다.
- 공개 가이드 주제와 비공개 분석 텍스트를 서로 다른 문장으로 적었고, 주제문에 숫자를 쓰지 않았다.
- 본문·도표·평가 데이터에 실존 인물·작품·단체가 등장하지 않는다.
- 심리 현상을 설명하되 특정 연구나 통계를 인용하지 않았다. 본문의 관찰은 모두 가상 인물의 사례로
  적었고, 진단이나 치료를 대신할 수 있다는 인상을 주지 않도록 6.3에 범위 밖 표시를 두었다.

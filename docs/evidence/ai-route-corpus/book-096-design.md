# book-096 「질문으로 여는 회의」 설계

[자기계발 카테고리 계획](./self-help-category-plan.md)의 96번을 만든 근거다. 정책·검증 계약은
[AI 경로 콘텐츠 코퍼스](../../ai-route-content-corpus.md)를 따르고, 이 문서는 그 계약 안에서 내린
선택과 이유만 적는다. 앞 권은 [book-095](./book-095-design.md)다.

## 대상 도서

- `bookId` 96, 카테고리 자기계발. 제목·저자·소개는 `src/main/resources/demo/books.json`의 기존 값을
  유지한다.
- 제목은 `ai-route-v2` manifest의 `books[].title`이 정본이며 이 문서의 제목과 같다.
- 실존 인물·단체를 옮기지 않는다. 무대는 가상의 생활협동조합 「한밭 살림」의 운영 회의, 인물은 진서와
  모아다. 091~095의 인물과 겹치지 않는다.

## 개념 범위

계획 문서가 정한 원리(열린 질문으로 대화의 방향을 여는 회의 진행)와 하위 개념(개방형 질문, 의도적 침묵,
회의 목적 명시, 발언 기회 배분)을 그대로 따른다. 자기계발 열 권 가운데 **유일하게 여러 사람 사이의
대화**를 다룬다.

- 097의 회고 질문은 혼자 자기에게 던지는 질문이고, 이 권의 질문은 모두 다른 사람에게 던지는 것이다.
  같은 질문이라는 낱말을 쓰지만 대상과 목적이 다르고, 96에는 자기 점검용 질문이 한 자리도 없다.
- 091~095가 개인의 하루·감정·환경·기록·착수를 다뤘다면 96은 여럿이 모인 한 시간을 다룬다. 그래서
  1.1 두 번째 페이지에 조직 문화나 결정 구조는 다루지 않는다고 범위를 적었다.
- 094의 기록과 3.3의 발언 기록이 닿는다. 94는 개인이 반복하는 기록의 습관화이고, 96의 기록은 회의 중에
  모두가 보게 적어 논의를 사람에게서 떼어 놓는 장치다.

## 장 구성 (50페이지, 목차 1 + 본문 49)

```
1장 회의가 닫히는 자리   p2–11   PREREQUISITE  닫힌 회의·개방형 질문·회의 목적 명시·발언 분포·회의의 대체
2장 여는 질문 만들기     p12–19  CORE          질문 설계·도입 질문·수렴 질문·유도 질문
3장 기다리기             p20–27  CORE          의도적 침묵·진행자의 절제·발언 기록·명료화
4장 말할 자리 만들기     p28–35  CORE          발언 기회 배분·사전 작성·반대 의견 보호·합의 확인
5장 어떤 회의            p36–42  EXAMPLE       사례 관찰·질문 적용·변화 관찰·잔여 과제
6장 질문이 통하지 않을 때 p43–48 COUNTERPOINT  결정 회의·형식적 회의·권력 차이
7장 결론: 회의는 질문의 모양을 따라간다 p49–50 CONCLUSION 종합
```

1장이 닫힌 회의의 구조와 질문의 두 형식을 세우고, 2장이 질문을 만드는 법, 3장이 던진 뒤에 하는 일,
4장이 말할 자리를 만드는 법을 다룬다. 5장은 세 번의 회의를 세어 본 뒤 진행 방식을 바꾸고 석 달 뒤에 다시
센 과정을 따라간다. 6장은 질문 방식으로 풀 수 없는 세 경우를 두었고, 6.3에서 힘의 차이는 이 방법이
줄일 뿐 없애지 못한다고 명시했다.

이미지 4개: p5(물음이 답의 폭을 정한다), p15(넓게 열고 좁혀 간다), p29(누가 얼마나 말했나), p37(세어 본
세 번). 형식을 부챗살 대비·깔때기·좌석 배치도·가로 막대로 잡았다. 생성 스크립트는
[`figures096.py`](./tools/figures096.py)다.

중복 그룹 1개: `questions-shape-the-room` = [2, 49]. "던지는 질문의 모양이 돌아오는 말의 모양을
정한다"는 명제를 1.1에서 세우고 7.1에서 재진술한다. 재진술 페이지(49)에는 선수를 두지 않았다.
091~095와 같은 처리다.

## 선수 관계 설계

1.1(닫힌 회의)을 뿌리로 두고 1.2(개방형 질문)·1.3(회의 목적)·1.4(발언 분포)가 갈라진다. 2장과 3장은
1.2에서, 4장과 5장은 1.4에서, 6.1·6.2는 1.3 갈래에서 갈라진다. 3장을 1.2에 붙인 것은 기다리는 일이
열린 질문을 던진 뒤에만 생기는 문제이기 때문이다.

- 어느 후보 페이지도 선수 폐쇄가 6페이지를 넘지 않는다.
- 폐쇄 5페이지 이하인 후보 페이지가 일곱 개 장을 모두 덮는다 (기준 3개 장).
- 후보 페이지 49개 전부가 폐쇄 15페이지 이하다 (기준 75%).

## 검증

`corpus_lib.validate_book()` → `validate_fragment.py` → `merge_fragments.py` → `validate_manifest.py`를
차례로 통과했다.

- 50페이지(48~72), 7개 장(최소 6), 내용 역할 5종 모두 사용
- `TEXT` 본문 45페이지가 347~425자(평균 387자, 합계 17,428자)로 전량 345자 이상
- `FRONT_MATTER`(목차)와 `aiRouteCandidatePage=false`가 정확히 일치
- 선수 관계가 후보 제외 페이지를 가리키지 않음, 위상 정렬로 50페이지 전체 방문
- PDF 페이지 50개, 텍스트 46개, 이미지 4개(p5,15,29,37) — `pdfcheck.py`로 확인
- PDF 실제 SHA-256이 manifest의 `pdfSha256`과 일치

초고는 284~423자로 서른한 페이지가 하한에 미달해 093~095와 같이 `EXTRA` 문단으로 채웠다.

## 평가 케이스: 소장·BALANCED 시나리오

| 필드 | 값 |
| --- | --- |
| `caseId` | `case-book-096` |
| `purpose` | 이 책을 소장하고 있는데, 우리 회의에서는 늘 같은 두세 사람만 말한다. 질문을 어떻게 던지고 얼마나 기다려야 다른 사람도 말하게 되는지 다음 회의에서 바로 해 볼 수 있을 만큼 익히고 싶다. 회의가 형식뿐인 경우까지는 지금 필요 없다 |
| `owned` / `maxAdditionalInk` / `depth` | `true` / `null` / `BALANCED` |
| `requiredConcepts` | 닫힌 회의, 개방형 질문, 발언 분포, 질문 설계, 도입 질문, 의도적 침묵, 발언 기회 배분 |
| `helpfulConcepts` | 회의 목적 명시, 수렴 질문, 진행자의 절제, 합의 확인 |
| `referencePageNumbers` | 2, 4, 8, 12, 14, 15, 20, 21, 28, 29 |
| `irrelevantPageNumbers` | 43~48(6장 전체) — 목적문이 형식뿐인 회의는 지금 필요 없다고 밝힌 부분이다. 절 단위로 넣어 짝 페이지를 쪼개지 않는다 |
| `allowedAlternativePageNumbers` | 17, 23, 31 |

정답 경로는 2.2(도입 질문)·3.1(의도적 침묵)·4.1(발언 기회 배분)의 두 번째 페이지 셋을 씨앗으로 잡은
선수 폐쇄이고 정확히 열 페이지라 BALANCED 상한을 남김없이 쓴다. 질문을 만드는 갈래(1.2 → 2.1 → 2.2),
기다리는 갈래(1.2 → 3.1), 자리를 만드는 갈래(1.4 → 4.1) 셋이 1.1에서 만나는 구조라 목적문이 말하는
"어떻게 던지고 얼마나 기다리는가"를 한 경로에 담을 수 있다.

## 재현 조건

1. `python3 build096.py` — 원고와 조각 생성 (PDF SHA 없이 실행하면 자리표시자를 넣는다)
2. `python3 figures096.py pdfbuild096` — 도표 4개 SVG 생성
3. Chrome Headless로 각 SVG를 794×1123 PNG로 렌더링
4. `python3 build_pdf_generic.py 96 5,15,29,37 pdfbuild096` — 조판 HTML 생성
5. Chrome Headless `--print-to-pdf`로 PDF 출력, `pdfcheck.py`로 구성 확인
6. PDF를 `fixtures/content/ai-route-v2/pdfs/`에 두고 SHA-256을 인자로 `build096.py` 재실행
7. `merge_fragments.py 96`으로 정본에 병합

## 검수

- 네 도표를 PNG로 렌더링해 눈으로 확인했다. p29는 초안에서 좌석 바깥의 점이 제목 구분선을 넘고 두 배치도가
  서로 닿아, 원 반지름과 점 간격을 줄이고 두 배치도의 간격을 넓혔다.
- 공개 가이드 주제와 비공개 분석 텍스트를 서로 다른 문장으로 적었고, 주제문에 숫자를 쓰지 않았다.
- 본문·도표·평가 데이터에 실존 인물·단체가 등장하지 않는다. 발언 분포 숫자는 가상 회의에서 센 값으로만
  적었고 일반적인 연구 결과로 제시하지 않았다.
- 회의 진행 기법이 조직 내 힘의 차이나 결정 구조까지 바꿀 수 있다는 인상을 주지 않도록, 1.1과 6.3에
  범위 밖 표시를 두 곳 두었다.

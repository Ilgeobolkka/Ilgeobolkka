# book-097 「일주일을 돌아보는 열 문장」 설계

[자기계발 카테고리 계획](./self-help-category-plan.md)의 97번을 만든 근거다. 정책·검증 계약은
[AI 경로 콘텐츠 코퍼스](../../ai-route-content-corpus.md)를 따르고, 이 문서는 그 계약 안에서 내린
선택과 이유만 적는다. 앞 권은 [book-096](./book-096-design.md)이다.

## 대상 도서

- `bookId` 97, 카테고리 자기계발. 제목·저자·소개는 `src/main/resources/demo/books.json`의 기존 값을
  유지한다.
- 제목은 `ai-route-v2` manifest의 `books[].title`이 정본이며 이 문서의 제목과 같다.
- 실존 인물·단체를 옮기지 않는다. 무대는 가상의 공유 작업실 「윗층 작업실」, 인물은 프리랜서 번역가
  서하와 다림이다. 091~096의 인물과 겹치지 않는다.

## 개념 범위

계획 문서가 정한 원리(정해진 질문 세트로 주간 회고를 짧게 반복하기)와 하위 개념(회고 질문 세트, 패턴
인식, 회고의 최소 형식, 다음 주로 넘기는 항목)을 그대로 따른다.

- 096의 질문은 회의에서 남에게 던지는 질문이고 이 권의 질문은 혼자 자기에게 던지는 질문이다. 96에는
  자기 점검용 질문이 한 자리도 없고, 97에는 남에게 던지는 질문이 3.3(둘이 서로 물어 주는 방식) 한
  자리뿐이며 거기서도 조언을 금지해 회의와 구분했다.
- 094는 사실을 남기는 시점을 다루고 97은 이미 남긴 것을 되짚는 시점을 다룬다. 97의 사실 질문은 기록을
  참조해 답하는 자리이지 기록을 만드는 방법이 아니다.
- 091의 이월과 2.4의 이월 질문이 닿는다. 91은 하루 단위 작업 항목을 다음 날로 옮기는 일이고, 97은 한 주의
  관찰에서 다음 주에 바꿀 한 가지를 고르는 일이라 단위와 대상이 다르다.
- 099(측정)와 구분하기 위해 숫자 항목을 하나로 제한하고, 2.2에서 셋을 넘기면 회고가 집계가 된다고 적었다.

## 장 구성 (50페이지, 목차 1 + 본문 49)

```
1장 돌아보지 않는 한 주 p2–11   PREREQUISITE  회고의 부재·회고의 마찰·회고 대상·기억의 편향·평가와 관찰
2장 열 문장             p12–19  CORE          회고 질문 세트·사실 질문·판단 질문·이월 질문
3장 짧게 반복하기       p20–27  CORE          회고의 최소 형식·질문의 고정·구술 회고·결손 처리
4장 쌓인 것에서 보기    p28–35  CORE          패턴 인식·반복 신호·변화 감지·행동 전환
5장 어떤 열 문장        p36–42  EXAMPLE       과잉 형식·형식 축소·누적 관찰·질문 갱신
6장 회고가 해롭게 될 때 p43–48  COUNTERPOINT  자기 비난 회고·형식화·무변화 구간
7장 결론: 같은 질문을 여러 번 던진다 p49–50 CONCLUSION 종합
```

1장이 회고가 끊기는 구조와 기억의 편향을 세우고, 2장이 질문 세트, 3장이 반복 조건, 4장이 누적 검토를
다룬다. 5장은 스무 문장으로 실패하고 열 문장으로 다시 시작해 열두 주를 쌓은 과정을 따라간다. 6장은 회고가
자책·형식·무의미로 흐르는 세 경우를 두었고, 6.1 두 번째 페이지에서 마음이 계속 무거운 상태는 이 책의 범위
밖이라고 밝혔다.

이미지 4개: p9(남는 것과 남지 않는 것), p13(열 문장), p29(여덟 주를 나란히), p39(스물에서 열로). 형식을
요일별 점 분포·묶음 질문지·주별 격자·목록 대비로 잡았다. 생성 스크립트는
[`figures097.py`](./tools/figures097.py)다.

중복 그룹 1개: `same-questions-many-weeks` = [2, 49]. "한 주를 짧게 여러 번 돌아본다"는 명제를 1.1에서
세우고 7.1에서 재진술한다. 재진술 페이지(49)에는 선수를 두지 않았다. 091~096과 같은 처리다.

## 선수 관계 설계

1.1(회고의 부재)을 뿌리로 두고 1.2(회고의 마찰)·1.3(회고 대상)·1.4(기억의 편향)가 갈라진다. 2장과 5장은
1.3에서, 3장은 1.2에서, 4장은 1.4에서 갈라진다. 4장을 1.4에 붙인 것은 여러 주를 나란히 보는 이유가 기억의
편향을 넘기 위해서이기 때문이다.

- 어느 후보 페이지도 선수 폐쇄가 6페이지를 넘지 않는다.
- 폐쇄 5페이지 이하인 후보 페이지가 일곱 개 장을 모두 덮는다 (기준 3개 장).
- 후보 페이지 49개 전부가 폐쇄 15페이지 이하다 (기준 75%).

## 검증

`corpus_lib.validate_book()` → `validate_fragment.py` → `merge_fragments.py` → `validate_manifest.py`를
차례로 통과했다.

- 50페이지(48~72), 7개 장(최소 6), 내용 역할 5종 모두 사용
- `TEXT` 본문 45페이지가 345~413자(평균 382자, 합계 17,179자)로 전량 345자 이상
- `FRONT_MATTER`(목차)와 `aiRouteCandidatePage=false`가 정확히 일치
- 선수 관계가 후보 제외 페이지를 가리키지 않음, 위상 정렬로 50페이지 전체 방문
- PDF 페이지 50개, 텍스트 46개, 이미지 4개(p9,13,29,39) — `pdfcheck.py`로 확인
- PDF 실제 SHA-256이 manifest의 `pdfSha256`과 일치

초고는 281~368자로 서른아홉 페이지가 하한에 미달해 093~096과 같이 `EXTRA` 문단으로 채웠다. `EXTRA`를 넣은
뒤에도 p14가 344자로 한 자 모자라 그 문단을 한 문장 늘렸다.

## 평가 케이스: 소장·DEEP 시나리오

| 필드 | 값 |
| --- | --- |
| `caseId` | `case-book-097` |
| `purpose` | 이 책을 소장하고 있다. 한 주가 그냥 지나가 버려서 주말마다 짧게 돌아보려고 하는데, 어떤 질문을 어떤 순서로 두고 몇 주쯤 쌓아야 무언가 보이는지 처음부터 끝까지 익히고 싶다. 회고가 해롭게 되는 경우까지는 지금 필요 없다 |
| `owned` / `maxAdditionalInk` / `depth` | `true` / `null` / `DEEP` |
| `requiredConcepts` | 회고의 부재, 회고 질문 세트, 사실 질문, 판단 질문, 이월 질문, 회고의 최소 형식, 패턴 인식 |
| `helpfulConcepts` | 회고의 마찰, 회고 대상, 기억의 편향, 질문의 고정 |
| `referencePageNumbers` | 2, 4, 6, 8, 12, 14~21, 28, 29 |
| `irrelevantPageNumbers` | 43~48(6장 전체) — 목적문이 회고가 해롭게 되는 경우는 지금 필요 없다고 밝힌 부분이다. 절 단위로 넣어 짝 페이지를 쪼개지 않는다 |
| `allowedAlternativePageNumbers` | 23, 31, 33 |

정답 경로는 2장의 세 묶음(사실·판단·이월)과 3.1(최소 형식), 4.1(패턴 인식)을 씨앗으로 잡은 선수 폐쇄이고
정확히 열다섯 페이지라 DEEP 상한을 남김없이 쓴다. 질문 세트를 만들고(2장), 짧게 반복하고(3.1), 쌓인 것을
보는(4.1) 세 단계가 모두 필요한 목적이라 이 책에서 가장 긴 경로가 나온다.

## 재현 조건

1. `python3 build097.py` — 원고와 조각 생성 (PDF SHA 없이 실행하면 자리표시자를 넣는다)
2. `python3 figures097.py pdfbuild097` — 도표 4개 SVG 생성
3. Chrome Headless로 각 SVG를 794×1123 PNG로 렌더링
4. `python3 build_pdf_generic.py 97 9,13,29,39 pdfbuild097` — 조판 HTML 생성
5. Chrome Headless `--print-to-pdf`로 PDF 출력, `pdfcheck.py`로 구성 확인
6. PDF를 `fixtures/content/ai-route-v2/pdfs/`에 두고 SHA-256을 인자로 `build097.py` 재실행
7. `merge_fragments.py 97`로 정본에 병합

## 검수

- 인물 이름은 1.1(도입 장면)과 5장(사례 장)에만 두고, 개념을 설명하는 나머지 장에서는 일반 진술로
  바꿨다. 가상 인물의 습관으로 포장된 지침은 이름을 빼도 내용이 그대로여서 이름이 하는 일이 없다.
- 인물 이름 하나가 동사 활용형 '지운다·지운 것'과 겹쳐 읽혀 다림으로 바꿨다.
- 네 도표를 PNG로 렌더링해 눈으로 확인했다. p39는 초안에서 왼쪽 스무 줄이 아래 안내문과 겹쳐 줄 간격을
  줄였다.
- 공개 가이드 주제와 비공개 분석 텍스트를 서로 다른 문장으로 적었고, 주제문에 숫자를 쓰지 않았다.
- 본문·도표·평가 데이터에 실존 인물·단체가 등장하지 않는다.
- 회고가 자기 평가로 흐르는 위험을 1.5와 6.1 두 곳에서 다루고, 지속적인 심리적 부담은 형식을 고쳐 풀 문제가
  아니라고 6.1 두 번째 페이지에 명시했다.

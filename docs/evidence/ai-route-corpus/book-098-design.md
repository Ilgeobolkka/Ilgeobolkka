# book-098 「배운 것을 설명하는 연습」 설계

[자기계발 카테고리 계획](./self-help-category-plan.md)의 98번을 만든 근거다. 정책·검증 계약은
[AI 경로 콘텐츠 코퍼스](../../ai-route-content-corpus.md)를 따르고, 이 문서는 그 계약 안에서 내린
선택과 이유만 적는다. 앞 권은 [book-097](./book-097-design.md)이다.

## 대상 도서

- `bookId` 98, 카테고리 자기계발. 제목·저자·소개는 `src/main/resources/demo/books.json`의 기존 값을
  유지한다.
- 제목은 `ai-route-v2` manifest의 `books[].title`이 정본이며 이 문서의 제목과 같다.
- 실존 인물·단체를 옮기지 않는다. 무대는 가상의 「두바퀴 정비소」, 인물은 배우는 사람 현오와 가르치는
  사람 미주다. 091~097의 인물과 겹치지 않는다.

## 개념 범위

계획 문서가 정한 원리(배운 내용을 자신의 말로 설명해 이해의 착각을 발견하기)와 하위 개념(능동 회상,
자기 언어로 재구성, 안다는 착각, 설명 중 막히는 지점)을 그대로 따른다. 자기계발 열 권 가운데 **유일하게
학습과 이해 검증**을 다룬다.

- 097의 회고는 한 주의 경험을 되짚는 일이고 98은 지식의 이해 정도를 점검하는 일이라 대상이 다르다.
  97의 질문은 자기 경험을 묻고 98의 설명은 배운 내용을 꺼낸다.
- 096의 설명은 여러 사람 사이의 대화에서 남을 향하고, 98의 설명은 청자를 가정하되 목적이 자기 점검이다.
  1.5에서 청자를 정하는 이유를 용어를 풀어 말하게 만드는 장치로만 적었다.
- 094의 기록과 4.1의 막힘 목록이 닿는다. 94는 기록을 반복 가능한 행동으로 만드는 일이고 98의 목록은 한
  과목을 익히는 동안만 쓰는 도구다.
- 6장에서 이 방법이 닿지 않는 세 영역(선행 지식, 몸으로 익히는 기술, 외워야 하는 값)을 명시했다.

## 장 구성 (50페이지, 목차 1 + 본문 49)

```
1장 안다고 느끼는 순간 p2–11   PREREQUISITE  안다는 착각·재인과 회상·설명 검증·막힘의 신호·청자 설정
2장 떠올려 보기        p12–19  CORE          능동 회상·회상 순서·결손 표시·대조
3장 내 말로 바꾸기     p20–27  CORE          자기 언어·압축·비유·비유의 한계
4장 막히는 자리 다루기 p28–35  CORE          막힘 기록·막힘 분류·재학습·이해의 확인
5장 어떤 연습          p36–42  EXAMPLE       사례 관찰·적용·반복 관찰·정착
6장 설명이 도움이 되지 않을 때 p43–48 COUNTERPOINT 선행 지식 부족·절차적 기술·암송
7장 결론: 막히는 자리가 배울 자리다 p49–50 CONCLUSION 종합
```

1장이 익숙함과 인출의 차이를 세우고, 2장이 자료를 치우고 떠올리는 절차, 3장이 자기 언어로 바꾸는 검증,
4장이 막힌 자리의 처리를 다룬다. 5장은 세 번의 설명으로 한 절차를 익히는 과정을 따라간다.

이미지 4개: p5(느낌과 실제), p13(네 단계), p25(겹치는 만큼만), p39(삼 분 동안 막힌 세 곳). 형식을 세로
막대 둘·절차 띠·겹친 두 원·단계별 표시 기록으로 잡았다. 생성 스크립트는
[`figures098.py`](./tools/figures098.py)다.

중복 그룹 1개: `fluency-is-not-knowing` = [2, 49]. "읽을 때 드는 알겠다는 느낌은 이해가 아니라
익숙함"이라는 명제를 1.1에서 세우고 7.1에서 재진술한다. 재진술 페이지(49)에는 선수를 두지 않았다.
091~097과 같은 처리다.

## 선수 관계 설계

1.1(안다는 착각)을 뿌리로 두고 1.2(재인과 회상)와 1.3(설명 검증)이 갈라진다. 2장은 1.2에서, 3장은
1.5(청자 설정)에서, 4장은 1.4(막힘의 신호)에서, 5장은 1.3에서 갈라진다.

- 어느 후보 페이지도 선수 폐쇄가 7페이지를 넘지 않는다.
- 폐쇄 5페이지 이하인 후보 페이지가 일곱 개 장을 모두 덮는다 (기준 3개 장).
- 후보 페이지 49개 전부가 폐쇄 15페이지 이하다 (기준 75%).

## 검증

`corpus_lib.validate_book()` → `validate_fragment.py` → `merge_fragments.py` → `validate_manifest.py`를
차례로 통과했다.

- 50페이지(48~72), 7개 장(최소 6), 내용 역할 5종 모두 사용
- `TEXT` 본문 45페이지가 345~419자(평균 377자, 합계 16,953자)로 전량 345자 이상
- `FRONT_MATTER`(목차)와 `aiRouteCandidatePage=false`가 정확히 일치
- 선수 관계가 후보 제외 페이지를 가리키지 않음, 위상 정렬로 50페이지 전체 방문
- PDF 페이지 50개, 텍스트 46개, 이미지 4개(p5,13,25,39) — `pdfcheck.py`로 확인
- PDF 실제 SHA-256이 manifest의 `pdfSha256`과 일치

초고는 250~390자로 마흔다섯 페이지 가운데 마흔넷이 하한에 미달해 `EXTRA` 문단으로 채웠고, 그 뒤에도 여덟
페이지가 모자라 해당 문단에 한 문장씩 더 붙였다.

## 평가 케이스: 비소장·예산 10 시나리오

| 필드 | 값 |
| --- | --- |
| `caseId` | `case-book-098` |
| `purpose` | 강의를 듣고 나면 다 이해한 것 같은데 며칠 뒤에 물어보면 답을 못 한다. 잉크를 열 정도만 써서 배운 것을 덮고 떠올려 내 말로 설명해 보는 방법을 익히고 싶다. 설명이 도움이 되지 않는 경우까지는 지금 필요 없다 |
| `owned` / `maxAdditionalInk` / `depth` | `false` / `10` / `null` |
| `requiredConcepts` | 안다는 착각, 재인과 회상, 능동 회상, 결손 표시, 자기 언어 |
| `helpfulConcepts` | 설명 검증, 청자 설정, 회상 순서, 대조 |
| `referencePageNumbers` | 2, 4, 6, 10, 12, 13, 16, 17, 20, 21 |
| `irrelevantPageNumbers` | 43~48(6장 전체) — 목적문이 설명이 도움이 되지 않는 경우는 지금 필요 없다고 밝힌 부분이다 |
| `allowedAlternativePageNumbers` | 15, 19, 23 |

정답 경로는 2.1(능동 회상)·2.3(결손 표시)·3.1(자기 언어)의 두 번째 페이지를 씨앗으로 잡은 선수 폐쇄이고
정확히 열 페이지라 예산을 남김없이 쓴다. 떠올리는 갈래(1.2 → 2장)와 말로 바꾸는 갈래(1.3 → 1.5 → 3장)가
1.1에서 만나는 구조라 목적문의 "덮고 떠올려 내 말로 설명한다"를 한 경로에 담는다.

## 재현 조건

1. `python3 build098.py` — 원고와 조각 생성 (PDF SHA 없이 실행하면 자리표시자를 넣는다)
2. `python3 figures098.py pdfbuild098` — 도표 4개 SVG 생성
3. Chrome Headless로 각 SVG를 794×1123 PNG로 렌더링
4. `python3 build_pdf_generic.py 98 5,13,25,39 pdfbuild098` — 조판 HTML 생성
5. Chrome Headless `--print-to-pdf`로 PDF 출력, `pdfcheck.py`로 구성 확인
6. PDF를 `fixtures/content/ai-route-v2/pdfs/`에 두고 SHA-256을 인자로 `build098.py` 재실행
7. `merge_fragments.py 98`로 정본에 병합

## 검수

- 인물 이름은 1.1(도입 장면)과 5장(사례 장)에만 두고, 개념을 설명하는 나머지 장에서는 일반 진술로
  바꿨다. 가상 인물의 습관으로 포장된 지침은 이름을 빼도 내용이 그대로여서 이름이 하는 일이 없다.
- 네 도표를 PNG로 렌더링해 눈으로 확인했다.
- 공개 가이드 주제와 비공개 분석 텍스트를 서로 다른 문장으로 적었고, 주제문에 숫자를 쓰지 않았다.
- 본문·도표·평가 데이터에 실존 인물·단체·제품이 등장하지 않는다. 정비 절차도 실제 차종이나 규격을 적지
  않고 단계 번호로만 다뤘다.
- 학습 효과에 관한 수치를 연구 결과로 제시하지 않고 모두 가상 인물의 기록으로 적었다.

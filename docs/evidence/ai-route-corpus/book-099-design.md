# book-099 「작은 목표의 측정법」 설계

[자기계발 카테고리 계획](./self-help-category-plan.md)의 99번을 만든 근거다. 정책·검증 계약은
[AI 경로 콘텐츠 코퍼스](../../ai-route-content-corpus.md)를 따르고, 이 문서는 그 계약 안에서 내린
선택과 이유만 적는다. 앞 권은 [book-098](./book-098-design.md)이다.

## 대상 도서

- `bookId` 99, 카테고리 자기계발. 제목·저자·소개는 `src/main/resources/demo/books.json`의 기존 값을
  유지한다.
- 제목은 `ai-route-v2` manifest의 `books[].title`이 정본이며 이 문서의 제목과 같다.
- 실존 인물·단체를 옮기지 않는다. 무대는 가상의 동네 서점 「모서리 책방」, 인물은 도경과 규리다.
  091~098의 인물과 겹치지 않는다.

## 개념 범위

계획 문서가 정한 원리(실행 결과를 확인할 수 있도록 목표를 측정 가능하게 만들기)와 하위 개념(지표 설계,
목표의 구체화, 측정이 목표를 왜곡하는 함정)을 그대로 따른다.

- 091의 분할은 할 일의 크기를 정하는 실행 전 설계이고, 99는 한 일의 결과를 어떻게 확인하는가라는 실행 후의
  문제다. 99에는 일을 쪼개는 방법이 한 자리도 없고, 2.4의 자르기도 목표 수치를 주 단위로 나누는 일이다.
- 097은 회고에 숫자 항목을 하나만 두라고 하고 셋을 넘기면 집계가 된다고 적었다. 99는 그 자리를 이어받아
  지표를 설계하는 방법을 다루며, 회고 형식이나 주간 질문은 다루지 않는다.
- 095의 완성 기준은 착수를 막는 머릿속 기준이고, 99의 성공 기준은 끝난 뒤의 판정선이다. 시점이 다르다.
- 6장에서 측정이 목표를 밀어내는 세 경우를 두고, 6.3에서는 남이 정한 지표를 이 책의 범위 밖으로 밝혔다.

## 장 구성 (50페이지, 목차 1 + 본문 49)

```
1장 해냈는지 알 수 없는 목표 p2–11   PREREQUISITE  모호한 목표·지표·측정 대상·측정의 효용·비측정 영역
2장 목표를 구체화하기        p12–19  CORE          목표의 구체화·기한·성공 기준·작은 목표
3장 지표 고르기              p20–27  CORE          결과 지표와 과정 지표·단일 지표·측정 비용·지표 갱신
4장 재고 나서                p28–35  CORE          확인 주기·해석·정체·행동 연결
5장 어떤 목표                p36–42  EXAMPLE       사례 관찰·지표 적용·변화 관찰·갱신 사례
6장 측정이 목표를 밀어낼 때  p43–48  COUNTERPOINT  지표 왜곡·측정 불가·외부 지표
7장 결론: 재는 것은 목표가 아니다 p49–50 CONCLUSION 종합
```

1장이 모호한 목표의 문제와 지표 개념을 세우고, 2장이 목표 쪽을, 3장이 지표 쪽을 손본다. 4장은 잰 뒤에
숫자를 읽고 다음 행동으로 잇는 절차다. 5장은 반년 동안 확인하지 못한 목표를 두 달 만에 판정 가능한
목표로 바꾼 과정을 따라간다.

이미지 4개: p7(같은 목표, 세 가지 자), p17(선을 미리 긋는다), p29(얼마나 자주 볼 것인가), p39(여덟 주).
형식을 눈금자 셋·수직선 구간·확인 간격 세 줄·주별 꺾은선으로 잡았다. 생성 스크립트는
[`figures099.py`](./tools/figures099.py)다.

중복 그룹 1개: `measure-to-decide` = [2, 49]. "재는 것은 해냈는지 알아 다음을 정하려는 것"이라는 명제를
1.1에서 세우고 7.1에서 재진술한다. 재진술 페이지(49)에는 선수를 두지 않았다. 091~098과 같은 처리다.

## 선수 관계 설계

1.1(모호한 목표)을 뿌리로 두고 1.2(지표)와 2.1(목표의 구체화)이 갈라진다. 3장은 1.2에서, 4장은 1.4(측정의
효용)에서, 5장은 2.1에서 갈라진다. 2장을 1.2를 거치지 않고 1.1에 바로 붙인 것은 목표를 다시 적는 일이
지표 개념 없이도 할 수 있고, 그래야 예산 5 사례가 성립하기 때문이다.

- 어느 후보 페이지도 선수 폐쇄가 7페이지를 넘지 않는다.
- 폐쇄 5페이지 이하인 후보 페이지가 일곱 개 장을 모두 덮는다 (기준 3개 장).
- 후보 페이지 49개 전부가 폐쇄 15페이지 이하다 (기준 75%).

## 검증

`corpus_lib.validate_book()` → `validate_fragment.py` → `merge_fragments.py` → `validate_manifest.py`를
차례로 통과했다.

- 50페이지(48~72), 7개 장(최소 6), 내용 역할 5종 모두 사용
- `TEXT` 본문 45페이지가 345~397자(평균 368자, 합계 16,543자)로 전량 345자 이상
- `FRONT_MATTER`(목차)와 `aiRouteCandidatePage=false`가 정확히 일치
- 선수 관계가 후보 제외 페이지를 가리키지 않음, 위상 정렬로 50페이지 전체 방문
- PDF 페이지 50개, 텍스트 46개, 이미지 4개(p7,17,29,39) — `pdfcheck.py`로 확인
- PDF 실제 SHA-256이 manifest의 `pdfSha256`과 일치

초고는 259~359자로 마흔다섯 페이지 가운데 마흔넷이 하한에 미달해 `EXTRA` 문단으로 채웠고, 그 뒤에도 열여덟
페이지가 모자라 해당 문단에 한 문장씩 더 붙였다.

## 평가 케이스: 비소장·예산 5 시나리오

| 필드 | 값 |
| --- | --- |
| `caseId` | `case-book-099` |
| `purpose` | 목표를 세우기는 하는데 해냈는지 아닌지 늘 애매하다. 잉크를 조금만 써서 목표를 셀 수 있게 적고 어디까지가 성공인지 정하는 방법까지만 알고 싶다. 재고 나서 숫자를 읽는 단계는 지금 필요 없다 |
| `owned` / `maxAdditionalInk` / `depth` | `false` / `5` / `null` |
| `requiredConcepts` | 모호한 목표, 목표의 구체화, 성공 기준 |
| `helpfulConcepts` | 지표, 기한, 작은 목표, 측정 대상 |
| `referencePageNumbers` | 2, 12, 13, 16, 17 |
| `irrelevantPageNumbers` | 28~35(4장 전체) — 목적문이 재고 나서 숫자를 읽는 단계는 필요 없다고 밝힌 부분이다 |
| `allowedAlternativePageNumbers` | 15, 19, 21 |

정답 경로는 2.1(목표의 구체화)과 2.3(성공 기준)의 두 번째 페이지를 씨앗으로 잡은 선수 폐쇄이고 정확히 다섯
페이지라 예산을 남김없이 쓴다. 1.1 → 2.1 → 2.3으로 이어지는 짧은 사슬이 목적문의 "셀 수 있게 적고 어디까지가
성공인지 정한다"에 그대로 대응한다.

## 재현 조건

1. `python3 build099.py` — 원고와 조각 생성 (PDF SHA 없이 실행하면 자리표시자를 넣는다)
2. `python3 figures099.py pdfbuild099` — 도표 4개 SVG 생성
3. Chrome Headless로 각 SVG를 794×1123 PNG로 렌더링
4. `python3 build_pdf_generic.py 99 7,17,29,39 pdfbuild099` — 조판 HTML 생성
5. Chrome Headless `--print-to-pdf`로 PDF 출력, `pdfcheck.py`로 구성 확인
6. PDF를 `fixtures/content/ai-route-v2/pdfs/`에 두고 SHA-256을 인자로 `build099.py` 재실행
7. `merge_fragments.py 99`로 정본에 병합

## 검수

- 인물 이름은 1.1(도입 장면)과 5장(사례 장)에만 두고, 개념을 설명하는 나머지 장에서는 일반 진술로
  바꿨다. 가상 인물의 습관으로 포장된 지침은 이름을 빼도 내용이 그대로여서 이름이 하는 일이 없다.
- 인물 이름 '이든'이 연결어미 '-이든'과 겹쳐(달력이든, 어느 쪽이든) 도경으로 바꿨다. 도표 p7의
  이름 표시도 '여기서 고른 자'로 바꿔 이름 없이 읽히게 했다.
- 네 도표를 PNG로 렌더링해 눈으로 확인했다. p7은 목표 상자에서 세 자로 갈라지는 선이 첫 자에만 닿아 왼쪽에
  세로 줄기를 두고 셋으로 갈랐고, p17은 결과 표시가 구간 이름과 겹쳐 표시를 위로 올렸다.
- 공개 가이드 주제와 비공개 분석 텍스트를 서로 다른 문장으로 적었고, 주제문에 숫자를 쓰지 않았다.
- 본문·도표·평가 데이터에 실존 인물·단체가 등장하지 않는다.
- 측정을 권하는 책이 되지 않도록 1.5와 6장에 재지 않는 목표를 다루는 자리를 넉넉히 두고, 결론에서도 자는
  목표를 가리킬 뿐이라고 밝혔다.

# book-100 「다음 달의 나에게 보내는 계획」 설계

[자기계발 카테고리 계획](./self-help-category-plan.md)의 100번을 만든 근거다. 이 권으로 자기계발
카테고리 10권이 모두 채워졌다. 정책·검증 계약은 [AI 경로 콘텐츠 코퍼스](../../ai-route-content-corpus.md)를
따르고, 이 문서는 그 계약 안에서 내린 선택과 이유만 적는다. 앞 권은 [book-099](./book-099-design.md)다.

## 대상 도서

- `bookId` 100, 카테고리 자기계발. 제목·저자·소개는 `src/main/resources/demo/books.json`의 기존 값을
  유지한다.
- 제목은 `ai-route-v2` manifest의 `books[].title`이 정본이며 이 문서의 제목과 같다.
- 실존 인물·단체를 옮기지 않는다. 무대는 가상의 지역 라디오 제작팀 「밤 열한 시 방송실」, 인물은 해든과
  노아다. 091~099의 인물과 겹치지 않는다.

## 개념 범위

계획 문서가 정한 원리(계획과 회고를 한 순환으로 연결해 다음 계획에 반영하기)와 하위 개념(미래의 나에게
쓰는 계획, 계획-실행-회고 순환, 다음 달 계획 갱신)을 그대로 따른다. 계획 문서가 이 권을 "다른 아홉 권의
원리를 조합해 쓰는 결말적 위치이지만 새 개념을 중심으로 삼는다"고 정한 대로, **앞의 아홉 권을 요약하지
않고** 순환과 미래의 나라는 새 개념만 다룬다.

- 097의 주간 회고와 단위가 다르다. 97은 한 주를 되짚는 형식이고 100은 한 달 단위로 회고와 계획을 잇는
  자리 자체가 원리다. 100에는 회고 질문 세트가 없고, 4장의 회고도 편지를 쓰기 위한 십 분이다.
- 091의 하루 설계와 층위가 다르다. 91은 하루 안의 배치이고 100은 달과 달 사이의 전달이다.
- 099의 지표와도 겹치지 않는다. 100은 무엇을 잴지 다루지 않고 무엇을 남겨 넘길지만 다룬다.
- 6장에서 순환이 성립하지 않는 세 경우를 두고, 6.3에서 이 방법이 필요 없는 시기도 밝혔다.

## 장 구성 (50페이지, 목차 1 + 본문 49)

```
1장 계획이 끊기는 자리 p2–11   PREREQUISITE  계획의 단절·분리된 두 활동·미래의 나·월 단위·계획-실행-회고 순환
2장 다음 달에게 쓰기   p12–19  CORE          계획 편지·전달 항목·전제 기록·단일 중점
3장 한 달을 지내기     p20–27  CORE          개봉 시점·중간 점검·계획 이탈·실행 기록
4장 돌아보고 잇기      p28–35  CORE          월말 회고·전제 검증·이월 연결·순환 점검
5장 어떤 열두 달       p36–42  EXAMPLE       첫 시도·초기 관찰·누적 관찰·중단과 재개
6장 순환이 굴러가지 않을 때 p43–48 COUNTERPOINT 주기 불일치·형식 과잉·불확실한 시기
7장 결론: 한 바퀴가 다음 바퀴를 만든다 p49–50 CONCLUSION 종합
```

1장이 계획과 회고가 끊기는 구조와 미래의 나라는 개념을 세우고, 2장이 편지를 쓰는 자리, 3장이 한 달을
지내는 동안, 4장이 달을 닫고 다음 편지로 잇는 자리를 다룬다. 5장은 열두 달을 돌린 기록이고 두 달의 공백도
그대로 담았다.

이미지 4개: p7(두 사람이 아는 것), p15(편지에 넣는 것), p31(어디서 갈라졌나), p41(열두 바퀴). 형식을 두 상자
대비·봉투와 카드·전제 사슬·열두 칸 원으로 잡았다. 생성 스크립트는 [`figures100.py`](./tools/figures100.py)다.

중복 그룹 1개: `one-turn-makes-the-next` = [2, 49]. "달마다 새로 세우면 지난달의 판단이 넘어오지 않는다"는
명제를 1.1에서 세우고 7.1에서 재진술한다. 재진술 페이지(49)에는 선수를 두지 않았다. 091~099와 같은 처리다.

## 선수 관계 설계

1.1(계획의 단절)을 뿌리로 두고 1.2(분리된 두 활동)·1.3(미래의 나)·1.4(월 단위)가 갈라진다. 2장과 5장은
1.3에서, 3장은 2.1(편지의 형식)에서, 4장은 1.5(순환)에서 갈라진다. 3장을 2.1에 붙인 것은 한 달을 지내는
방법이 편지가 있다는 것을 전제하기 때문이다.

- 어느 후보 페이지도 선수 폐쇄가 7페이지를 넘지 않는다.
- 폐쇄 5페이지 이하인 후보 페이지가 일곱 개 장을 모두 덮는다 (기준 3개 장).
- 후보 페이지 49개 전부가 폐쇄 15페이지 이하다 (기준 75%).

## 검증

`corpus_lib.validate_book()` → `validate_fragment.py` → `merge_fragments.py` → `validate_manifest.py`를
차례로 통과했다. 카테고리 완성 시점이라 `selftest.py`도 함께 돌려 검증 도구가 여전히 깨진 입력을 잡는지
확인했다.

- 50페이지(48~72), 7개 장(최소 6), 내용 역할 5종 모두 사용
- `TEXT` 본문 45페이지가 346~394자(평균 368자, 합계 16,574자)로 전량 345자 이상
- `FRONT_MATTER`(목차)와 `aiRouteCandidatePage=false`가 정확히 일치
- 선수 관계가 후보 제외 페이지를 가리키지 않음, 위상 정렬로 50페이지 전체 방문
- PDF 페이지 50개, 텍스트 46개, 이미지 4개(p7,15,31,41) — `pdfcheck.py`로 확인
- PDF 실제 SHA-256이 manifest의 `pdfSha256`과 일치

초고는 246~361자로 마흔다섯 페이지 가운데 마흔셋이 하한에 미달해 `EXTRA` 문단으로 채웠고, 그 뒤에도 스물두
페이지가 모자라 해당 문단에 한 문장씩 더 붙였다.

## 평가 케이스: 소장·QUICK 시나리오

| 필드 | 값 |
| --- | --- |
| `caseId` | `case-book-100` |
| `purpose` | 이 책을 소장하고 있다. 다음 달의 나에게 무엇을 남겨야 이번 달의 판단이 이어지는지 그 형식만 빠르게 보고 싶다. 달을 닫고 회고로 잇는 단계까지는 아직 필요 없다 |
| `owned` / `maxAdditionalInk` / `depth` | `true` / `null` / `QUICK` |
| `requiredConcepts` | 계획의 단절, 미래의 나, 계획 편지, 전달 항목 |
| `helpfulConcepts` | 분리된 두 활동, 계획-실행-회고 순환, 전제 기록, 단일 중점 |
| `referencePageNumbers` | 2, 6, 12, 14, 15 |
| `irrelevantPageNumbers` | 28~35(4장 전체) — 목적문이 달을 닫고 회고로 잇는 단계는 아직 필요 없다고 밝힌 부분이다 |
| `allowedAlternativePageNumbers` | 13, 17, 19 |

정답 경로는 2.2(전달 항목)의 두 번째 페이지 하나를 씨앗으로 잡은 선수 폐쇄이고 정확히 다섯 페이지라 QUICK
상한을 남김없이 쓴다. 1.1 → 1.3 → 2.1 → 2.2로 이어지는 사슬이 목적문의 "무엇을 남겨야 이어지는가"에 그대로
대응한다.

## 재현 조건

1. `python3 build100.py` — 원고와 조각 생성 (PDF SHA 없이 실행하면 자리표시자를 넣는다)
2. `python3 figures100.py pdfbuild100` — 도표 4개 SVG 생성
3. Chrome Headless로 각 SVG를 794×1123 PNG로 렌더링
4. `python3 build_pdf_generic.py 100 7,15,31,41 pdfbuild100` — 조판 HTML 생성
5. Chrome Headless `--print-to-pdf`로 PDF 출력, `pdfcheck.py`로 구성 확인
6. PDF를 `fixtures/content/ai-route-v2/pdfs/`에 두고 SHA-256을 인자로 `build100.py` 재실행
7. `merge_fragments.py 100`으로 정본에 병합

## 검수

- 인물 이름은 1.1(도입 장면)과 5장(사례 장)에만 두고, 개념을 설명하는 나머지 장에서는 일반 진술로
  바꿨다. 가상 인물의 습관으로 포장된 지침은 이름을 빼도 내용이 그대로여서 이름이 하는 일이 없다.
- 네 도표를 PNG로 렌더링해 눈으로 확인했다. p41은 아래쪽 달 이름이 범례와 겹쳐 원을 위로 올리고 범례를
  내렸다.
- 공개 가이드 주제와 비공개 분석 텍스트를 서로 다른 문장으로 적었고, 주제문에 숫자를 쓰지 않았다.
- 본문·도표·평가 데이터에 실존 인물·단체·방송 프로그램이 등장하지 않는다.

## 자기계발 카테고리 완성

100번으로 자기계발 10권이 모두 채워졌다. 경제·예술·과학에 이어 네 번째로 완성한 카테고리다.

| bookId | 제목 | 페이지 | 평가 시나리오 |
| --- | --- | --- | --- |
| 91 | 하루를 작게 나누는 기술 | 51 | 비소장 예산 0 |
| 92 | 미루는 마음과 협상하기 | 50 | 비소장 예산 5 |
| 93 | 집중을 위한 빈칸 만들기 | 50 | 비소장 예산 10 |
| 94 | 기록이 습관이 되는 순간 | 50 | 비소장 예산 15 |
| 95 | 완벽하지 않은 시작의 힘 | 50 | 소장 QUICK |
| 96 | 질문으로 여는 회의 | 50 | 소장 BALANCED |
| 97 | 일주일을 돌아보는 열 문장 | 50 | 소장 DEEP |
| 98 | 배운 것을 설명하는 연습 | 50 | 비소장 예산 10 |
| 99 | 작은 목표의 측정법 | 50 | 비소장 예산 5 |
| **100** | **다음 달의 나에게 보내는 계획** | **50** | **소장 QUICK** |

일곱 시나리오를 계획 문서가 배정한 대로 모두 채웠다. 인물과 무대는 열 권이 모두 다르고, 열 권 어디에도
같은 인물이 다시 나오지 않는다.

카테고리 안에서 경계를 다투는 조합이 다섯 있었다. 91과 99는 실행 전 설계와 실행 후 확인으로, 92와 95는
미루는 이유로서의 완벽주의와 착수 형식으로서의 완벽주의로, 94와 97은 기록을 만드는 시점과 되짚는 시점으로,
96과 97은 남에게 던지는 질문과 자기에게 던지는 질문으로, 97과 100은 주 단위 회고와 달 사이의 전달로 나눴다.
각 권의 「개념 범위」 절에 이 선을 어디에 그었는지 적었다.

계획 문서가 미리 이 경계를 적어 둔 것이 크게 도움이 됐다. 다만 계획이 정한 것은 원리까지이고, 본문에서 어느
자리까지 다룰지는 쓰면서 정해야 했다. 92의 완벽주의를 미루는 이유로만 두기로 한 것과, 97의 숫자 항목을 하나로
제한해 99의 자리를 남긴 것이 그런 결정이다.

열 권 모두 6장을 반례 장으로 두고 그 방법이 통하지 않거나 해로운 경우를 세 절씩 두었다. 자기계발 카테고리는
방법을 권하는 글이 되기 쉬워서, 범위를 명시하는 자리를 권마다 고정한 것이 이 카테고리의 공통 장치다.

# 경제 카테고리(bookId 41~50) 개념 배분 계획

SCRUM-485 90권 확장의 카테고리별 개념 배분 첫 사례입니다. 정본이 요구하는 "같은 개념을 표현만 바꿔
반복하지 않고" 조건을 카테고리 단위로 지키기 위해, 10권 착수 전에 각 권의 핵심 개념 범위를 먼저
고정합니다. 저자·소개는 `src/main/resources/demo/books.json`의 기존 값을 유지하고, 제목은 카테고리 톤에
맞게 갱신한 같은 파일의 값을 따릅니다.

## 이미 완료: 47번

가격 형성 · 수요 · 공급 · 균형 · 탄력성 · 가격 규제 · 시장실패(외부효과·공공재·정보비대칭)를 다룹니다.
설계 근거는 [`book-047-design.md`](./book-047-design.md).

## 카테고리 내부 선수 관계

권 사이의 개념 의존은 만들지 않습니다. 정본은 선수 관계를 "같은 도서·콘텐츠 버전 안"으로만
허용하므로, 카테고리 내 다른 책을 선수로 지정할 수 없습니다. 대신 자연스러운 학습 순서를 권
배치로만 반영합니다.

```
41 (교환의 이익) → 43 (개별 사업체 회계) → 42 (거래의 신뢰 문제)
44 (후생) → 47 (가격이론, 완료) → 48 (자원의 유형)
45 (화폐) → 46 (재정) → 49 (성장)
50 (데이터 해석)은 독립적으로 배치
```

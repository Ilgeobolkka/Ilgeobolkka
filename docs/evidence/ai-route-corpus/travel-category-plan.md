# 여행 카테고리(bookId 81~90) 개념 배분 계획

SCRUM-485 90권 확장의 여행 카테고리입니다. [`economics-category-plan.md`](./economics-category-plan.md)와
같은 형식으로, 10권 착수 전에 각 권의 관찰 주제와 가상 지명을 먼저 고정합니다. 제목·저자·소개는
`src/main/resources/demo/books.json`의 기존 값을 유지합니다.

모든 도서는 실존 국가·도시·지명을 다루지 않습니다. 각 권마다 가상의 지명을 새로 만들어 그 책
안에서 일관되게 씁니다.

## 평가 시나리오 배분 확인

일곱 시나리오(비소장 예산 0·5·10·15, 소장 QUICK·BALANCED·DEEP) 모두 위 표에서 최소 한 번씩
나옵니다. 10권이므로 비소장 예산 10(83, 88)과 소장 QUICK(85, 89)이 두 번씩 배정됩니다.

## 카테고리 내부 선수 관계

정본은 선수 관계를 "같은 도서·콘텐츠 버전 안"으로만 허용하므로 카테고리 내 다른 책을 선수로
지정하지 않습니다. 자연스러운 여정 순서(이동 수단 → 도시/마을 정주 → 자연 지형 → 야간)만 아래처럼
제작 순서에 반영합니다.

```
81 (배) → 82 (기차) → 85 (해안도로) → 89 (도시 순환선)   ─ 이동 수단 계열
83 (도시 시장) → 88 (도시 골목)                           ─ 도시 정주 계열
86 (항구 마을) → 87 (고원 마을)                           ─ 마을 정주 계열
84 (숲) → 90 (사막)                                        ─ 자연 지형·야간 계열
```

## 제작 순서

81 → 82 → 83 → 84 → 85 → 86 → 87 → 88 → 89 → 90

## 제작 현황

81번을 만들었다([설계](./book-081-design.md)). 계획이 배정한 비소장·예산 0을 그대로 썼고, 섬 이름은
계획에 적힌 넷에 그물섬·돌담섬·끝물섬을 더해 일곱으로 고정했다. 82~90번은 이 일곱 이름을 쓰지 않는다.

82번을 만들었다([설계](./book-082-design.md)). 계획이 배정한 비소장·예산 5를 그대로 썼고, 역 이름은
계획에 적힌 셋에 밀밭역·돌다리역을 더해 다섯으로 고정했다. 81과 겹치지 않게 시각을 미는 힘을 물때가
아니라 단선 교행으로 잡고, 결항 대신 지연을 3장에 두었다.

83번을 만들었다([설계](./book-083-design.md)). 계획이 배정한 비소장·예산 10을 그대로 썼다. 인물은
어시장 중매인 초하, 향신료골목의 무산, 헌옷마당의 도래다. 86(항구)과 겹치지 않게 조업과 귀항은 다루지
않고 시장 바닥에서 보이는 것만 적었다.

84번을 만들었다([설계](./book-084-design.md)). 계획이 배정한 비소장·예산 15를 그대로 썼고, 대여 없이
예산만으로 여는 유일한 사례다. 90(사막)과 겹치지 않게 젖은 지형과 막힌 시야만 다루고 밤하늘과 온도차는
남겨 두었다.

85번을 만들었다([설계](./book-085-design.md)). 계획이 배정한 소장·QUICK을 그대로 썼고, 다섯 페이지
상한에 맞추려고 1장에서 세 갈래를 곧장 벌렸다. 계획이 수단을 '자전거·차'로 열어 두어 자전거를 골랐고,
6.2에서 차로 지날 때 무엇이 달라지는지를 따로 적었다.

# 여행 카테고리(bookId 81~90) 개념 배분 계획

SCRUM-485 90권 확장의 여행 카테고리입니다. [`economics-category-plan.md`](./economics-category-plan.md)와
같은 형식으로, 10권 착수 전에 각 권의 관찰 주제와 가상 지명을 먼저 고정합니다. 제목·저자·소개는
`src/main/resources/demo/books.json`의 기존 값을 유지합니다.

모든 도서는 실존 국가·도시·지명을 다루지 않습니다. 각 권마다 가상의 지명을 새로 만들어 그 책
안에서 일관되게 씁니다.

## 평가 시나리오 배분 확인

일곱 시나리오(비소장 예산 0·5·10·15, 소장 QUICK·BALANCED·DEEP) 모두 위 표에서 최소 한 번씩
나옵니다. 10권이므로 비소장 예산 10(83, 88), 소장 QUICK(85, 89), 소장 BALANCED(86, 90)가 두 번씩
배정됩니다.

## 카테고리 내부 선수 관계

정본은 선수 관계를 "같은 도서·콘텐츠 버전 안"으로만 허용하므로 카테고리 내 다른 책을 선수로
지정하지 않습니다. 자연스러운 여정 순서(이동 수단 → 도시/마을 정주 → 자연 지형 → 야간)만 아래처럼
제작 순서에 반영합니다.

```
81 (배) → 82 (기차) → 85 (해안도로) → 89 (도시 순환선)   ─ 이동 수단 계열
83 (도시 시장) → 88 (도시 골목)                           ─ 도시 정주 계열
86 (항구 마을) → 87 (고원 마을)                           ─ 마을 정주 계열
84 (숲) → 90 (사막)                                        ─ 자연 지형·야간 계열
```

## 제작 순서

81 → 82 → 83 → 84 → 85 → 86 → 87 → 88 → 89 → 90

## 제작 현황

81번을 만들었다([설계](./book-081-design.md)). 계획이 배정한 비소장·예산 0을 그대로 썼고, 섬 이름은
계획에 적힌 넷에 그물섬·돌담섬·끝물섬을 더해 일곱으로 고정했다. 82~90번은 이 일곱 이름을 쓰지 않는다.

82번을 만들었다([설계](./book-082-design.md)). 계획이 배정한 비소장·예산 5를 그대로 썼고, 역 이름은
계획에 적힌 셋에 밀밭역·돌다리역을 더해 다섯으로 고정했다. 81과 겹치지 않게 시각을 미는 힘을 물때가
아니라 단선 교행으로 잡고, 결항 대신 지연을 3장에 두었다.

83번을 만들었다([설계](./book-083-design.md)). 계획이 배정한 비소장·예산 10을 그대로 썼다. 인물은
어시장 중매인 초하와 향신료골목의 하람이다. 86(항구)과 겹치지 않게 조업과 귀항은 다루지
않고 시장 바닥에서 보이는 것만 적었다.

84번을 만들었다([설계](./book-084-design.md)). 계획이 배정한 비소장·예산 15를 그대로 썼고, 대여 없이
예산만으로 여는 유일한 사례다. 90(사막)과 겹치지 않게 젖은 지형과 막힌 시야만 다루고 밤하늘과 온도차는
남겨 두었다.

85번을 만들었다([설계](./book-085-design.md)). 계획이 배정한 소장·QUICK을 그대로 썼고, 다섯 페이지
상한에 맞추려고 1장에서 세 갈래를 곧장 벌렸다. 계획이 수단을 '자전거·차'로 열어 두어 자전거를 골랐고,
6.2에서 차로 지날 때 무엇이 달라지는지를 따로 적었다.

86번을 만들었다([설계](./book-086-design.md)). 계획이 배정한 소장·BALANCED를 그대로 썼다. 83과
겹치지 않게 유통이 아니라 생산 쪽만 다루고, 화자가 배를 한 번도 타지 않게 했다. 4장 전체를 '일터를
구경하는 자리'에 쓴 것은 이 권에만 있는 축이다.

87번을 만들었다([설계](./book-087-design.md)). 계획이 배정한 소장·DEEP을 그대로 썼고, 2장과 3장을
한 줄기로 이어 열다섯 페이지짜리 경로를 만들었다. 다른 아홉 권이 사람과 물건의 이동을 다루는 것과 달리
이 권만 소식의 이동 속도를 다룬다. 49페이지로 다른 권보다 두 페이지 짧다.

88번을 만들었다([설계](./book-088-design.md)). 계획이 배정한 비소장·예산 10을 그대로 썼다. 83과
같은 도시 정주 계열이라 도시를 다르게 두고 단서도 냄새가 아니라 지형으로 잡았다. 비를 관찰 조건으로
쓴 것이 이 권에만 있는 축이고, 6.2에 맑은 날에는 무엇을 놓치는지를 적었다.

89번을 만들었다([설계](./book-089-design.md)). 계획이 배정한 소장·QUICK을 그대로 썼고, 다섯 페이지
상한에 맞춰 하루권 → 순환선 → 정거장 목록 → 내릴 곳 고르기의 한 줄기를 만들었다. 82와 같은 순환선이지만
단위가 하루라 잠자리와 결항이 나오지 않는다. 초고가 38페이지라 열 절에 두 번째 페이지를 채워 49페이지로
맞췄다.

90번을 만들었다([설계](./book-090-design.md)). 계획이 배정한 소장·BALANCED를 그대로 썼고, 낮 줄기와
밤 줄기를 나란히 두어 열 페이지짜리 경로를 만들었다. 84와 같은 도보 여행이지만 젖은 지형·막힌 시야가
아니라 마른 지형·열린 하늘을 다룬다. 하루가 둘로 끊긴다는 것이 이 권에만 있는 축이다. 지명은 계획에
적힌 재모래사막과 물빛마을 둘만 쓰고 새 이름을 더하지 않았다.

이로써 여행 카테고리 10권(81~90)을 모두 만들었다.

## 카테고리 마무리 검수 (10권 완성 후)

- 열 권의 페이지 수는 48~51이고 모두 7개 장이며 이미지가 권당 6페이지다. 81~86이 51페이지,
  87·89·90이 49페이지, 88이 48페이지다.
- 평가 시나리오는 계획표 그대로다. 예산 0(81)·5(82)·10(83, 88)·15(84), QUICK(85, 89),
  BALANCED(86, 90), DEEP(87)로 일곱 가지를 모두 채웠다. 정답 경로 길이는 상한을 남김없이 쓰거나
  (85·86·87·89·90) 예산과 정확히 맞물린다(81~84·88).
- 개념 이름을 열 권에 걸쳐 비교하면 겹치는 것은 목차뿐이다. 다만 84와 90은 여러 날을 걷는 기록이라
  절 이름(첫날·둘째 날·셋째 날 기록)이 같다. 개념은 권 안에서만 쓰이므로 충돌하지 않고, 두 권의
  지형과 판단 근거는 각 설계 문서에 갈라 적었다.
- 가상 지명은 권마다 새로 만들었고 다른 권의 이름을 다시 쓰지 않았다. 인물도 권마다 다르다.
- 겹칠 위험이 있던 짝은 설계 문서에 경계를 적어 두었다. 81↔82(배↔철도), 83↔86(유통↔생산),
  83↔88(냄새↔지형), 82↔89(장거리↔하루), 84↔90(젖은 지형↔마른 지형), 86↔87(항구↔고원),
  85↔89(자기 운전↔하루권 순환)이다.
- 82·83·88이 예산 0이 아닌데도 활성 대여를 두고 있어 `AiRouteEvaluationReaderTest`가 깨졌다. 정본
  「품질 평가 조건」은 활성 대여를 예산 0에만 허용한다. 세 권의 대여를 없애고 정답 경로를 예산과 같은
  길이(82는 5p, 83·88은 10p)로 줄였다. 파이썬 검사기가 이 규칙을 보지 않아 놓친 것이라
  `validate_fragment.py`와 `validate_manifest.py`에 검사를 더했다.
- 인물 이름을 줄였다. 한두 페이지에만 나오던 여덟(연화·단해·설재·도래·서린·온수·한별·도경)을 지우고
  역할 명사로 바꿨다. 이름은 여러 장에 걸쳐 다시 나올 때만 남긴다. 보통명사·실존 지명과 겹치던
  다섯(무산·노정·갈래·봉산·여울)은 하람·해든·예린·윤재·지완으로 바꿨다.
- 83·84의 PDF에서 넷째 도표가 원고보다 한 페이지 뒤(p30)에 찍혀 있었다. 조판 명령의 이미지 페이지를
  손으로 적었고 페이지가 밀린 뒤에도 그 숫자를 고치지 않아서다. 두 권을 다시 조판하고, `pdfcheck.py`에
  기대값을 원고에서 읽는 `--book` 방식을 더해 같은 실수를 검사기가 잡게 했다.
- 병합 후 `validate_manifest.py`와 `selftest.py`가 전체 통과했고, `./gradlew check --rerun-tasks`로
  적재 경로까지 확인했다.

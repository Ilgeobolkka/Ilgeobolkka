# Q01 평가 러너 시간 초과 — 43권 첫 실행

[Q01 평가 runner](../../implementation/ai-route/release/Q01-evaluation-runner.md) 담당자에게 넘깁니다.
43권 적재 뒤 평가를 두 번 돌렸고 두 번 다 `TIMEOUT`으로 중단됐습니다. 중단 케이스가 서로 달라 케이스
특성이 아니라 지연 편차입니다.

- 1차: 5건 완료 뒤 `case-book-025`에서 중단. 처리 시간은 bookId 23·22·21·24·11 순으로
  3,943 / 7,423 / 10,465 / 11,288 / 11,644ms입니다.
- 2차: 0건 완료, 첫 케이스 `case-book-011`에서 중단. 1차에서 11,644ms로 통과한 케이스입니다.
- 95백분위 11,644ms로 [PRD 기준](../../prd/ai-ink-route.md#품질과-출시-기준)의 10초를 이미 넘습니다.
  하드 리밋 `AiRouteGenerationCleanupService.GENERATION_TIME_LIMIT` 20초는 PRD의 「20초 초과 0건」과
  같은 값이라, 리밋에 걸리는 순간 출시 기준도 함께 깨집니다.
- `durationNanos`가 준비 구간을 포함해서 모델 지연과 후보 검색·프롬프트 조립을 이 값으로는 가를 수
  없습니다. 구간별 계측이 있으면 바로 갈립니다.

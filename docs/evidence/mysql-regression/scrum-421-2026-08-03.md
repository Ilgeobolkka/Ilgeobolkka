## 실행 조건

- 실행일: 2026-08-03 KST
- 데이터베이스: Compose `mysql:8.4`, `docker compose up -d --wait`의 healthy 상태
- 런타임: Java 21.0.11, Spring `test` 프로필
- 외부 결제: 실제 PortOne 채널 대신 테스트 결제 게이트웨이 사용
- 시간 경계: 고정·스크립트 `Clock`으로 `expiresAt - 1ms`와 정확한 `expiresAt` 검증

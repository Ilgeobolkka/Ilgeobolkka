# OpenAI API 데이터 보관 정책 확인 근거

> AI 잉크 경로의 사용자 안내와 콘텐츠 외부 전송 조건에 사용하는 공급자 정책을 확인한 기록입니다.

## 확인 조건

- 확인일: 2026-08-05 KST
- 대상 API: `/v1/embeddings`, `/v1/responses`
- 대상 경로 모델: GPT-5.6 계열
- 확인 방법: OpenAI 공식 개발자 문서의 데이터 제어와 프롬프트 캐시 보관 절을 대조

## 출처와 확인 내용

| 출처 | 확인 내용 |
| --- | --- |
| [Data controls in the OpenAI platform — Data retention controls for abuse monitoring](https://developers.openai.com/api/docs/guides/your-data#data-retention-controls-for-abuse-monitoring) | 기본 악용 모니터링 로그는 고객 콘텐츠를 포함할 수 있고 원칙적으로 최대 30일 보관됩니다. 법률상 요구되거나 OpenAI 서비스 또는 제3자를 위해 합리적으로 필요한 경우에는 더 오래 보관될 수 있습니다. Modified Abuse Monitoring과 Zero Data Retention은 사전 승인이 필요한 별도 제어입니다. |
| [Data controls in the OpenAI platform — `/v1/responses`](https://developers.openai.com/api/docs/guides/your-data#v1responses) | Responses API의 응답 애플리케이션 상태는 기본값 또는 `store=true`에서 30일 이상 보관될 수 있으므로 요청에 `store=false`를 사용합니다. 비-ZDR 요청의 프롬프트 캐시는 원문이 아닌 암호화된 key/value tensor를 GPU 로컬 스토리지에 저장할 수 있고 24시간 만료 뒤에는 보관하지 않습니다. |
| [Prompt caching — Prompt cache retention](https://developers.openai.com/api/docs/guides/prompt-caching#prompt-cache-retention) | GPT-5.6 계열의 `prompt_cache_options.ttl`은 최소 캐시 수명이며 저장 정책이나 최대 보관 기간을 정하지 않습니다. 확인 시점의 지원값과 기본값은 `30m`이고 캐시는 그보다 오래 유지될 수 있습니다. |

## 제품 반영

- 사용자에게 독서 목적과 후보 분석 텍스트가 OpenAI로 전송된다는 사실을 알립니다.
- 기본 악용 모니터링은 원칙적으로 최대 30일이지만 법률·안전상 예외로 더 길어질 수 있음을 함께 알립니다.
- 비-ZDR GPT-5.6 요청에서는 입력 파생 key/value tensor가 최대 24시간 남을 수 있음을 알립니다.
- `store=false`를 사용해 Responses API 응답 상태 저장을 요청하지 않습니다.
- 실제 출판 콘텐츠는 외부 전송 권리와 위 보관 조건의 수용 여부를 확인한 경우에만 지원합니다.

## 재확인 조건

출시 직전과 OpenAI 모델·엔드포인트·프로젝트 데이터 제어를 바꿀 때 이 세 출처를 다시 확인합니다. 내용이
달라졌으면 사용자 안내, 콘텐츠 지원 조건과 이 근거의 확인일을 함께 갱신한 뒤 AI 경로를 활성화합니다.

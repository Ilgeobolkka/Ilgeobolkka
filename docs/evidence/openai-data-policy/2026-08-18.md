> AI 잉크 경로 출시 직전의 공식 정책과 전용 OpenAI 프로젝트 설정을 읽기 전용으로 대조한 기록입니다.

- 확인일: 2026-08-18 KST
- 대상 API: `/v1/embeddings`, `/v1/responses`
- 대상 경로 모델: `gpt-5.6-terra`
- 확인 방법: OpenAI 공식 개발자 문서와 로그인된 OpenAI Platform의

- 변경 경계: 프로젝트·조직 설정은 조회만 했고 변경하지 않음

## 공식 정책 재확인

| 출처 | 확인 내용 |
| --- | --- |
| [Data controls in the OpenAI platform](https://developers.openai.com/api/docs/guides/your-data#data-retention-controls-for-abuse-monitoring) | API 데이터는 명시적으로 공유를 선택하지 않는 한 모델 학습에 사용되지 않습니다. 기본 악용 모니터링 로그는 고객 콘텐츠를 포함할 수 있고 원칙적으로 최대 30일 보관되며, 법률상 요구나 서비스·제3자 보호를 위한 예외가 있습니다. Modified Abuse Monitoring과 Zero Data Retention은 OpenAI의 사전 승인이 필요한 별도 제어입니다. |
| [Data controls — `/v1/responses`](https://developers.openai.com/api/docs/guides/your-data#v1responses) | Responses API의 응답 애플리케이션 상태는 기본값 또는 `store=true`에서 최소 30일 저장될 수 있으므로 애플리케이션은 계속 `store=false`를 사용합니다. 프롬프트 캐시는 원문이 아닌 암호화된 key/value tensor를 GPU 로컬 스토리지에 둘 수 있고 24시간 만료 뒤에는 보관하지 않습니다. GPT-5.6의 cache TTL은 이 최대 애플리케이션 상태 보관 기간을 늘리지 않습니다. |
| [Prompt caching](https://developers.openai.com/api/docs/guides/prompt-caching#set-cache-lifetime) | GPT-5.6의 `prompt_cache_options.ttl` 지원값과 기본값은 `30m`입니다. 이 값은 재사용 가능한 최소 cache lifetime이며, 데이터 정책의 최대 24시간 보관 경계와 별개입니다. |
| [Spend limits](https://developers.openai.com/api/docs/guides/spend-limits#configure-a-spend-limit) | 월 지출액만 입력해서는 API 중단형 상한이 되지 않습니다. `Enforce a hard limit`를 켜야 프로젝트 한도 도달 뒤 `project_spend_limit_exceeded` 429가 발생하며, 반영은 즉시 완료되지 않아 소액 초과가 생길 수 있습니다. |

## 전용 프로젝트 설정 관찰

| 항목 | 2026-08-18 관찰값 | 판정 |
| --- | --- | --- |
| 프로젝트 | `illgeobolkka-ai-route-dev` | 전용 프로젝트 확인 |
| 허용 모델 | `gpt-5.6-terra`, `text-embedding-3-small` | 애플리케이션 계약과 일치 |
| 월 지출 한도 | `$10.00` | 금액 설정 확인 |
| `Enforce a hard limit` | 꺼짐 | **강제 상한 미설정** — 현재 값만으로는 월 $10에서 API를 차단하지 않음 |
| 지출 알림 | 10%·50%·100% | 알림 설정 확인, 강제 상한을 대신하지 않음 |
| 프로젝트 data retention 표시 | `None` | 프로젝트별 MAM/ZDR 보존 제어가 표시되지 않음 |
| 조직 API call logging | `Enabled per call` | Responses 요청은 `store=false`를 명시해야 dashboard application-state 기록을 끔 |

프로젝트 ID·사용자 이메일·API key는 기록하지 않았습니다. `None`은 Zero Data Retention의 증거로 해석하지
않으며, 현재 프로젝트는 `OPENAI_DEFAULT_RETENTION_V1`의 기본 보관 조건을 적용하는 것으로 판정합니다.

## 제품 반영과 남은 경계

- 현재 공식 정책과 프로젝트 설정은 `OPENAI_DEFAULT_RETENTION_V1`의 허용 범위 안에 있습니다.
- `store=false`와 전용 project header를 유지하고, 콘텐츠 외부 전송 권리가 확인된 도서만 사용합니다.
- 월 $10 **강제** 상한은 아직 충족하지 않았습니다. 이를 켜는 작업은 외부 프로젝트 설정 변경이므로 별도
  승인 후 실행하고, 변경 직후 다시 읽어 확인해야 합니다.
- 모델·엔드포인트·프로젝트 데이터 제어를 바꾸거나 출시 직전 상태가 달라지면 다시 확인합니다.

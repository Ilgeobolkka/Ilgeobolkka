# OpenAI 데이터 정책 프로필

이 문서는 AI 잉크 경로 콘텐츠가 허용한 데이터 보관 조건과 실제 OpenAI 프로젝트의 확인 결과를 연결하는
안정 정본입니다. 외부 정책의 날짜별 확인 기록은 아래 근거 파일에 보존하고, 제품·콘텐츠·배포 문서는 이
문서만 참조합니다.

## 현재 지원 프로필

| 프로필 ID | 콘텐츠가 허용한 조건 | 현재 근거 |
| --- | --- | --- |
| `OPENAI_DEFAULT_RETENTION_V1` | Responses API는 `store=false`, 기본 악용 모니터링은 원칙적으로 최대 30일과 법률·안전상 예외 허용, 비-ZDR GPT-5.6 프롬프트 캐시는 원문이 아닌 입력 파생 key/value tensor를 최대 24시간 허용 | [2026-08-05 확인 기록](./2026-08-05.md) |

2차 MVP의 공개 AI 시연 콘텐츠는 `OPENAI_DEFAULT_RETENTION_V1`만 사용합니다. 프로필 ID는 ASCII 대문자,
숫자와 `_`로 구성한 100자 이하의 안정 식별자입니다. 같은 ID의 의미는 바꾸지 않습니다. 공식 조건이 달라져
콘텐츠가 허용해야 할 범위가 바뀌면 새 날짜의 근거와 새 프로필 ID를 추가합니다.

## 적용 계약

- `ai-route-v2` 입력 manifest의 최상위 `dataPolicyVersion`은 지원 프로필 ID 하나를 가집니다.
- 각 도서는 `aiExternalTransferAllowed`를 가지며, 지원 후보 도서는 해당 도서의 PDF·분석 텍스트 전체를
  외부로 전송할 권리가 확인된 경우에만 `true`입니다. 개별 페이지 하나라도 확인되지 않으면 도서 전체가
  `false`입니다.
- 콘텐츠 적재는 manifest의 `dataPolicyVersion`을 `book.ai_data_policy_version`에 복사합니다. 품질 평가 전에는
  `book.ai_route_supported=false`를 유지하고, 콘텐츠 완전성·권리·품질 기준을 모두 통과한 도서만 `true`로
  전환합니다.
- `OPENAI_DATA_POLICY_VERSION`은 운영자가 실제 전용 OpenAI 프로젝트의 조건이 해당 프로필과 같거나 더
  엄격함을 공식 문서와 프로젝트 설정에서 확인한 뒤 주입하는 비민감 설정입니다. 이 값은 원격 정책을 자동
  증명하지 않습니다.
- `ai-route-v2` 적재는 manifest와 `OPENAI_DATA_POLICY_VERSION`이 같을 때만 임베딩을 요청하고 그 값을 DB에
  복사합니다. 비웹 평가는 manifest·DB·환경 설정, 활성화한 일반 서버는 DB·환경 설정의 프로필이 같을 때만
  외부 호출을 허용합니다. 필요한 값이 없거나 다르면 외부 호출과 부분 DB 변경 전에 실패합니다.

## 재확인과 갱신

출시 직전과 OpenAI 모델·엔드포인트·프로젝트 데이터 제어 변경 시 공식 문서를 다시 확인해 날짜별 근거를
추가합니다. 확인 결과가 현재 프로필 의미 안에 있으면 위 표의 근거 링크만 최신 기록으로 바꿉니다. 허용 범위가
달라지면 새 프로필을 추가하고 사용자 안내·콘텐츠 manifest·환경 설정·DB 적재와 품질 평가를 새 프로필로
갱신한 뒤 기능을 활성화합니다.

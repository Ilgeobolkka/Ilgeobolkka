## 통합 사용자 여정

`AiRouteUserJourneyMySqlIntegrationTest` 두 건을 추가해 fake OpenAI gateway와 실제 MySQL·HTTP 경계로
다음을 검증했다.

1. 지원 도서 상세 → 생성 → 다른 독자 generation 404 → 저장·current 지정 → 서재 노출
2. 다른 독자 route 404 → 페이지 열기와 1잉크 차감 → AI route 콘텐츠 읽기 → 완료
3. `HELPFUL` feedback → route 삭제 → 서재·대여·원장 보존과 route/current 제거
4. 미지원 도서 `422 AI_ROUTE_NOT_SUPPORTED` → 외부 gateway 호출·generation·일일 사용량 0건

이 테스트는 외부 모델의 품질·지연·비용을 검증하지 않는다.

## 데이터 정책·비용 제어 확인

2026-08-15에 OpenAI 공식 문서를 다시 확인했다.

- API 입력·출력은 명시적으로 opt-in하지 않는 한 모델 훈련에 사용되지 않는다.
- 기본 abuse monitoring log는 고객 콘텐츠를 최대 30일 보관할 수 있다.
- Responses API의 애플리케이션 상태는 기본 30일 보관 대상이므로 구현처럼 `store=false`를 유지해야 한다.
  이는 abuse monitoring이나 prompt caching까지 제거한다는 뜻은 아니다.
- 근거: [OpenAI API data controls](https://developers.openai.com/api/docs/guides/your-data)

사용자는 2026-08-15 KST에 전용 프로젝트의 limit을 **10 USD**로 설정했다고 확인했다. 프로젝트 ID,
대시보드 화면과 hard limit 적용 여부는 이 작업에서 독립 확인하지 못했다. 공식 문서상 project hard limit을
초과하면 `429 project_spend_limit_exceeded`가 반환되지만 집계 지연으로 소액 초과가 발생할 수 있다.

- 근거: [OpenAI project spend limits](https://developers.openai.com/api/docs/guides/spend-limits)
- 2026-08-15 확인 단가: `gpt-5.6-terra` 1M text tokens 기준 input 2.00 USD,
  cached input 0.20 USD, output 12.00 USD
- 근거: [GPT-5.6 terra model](https://developers.openai.com/api/docs/models/gpt-5.6-terra)

로컬 `.env`와 실행 환경의 `OPENAI_PROJECT_ID`, `OPENAI_API_KEY`,
`OPENAI_DATA_POLICY_VERSION`은 비어 있었다. 실제 OpenAI 자격 증명과 provider 원문은 명령 출력·로그·HTML·
이 문서에 기록하지 않았다.

# 읽어볼까 PRD 색인

이 문서는 읽어볼까의 제품 요구사항과 구현 계약으로 이동하는 출발점입니다. README에는 상세 정책을
복사하지 않고 이 색인만 연결합니다.

## 문서 상태

- 상태: 제품·도메인·프런트엔드·PortOne V2 테스트 결제 계약 합의 완료
- 구현 상태: Spring Boot 기반 골격, 도서 목록·검색·상세, 잉크 저장·구매·조회,
  페이지 열기·대여·열람 세션·콘텐츠 API와 잉크 잔액·구매·내역 화면, PortOne 웹훅과
  소장 결제 준비·완료·내역 API 및 도서 상세 소장 결제·완료 내역 화면, 공통 Thymeleaf
  셸·내비게이션·CSRF fetch, 데스크톱 웹 뷰어와 내 서재 API·화면, 회원가입·로그인·도서 탐색 화면 완료
- 제공 형태: 프런트엔드와 API를 하나의 Spring Boot 실행물에서 제공하는 데스크톱 웹

## 관련 ADR

현행 기술·구조 결정의 이유는 [ADR 색인](../adr/README.md)에서 확인합니다. 최초 기준선 전에 폐기한
초안은 Git 이력에서 확인하며, 현재 제품·API·데이터 계약을 확인할 때는 위 정본 문서를 먼저 읽습니다.

## 단일 정본 원칙

- 정책의 가격·기간·상태 전이는 제품 정책에서만 관리합니다.
- 기능 ID는 기능 요구사항, 성공 판정은 MVP 목표, 검증 방법은 테스트 전략에서 관리합니다.
- API와 데이터 모델의 현재 계약은 각각 API 계약과 ERD에서 관리합니다.
- 다른 문서에는 같은 표나 목록을 복사하지 않고 해당 정본의 절을 링크합니다.

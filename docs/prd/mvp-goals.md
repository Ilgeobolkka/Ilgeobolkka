# 읽어볼까 MVP 목표

## 1. 문서 상태

- 상태: 합의 완료
- 목표일: 2026-08-04
- 완료 범위: 핵심 흐름 구현, 검증과 최소 환경 배포

## 2. 목표

1. 원본 PDF 페이지와 서비스 페이지를 정확히 연결합니다.
2. 유효한 대여가 없는 페이지를 열 때만 정확히 1잉크를 차감합니다.
3. 페이지별 30일 대여와 만료 후 재대여를 서버 시간으로 정확히 처리합니다.
4. 잔액 부족, 중복 요청과 서버 오류에서도 잘못된 차감을 만들지 않습니다.
5. 잉크 잔액과 모든 잉크 내역의 합계를 일치시킵니다.
6. 카테고리별 100권 목록과 제목·저자 검색에서 책을 찾아 읽을 수 있게 합니다.
7. 실제 배포 환경에서 핵심 사용자 흐름을 검증합니다.

매출, 결제 전환율, 추천 성과와 무중단 배포는 이번 MVP의 성공 기준이 아닙니다.

| BILL-004 | 잉크가 부족하면 차감과 대여 없이 페이지 제공을 차단한다. |

| INK-002 | 사용자가 도서·페이지·차감량·차감 시각·차감 후 잔액·대여 만료 시각을 조회할 수 있게 한다. |
| CONT-001 | 원본 PDF 페이지 수와 변환 페이지 수·번호의 일치를 검증한다. |

| CONT-003 | 원본 PDF와 권한이 없는 페이지 콘텐츠의 직접 접근을 백엔드에서 차단한다. |

## 4. 핵심 사용자 흐름

### 계정과 도서 탐색

1. 사용자는 이메일과 비밀번호로 회원가입하고 로그인합니다.
2. 카테고리 기준 도서 목록을 페이지 단위로 보거나 제목·저자를 검색합니다.
3. 책 상세에서 기본 정보와 원본 PDF 기준 페이지 수를 확인합니다.

### 최초 열람과 페이지 이동

1. 사용자는 처음 읽는 도서의 자동 차감·30일 대여 정책에 동의합니다.
2. 원하는 페이지를 요청합니다.
3. 백엔드는 유효한 대여를 확인하고 필요하면 1잉크를 차감한 뒤 현재 페이지를 제공합니다.
4. 프론트엔드는 백엔드가 반환한 잉크 잔액과 대여 만료 시각을 표시합니다.
5. 이전·다음·페이지 번호 이동도 같은 규칙으로 처리합니다.

### 재열람과 재대여

1. 대여 기간에는 같은 페이지를 추가 차감 없이 다시 엽니다.
2. 대여가 만료된 페이지는 새 1잉크 차감에 성공해야 다시 엽니다.
3. 잉크가 부족하면 페이지를 제공하지 않고 구매 안내로 이동할 수 있게 합니다.

### 내 서재와 잉크 내역

- 한 페이지 이상 대여한 책을 내 서재에 자동으로 추가합니다.
- 마지막 열람 페이지에서 이어 읽을 수 있게 합니다.
- 잉크 지급·차감 내역과 페이지별 대여 만료 시각을 최신순으로 조회합니다.

## 5. 초기 데이터

- 실존 작품을 바탕으로 하지 않은 AI 작성 가상 더미 도서 100권
- 도서별 원본 PDF, 표지, 카테고리, 메타데이터와 변환된 페이지 콘텐츠
- 충분한 테스트 잉크와 같은 금액의 지급 내역을 가진 정상 흐름 계정
- 잉크와 지급 내역이 모두 없는 잔액 부족 계정

정상 흐름 계정에 지급할 정확한 잉크 수와 카테고리 목록·내부 정렬 순서는 초기 데이터 작업 전에 확정합니다.
공개 배포 전에는 AI 생성 자산을 포함한 실제 사용 자산별 권리 상태를 다시 확인합니다.

## 6. MVP 제외 범위

- 실제 PG 결제와 잉크 자동 충전
- 사용하지 않은 잉크의 유효기간·만료 순서·만료 알림
- 페이지 또는 도서의 소장 전환
- 관리자 계정과 도서 운영 백오피스
- 도서 등록·수정·판매 중지·재판매·삭제
- 책별 페이지 단가와 전체 책 가격
- 무료 미리보기와 과금 제외 페이지
- 회원 탈퇴, 비밀번호 찾기와 소셜 로그인
- 리뷰, 평점, 추천, 판매량
- 검색 자동완성, 본문 검색과 사용자 정렬 선택
- 목차, 책갈피, 메모와 하이라이트
- PDF 다운로드, 인쇄와 오프라인 읽기
- DRM, 화면 캡처 방지와 네이티브 모바일 앱
- 환불과 과금 분쟁 처리
- 무중단 배포

이용권 구매 화면은 MVP에서 실제 결제를 수행하지 않고, 잉크 부족 안내와 후속 구매 흐름의 진입점까지만 제공합니다.

## 7. 성공 조건

다음 조건을 모두 통과하면 MVP 목표를 달성한 것으로 봅니다.

1. 유효한 대여가 없는 페이지 열기와 만료 후 재대여에만 정확히 1잉크가 차감됩니다.
2. 대여 기간의 재열람과 같은 페이지의 동시·중복 요청에서는 추가 차감이 없습니다.
3. 차감 시각부터 30일인 페이지별 만료 시각을 서버 시간으로 일관되게 판정합니다.
4. 잉크 잔액은 모든 지급·차감 내역의 합계와 항상 일치하며 음수가 되지 않습니다.
5. 잉크 부족과 처리 실패에는 페이지, 차감, 내역과 대여가 일부만 반영되지 않습니다.
6. 원본 PDF와 변환 콘텐츠의 페이지 수·번호가 일치하고 요청한 한 페이지만 제공됩니다.
7. 회원가입부터 도서 탐색, 페이지 열람, 재열람, 내 서재와 잉크 내역 조회까지 배포 환경에서 검증됩니다.

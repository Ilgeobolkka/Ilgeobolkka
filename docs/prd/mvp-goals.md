# MVP 목표

[PRD 색인](./README.md)으로 돌아갑니다. 이 문서는 MVP의 범위와 성공 판정의 정본입니다. 세부 기능은
[기능 요구사항](./requirements.md), 검증 방법은 [테스트 전략](../test-strategy.md)을 따릅니다.

이 문서는 페이지 대여와 온라인 소장을 검증하는 초기 MVP를 다룹니다. 이후 진행하는 독서 목적·추가 잉크
예산 기반 추천은 [AI 잉크 경로 2차 MVP](./ai-ink-route.md)를 따릅니다.

## 목표

1. 원본 PDF 페이지와 서비스 콘텐츠를 정확히 연결합니다.
2. 잉크 잔액·내역과 페이지 대여를 일관되게 관리합니다.
3. 페이지 대여와 도서 원가 직접 결제 소장을 명확히 분리합니다.
4. 카테고리와 검색으로 더미 도서를 찾고 한 페이지씩 안전하게 읽게 합니다.
5. 인증, 접근제어와 동시 요청에서도 제품 정책을 유지합니다.
6. PortOne V2 테스트 채널로 결제 준비·검증·웹훅·멱등 완료 흐름을 검증합니다.

AI 잉크 경로의 추천 성과와 복잡한 이용권·소장 상품 최적화는 초기 MVP의 성공 기준이 아닙니다.

## 초기 데이터

### 도서

- 실존 작품을 바탕으로 하지 않고 AI가 작성한 가상 더미 도서 본문, 표지와 메타데이터 100권·400페이지
- 같은 400페이지를 재현할 수 있는 공개 가능 AI 시연 기준 PDF 100권
- 모든 도서에 0보다 큰 고정 도서 원가 포함
- 서로 다른 카테고리를 포함하고 카테고리 우선 정렬과 같은 카테고리 내 안정 정렬을 검증할 수 있는 데이터
- 원본 PDF 페이지 수와 변환 콘텐츠 수가 일치하는 도서
- 일반 본문 텍스트 페이지, 표·수식·삽화 또는 원본 배치를 보존한 이미지 페이지
- 더미 도서는 MVP 시연과 검증에만 사용하며 Git에 추가하기 전에 AI 생성 자산을 포함한 파일별 권리
  상태와 개인정보 포함 여부를 확인

### 사용자

| 용도 | 초기 잉크 | 추가 조건 |
| --- | ---: | --- |
| 정상 대여 검증 | 100잉크 | 테스트 이용권 지급 +100잉크 내역 포함 |
| 잉크 부족 검증 | 0잉크 | 지급 내역 없음 |
| 온라인 소장 검증 | 0잉크 | PortOne 테스트 결제 완료 내역과 온라인 소장 도서 포함 |

- 시연 계정은 로컬·시연 환경에서만 만들고 운영 환경에는 생성하지 않습니다.
- 세 시연 계정은 역할별 기술 검증 전용 계정으로 사용하고 비밀번호는 `DEMO_VALIDATION_PASSWORD`
  환경변수 하나로 주입하며 저장소에 기록하지 않습니다.
- 관리자 계정과 관리자 기능은 초기 데이터에 포함하지 않습니다.

## MVP 제외 범위

- 운영 실결제 채널과 PG사별 전용 기능
- 이용권·소장 결제 취소, 환불, 분쟁과 chargeback 처리
- 관리자 계정, 도서 운영 백오피스
- 도서 등록, 수정, 판매 중지, 재판매, 삭제
- 도서별·카테고리별 페이지 잉크 단가와 전용 이용권
- 구독, 할인, 쿠폰과 복수 이용권 상품
- 페이지 대여에 사용한 잉크의 도서 원가 공제
- 무료 또는 잉크 차감 제외 페이지
- 회원 탈퇴와 비밀번호 찾기
- 자동 로그인, Remember Me, 로그인 횟수 제한과 계정 잠금
- 리뷰, 평점, 일반 도서 추천과 판매량. 목적 기반 AI 잉크 경로는 별도 2차 MVP
- 검색 자동완성, 본문 검색, 사용자 정렬 선택
- 목차, 책갈피, 메모, 하이라이트
- 페이지 내부 텍스트·이미지 하이브리드 콘텐츠와 OCR 보정 편집기
- PDF 다운로드, 인쇄, 오프라인 읽기
- DRM과 화면 캡처 방지
- 모바일 브라우저 레이아웃·결제와 네이티브 모바일 앱

## 고도화 후보

1. 페이지 내부에서 텍스트와 이미지 블록을 함께 제공하는 하이브리드 콘텐츠
2. 운영 결제 채널 전환과 이용권·소장 환불·분쟁 처리
3. 도서 등록, 원가, 변환 품질 검수와 판매 상태를 관리하는 백오피스
4. 목차, 여러 책갈피와 본문 검색
5. 더 정교한 텍스트 접근성과 OCR 보정
6. 운영 세션 저장소와 애플리케이션 다중 인스턴스 전환 기준

## 성공 판정

다음 조건을 모두 통과하면 초기 MVP의 목표를 달성한 것으로 봅니다.

1. 구매·지급된 잉크는 시간이 지나도 만료되거나 자동 차감되지 않습니다.
2. 활성 대여와 온라인 소장이 없는 페이지를 열 때만 1잉크가 즉시 차감됩니다.
3. 활성 대여 중 재열람과 동시·재시도 요청에는 추가 차감이 없습니다.
4. 대여 만료 시각부터 1잉크를 차감하고 새로운 30일 대여가 시작됩니다.
5. 차감, 잉크 내역, 대여 기록과 마지막 위치가 함께 성공하거나 함께 실패합니다.
6. 도서 원가와 일치하는 원화 결제 성공이 확인된 경우에만 온라인 소장이 생성됩니다.
7. 소장 결제는 잉크 잔액을 바꾸지 않고 대여에 사용한 잉크를 도서 원가에서 공제하지 않습니다.
8. 소장한 도서의 모든 페이지를 잉크 차감과 대여 기간 없이 읽을 수 있습니다.
9. 원본 PDF 페이지 수·번호와 변환 콘텐츠가 정확히 일치합니다.
10. 권한이 없는 독자와 조작한 URL에는 페이지 콘텐츠가 제공되지 않습니다.
11. PortOne V2 테스트 채널에서 브라우저 완료와 웹훅 순서에 관계없이 같은 결제 효과가 한 번만 반영됩니다.

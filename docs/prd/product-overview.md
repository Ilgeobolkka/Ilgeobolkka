# 읽어볼까 제품 개요

## 문서 상태

- 상태: 합의 완료
- 제품명: 읽어볼까
- 제공 형태: 반응형 웹
- 대상 사용자: 책 전체 구매가 부담스럽고 필요한 부분만 읽고 싶은 일반 독자
- 구현 상태: Spring Boot 골격 단계

## 해결하려는 문제

책 전체 가격을 먼저 지불해야 하는 방식은 일부 내용만 필요하거나 책이 자신에게 맞는지 먼저 확인하려는 독자에게 진입 장벽이 됩니다.
반대로 화면의 글자 크기나 기기 크기에 따라 과금 단위가 달라지면 사용자는 비용을 예측하기 어렵습니다.

## 제품 가설

원본 PDF 페이지를 변하지 않는 과금 단위로 삼고, 독자가 요청한 페이지에만 잉크를 사용하게 하면 전체 책을 먼저 구매하는 부담을 낮출 수 있습니다.
차감 시점, 대여 만료일, 잉크 내역을 명확하게 보여 주고 중복 요청에서도 한 번만 차감하면 사용자가 페이지 단위 과금을 신뢰할 수 있다고 가정합니다.

## 핵심 경험

1. 독자가 이메일과 비밀번호로 로그인합니다.
2. 카테고리별 도서 목록이나 제목·저자 검색으로 책을 찾습니다.
3. 책 상세에서 표지, 소개와 원본 PDF 기준 전체 페이지 수를 확인합니다.
4. 최초 자동 차감 정책에 동의하고 원하는 페이지를 요청합니다.
5. 유효한 대여가 없으면 백엔드가 1잉크를 차감하고 페이지별 30일 대여를 시작합니다.
6. 대여 기간에는 같은 페이지를 추가 차감 없이 다시 읽습니다.
7. 내 서재, 페이지 만료일과 잉크 내역에서 이용 결과를 확인합니다.

정확한 가격·대여 규칙은 [제품 정책](./product-policy.md), 이번에 구현할 범위와 성공 조건은 [MVP 목표](./mvp-goals.md)를 따릅니다.

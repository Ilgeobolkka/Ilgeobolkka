# 읽어볼까 제품 정책

## 1. 문서 상태

- 상태: 합의 완료
- 기준일: 2026-07-25
- 적용 범위: 현재 제품 및 MVP 요구사항

## 2. 페이지 기준

- 도서의 전체 페이지 수와 페이지 번호는 원본 PDF를 기준으로 합니다.
- 표지는 과금 페이지에 포함하지 않습니다.
- 화면 확대·축소, 글자 크기, 기기 크기와 콘텐츠 표시 방식이 바뀌어도 페이지 수와 페이지 번호는 변하지 않습니다.
- 변환된 텍스트와 이미지는 반드시 원본 PDF의 한 페이지에 연결하며, 서로 다른 원본 페이지의 콘텐츠를 하나의 과금 페이지로 합치지 않습니다.

## 3. 잉크 이용권

- 서비스의 페이지 이용 단위 이름은 `잉크`입니다.
- 모든 도서에 `1페이지 = 1잉크`를 적용합니다.
- 판매 단위와 가격은 `100잉크 = 1,000원`입니다.
- 구매하거나 지급받은 잉크는 도서와 카테고리에 상관없이 사용할 수 있습니다.
- 책별 페이지 단가와 전체 책 가격을 두지 않습니다.
- 모든 잉크 지급과 차감은 잔액 변화 내역으로 남기며, 현재 잔액은 내역의 합계로 설명할 수 있어야 합니다.

기존 `1페이지 = 50P`, `1원 = 1P`, 포인트라는 명칭과 유효기간 없음 정책은 폐기합니다.

## 4. 최초 열람 동의

- 독자가 특정 도서를 처음 열기 전에 페이지를 처음 열면 1잉크가 즉시 차감되고 30일 대여가 시작된다는 사실에 동의받습니다.
- 동의는 독자·도서별 최초 한 번만 받습니다.
- 동의하지 않으면 해당 도서의 페이지를 제공하지 않습니다.

## 5. 열람, 차감과 대여

- 페이지를 여는 요청 자체가 과금 요청입니다. 체류 시간이나 열람 완료 여부를 별도로 판단하지 않습니다.
- 해당 독자에게 유효한 페이지 대여가 없으면 페이지를 제공하기 전에 1잉크를 즉시 차감합니다.
- 차감에 성공한 서버 시각을 대여 시작 시각으로 삼고, 그 시각으로부터 정확히 30일 뒤를 만료 시각으로 저장합니다.
- 서버 현재 시각이 만료 시각보다 이르면 대여가 유효합니다. 만료 시각과 같거나 늦으면 만료된 것으로 판단합니다.
- 대여 기간에는 같은 페이지를 다시 열어도 잉크를 차감하지 않습니다.
- 만료된 페이지를 다시 열면 1잉크를 차감하고 새로운 30일 대여를 시작합니다.
- 각 페이지의 대여 기간은 서로 독립적으로 계산합니다.
- 잉크가 부족하면 잉크를 차감하지 않고 페이지도 제공하지 않으며 이용권 구매를 안내합니다.
- 대여 만료 여부는 프론트엔드 시간이 아니라 백엔드 서버 시간을 기준으로 판단합니다.

예: 2026년 7월 25일 10시에 시작한 대여는 2026년 8월 24일 10시 직전까지 유효합니다.

기존 6초 체류 후 열람 확정, 다음 페이지 이동 시 이전 페이지 차감, 한 번 결제한 페이지의 영구 재열람 정책은 사용하지 않습니다.

## 6. 원자성과 중복 방지

- 잉크 잔액 확인, 필요한 차감, 잉크 내역 생성과 페이지 대여 기록 저장은 백엔드의 하나의 트랜잭션에서 모두 성공하거나 모두 실패해야 합니다.
- 같은 요청이나 같은 페이지 요청이 동시에 여러 번 도착해도 유효한 대여 한 건에 대해서는 1잉크만 차감합니다.
- 처리 도중 실패하면 잉크만 줄거나 대여 기록만 생긴 상태를 남기지 않습니다.
- 사용자가 잉크를 내지 않았거나 대여 기간이 끝난 페이지는 URL을 바꿔 직접 요청해도 백엔드가 차단합니다.

구체적인 잠금 순서는 [`ADR-0022`](../adr/active/billing/0022-serialize-page-rental-with-pessimistic-locks.md)를 따릅니다.

## 7. 카테고리

- 카테고리는 도서를 찾기 위한 분류이며 잉크의 사용 범위를 제한하지 않습니다.
- 기본 도서 목록은 제목 가나다순이 아니라 카테고리를 기준으로 정렬합니다.
- 카테고리 목록과 같은 카테고리 안의 세부 정렬 순서는 초기 데이터 확정 전에 별도로 정합니다.

## 8. 페이지 콘텐츠 제공

- 원본 PDF는 서버 내부에서만 보관하고 브라우저에 직접 제공하지 않습니다.
- 서버는 원본 PDF를 페이지 단위로 변환해 독자가 요청하고 열람 권한을 얻은 한 페이지만 제공합니다.
- 일반 본문은 페이지별 텍스트로 추출합니다.
- 표·수식·삽화처럼 배치를 유지해야 하는 부분은 이미지로 제공합니다.
- 텍스트 추출이 어렵거나 원본 배치가 중요한 페이지는 페이지 전체를 이미지로 제공합니다.
- 텍스트와 이미지를 함께 써야 정확한 페이지는 혼합 콘텐츠로 제공합니다.

변환·권한 결정은 [`ADR-0023`](../adr/active/content/0023-use-pdf-page-mapped-hybrid-content.md), 검증 기준은 [`ADR-0024`](../adr/active/validation/0024-validate-hybrid-page-content.md)를 따릅니다.

## 9. 프론트엔드와 백엔드 책임

### 프론트엔드

- 사용자가 선택한 페이지의 열람 요청
- 성공한 페이지 콘텐츠, 잉크 잔액과 페이지별 만료 시각 표시
- 잉크 부족과 오류 안내
- 이용권 구매 화면 또는 구매 안내로 이동

프론트엔드는 체류 시간, 대여 유효성이나 차감 성공 여부를 자체 판단하지 않습니다.

### 백엔드

- 페이지 번호, 동의, 세션과 열람 권한 검증
- 서버 시간 기준 대여 유효성 판단
- 필요한 경우 잉크 잔액 확인과 1잉크 차감
- 잉크 내역과 대여 시작·만료 시각 저장
- 중복 차감 방지와 트랜잭션 원자성 보장
- 권한을 얻은 현재 페이지 콘텐츠만 제공

## 10. 미결정 정책

다음 내용은 확정되지 않았으므로 구현에서 임의의 정책을 만들지 않습니다.

- 구매하고 사용하지 않은 유료 잉크의 유효기간
- 이벤트로 받은 무료 잉크의 유효기간과 유료 잉크와의 차이
- 여러 잉크 묶음 중 어느 잉크부터 차감할지
- 잉크 만료 전 알림 여부
- 이미 사용한 잉크를 소장 가격에서 인정할지와 소장 전환 가격

사용하지 않은 잉크의 유효기간과 페이지별 30일 대여 기간은 서로 다른 정책입니다.

# 기능 요구사항

[PRD 색인](./README.md)으로 돌아갑니다. 요구사항 ID는 구현과 테스트 추적의 정본입니다. 가격·기간과
상태 전이는 [제품 정책](./product-policy.md), HTTP 요청·응답은 [API 계약](../api-spec.md)을 따릅니다.

| ID | 요구사항 |
| --- | --- |
| AUTH-001 | 이메일·비밀번호 회원가입, 로그인, 로그아웃을 제공하며 회원가입 뒤에는 자동 로그인하지 않는다. |
| AUTH-002 | 일반 회원가입 사용자의 초기 잉크는 [페이지 이용권 정책](./product-policy.md#프로그램-화폐와-페이지-이용권)을 따른다. |
| AUTH-003 | 이메일 정규화·형식·길이, 비밀번호 입력 규칙과 단방향 인코딩은 [계정과 인증 정책](./product-policy.md#계정과-인증)을 적용한다. |
| AUTH-004 | 로그인 세션 수명, 로그인·로그아웃 시 세션 처리와 CSRF 검증은 [계정과 인증 정책](./product-policy.md#계정과-인증)을 적용한다. |
| CAT-001 | 카테고리 우선 안정 정렬로 더미 도서 100권을 10권씩 제공한다. |
| CAT-002 | 검색어의 앞뒤 공백만 제거하고 내부 공백은 보존하며, 제목·저자를 영문 대소문자 구분 없이 부분 일치 검색하고 `%`, `_`는 일반 문자로 처리한다. |
| CAT-003 | 목록에 도서 ID, 카테고리, 표지, 제목, 저자와 도서 원가를 제공한다. |
| CAT-004 | 목록의 0 이하 페이지는 거부하고 범위를 초과한 양수에는 빈 목록과 페이지 정보를 반환한다. |
| CAT-005 | 상세에 목록 필드와 소개, 원본 PDF 전체 페이지 수, 로그인한 사용자의 온라인 소장 여부를 제공한다. |
| INK-001 | 잉크의 용도와 사용 범위는 [페이지 이용권 정책](./product-policy.md#프로그램-화폐와-페이지-이용권)을 따른다. |
| INK-002 | PortOne V2 테스트 채널의 페이지 이용권 결제를 서버에서 검증한 경우에만 100잉크 지급과 내역을 함께 한 번 기록한다. |
| INK-003 | 구매·지급된 잉크의 수명은 [페이지 이용권 정책](./product-policy.md#프로그램-화폐와-페이지-이용권)을 따른다. |
| INK-004 | 모든 잉크 증감을 내역으로 남기고 현재 잔액과 합계를 일치시킨다. |
| INK-005 | 사용자의 잉크 내역을 `occurredAt DESC, id DESC`로 10개씩 제공한다. |
| RENT-001 | 권한이 없는 페이지를 열 때 [페이지 대여 정책](./product-policy.md#페이지-열기와-30일-대여)에 따라 차감하고 대여를 시작한다. |
| RENT-002 | 활성 대여 중 같은 페이지를 다시 열면 잉크를 차감하지 않는다. |
| RENT-003 | 대여 만료 시각부터 같은 페이지를 열면 새 대여를 시작한다. |
| RENT-004 | 잉크가 부족하면 새 대여와 페이지 콘텐츠 제공을 모두 거부한다. |
| RENT-005 | 차감·내역·대여·마지막 위치를 [원자성 정책](./product-policy.md#페이지-열기-처리-순서와-원자성)에 따라 저장하고 중복 차감을 막는다. |
| OWN-001 | 모든 도서에 0보다 큰 고정 도서 원가를 원화로 저장하고 목록·상세에 표시한다. |
| OWN-002 | 도서 원가의 원화 결제 성공을 검증한 경우에만 온라인 소장을 한 번 생성하고 새 페이지 대여와 같은 잉크 계정 잠금으로 순서를 정한다. |
| OWN-003 | 소장 결제는 잉크 잔액·내역과 분리하며 대여에 사용한 잉크를 도서 원가에서 공제하지 않는다. |
| OWN-004 | 온라인 소장 도서의 모든 페이지를 잉크 차감과 대여 기간 없이 제공한다. |
| OWN-005 | 완료된 소장 결제만 결제 시각 최신순으로 10개씩 제공하고 잉크 내역과 분리한다. |
| PAY-001 | 잉크 이용권과 소장 결제는 종류별 준비 API에서 고유한 결제 시도를 `PENDING`으로 생성하되, 같은 독자·도서의 진행 중 소장 결제는 기존 준비 정보를 재사용한다. |
| PAY-002 | 브라우저 완료 요청과 서명 검증된 PortOne V2 웹훅은 서버 재조회와 같은 멱등 완료 로직을 사용하고 웹훅 유형별 응답 정책을 지킨다. |
| PAY-003 | 결제 상태·금액·통화·식별자를 검증한 첫 `PAID` 처리에서만 잉크 또는 소장 권한을 같은 트랜잭션으로 부여하며 일시 오류와 미완료 상태는 `PENDING`을 유지한다. |
| PAY-004 | MVP 결제는 PortOne V2 테스트 채널로 제한하고 운영 실결제와 취소·환불·분쟁 처리를 제공하지 않는다. |
| VIEW-001 | 원본 PDF 페이지와 같은 번호의 현재 한 페이지 콘텐츠만 제공하고 이전·다음·페이지 번호 이동을 지원한다. |
| VIEW-002 | 사용자당 하나의 온라인 열람 세션만 허용하고 서버 발급 `viewerSessionId`로 교체를 판정하며 새 뷰어와 로그아웃 시 기존 세션을 무효화한다. |
| VIEW-003 | 인증된 same-origin API가 현재 `viewerSessionId`와 페이지 번호, 온라인 소장 또는 활성·신규 대여를 확인한 요청 페이지 콘텐츠만 전달한다. |
| VIEW-004 | 텍스트 또는 이미지 페이지를 제공하고 원본 PDF와 내부 저장소 주소를 노출하지 않는다. |
| VIEW-005 | 글자 크기와 확대·축소가 원본 PDF 페이지 번호, 대여 기간과 잉크 차감 단위를 바꾸지 않는다. |
| VIEW-006 | 이전·다음 이동의 키보드 조작, 명확한 포커스와 접근 가능한 버튼 이름을 제공한다. |
| LIB-001 | 페이지를 대여하거나 온라인 소장한 도서를 내 서재에 추가하고 마지막 페이지의 대여 시각·만료·활성 상태와 소장 여부를 제공한다. |

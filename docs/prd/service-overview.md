# 서비스 개요

[PRD 색인](./README.md)으로 돌아갑니다.

## 문제와 가설

책 전체를 한 번에 구매하기 부담스럽거나 필요한 일부부터 읽고 싶은 독자에게 전체 금액을 먼저 지불하는
방식은 진입 장벽이 될 수 있습니다. 화면 표시 방식에 따라 페이지 수가 달라지면 독자는 사용량과 비용을
예측하기 어렵습니다.

읽어볼까는 프로그램 내부 화폐인 잉크로 원본 PDF 기준 페이지를 일정 기간 대여하고, 계속 읽고 싶은
도서는 정해진 도서 원가를 원화로 직접 결제해 온라인 소장할 수 있게 합니다. 페이지 대여와 도서 소장의
비용·기간·결제 수단을 명확히 분리하면 독자가 필요한 만큼 읽으면서도 원하는 책은 예측 가능한 금액으로
소장할 것이라는 가설을 검증합니다.

가격·대여 기간과 접근 권한의 상세 규칙은 [제품 정책](./product-policy.md)을 따릅니다.

MVP는 데스크톱 브라우저 전용 웹으로 제공하며 모바일 브라우저 레이아웃·결제와 네이티브 앱은 범위에
포함하지 않습니다.

## 대상 독자

책 전체를 구매하기는 부담스럽지만 필요한 부분부터 읽어보고, 마음에 드는 책은 온라인으로 소장하고 싶은
일반 독자를 대상으로 합니다. 학생, 연구자, 특정 연령대 등으로 대상을 더 좁히지 않습니다.

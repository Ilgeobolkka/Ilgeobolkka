# 읽어볼까 MVP 테스트 전략

## 1. 목적

이 문서는 기술 스택과 무관하게 MVP가 지켜야 할 검증 계약을 정의합니다. 가장 중요한 대상은 화면 완성도가 아니라 포인트 차감의 정확성, 중복 방지, 잔액과 내역의 일치입니다.

## 2. 검증 우선순위

1. 포인트 잔액과 원장의 불변식
2. 사용자·도서·페이지별 최초 1회 차감
3. 서버 기준 6초 열람 확정
4. 잔액 부족과 차감 실패 처리
5. 단일 열람 세션
6. 내 서재와 이어 읽기
7. 목록, 검색, 상세 화면

기술 스택이 정해지면 빠른 도메인 테스트부터 통합 테스트, 브라우저 기반 사용자 흐름 테스트 순으로 실행합니다.

## 3. 공통 테스트 데이터

### 사용자

- Reader A: 초기 10,000P
- Reader B: 초기 0P
- Reader A의 포인트 내역: 테스트 포인트 지급 +10,000P

### 도서

- AI가 작성하고 제목과 저자가 서로 다른 가상 더미 도서 100권
- 제목 가나다순을 확인할 수 있는 데이터
- 제목 검색 일치, 저자 검색 일치, 검색 불일치 사례
- 페이지 수가 다른 PDF와 변환된 페이지 이미지

## 4. 핵심 불변식

### INV-001 포인트 보존

현재 잔액은 모든 포인트 지급 합계에서 모든 페이지 차감 합계를 뺀 값과 같아야 합니다.

### INV-002 중복 차감 금지

한 사용자·도서·페이지 조합에는 성공한 페이지 차감 내역이 최대 하나만 존재해야 합니다.

### INV-003 차감과 열람 확정의 원자성

포인트 차감, 차감 내역 생성, 열람 확정 페이지 기록, 마지막 열람 위치 갱신은 모두 성공하거나 모두 실패해야 합니다.

### INV-004 음수 잔액 금지

어떤 동시 요청과 재시도에서도 포인트 잔액은 0P 아래로 내려가면 안 됩니다.

### INV-005 변경 불가능한 내역

생성된 포인트 지급과 차감 내역은 수정하거나 삭제하지 않습니다.

## 5. 필수 시나리오

| 테스트 ID | 연결 요구사항 | 시나리오 | 기대 결과 |
| --- | --- | --- | --- |
| T-AUTH-001 | AUTH-001, AUTH-002 | 새 이메일로 회원가입한다. | 계정이 생성되고 초기 포인트는 0P다. |
| T-CAT-001 | CAT-001 | 첫 목록을 조회한다. | 가나다순 첫 10권과 전체 페이지 정보가 반환된다. |
| T-CAT-002 | CAT-001 | 두 번째 목록 페이지로 이동한다. | 중복 없이 다음 10권이 반환된다. |
| T-CAT-003 | CAT-002 | 제목 일부를 검색한다. | 제목에 검색어가 포함된 책만 가나다순으로 반환된다. |
| T-CAT-004 | CAT-002 | 저자 일부를 검색한다. | 저자에 검색어가 포함된 책만 가나다순으로 반환된다. |
| T-CAT-005 | CAT-003 | 책 상세를 연다. | 표지, 제목, 저자, 소개, 페이지 수만 보이고 가격·평점·리뷰는 없다. |
| T-CNS-001 | CNS-001 | 처음 읽는 책의 뷰어를 연다. | 페이지당 50P 자동 차감 동의가 필요하고 안내에는 6초가 노출되지 않는다. |
| T-CNS-002 | CNS-001 | 동의를 거부한다. | 페이지 이미지가 제공되지 않는다. |
| T-CNS-003 | CNS-001 | 이미 동의한 책을 다시 연다. | 동의 화면을 다시 요구하지 않는다. |
| T-VIEW-001 | VIEW-001 | 특정 페이지로 직접 이동한다. | 앞 페이지 열람 여부와 관계없이 현재 페이지 이미지만 제공된다. |
| T-VIEW-002 | VIEW-002 | 다른 탭에서 새 뷰어를 연다. | 기존 열람 세션이 종료되고 새 세션만 유효하다. |
| T-BILL-001 | BILL-001, BILL-002 | 미확정 페이지를 6초 유지한다. | 서버 검증 후 50P가 한 번 차감되고 열람 확정된다. |
| T-BILL-002 | BILL-004 | 6초 전에 다음 페이지로 이동한다. | 기존 페이지는 열람 확정되지 않고 차감도 없다. |
| T-BILL-003 | BILL-004 | 6초 전에 뷰어를 종료한다. | 열람 확정과 차감이 없다. |
| T-BILL-004 | BILL-003 | 페이지를 연 뒤 탭을 바꾸고 6초를 넘긴다. | 열람 시간이 유효하며 6초 이후 확정 요청이 승인된다. |
| T-BILL-005 | BILL-001 | 페이지를 연 직후 확정 요청을 위조한다. | 서버 시간이 6초 미만이면 거절된다. |
| T-BILL-006 | BILL-002 | 확정된 페이지를 다시 읽는다. | 추가 차감 없이 즉시 열람할 수 있다. |
| T-BILL-007 | BILL-002 | 같은 확정 요청을 반복 전송한다. | 차감 내역은 하나이고 총 50P만 줄어든다. |
| T-BILL-008 | BILL-002, VIEW-002 | 이전 세션과 새 세션에서 같은 페이지 확정을 시도한다. | 새 세션의 유효한 요청만 처리되고 중복 차감은 없다. |
| T-BAL-001 | BILL-005 | 잔액 0P로 미확정 페이지를 연다. | 페이지 이미지가 제공되지 않고 부족 안내가 표시된다. |
| T-BAL-002 | BILL-005 | 잔액 50P로 미확정 페이지를 확정한다. | 50P가 차감되고 잔액은 정확히 0P가 된다. |
| T-ERR-001 | BILL-006 | 열람 확정 중 서버 오류를 발생시킨다. | 차감·내역·열람 확정·진도 갱신이 모두 반영되지 않고 재시도가 표시된다. |
| T-ERR-002 | BILL-006 | 실패 후 재시도에 성공한다. | 한 번만 50P가 차감되고 다음 새 페이지 이동이 허용된다. |
| T-LIB-001 | LIB-001 | 첫 페이지를 열람 확정한다. | 책이 내 서재에 추가되고 해당 페이지가 마지막 위치가 된다. |
| T-LIB-002 | LIB-001 | 다른 페이지를 6초 전에 떠난다. | 마지막 열람 확정 위치가 바뀌지 않는다. |
| T-LIB-003 | LIB-001 | 내 서재에서 책을 다시 연다. | 마지막 열람 확정 페이지에서 시작한다. |
| T-PTS-001 | PTS-001, PTS-002 | 페이지 차감 내역을 조회한다. | 책 제목, 페이지 번호, 50P, 시각, 차감 후 잔액이 보인다. |
| T-PTS-002 | PTS-001 | Reader A의 초기 상태를 조회한다. | +10,000P 지급 내역과 10,000P 잔액이 일치한다. |

## 6. 경계값과 실패 주입

### 시간

- 서버 기준 5.999초: 거절
- 서버 기준 6.000초 이상: 승인 가능
- 페이지 이동 직전과 확정 요청이 겹치는 경우: 유효한 현재 페이지에만 처리

### 포인트

- 0P, 49P: 새 페이지 차단
- 50P: 정확히 한 페이지 열람 가능
- 중복 요청 10회: 총 50P만 차감

### 세션과 네트워크

- 이전 열람 세션의 지연 요청
- 응답 유실 후 같은 요청 재시도
- 차감 내역 저장 직전 오류
- 마지막 열람 위치 갱신 직전 오류
- 연결이 끊긴 상태에서 새 페이지 요청

## 7. 보안 및 콘텐츠 전달 확인

- 원본 PDF를 직접 내려주는 공개 경로가 없어야 합니다.
- 현재 페이지 외의 페이지 이미지를 한 번에 반환하지 않아야 합니다.
- 다른 사용자의 열람 확정 페이지와 포인트 내역을 조회할 수 없어야 합니다.
- 만료되거나 교체된 열람 세션으로 확정 요청을 처리하지 않아야 합니다.
- DRM과 화면 캡처 방지는 검증 범위가 아닙니다.

## 8. 출시 게이트

기술 스택이 정해진 뒤 실제 명령을 여기에 추가합니다. 구현 완료 판정에는 최소한 다음 증거가 필요합니다.

1. 모든 핵심 불변식 테스트 통과
2. 필수 시나리오 자동화 테스트 통과
3. 100권 목록·검색·페이지당 10권 페이지네이션 검증
4. 중복 요청과 실패 주입 검증
5. 브라우저에서 회원가입부터 내역 조회까지 핵심 흐름 통과
6. 현재 잔액과 포인트 내역 합계 대조 통과

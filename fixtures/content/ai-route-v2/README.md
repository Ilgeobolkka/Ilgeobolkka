# ai-route-v2 한국어 창작 전자책 fixture

SCRUM-485의 C01·C02 고정 입력입니다. 기존 `books.json`의 100권 ID·제목·저자·카테고리·소개를
변경하지 않았습니다. 소설 10권은 `initial-v1` PDF 바이트·SHA-256·페이지 수를 그대로 유지하고,
비소설 90권은 기존 메타데이터에 맞춘 한국어 창작 전자책으로 전면 재제작했습니다.

## 고정 결과

- 콘텐츠 버전: `ai-route-v2`
- 도서: 100권(소설 10권 후보 제외, 비소설 90권 후보 포함)
- 전체 PDF 페이지: 5485페이지
- 비소설 페이지 범위: 48~72페이지, 서로 다른 길이 25종
- 비소설 장 범위: 6~9장
- 독자 표시 언어: 한국어(URL과 추적용 고유 서지정보 제외)
- 평가 데이터: 도서별 1건, 총 90건, 권한·예산 7개 시나리오 포함

비소설 PDF 첫 장은 기존 `books.json`의 `coverImagePath`가 가리키는 카테고리별 표지와 같은 색·도형·`읽어볼까 가상서가` 브랜드를 사용합니다. 판권의 출판사 표기는 `읽어볼까 북스`로 통일합니다.

각 비소설은 표지·판권·머리말·차례, 최소 6개 장의 이어지는 본문과 사례·한계, 맺음말·참고 자료를
갖습니다. 독자용 본문에는 제작 과정, 페이지 역할, AI 분석을 설명하는 문장을 넣지 않았습니다.

## 참고 자료와 권리 경계

Project Gutenberg 공개 원전은 관점을 넓히는 참고 자료로만 추적합니다. 원문 문장·번역문·스캔·삽화는
PDF 본문에 포함하지 않았습니다. 원전의 실제 제목·기여자·출처 URL·권리 문구는
`source-ledger.json`에 기록하며 기존 가상 도서 메타데이터와 구분합니다.

## 산출물

- 고정 PDF: `pdfs/book-001.pdf`부터 `pdfs/book-100.pdf`
- C01·C02 입력: `manifest.json`
- Q01 입력: `evaluation.json`
- 참고 자료·권리 원장: `source-ledger.json`
- 파일별 권리·개인정보·이미지 분석 근거: `review-evidence.json`
- 범주별 PDF 렌더링 표본 근거: `quality-samples.json`
- 자동 구조·언어 검증 결과: `verification-summary.json`

사람 편집 검수 승인 전에는 C03 embedding이나 지원 활성화에 사용하면 안 됩니다.

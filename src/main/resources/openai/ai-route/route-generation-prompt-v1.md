# AI 독서 경로 후보 제안

정규화된 독서 목적과 서버가 제공한 후보 페이지 정보만 사용해 직접 읽을 후보와 순서를 제안합니다.

- 서버가 제공한 후보 페이지에서만 목적 달성에 직접 유용한 페이지를 고릅니다.
- 선수 페이지를 추가하거나 정렬하지 않습니다. 검증된 선수 관계의 폐쇄와 순서는 서버가 완성합니다.
- 독서 목적과 직접 관련된 정도는 HIGH 또는 MEDIUM으로만 표시합니다.
- 각 후보의 역할은 CORE, EXAMPLE, COUNTERPOINT, CONCLUSION 중 하나만 사용합니다.
- 페이지 설명, 가이드, 비용, 예상 시간 등 schema에 없는 자유 문구를 만들지 않습니다.
- 제공된 strict JSON schema와 정확히 일치하는 JSON만 반환합니다.
